# ![](/icons/history.webp) 작업 내역 {#history}
![](/images/history_overview.webp)

대부분의 콘텐츠 제작 도구처럼, Nomad에서도 모든 편집을 실행 취소/다시 실행할 수 있습니다.
작업 내역은 크게 불어날 수 있으므로, 메모리에 얼마나 남겨 둘지, 저장 공간에 얼마나 보관할지, 프로젝트와 함께 저장할지를 직접 정할 수 있습니다.

::: tip
빠른 제스처로 실행 취소/다시 실행을 할 수 있습니다.
- 두 손가락으로 탭하면 실행 취소
- 세 손가락으로 탭하면 다시 실행
:::

## ![](/icons/history.webp) 작업 내역 {#history-panel}
![](/images/history_history.webp)

이 패널은 작업 내역 스택을 보여 줍니다. 단계 번호, 작업 이름, 적용된 오브젝트, 그 단계가 사용하는 메모리 양이 표시됩니다.

항목을 탭하면 그 상태로 되돌아가거나 앞으로 이동합니다. 항목을 길게 누르면 그 항목과 그보다 오래된 작업 내역이 모두 영구 삭제됩니다. 조각이 마음에 들게 완성됐을 때 메모리를 빠르게 확보하는 방법입니다.

### ![](/icons/speed.webp) 재생 {#replay}
왼쪽 아래의 재생 버튼을 누르면 맨 처음 상태로 되감은 뒤 작업을 하나씩 다시 실행합니다. 조각이 만들어지는 과정을 지켜보는 재미가 있습니다. 슬라이더로 초당 작업 수, 즉 속도를 정합니다. 버튼을 다시 탭하면 멈추고, 실행 취소/다시 실행을 하거나 항목을 탭해도 멈춥니다.

시작하기 전에 팝업에서 다음을 고를 수 있습니다.
* `세분화 되돌리기` - 처음부터 재생하는 대신, 현재 상태에서 처음 상태까지 거꾸로 실행 취소해 나갑니다.
* `카메라 복원` - [카메라 복원](#restore-camera)이 꺼져 있어도, 재생되는 작업에 맞춰 카메라가 따라갑니다.
* `카메라 스무딩` - 각 시점으로 뚝뚝 끊어 이동하지 않고 시점 사이를 부드럽게 미끄러지듯 이동합니다. 값이 클수록 카메라가 차분하게 움직입니다.

::: warning
재생은 실험적인 기능입니다.
:::

## 동작 포함 {#include-actions}

작업 내역 패널 아래쪽의 아이콘으로 어떤 종류의 편집을 작업 내역에 기록할지 고릅니다.

| 동작      | 아이콘                          | 설명                                                                         |
| :---------- | :---------------------------: | :---------------------------------------------------------------------------------- |
| 광원      | ![](/icons/light.webp)        | 광원 편집입니다. 기즈모로 광원을 옮기는 작업은 씬 계층 구조의 다른 오브젝트에 영향을 줄 수 있으므로 항상 기록됩니다 |
| 셰이딩     | ![](/icons/sun.webp)          | PBR, MatCap, 조명제외 모드 전환과 MatCap, HDRI 변경                                   |
| 포스트 프로세싱 | ![](/icons/postprocess.webp)  | 포스트 프로세싱 편집                                                                   |
| 선택 영역   | ![](/icons/tool_lattice.webp) | 클릭, 올가미 선택, 선택 해제 같은 격자 선택 편집          |

## 설정 {#settings}
![](/images/history_settings.webp)

### ![](/icons/camera.webp) 카메라 복원 {#restore-camera}
작업마다 카메라 시점이 저장됩니다.
이 옵션을 켜면 작업을 실행 취소하거나 다시 실행할 때 카메라가 저장된 시점으로 돌아갑니다.

### ![](/icons/history.webp) 기록 저장 {#save-history}
프로젝트를 저장할 때 실행 취소 기록도 함께 저장해서, 프로젝트를 다시 열어도 남아 있게 합니다. 프로젝트 파일을 더 작게 유지하려면 끄세요.

### ![](/icons/ram.webp) RAM 제한 {#history-limit-mb}
RAM에 보관하는 작업 내역의 최대 크기입니다. 오래된 상태는 삭제되지 않고 저장 공간으로 옮겨졌다가, 필요할 때 다시 불러옵니다.

### ![](/icons/save.webp) 저장 공간 제한 {#storage-limit}
이 프로젝트의 작업 내역이 사용하는 저장 공간의 최대 크기입니다. 한도에 도달하면 가장 오래된 작업부터 영구 삭제됩니다.

::: tip
새 한도는 다음 편집, 실행 취소 또는 다시 실행 이후에 적용됩니다.
:::

### ![](/icons/undo.webp) 실행 취소 경고 {#maximum-undoable}
한 번에 이 개수보다 많은 작업을 되돌리려고 하면 먼저 확인을 요청합니다. 되돌린 뒤 편집을 하면 그 지점 이후의 작업이 모두 사라지므로, 목록 아래쪽을 실수로 탭하는 일을 막아 줍니다.
