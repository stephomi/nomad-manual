# ![](/icons/transform.webp) 트랜스폼 {#transform}

이 메뉴는 선택한 오브젝트의 트랜스폼을 숫자로 보여줍니다. 위치, 회전과 스케일, 그리고 크기를 확인할 수 있습니다. 정확한 값을 입력하거나, 초기화하거나, 메시에 베이크할 수 있습니다.

![](/images/transform_overview.webp)

## 개요 {#overview}

모든 오브젝트에는 버텍스와 별개로 이동, 회전, 스케일(즉, 매트릭스)을 저장하는 노드가 있습니다. [기즈모](tools.md#gizmo)와 [트랜스폼](tools.md#transform) 도구는 뷰포트에서 드래그할 때 이 매트릭스를 바꿉니다. 이 메뉴에서는 그 값을 읽고 직접 입력할 수 있습니다. 노드를 움직이는 것과 버텍스를 움직이는 것의 차이는 [노드와 버텍스](tools.md#nodes-and-vertices)를 참고하세요.

값을 좌우로 드래그하면 바뀌고, 탭하면 숫자를 입력할 수 있습니다. X, Y, Z 값은 기즈모 축처럼 빨강, 초록, 파랑으로 표시됩니다.

::: tip
값을 입력하면 오브젝트를 정밀하게 배치할 때 편리합니다. 예를 들어 여러 파츠를 정확히 같은 높이에 놓거나, 기즈모로 자유롭게 회전한 뒤 회전 값을 딱 떨어지는 숫자로 되돌릴 수 있습니다.
:::

## 매트릭스 {#matrix}

제목은 값이 어느 공간을 기준으로 표시되는지 알려줍니다. `로컬`(부모 오브젝트 기준) 또는 `세계`입니다.

### 오브젝트와 피벗 {#object-pivot}

* `오브젝트` - 오브젝트 자체의 트랜스폼 값입니다.
* `피벗` - 기즈모 핸들처럼 값이 [피벗](tools.md#pivot)을 기준으로 선택 항목을 조작합니다. 각 행은 0으로 표시되며, 값을 바꾸면 선택 항목이 피벗을 중심으로 이동, 회전, 스케일됩니다. `편집`(자물쇠 아이콘)을 켜면 오브젝트는 그대로 두고 피벗만 움직일 수 있습니다.

### 로컬과 세계 {#local-world}

오브젝트에 부모나 자식이 있거나 여러 오브젝트를 선택한 경우, 값을 어느 공간에서 표시할지 고를 수 있습니다. `로컬`(부모 기준) 또는 `세계`입니다.

### 작업 {#actions}

| 작업          | 아이콘                        | 설명 |
| :-----------: | :---------------------------: | :---------- |
| 원점 이동     | ![](/icons/target.webp)      | 오브젝트를 세계 원점으로 옮깁니다. |
| 베이크        | ![](/icons/bake.webp)        | 매트릭스를 버텍스에 적용하고 매트릭스를 초기화합니다. 겉보기에는 아무것도 바뀌지 않지만, 오브젝트의 원점이 이제 세계 원점이 됩니다. |
| 피벗          | ![](/icons/gizmo.webp)       | 피벗을 오브젝트에 베이크합니다. 오브젝트의 원점과 방향이 피벗의 것으로 바뀝니다. 겉보기에는 아무것도 바뀌지 않습니다. |
| 편집          | ![](/icons/lock.webp)        | (`피벗` 모드) 피벗만 움직입니다. |
| 초기화        | ![](/icons/reset.webp)       | 트랜스폼을 기본값(단위 행렬)으로 초기화합니다. `피벗` 모드에서는 대신 피벗을 제자리로 되돌립니다. |

선택한 오브젝트에 인스턴스가 있으면 베이크할 때 `인스턴스 해제` 옵션과 함께 확인을 요청합니다. 베이크는 버텍스를 바꾸는데, 인스턴스들은 버텍스를 공유하기 때문입니다.

### 이동, 회전, 스케일 {#translation-rotation-scale}

X, Y, Z축에 대한 오브젝트의 위치, 회전(도 단위), 스케일입니다. 각 행 끝에 있는 두 버튼으로 트랜스폼의 해당 부분만 버텍스에 베이크하거나 초기화할 수 있습니다.

오브젝트가 기울어져 있으면 `기울임` 행도 나타납니다. 예를 들어 회전된 부모를 균등하지 않게 스케일한 경우입니다.

### 균등 스케일 {#uniform-scale}

켜면 스케일이 세 축 모두 같은 하나의 값이 됩니다. 끄면 X, Y, Z를 따로 스케일할 수 있습니다.

## 치수 {#dimension}

선택 항목의 바운딩 박스 크기와 중심을 세계 단위로 보여줍니다. 여러 오브젝트를 선택하면 모두를 포함합니다.

* `크기` - 너비, 높이, 깊이입니다. 링크 버튼을 켜 두면 한 크기를 바꿀 때 나머지 두 크기도 같은 비율로 바뀌어 비율이 유지됩니다.
* `가운데 정렬` - 바운딩 박스의 중심입니다. 타깃 버튼을 누르면 선택 항목의 중심이 세계 원점에 오도록 옮깁니다.

::: tip
`크기`는 오브젝트에 실제 크기를 지정하는 가장 빠른 방법입니다. 예를 들어 3d 프린팅 전에 원하는 높이를 입력하면 링크가 비율을 유지해 줍니다.
:::
