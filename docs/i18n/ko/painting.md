# ![](/icons/paint.webp) 페인팅 {#painting}

페인트 스트로크의 색상, 거칠기, 메탈릭을 설정하고, 페인트 속성으로 전체를 채우며, 페인트 도구가 레이어, 마스크, 가려진 영역과 어떻게 상호작용할지 정합니다.

![](/images/paint_overview.webp)  

## 개요 {#overview}

Nomad는 PBR 버텍스 페인팅을 사용합니다. 이게 무슨 뜻일까요?

### PBR {#pbr}
PBR(Physically Based Rendering, 물리 기반 렌더링)은 영화, TV, 게임, 모바일에서 널리 쓰이는 컴퓨터 그래픽 기법입니다. 조명을 물리적 특성에 기반하게 하고, 표면을 색상, 거칠기, 메탈릭으로 정의하면 사실적인 다양한 질감을 표현할 수 있습니다.

### 버텍스 페인팅 {#vertex-painting}

버텍스 페인팅은 페인트 정보를 텍스처가 아니라 모델의 버텍스에 저장한다는 뜻입니다. Nomad는 수십만, 때로는 수백만 개의 버텍스를 가진 모델도 다룰 수 있으므로, 표면에 아주 세밀한 페인트를 칠할 수 있습니다. 디테일을 스컬프팅할 수 있다면 그 디테일을 칠할 수도 있습니다.

그래서 Nomad에서 페인팅할 때는 UV 매핑이 필요 없습니다. 다른 3d 앱에서는 UV 매핑이 느리고 기술적인 과정인 경우가 많습니다. 다른 3d 앱 상당수는 Nomad만큼 많은 버텍스를 지원하지 않지만, Nomad에는 이를 돕는 텍스처 베이크와 데시메이트 도구도 잘 갖춰져 있습니다.

### 텍스처링 {#texturing}

Nomad는 텍스처를 지원하지만, 텍스처는 가져온 모델에 포함되어 있거나 버텍스 페인팅을 텍스처로 베이크해서 만들어야 합니다. 

텍스처는 단순히 이미지이지만, 3d에서는 보통 오브젝트에 할당된 이미지를 가리킵니다.
이미지를 모델에 감싸려면 모델에 텍스처 좌표(UV)가 있어야 합니다.

Nomad는 [UV를 자동으로](topology.md#uv-unwrap) 계산할 수 있지만, 전체적인 품질은 세밀하게 조절하기 어렵습니다.

::: tip
작업흐름의 한 예:
- Nomad에서 스컬프팅한 다음 [UV 펼치기](topology.md#uv-unwrap)
- Nomad에서 이미 페인팅을 시작했다면 [버텍스 페인팅을 텍스처로 옮기기](topology.md#bake-texture)
- Procreate로 내보내기
- Procreate에서 텍스처 작업
- 렌더링을 위해 다시 Nomad로 가져오기
:::

개요는 여기까지입니다. 이제 페인팅 메뉴의 각 섹션을 살펴봅시다.


## 스트로크 페인팅 {#stroke-painting}
![](/images/paint_intensity.webp)  

이 도구에서 페인팅을 켭니다. 스컬프팅과 페인팅을 동시에 해야 할 때 유용합니다. 페인팅할 수 있는 도구인데 이 체크박스가 꺼져 있으면, 제목 옆의 경고 아이콘이 알려줍니다.

페인팅이 주된 기능인 도구(페인트, 스머지, 마스크 등)에는 이 체크박스가 없습니다.

### ![](/icons/opacity.webp) 페인트 강도 {#paint-intensity}

도구의 기본 강도와 다른 강도로 페인팅할 수 있게 해 주는 슬라이더입니다.

옆의 슬라이더 버튼을 누르면, 스컬프팅과 페인팅을 동시에 하는 도구를 위해 사이드 바에 빠른 페인트 강도 슬라이더가 추가됩니다.

`알파`, `폴오프`, `강도 랜덤화` 버튼은 해당 기능이 페인팅에도 영향을 줄지 정합니다. 예를 들어 점토 도구에서 랜덤화를 켜 두되, 색상은 랜덤화되지 않게 할 수 있습니다.

* `알파` - 끄면 페인팅이 알파를 무시하고 브러시 영역 전체를 칠합니다. VDM 도구에서는 이 버튼 대신 `스탬프 재질`이 있으며, 스탬프에 저장된 재질을 켜거나 끕니다.
* `폴오프` - 끄면 페인팅이 브러시 가장자리까지 최대 강도로 유지됩니다.
* `강도 랜덤화` - 스트로크 랜덤화의 강도 부분이 페인팅에 영향을 줄지 정합니다. 위치, 회전, 스케일 랜덤화는 항상 스탬프 전체를 움직입니다.

이 옵션들은 [모두 칠하기](#paint-all)에서는 무시되지만, 트라이플레이너 방식에서는 알파가 사용됩니다.

### ![](/icons/link.webp) 전역 머티리얼 {#global-material}
이 옵션을 켜면 선택한 머티리얼이 다른 도구들과 같아집니다. 거칠기, 메탈릭, 색상 설정만 반영된다는 점에 유의하세요. 끄면 이 도구만의 머티리얼을 쓸 수 있습니다.


## 머티리얼 {#material}
![](/images/paint_material.webp) 

첫 번째 아이콘은 머티리얼 미리보기 도형입니다. 3d 머티리얼 미리보기를 드래그하면 회전합니다. 

두 번째 아이콘은 선택한 알파와 폴오프 옵션이 적용된 페인트 스트로크 미리보기입니다.

### ![](/icons/falloff.webp) 커브 {#curves}

[PBR 슬라이더](#pbr-sliders)의 텍스처 슬롯을 위한 커브 편집기를 엽니다. 이미지 파일은 건드리지 않고, 칠하기 전에 텍스처 값을 다시 매핑합니다. 텍스처 슬롯에 작은 커브 아이콘이 있으면 커브가 편집되었다는 뜻입니다.

### ![](/icons/cog.webp) 머티리얼 옵션 {#material-options}

제목 옆의 `머티리얼` 버튼에는 두 가지 설정이 있습니다.

`뷰포트 머티리얼 미리보기`는 색상, 거칠기, 메탈릭, 불투명도, 강도 슬라이더를 바꾸는 동안 선택한 오브젝트에 어떻게 표시할지 정합니다.

* `없음` - 속성을 조정할 때 모델에 미리보기를 표시하지 않습니다
* `머티리얼` - 속성을 조정할 때 머티리얼 값을 오브젝트에 미리 보여줍니다.
* `트라이플레이너` - 머티리얼을 트라이플레이너 투영으로 미리 보여줍니다. 

아래의 색상, 거칠기, 메탈릭, 불투명도 체크박스는 [머티리얼 스포이드](#material-picker)가 어떤 채널을 바꿀지 정합니다.

### ![](/icons/dropper.webp) 머티리얼 스포이드 {#material-picker}

스포이드로 씬의 어느 오브젝트에서든 커서 아래의 머티리얼을 가져옵니다. [머티리얼 옵션](#material-options)에서 체크한 채널만 바뀝니다.

## 머티리얼 프리셋 {#material-presets}
3d 미리보기 도형을 탭하면 머티리얼 프리셋 메뉴가 나타납니다. 프리셋을 복제해서 나만의 프리셋을 만들 수 있습니다.

![](/images/paint_presets.webp) 

`텍스처 임베드` 토글을 켜면 이 머티리얼이 사용하는 텍스처의 사본을 프리셋 안에 저장합니다. 끄면 프리셋은 Nomad의 textures/ 폴더에 있는 텍스처를 참조하기만 합니다. 텍스처가 들어간 프리셋을 텍스처를 따로 보내지 않고 공유하고 싶을 때 켜세요.

`알파 포함`을 켜면 브러시 알파도 머티리얼 프리셋에 저장됩니다.

## PBR 슬라이더 {#pbr-sliders}
![](/images/paint_sliders.webp) 

[PBR](shading.md#pbr) 페인팅은 4개의 채널을 사용합니다.
- `색상` 칠할 색입니다. 스포이드로 모델의 다른 부분이나 참조 이미지에서 색을 가져올 수 있습니다.
- `거칠기` 표면이 얼마나 "거친지" 또는 "매끈한지"를 나타냅니다. 거칠기 값이 낮으면 반사가 선명해집니다.
- `메탈릭` 표면이 금속인지 아닌지를 나타냅니다. 대부분의 경우 0% 또는 100%여야 하며, 중간 값은 예외적인 경우에만 씁니다.
- `불투명도` 머티리얼이 얼마나 비쳐 보이는지입니다. 엄밀히 말하면 PBR 사양에 포함되지는 않지만, 여러 상황에서 유용합니다. 1은 완전히 불투명하고, 0은 투명합니다. 불투명도와 굴절은 다르다는 점에 유의하세요. Nomad에서 굴절은 굴절 머티리얼로 처리합니다. 

머티리얼 프리셋을 선택하면 3개 채널이 동시에 칠해집니다(불투명도는 의도적으로 제외되는 경우가 많습니다). 그래서 그냥 '빨강'을 칠하는 대신 '빨갛고 거친 금속'이나 '하얗고 매끈한 플라스틱'을 칠할 수 있습니다.

사각형은 텍스처 슬롯입니다. 클릭하면 그 속성에 단색 값 대신 텍스처를 사용합니다. 색상 텍스처는 색에 색조를 입히고, 거칠기, 메탈릭, 불투명도 텍스처는 슬라이더 값을 대체합니다(이를 나타내기 위해 라벨에 취소선이 그어집니다). 불투명도 텍스처의 경우 `알파를 값으로 사용`을 켜면 텍스처의 그레이스케일 값 대신 알파 채널을 읽습니다.

VDM 도구에서 스탬프에 자체 재질이 있으면, 텍스처 슬롯 옆에 이를 보여주는 슬롯이 추가로 나타납니다. 탭하면 스탬프의 해당 채널을 사용하거나 무시합니다.

슬라이더 옆의 브러시 아이콘을 누르면 오브젝트 전체에 그 속성을 채웁니다.

체크박스로 각 속성을 켜거나 끌 수 있습니다. 예를 들어 색상만 칠하거나, 거칠기와 불투명도만 칠할 수 있습니다. 

다음은 거칠기와 메탈릭 값에 따른 몇 가지 예입니다.

|                | 메탈릭 0%                         | 메탈릭 100%                  |
| :------------: | :-------------------------------: | :--------------------------: |
| 거칠기 0%      | ![](/images/dielectric_r0.webp)   | ![](/images/metal_r0.webp)   |
| 거칠기 50%     | ![](/images/dielectric_r50.webp)  | ![](/images/metal_r50.webp)  |
| 거칠기 100%    | ![](/images/dielectric_r100.webp) | ![](/images/metal_r100.webp) |

::: warning
거칠기와 메탈릭은 [조명 포함 (PBR)](shading.md#pbr) 셰이딩 모드가 필요합니다. [MatCap](shading.md#matcap)이나 [조명제외](shading.md#unlit) 모드에서는 무시되며, 메뉴에 경고가 표시됩니다.
:::

::: tip
PBR 페인팅에 텍스처를 쓸 때는 `도장` 도구로 바꾸거나, 스트로크 메뉴에서 점 이외의 모드를 사용하면 좋은 경우가 많습니다. 점 모드에서는 텍스처가 번질 수 있습니다.

![](/videos/paint_color_texture.mp4)  
:::

::: tip
폴리곤 수가 적은 오브젝트에 금속 표면을 칠한다면, `부드러운 셰이딩`을 [전체](settings.md#smooth-shading) 또는 [오브젝트별](material.md#smooth-shading)로 켜 보세요.
:::

## ![](/icons/paint.webp) 모두 칠하기 {#paint-all}

![](/images/paint_paint_all.webp)

현재 머티리얼을 선택한 오브젝트에 적용합니다. `모두 칠하기`로 일반 방식으로 칠하거나, `모두 칠하기 + 트라이플레이너`로 트라이플레이너 투영으로 칠할 수 있습니다. 트라이플레이너 방식은 아직 확정하지 않은 기본 도형에서는 사용할 수 없습니다.

색상/메탈릭/거칠기/불투명도 슬라이더 옆의 체크박스가 반영되므로, 꺼진 속성은 채워지지 않습니다.

추가 버튼으로 모두 칠하기가 받는 영향을 더 조절할 수 있습니다. 대부분 백분율이 표시되며, 효과가 없을 때는 회색으로 비활성화됩니다.

| 아이콘                      | 설명                                          |
| :-------------------------: | :-------------------------------------------: |
| ![](/icons/shield.webp)    | 마스크된 영역은 영향을 받지 않습니다.         |
| ![](/icons/tool_hide.webp) | 가려진 영역은 영향을 받지 않습니다.           |
| ![](/icons/opacity.webp)   | 위의 도구 페인팅 인자를 사용합니다.           |
| ![](/icons/layer.webp)     | 레이어에서 칠하지 않은 영역은 영향을 받지 않습니다. |
| ![](/icons/triplanar.webp) | `버텍스`: 트라이플레이너 방식에서 표시된 도구 강도만큼 알파로 표면도 오프셋합니다. |
| ![](/icons/cog.webp)       | 트라이플레이너 설정을 엽니다                  |

### ![](/icons/cog.webp) 트라이플레이너 설정 {#triplanar-settings}
![](/images/paint_triplanar_settings.webp)

[머티리얼 메뉴의 트라이플레이너 설정](material.md#triplanar)과 비슷하게, 투영의 블렌딩, 타일링, 오프셋을 조절할 수 있습니다. 

이 메뉴 위쪽의 미리보기 체크박스를 켜면 값을 조정하는 동안 미리보기가 계속 표시됩니다.
