# ![](/icons/layer.webp) 레이어 {#layers}

이 메뉴에는 레이어 스택이 있습니다. 레이어는 오브젝트에 대한 편집을 비파괴적으로 저장하는 방법이며, 레이어를 조합하고 다른 용도로 활용하는 다양한 방법도 제공합니다.

![](/images/layers_overview.webp) 

## 개요 {#overview}

Nomad의 레이어는 여러 용도로 쓰입니다.

페인트 정보(색상, 거칠기, 메탈릭, 불투명도)는 2d 페인팅 앱과 비슷하게 레이어에서 동작합니다. 레이어를 만들고 모델에 페인트를 칠할 수 있습니다. 레이어는 켜고 끌 수 있고, 불투명도를 조정하거나, 복제하거나, 레이어 스택에서 순서를 바꾸거나, 블렌드 모드를 조정할 수 있습니다.

Nomad는 스컬프팅에도 레이어를 사용합니다. 레이어에는 주름 같은 세밀한 디테일을 저장할 수도 있고, 큰 변형을 저장할 수도 있습니다. 그래서 다른 3d 앱의 블렌드셰이프/셰이프 키/모프 타깃처럼 활용할 수 있습니다. 예를 들어 서로 다른 레이어에 여러 표정을 스컬프팅한 다음, 레이어 슬라이더를 조절해 조합하면 새로운 표정을 만들 수 있습니다.

이 경우 레이어에 저장된 변경 사항은 순수하게 더해지기만 하므로, 페인트와 달리 레이어 순서는 상관없습니다.

레이어는 [레이어 지우기](tools.md#delete-layer) 도구로 일부를 지울 수 있고, 레이어에 저장된 여러 정보를 바탕으로 마스크를 만들 수도 있습니다.

![](/videos/layer.mp4)

::: tip
대부분의 스컬프팅 소프트웨어와 달리, Nomad에서는 메시의 토폴로지를 바꿔도 레이어가 사라지지 않습니다. [복셀 리메셔](topology.md#voxel-remesher), [다중해상도](topology.md#multiresolution), [자르기](tools.md#trim)/[분할](tools.md#split) 도구를 사용할 수 있습니다. 다만 [복셀 리메셔](topology.md#voxel-remesher)를 사용하면 레이어의 품질이 떨어질 수 있습니다.
:::

::: tip
레이어를 블렌드셰이프/모프 타깃으로 쓴다면, [씬 메뉴](scene.md#object-menu)에 추가 레이어 기능이 있습니다. 레이어를 오브젝트로 분리하거나, 일치하는 오브젝트들을 레이어로 합칠 수 있습니다.
:::

## 레이어 메뉴 {#layer-menu}

![](/images/layers_menu.webp)

제목에는 선택한 오브젝트의 이름이 표시됩니다. 기본 도형에서는 레이어를 쓸 수 없으므로, 먼저 기본 도형을 확정하세요.

`레이어 추가`를 누르면 새 레이어가 만들어집니다. `레이어 병합`은 모든 레이어를 기반 메시에 병합하며, 아이콘 옆의 숫자는 레이어 개수입니다.

각 레이어에는 이름, 강도/계수를 조절하는 슬라이더, 옵션 버튼이 있습니다. 레이어를 탭하면 활성 레이어가 되어, 스컬프팅과 페인팅이 그 레이어에 기록됩니다. 다시 기반 메시에서 작업하려면 `기반`을 탭하세요.

### ![](/icons/sort_right.webp) 목록 펼치기 {#ui-expand-list}

기본적으로 레이어 목록에는 각 레이어의 표시 여부, 블렌드 모드, 강도만 보이고, 활성 레이어만 모든 설정이 펼쳐져 있습니다. 제목 왼쪽의 화살표를 누르면 모든 레이어의 설정이 펼쳐집니다.

![](/images/layers_expand.webp)

### 옵션 {#options}

| 작업         | 아이콘                       | 설명                                                |
| :----------: | :--------------------------: | :-------------------------------------------------  |
| 표시됨       | ![](/icons/eye_open.webp)   | 레이어를 표시하거나 숨깁니다                        |
| 블렌드 모드  | ![](/icons/opacity.webp)    | 포토샵 방식의 블렌드 모드입니다. 4개의 아이콘은 색상, 거칠기, 메탈릭, 불투명도의 모드를 나타냅니다.                                 |
| 이름 변경    | ![](/icons/pencil.webp)     | 레이어 이름을 편집합니다                            |
| 삭제         | ![](/icons/trash.webp)      | 레이어를 삭제합니다                                 |
| 복제         | ![](/icons/clone.webp)      | 레이어를 복제합니다                                 |
| 아래 레이어와 병합 | ![](/icons/merge_down.webp) | 레이어를 아래 레이어(또는 기반 메시)와 병합합니다 |
| 더 보기      | ![](/icons/more.webp)       | [더 보기...](#more) 옵션                            |

레이어가 펼쳐져 있지 않을 때는 `이름 변경`, `삭제`, `복제`, `아래 레이어와 병합`이 [더 보기...](#more) 메뉴에 있습니다.

레이어를 레이어 스택의 다른 위치로 옮기려면 이름을 길게 누른 다음 드래그하세요.

### 기반 {#base}

`기반` 행의 점 3개 버튼에서 `기반 → 레이어` 버튼을 누르면 기반 메시의 페인트가 새 레이어로 옮겨집니다. 그러면 기반은 배경 머티리얼로 초기화됩니다. 레이어를 만들기 전에 페인트를 많이 칠했을 때 편리합니다.

* 옆의 마스크와 가리기 버튼을 켜면 마스크되거나 가려진 영역은 건드리지 않습니다.
* `추출` - 옮길 채널입니다. `색상`, `불투명도`, `거칠기`, `메탈릭` 중에서 고릅니다.
* `배경 머티리얼` - 켜면 이 머티리얼과 다른 값만 옮깁니다. 슬라이더로 설정하거나, 스포이트로 모델에서 직접 고를 수 있습니다.

### ![](/icons/more.webp) 더 보기... {#more}

'더 보기...' 버튼을 누르면 현재 레이어의 추가 옵션이 두 개의 탭으로 나타납니다. 설정(톱니바퀴 아이콘)과 추출(큐브 아이콘)입니다.

![](/images/layers_more.webp) 

#### 채널 계수 {#channel-factors}

레이어의 스컬프트/색상/거칠기/메탈릭/불투명도 양을 배율로 조절합니다. 이 값은 레이어 계수 슬라이더와 곱해집니다. 예를 들어 레이어 강도가 1이고 색상 채널 계수가 0.5이면, 색상은 0.5의 강도로 표시됩니다.

`오프셋`은 레이어의 스컬프트 강도를 조절합니다. 색상/거칠기/메탈릭은 0에서 1 사이로 제한되지만, 오프셋은 양수든 음수든 어떤 값이든 될 수 있습니다. 

::: tip
오프셋을 이용하면 돌기 레이어를 움푹 팬 레이어로, 미소를 찡그린 표정으로 바꿀 수 있습니다.
![](/videos/layer_happysad.mp4)


대칭 레이어를 복제한 다음, 레이어 지우기로 왼쪽/오른쪽 형태로 나눌 수 있습니다.
![](/videos/layer_leftright.mp4)

오프셋 계수가 음수인 레이어를 빈 레이어에 베이크하면 새로운 양수 형태를 만들 수 있습니다.

오프셋 계수가 1보다 큰 레이어로는 더 과장된 블렌드셰이프를 실험해 볼 수 있습니다.
:::

::: warning
현재 레이어는 3개 채널(색상/메탈릭/거칠기)이 하나의 불투명도 채널을 공유합니다.
채널별 강도가 최대가 아닌 레이어 여러 개를 병합하면 최종 결과가 다르게 보일 수 있습니다.

언젠가는 채널마다 별도의 알파 채널을 두어 이 제한이 없어질 수도 있습니다.
:::


#### ![](/icons/shield.webp) 마스크 {#mask}
각 슬라이더 옆의 마스크 버튼을 누르면 그 채널로 마스크를 만듭니다. 페인팅 앱에서 레이어로 선택 영역을 만드는 것과 비슷하게, 레이어에서 해 둔 작업을 다른 작업에 다시 활용할 수 있습니다.

#### ![](/icons/preview.webp) 미리보기 {#preview}
![](/images/layers_preview.webp) 

다음 옵션들은 '더 보기...' 메뉴의 추출 탭에 있습니다.

켜면 이 레이어의 추출 설정을 미리 보여줍니다(다음 섹션 참고).

`X-레이`는 미리보기 중에 어떤 오브젝트를 투명하게 할지 고릅니다(`없음`, `미선택`, `선택된`, `전체`). 그래서 추출된 형태는 불투명하게 보입니다. 추출 높이를 음수로 쓸 때 유용합니다.

#### ![](/icons/mask_extract.webp) 추출 {#extract}
![](/images/layers_extract.webp) 

![](/videos/layer_shell.mp4)

`추출` 버튼은 레이어의 내용을 새 오브젝트로 복제합니다. 보통 다음 섹션에서 설정하는 두께가 적용됩니다.

`닫기 동작`은 복제 방식을 정합니다.

* `없음` - 해당 부분만 추출하고, 측면을 만들거나 구멍을 메우지 않습니다.
* `채우기` - 구멍을 삼각형으로 메우고 부드럽게 합니다. 평평한 표면에는 이 옵션을 쓰지 마세요.
* `셸` - 두께 값과 방향 옵션으로 추출한 형태를 닫습니다.
* `레이어` - 레이어의 차이를 추출합니다.

#### ![](/icons/height.webp) 높이 {#thickness}
![](/images/layers_thickness.webp) 

셸 돌출의 깊이입니다. 양수 값은 표면 바깥으로, 음수 값은 표면 안쪽으로 자랍니다. 닫기 동작이 `레이어`일 때는 숨겨집니다.

이 값 옆의 더하기/빼기는 돌출 방향을 정합니다.
* 빼기 ( - ) 는 현재 표면에서 시작해 아래로 돌출합니다. 
* 더하기 ( + ) 는 현재 표면에서 시작해 위로 돌출합니다.
* 더하기빼기 ( ± ) 는 돌출의 위아래를 같은 양만큼 밀어내므로, 원래 표면에 절반쯤 묻히게 됩니다.

#### 측면 {#edge-loop-side}
![](/images/layers_edgeloop.webp) 

이 섹션은 닫기 동작이 `셸`일 때 보입니다. 

`벽 분할`은 셸 측면을 따라 나눌 분할 수를 정합니다. `자동` 토글을 켜면 Nomad가 정사각형 폴리곤이 되도록 엣지 루프 수를 계산합니다.

#### 평활도 {#smoothness}
![](/images/layers_smoothness.webp) 

추출할 영역의 가장자리가 들쭉날쭉하다면, 이 옵션을 켜서 더 보기 좋은 형태로 부드럽게 하세요. `전체`는 추출한 표면 전체를, `경계만`은 가장자리만 부드럽게 합니다. `반복`은 스무딩의 세기를 정합니다.

_'더 보기...' 하위 메뉴는 여기까지입니다._

### ![](/icons/cog.webp) 고급 {#advanced}
![](/images/layers_advanced.webp)

메뉴 아래쪽의 `고급` 버튼은 오브젝트에 레이어가 생기면 나타납니다.

#### 상단 레이어들의 디테일 유지하기 {#keep-top-layers-details}

아래 레이어에 큰 변형을 가해도 위쪽 레이어의 작은 디테일이 계속 보이도록 합니다. 스컬프팅하는 동안 위쪽 레이어에서 오는 변형은 무시되지만, 그 디테일은 계속 보입니다. 위쪽 레이어에 비교적 작은 디테일만 있을 때 잘 동작합니다.

기본적으로는 레이어에 작은 주름을 스컬프팅한 다음 기반 레이어에 큰 변형을 가하면 주름이 사라집니다. 이 토글을 켜면 작은 디테일이 아래의 큰 변형 위에 항상 떠 있게 됩니다. 다음 영상에서 기본 상태에서는 주름 디테일이 사라지지만, '상단 레이어들의 디테일 유지하기'를 켜면 계속 보이는 것을 확인해 보세요.

![](/videos/layers_details.mp4)


#### 변환 동기화 {#sync-transform}

켜면 기즈모나 트랜스폼 도구를 사용할 때, 선택하지 않은 모든 레이어도 트랜스폼의 회전, 스케일, 기울임에 맞춰 조정됩니다. `자동`, `아니오`, `예` 중에서 고를 수 있습니다.

다른 레이어를 지금 적용하는 새 트랜스폼 없이 쓸 생각이라면 이 옵션을 끄세요.

`자동`으로 설정하면 보이는 레이어만 조정됩니다.
