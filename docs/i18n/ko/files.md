# ![](/icons/open.webp) 파일 {#files}

파일 메뉴에서는 Nomad 프로젝트를 저장하고 불러오고, 3d 모델을 임포트하고 익스포트하고, 렌더링한 이미지를 익스포트하고, Nomad를 다른 앱과 연결할 수 있습니다. `파일`, `렌더`, `연결`의 세 탭이 있습니다.

![](/images/file_menu.webp)

## 프로젝트 {#project}
![](/images/file_project.webp)

맨 위의 썸네일은 현재 프로젝트를 보여 주며, 옆에는 파일 크기, 자동 저장, 저장된 작업 내역이 표시됩니다. 썸네일을 탭하면 프로젝트를 둘러보는 작은 브라우저가 열리고, 거기서 프로젝트를 탭하면 열기, 추가, 덮어쓰기, 복제, 이름 변경, 삭제 메뉴가 나타납니다.

프로젝트에 아직 저장하지 않은 변경 사항이 있으면 썸네일 아래에 `변경 내용이 저장되지 않았습니다!`가 표시됩니다.

### 범위 {#scope}
데스크톱에서는 프로젝트를 어디에 저장할지 고를 수 있습니다.
* `내부` - 모바일과 같은 기본값입니다. 프로젝트는 Nomad 메인 폴더 안에만 저장됩니다.
* `원본 위치` - Nomad 폴더 밖에서 프로젝트를 열면, 저장할 때 원본 파일을 덮어씁니다. 이런 외부 프로젝트에서는 자동 저장이 동작하지 않습니다.

### ![](/icons/nomad.webp) 프리셋 {#preset}
데모와 캐릭터 부품 모음을 볼 수 있습니다. 하나를 선택한 다음, 다시 선택해서 `열기`나 `씬에 추가`를 고르세요. 이 브라우저에서 Poly Haven의 무료 모델을 내려받을 수도 있습니다.

![](/images/file_preset_preview.webp)

### ![](/icons/history.webp) 작업 내역... {#history}
프로젝트의 작업 내역 옵션으로 바로 갈 수 있습니다. 예를 들어 `기록 저장`을 켜면 프로젝트를 저장할 때 실행 취소 기록도 함께 남습니다. 버튼의 초록색 배지는 작업 내역이 프로젝트와 함께 저장된다는 뜻입니다. 자세한 내용은 [작업 내역](history.md#save-history)을 참고하세요.

### ![](/icons/save.webp) 저장 {#save}
Nomad 프로젝트를 저장합니다. 한 번도 저장한 적 없는 프로젝트라면 이름을 묻습니다.

### ![](/icons/save_as.webp) 다른 이름으로 저장... {#save-as}
프로젝트를 새 이름으로, 새 프로젝트로 저장합니다.

### ![](/icons/save_as.webp) 덮어쓰기... {#overwrite}
프로젝트 브라우저를 열어 현재 씬을 다른 프로젝트 위에 덮어써서 저장합니다. `선택한 오브젝트만 포함`을 켜면 씬 전체 대신 선택한 오브젝트만 저장합니다. 브라우저에는 새 프로젝트로 저장하는 `다른 이름으로 저장...` 버튼도 있습니다.

### ![](/icons/pencil.webp) 이름 변경 {#rename}
텍스트 상자를 띄워 현재 프로젝트의 이름을 바꿉니다.

### ![](/icons/open.webp) 열기... {#open}
프로젝트 브라우저를 열어 프로젝트를 엽니다.

### ![](/icons/add_file.webp) 씬에 추가... {#add}
프로젝트 브라우저를 엽니다. 프로젝트를 선택하면 그 내용이 현재 씬에 합쳐집니다.

### ![](/icons/trash.webp) 삭제... {#delete}
프로젝트 브라우저를 엽니다. 선택한 프로젝트는 파일 시스템에서 삭제됩니다.

### ![](/icons/new_file.webp) 신규 {#new}
새 프로젝트를 시작합니다. 저장하지 않은 변경 사항이 있으면 확인을 묻습니다. 확인 창에서 `배경`, `환경`, `MatCap`, `X-레이` 설정을 `유지`할지 `초기화`할지 고를 수 있고, 새 프로젝트에서 `기록 저장`을 쓸지도 정할 수 있습니다.

### ![](/icons/autosave.webp) 자동 저장... {#auto-save}
자동 저장 옵션을 조절하는 메뉴입니다. `자동 저장`을 켜면 일정한 간격으로 프로젝트를 별도의 파일에 저장합니다. 버튼의 배지로 켜져 있는지 알 수 있습니다.

Nomad가 백그라운드에서 저장하지 않는 이유는, 3d 파일이 꽤 클 수 있어서 조각하는 도중에 눈에 띄게 버벅일 수 있기 때문입니다.

또한 메모리 부족 문제를 피하기 위해, 저장하기 전에 보통 씬을 압축합니다.
이 압축과 압축 해제 때문에 저장이 더 느려지기도 합니다.

### 저장 간격 {#timer-pop-up}
자동 저장 사이에 Nomad가 몇 분을 기다릴지 정합니다.

### 카운트다운 표시 {#popup-timeout}
자동 저장 전에 카운트다운을 보여 주므로, 한창 작업 중이라면 취소할 수 있습니다. 끄면 조각을 멈추자마자 바로 저장합니다.

### ![](/icons/trash.webp) 자동 저장 폐기 {#discard-autosave}
프로젝트에 자동 저장 파일이 있으면 원래 프로젝트 대신 그 파일을 자동으로 불러옵니다. 그럴 필요가 없다면 이 버튼으로 자동 저장 파일을 지우세요. 그러면 파일을 불러올 때 마지막으로 수동 저장한 프로젝트가 열립니다.

### ![](/icons/open.webp) 오래된 저장 열기 {#open-outdated-save}
프로젝트에 자동 저장과 수동 저장이 모두 있으면, 이 버튼은 둘 중 더 오래된 쪽(`오래된 자동 저장 열기` 또는 `오래된 수동 저장 열기`)을 날짜와 함께 보여 주고 엽니다. 가장 최근 저장이 원하던 것이 아닐 때 편리합니다.

### ![](/icons/storage.webp) 최근 삭제된 항목... {#recently-deleted}
Nomad는 프로젝트 폴더에서 빠져나간 프로젝트의 데이터와, 임포트로 대체된 파일을 며칠 동안 보관한 뒤 완전히 삭제합니다. 임포트에 실패한 파일은 직접 지울 때까지 남아 있습니다. 이 목록에 크기와 날짜가 함께 표시되므로, 하나씩 지우거나 `모두 삭제`로 한꺼번에 지울 수 있습니다.

## 임포트 {#import}

### ![](/icons/add_file.webp) 임포트 {#import-button}
Nomad 프로젝트가 아닌 3d 파일을 임포트할 때 씁니다.

외부 씬 파일을 Nomad로 임포트할 때는 현재 씬에 *추가*하거나, 그 파일로 *새* 프로젝트를 시작할 수 있습니다.

추가하면 오브젝트가 그대로 현재 씬에 더해집니다.
`신규`를 고르면 새 오브젝트가 들어 있는 새 Nomad 프로젝트가 만들어집니다.

임포트 창에는 고른 파일이 모두 나열되며, 파일마다 각자의 임포트 옵션이 있습니다. 이미지도 이 방법으로 임포트할 수 있는데, 각 이미지를 `HDRI`, `MatCap`, `참조`, `알파`, `텍스처`, `VDM` 중 무엇으로 쓸지 고르면 됩니다.

Nomad는 다음 형식을 임포트할 수 있습니다.
- Nomad (.nom)
- glTF (.glb, .gltf)
- OBJ (.obj)
- STL (.stl)
- PLY (.ply)
- FBX (.fbx)
- ZBrush (.ztl, .zpr)
- USD (.usd, .usdz, .usda, .usdc), 지원하는 플랫폼에서

### ![](/icons/cog.webp) 설정 {#advanced}
프로젝트 썸네일 옆의 `설정...` 버튼을 누르면 주요 임포트 옵션이 나타납니다. 이 설정은 저장되지 않으며, 임포트 창에는 임포트하는 파일에 해당하는 옵션만 표시됩니다.

### 모든 형식 {#project-gltf-obj-stl-fbx}
#### ![](/icons/nomad.webp) 토폴로지 유지하기 {#keep-topology}
Nomad는 기본적으로 불러올 때 문제가 있는 지오메트리를 고치려고 합니다. 이 옵션을 켜면 버텍스/면 순서 변경, 중복 병합, 쓰이지 않는 버텍스 제거를 하지 않습니다.

::: warning
`토폴로지 유지하기`를 켜면 불리언, 결합, 데시메이트, 매니폴드 같은 작업에서 중복 버텍스가 병합되지 않을 수 있습니다.
:::

#### ![](/icons/image.webp) 텍스처 건너뛰기 {#skip-textures}
glTF처럼 텍스처를 포함할 수 있는 형식에서, 파일에 포함된 텍스처를 불러오지 않습니다.

### Nomad / glTF {#project-gltf}
#### ![](/icons/sliders.webp) UI 설정 불러오기 {#keep-gui-settings}

#### ![](/icons/vertex.webp) 중복 위치 병합 {#merge-duplicate-positions}
같은 위치에 있는 버텍스를 병합합니다.

#### ![](/icons/uv.webp) 중복 UV 병합 {#merge-duplicate-uvs}
같은 UV를 가진 텍스처 좌표를 병합합니다.

#### ![](/icons/paint.webp) 컬러 스페이스 {#color-space}

#### ![](/icons/image.webp) 형식 {#normal-format}

### ![](/icons/export.webp) 익스포트 버튼 {#export-button}
이 버튼을 누르면 선택한 설정으로 지오메트리를 익스포트합니다. 버튼에는 선택한 형식과 예상 파일 크기가 표시됩니다. Android에서는 옆의 `공유` 버튼으로 파일을 다른 앱에 바로 보낼 수 있습니다.

### 파일 형식 {#file-format}
익스포트할 형식을 고릅니다. `NOMAD`, `glTF`, `OBJ`, `FBX`, `PLY`, `STL`, `USD` 중에서 고를 수 있습니다. NOMAD는 Nomad 전용 형식이라 다른 소프트웨어에서는 열리지 않으므로, 주로 Nomad로 다시 임포트할 때 씁니다.

### 포함 {#allvisibleselected}
익스포트할 오브젝트를 고릅니다. `전체`, `표시됨`, `선택된` 중에서 고르며, 각 옵션 옆의 숫자는 익스포트될 오브젝트 수입니다.

### 한 개체당 하나의 파일 {#one-file-per-object}
오브젝트마다 각각 별도의 파일로 익스포트합니다. 숫자는 몇 개의 파일이 만들어질지 보여 줍니다.

### 유형 {#type}
익스포트로 여러 파일이 만들어질 때(한 개체당 하나의 파일, 또는 텍스처가 있는 OBJ), 파일을 `폴더`에 담을지 `압축` 파일로 묶을지 고릅니다. 일부 앱(Google Drive, One Drive 등)은 폴더 임포트를 지원하지 않으므로, 그럴 때는 압축 파일을 쓰면 됩니다.

### 기록 포함 {#embed-history}
NOMAD 전용입니다. 실행 취소 기록을 파일 안에 넣어서, Nomad에서 파일을 열 때 복원되도록 합니다. 파일 크기가 커지고, 씬 전체를 하나의 파일로 익스포트해야 합니다.

### 에셋 포함 {#embed-assets}
NOMAD 전용입니다. 직접 추가한 MatCap, 환경, 글꼴을 파일에 포함합니다. 기본 제공 에셋은 포함되지 않습니다.

### 버텍스 색상 {#vertex-colors}
파일 형식이 지원하면 버텍스 색상을 익스포트합니다. 이를 읽을 수 있는 3d 소프트웨어도 있지만, 모두 그렇지는 않습니다.

OBJ에서는 다음 중에서 고를 수 있습니다.
* `없음` - 색상을 넣지 않습니다.
* `RGB` - 버텍스 뒤에 색상을 덧붙입니다.
* `MRGB (ZBrush)` - 색상을 인코딩하는 또 다른 방식으로, 마스크 데이터도 지원합니다.

### 컬러 스페이스 {#color-space-export}
OBJ에서 `RGB` 버텍스 색상을 쓸 때만 해당합니다. 색상을 `선형`이나 `sRGB`로 기록합니다.

### PBR 페인트 {#pbr-paint}
거칠기, 메탈릭, 마스크 페인팅을 익스포트합니다. 다른 소프트웨어에서는 이 데이터를 무시할 수 있습니다.
PBR 버텍스 색상은 보조 버텍스 색상 속성으로 익스포트됩니다.
채널은 다음과 같이 묶입니다.

|           | 채널  |
| :-------: | :------: |
| 거칠기 | R        |
| 메탈릭 | G        |
| 마스킹   | B        |


### 레이어 {#layers}
레이어는 glTF 모프 타깃으로 지원됩니다. glTF가 공식적으로 지원하는 기능이므로 다른 소프트웨어에서도 동작할 것입니다.
Nomad는 레이어별 색상, 거칠기, 메탈릭도 익스포트하지만, 다른 소프트웨어에서는 무시됩니다.

### 레이어 페인트 {#layer-painting}
레이어 페인팅을 익스포트합니다. 다른 소프트웨어에서는 보통 무시됩니다.

### 페이스 그룹 {#face-group}
페이스 그룹을 익스포트합니다. 다른 소프트웨어에서 문제를 일으키는 경우가 가끔 있습니다.

### 오브젝트로 쓰기 {#write-objects}
OBJ 전용입니다. 오브젝트를 따로따로 유지합니다. 끄면 모든 것을 하나의 오브젝트로 익스포트하는데, 예를 들어 Substance Painter의 'Mesh ID / Polygroup' 기능을 쓸 때 유용합니다.

### 노멀 {#normals}
노멀 정보를 익스포트합니다. 다른 형식의 파일을 임포트할 때 Nomad는 항상 노멀을 직접 계산한다는 점에 유의하세요.

### 접선 {#tangents}
접선 정보를 익스포트합니다. 모델에 노멀 맵이 있을 때 쓰입니다. 

### 텍스처 {#textures}
머티리얼에 텍스처를 추가했다면 그 텍스처가 익스포트됩니다. 텍스처를 베이크하지는 않는다는 점에 유의하세요. 베이크는 토폴로지 메뉴의 베이크 옵션으로 합니다.

### 형식 {#fbx-format}
FBX 전용입니다. `바이너리`는 더 작지만 모든 앱에서 열리지는 않을 수 있고, `아스키`는 텍스트 파일입니다.

### 압축됨 {#compressed}
FBX 전용입니다. 파일 크기를 줄이는 대신 익스포트와 임포트가 느려집니다.

### 프리셋 {#usd-preset}
USD 전용입니다. 익스포트할 대상 앱을 고릅니다. `OpenUSD`, `Apple`, `Procreate`, `Zbrush` 중에서 고를 수 있으며, 일부 옵션은 특정 프리셋에서만 쓸 수 있습니다.

### 인스턴스 {#instance}
USD 전용입니다. 인스턴스 오브젝트를 지오메트리를 복제하는 대신 인스턴스로 익스포트합니다.

### 기울임 허용 {#allow-skew}
USD 전용입니다. 행렬 트랜스폼에 기울임(skew)을 허용합니다. 끄면 Nomad는 기울어진 트랜스폼을 스케일과 회전 트랜스폼으로 나눕니다.

### 리피터 {#repeater}
USD 전용입니다. 리피터로 만든 복사본을 인스턴스로 익스포트합니다.

### 복사본 합치기 {#join-copies}
각 오브젝트와 그 리피터 복사본을 하나의 오브젝트로 합칩니다.

::: tip 팁: 거칠기와 메탈릭을 Blender로 가져오기

Blender는 glTF/glb를 임포트할 수 있지만, 메탈릭과 거칠기용 버텍스 속성을 자동으로 인식하지는 못합니다. 이를 쓰려면 머티리얼 편집기에서 Vertex Color 노드를 만들고, 속성을 다음 색상 속성(보통 Col.001)으로 정합니다. 'Separate XYZ' 노드를 연결해서 X는 Roughness로, Y는 Metallic으로 보내세요.

이 영상에서 과정을 볼 수 있습니다.

![](/videos/blender_pbr.mp4)

::: 

::: tip 팁: USD 기능 지원

USD는 복잡한 형식이라 사양에는 많은 기능이 들어 있지만, 모든 3d 소프트웨어가 그 기능을 다 지원하지는 않습니다. 예를 들어 OSX/iOS는 버텍스 색상을 지원하지 않습니다. USD 익스포터의 프리셋 모드는 OpenUSD, Apple, Procreate, Zbrush와 최대한 호환되도록 설정을 추정합니다.

::: 

## ![](/icons/screen.webp) 렌더 {#render}

프로젝트의 모든 설정(광원, 머티리얼, 포스트 프로세싱 등)을 합친 이미지를 익스포트합니다. 

![](/images/file_render.webp)
### ![](/icons/preview.webp) 미리보기 {#preview}

메뉴 제목 옆의 `미리보기` 버튼을 누르면 인터페이스가 반투명해져서, 최종 결과의 구도를 미리 확인하기 좋습니다.

### ![](/icons/home.webp) 포커스 {#focus}
씬이나 선택 항목을 렌더 크기에 맞게 화면에 담습니다. 다시 탭하면 둘 사이를 전환합니다.

### ![](/icons/map.webp) 하이트맵 {#heightmap}
카메라에서 본 씬을 회색조 하이트맵으로 렌더링합니다. 가장 가까운 부분이 가장 밝습니다. 켜면 크기가 `사각형`으로 바뀌고 선택 항목이 화면에 담깁니다. 뷰포트의 작은 바로 그라데이션의 `포커스`를 조절할 수 있습니다.

`하이트맵`이 켜져 있으면 익스포트 버튼 옆에 `알파로 저장` 버튼이 나타나서, 파일을 익스포트하는 대신 렌더 결과를 새 브러시 알파로 저장할 수 있습니다.

### ![](/icons/opacity.webp) 투명한 배경 {#transparent-background}
렌더에 알파 채널을 넣습니다. 2d 프로그램에서 렌더 결과를 다른 이미지와 합성할 때 유용합니다. 반투명은 지원하지 않는다는 점에 유의하세요.

### ![](/icons/sliders.webp) 인터페이스 보기 {#show-interface}
렌더에 Nomad의 UI를 포함합니다.

### 최종 크기 {#final-size}
렌더에 쓸 해상도입니다. `스크린`, `720`, `1080`, `4096`, `사각형`, `커스텀` 중에서 고릅니다.

파일 메뉴가 열려 있을 때 렌더 영역이 화면 해상도와 다르면, 뷰포트에 점선으로 렌더 영역이 표시됩니다.

### 너비 / 높이 {#render-ratio}
`커스텀`일 때 이미지의 너비와 높이를 정합니다. 두 슬라이더 사이의 연결 버튼을 켜면 한쪽을 바꿀 때 비율이 유지됩니다. `사각형`일 때는 너비만 정할 수 있습니다.

### ![](/icons/export.webp) 익스포트 → PNG {#export-png}
이 버튼을 누르면 렌더링을 시작합니다. 끝나면 이미지를 저장하거나 공유할 방법을 고를 수 있습니다. 아주 큰 크기는 먼저 확인을 묻습니다. 기기의 메모리가 부족해질 수 있으니 그 전에 프로젝트를 저장해 두세요.

## ![](/icons/network.webp) 연결 {#link}

Nomad를 다른 기기나 앱과 연결해서 오브젝트를 주고받거나, 편집 내용을 실시간으로 동기화합니다. 한 기기가 세션을 호스트하고, 다른 기기들이 참가합니다.

### GoZ 활성화 {#enable-goz}
데스크톱 전용입니다. 같은 컴퓨터의 ZBrush와 메시를 주고받습니다. `보내기`는 메시를 ZBrush로 임포트하고, `가져오기`는 실행 중인 ZBrush에서 임포트합니다. `선택 영역`은 활성 서브툴을, `씬`은 모든 서브툴을 가져옵니다. ZBrush에서 언제든 GoZ를 눌러도 됩니다.

### 모드 {#link-mode}
* `끄기` - 연결하지 않습니다.
* `호스트` - 이 기기가 세션을 호스트하고 다른 기기의 참가를 기다립니다.
* `참가` - 주변 기기를 검색한 다음, 호스트의 이름을 탭해서 참가합니다.

Nomad 두 대를 연결하려면 한 기기에서 `호스트`를, 다른 기기에서 `참가`를 고르세요. Blender와 연결하려면 Nomad가 호스트여야 합니다. `연결` 제목 옆의 도움말 버튼에서 Nomad Blender Link 확장 프로그램을 설치하는 방법을 볼 수 있습니다.

### ![](/icons/network.webp) 네트워크 포트 {#network-port}
연결에 쓰는 네트워크 포트입니다. 다른 앱이 이미 이 포트를 쓰고 있을 때만 바꾸세요.

### 보내기 / 가져오기 {#send-get}
연결되면 `선택 영역`이나 `씬` 전체를 상대 기기로 `보내기`하거나, 상대 기기에서 `가져오기`할 수 있습니다. `교체`는 현재 씬을 삭제한 다음 상대 기기의 씬을 가져옵니다.

### ![](/icons/link.webp) 실시간 동기화 {#live-sync}
작업하는 동안 편집 내용을 상대 기기로 실시간 전송합니다. `작업 뷰`를 켜면 카메라도 동기화됩니다. `씬 편집`은 어느 기기가 편집 내용을 보낼지 정하며, `자동`이면 가장 최근에 작업한 쪽이 보냅니다. 그다음 동기화할 항목을 고르세요. `오브젝트 및 지오메트리`, `재질`, `광원`, `카메라`가 있고, 상대 쪽에서 지원하면 `셰이딩`과 `포스트 프로세싱`도 있습니다.

::: tip
기존 오브젝트는 실시간 동기화로 업데이트하기 전에, 먼저 `보내기`나 `가져오기`를 한 번 해서 연결해 두어야 합니다.
:::
