# ![](/icons/transform.webp) 自由变换 {#transform}

这个菜单以数值形式显示所选物体的变换：它在哪里、如何旋转和缩放、有多大。您可以输入精确的数值、重置它们，或者把它们烘焙到网格中。

![](/images/transform_overview.webp)

## 概述 {#overview}

每个物体除了顶点之外，还有一个节点，用来存储它的位移、旋转和缩放（即它的矩阵）。在视口中拖动时，[轴向变换](tools.md#gizmo)和[自由变换](tools.md#transform)工具改变的就是这个矩阵；而这个菜单让您可以直接读取它，并输入数值。关于移动节点和移动顶点的区别，请参阅[节点与顶点](tools.md#nodes-and-vertices)。

向左或向右拖动数值即可修改，轻点它可以输入数字。X、Y、Z 的数值分别显示为红色、绿色和蓝色，与轴向变换控件的坐标轴一致。

::: tip
输入数值很适合精确摆放物体，例如把几个部件放到完全相同的高度，或者在用轴向变换控件自由旋转之后，把旋转角度调回一个整数。
:::

## 矩阵 {#matrix}

标题会告诉您数值是在哪个空间中表示的：`本地`（相对于父物体）或 `世界`。

### 对象与轴心 {#object-pivot}

* `对象` - 数值就是物体自身的变换。
* `轴心` - 数值从[轴心](tools.md#pivot)出发控制所选内容，与轴向变换控件的手柄作用方式相同：各行显示为零，修改它们会围绕轴心移动、旋转或缩放所选内容。开启 `编辑`（锁形图标）可以只移动轴心，物体保持不动。

### 本地与世界 {#local-world}

当物体有父物体或子物体，或者选中了多个物体时，您可以选择在哪个空间中显示数值：`本地`（相对于父物体）或 `世界`。

### 操作 {#actions}

| 操作        | 图标                          | 说明 |
| :-----------: | :---------------------------: | :---------- |
| 移至原点   | ![](/icons/target.webp)      | 把物体移到世界原点。 |
| 烘焙          | ![](/icons/bake.webp)        | 把矩阵应用到顶点上，并重置矩阵。视觉上没有任何变化，但物体的原点现在就是世界原点。 |
| 轴心         | ![](/icons/gizmo.webp)       | 把轴心烘焙到物体中：物体的原点和朝向变为轴心的原点和朝向。视觉上没有任何变化。 |
| 编辑          | ![](/icons/lock.webp)        | （`轴心` 模式）只移动轴心。 |
| 重设         | ![](/icons/reset.webp)       | 把变换重置为单位矩阵。在 `轴心` 模式下，则改为把轴心放回原位。 |

如果所选物体有实例，烘焙时会要求确认，并提供 `去实例` 选项：因为烘焙会改变顶点，而顶点是各个实例共用的。

### 位移、旋转、缩放 {#translation-rotation-scale}

物体在 X、Y、Z 上的位置、旋转（以度为单位）和缩放。每行末尾的两个按钮分别用于只把这一部分变换烘焙到顶点中，或者将其重置。

当物体发生了剪切变形时（例如对旋转过的父物体进行非等比缩放之后），还会显示一行 `剪切`。

### 等比缩放 {#uniform-scale}

启用后，缩放只有一个数值，三个轴上都相同。关闭后可以分别缩放 X、Y、Z。

## 尺寸 {#dimension}

所选内容包围盒的大小和中心，以世界单位表示。选中多个物体时，它会涵盖所有物体。

* `尺寸` - 宽度、高度和深度。开启链接按钮后，修改其中一个尺寸，另外两个会按相同比例缩放，保持比例不变。
* `中心` - 包围盒的中心。目标按钮会移动所选内容，让它的中心位于世界原点。

::: tip
`尺寸` 是给物体设定真实世界尺寸的最快方法，例如在 3d 打印之前：设置您想要的高度，链接会帮您保持比例。
:::
