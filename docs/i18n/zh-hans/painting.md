# ![](/icons/paint.webp) 绘画 {#painting}

控制绘画笔触的颜色、粗糙度和金属度，可以一键填充绘画属性，还能设置绘画工具与图层、蒙版和隐藏区域如何相互作用。

![](/images/paint_overview.webp)  

## 概述 {#overview}

Nomad 使用 PBR 顶点绘画。这是什么意思呢？

### PBR {#pbr}
PBR，即基于物理的渲染（Physically Based Rendering），是电影、电视、游戏和移动设备中常用的一种计算机图形技术。通过让灯光遵循物理属性，并用颜色、粗糙度和金属度来定义表面，就能实现各种照片级写实的效果。

### 顶点绘画 {#vertex-painting}

顶点绘画是指绘画信息存储在模型的顶点中，而不是纹理中。由于 Nomad 能处理有几十万、甚至常常上百万顶点的模型，您的模型完全可以拥有非常精细的表面绘画：只要能雕刻出来的细节，也就能画出来。

这也意味着在 Nomad 中绘画不需要 UV 映射，而在其他 3d 应用中，这往往是一个缓慢又偏技术的过程。许多其他 3d 应用无法支持 Nomad 这样高的顶点数，不过 Nomad 也提供了好用的纹理烘焙和网格简化工具来帮忙。

### 纹理 {#texturing}

Nomad 支持纹理，但纹理必须来自导入的模型，或者通过把顶点绘画烘焙到纹理中得到。

纹理就是一张图像，但在 3d 语境中，它通常指指定给某个物体的图像。
要把图像包裹到模型上，模型需要纹理坐标（UV）。

Nomad 可以[自动计算 UV](topology.md#uv-unwrap)，但您对整体质量的控制不多。

::: tip
一个工作流示例：
- 在 Nomad 中雕刻，然后进行[UV 自动展开](topology.md#uv-unwrap)
- 如果您已经在 Nomad 中开始绘画，可以[把顶点绘画转移到纹理](topology.md#bake-texture)
- 导出到 Procreate
- 在 Procreate 中绘制纹理
- 再导回 Nomad 进行渲染
:::

以上就是概述，下面我们来看看绘画菜单的各个部分：


## 笔触绘画 {#stroke-painting}
![](/images/paint_intensity.webp)  

为这个工具启用绘画，适合需要同时雕刻和绘画的情况。如果工具可以绘画但这个复选框没有勾选，标题旁会有一个警告图标提醒您。

对于以绘画为主要功能的工具（例如绘画、涂抹、蒙版），没有这个复选框。

### ![](/icons/opacity.webp) 画笔强度 {#paint-intensity}

一个滑块，让绘画可以使用与工具主强度不同的强度。

旁边的滑块按钮会在侧边栏添加一个快捷的画笔强度滑块，适用于同时雕刻和绘画的工具。

`Alpha`、`衰减` 和 `随机化强度` 按钮决定这些功能是否影响绘画。例如，您可以为黏土工具启用随机化，但颜色不会被随机化。

* `Alpha` - 关闭后，绘画会忽略 Alpha，覆盖整个笔刷区域。使用 VDM 工具时，这个按钮会换成 `印章材质`，用来开启或关闭存储在印章中的材质。
* `衰减` - 关闭后，绘画一直到笔刷边缘都保持完整强度。
* `随机化强度` - 笔触随机化中的强度部分是否影响绘画。位置、旋转和缩放的随机化总是会移动整个印章。

[全部上色](#paint-all)会忽略这些选项，但它的三平面版本会使用 Alpha。

### ![](/icons/link.webp) 全局材质 {#global-material}
启用这个选项后，所选材质将与其他工具相同。请注意，它只考虑粗糙度、金属度和颜色设置。关闭它即可让这个工具使用自己的材质。


## 材质 {#material}
![](/images/paint_material.webp) 

第一个图标是材质预览形状。在 3d 材质预览上拖动可以旋转它。

第二个图标是使用所选 Alpha 和衰减选项时的绘画笔触预览。

### ![](/icons/falloff.webp) 曲线 {#curves}

为 [PBR 滑块](#pbr-sliders)的纹理槽打开曲线编辑器。它会在绘制之前重新映射纹理的数值，而不改动图像文件本身。纹理槽上有一个小曲线图标，就表示它的曲线已经修改过。

### ![](/icons/cog.webp) 材质选项 {#material-options}

标题旁的 `材质` 按钮包含两项设置。

`视口材质预览` 决定在您调整颜色、粗糙度、金属度、不透明度和强度滑块时，所选物体上会发生什么：

* `无` - 调整属性时，模型上不显示任何预览
* `材质` - 调整属性时，在物体上预览材质的数值。
* `三平面` - 以三平面投影的方式预览材质。

下方的颜色、粗糙度、金属度和不透明度复选框用来选择[材质吸管](#material-picker)会替换哪些通道。

### ![](/icons/dropper.webp) 材质吸管 {#material-picker}

吸管会从场景中任意物体上拾取光标下方的材质。只有在[材质选项](#material-options)中勾选的通道才会被替换。

## 材质预设 {#material-presets}
轻点 3d 预览形状会弹出材质预设菜单，您可以克隆这些预设来定义自己的预设。

![](/images/paint_presets.webp) 

`嵌入纹理` 开关会在预设中保存这个材质所用纹理的副本。不开启时，预设只会引用 Nomad textures/ 文件夹中的纹理。如果您想分享带纹理的预设，又不想单独发送纹理，就开启它。

`包含 Alpha` 还会把笔刷的 Alpha 一起保存到材质预设中。

## PBR 滑块 {#pbr-sliders}
![](/images/paint_sliders.webp) 

[PBR](shading.md#pbr) 绘画使用 4 个通道：
- `颜色` 要绘制的颜色。可以用吸管从模型的其他部分或参考图像中拾取颜色。
- `粗糙度` 表示表面有多“粗糙”或多“光滑”。粗糙度越低，反射越清晰。
- `金属度` 简单来说就是表面是否为金属。大多数情况下，这个值应该是 0% 或 100%，介于两者之间的值应该只是特例。
- `不透明度` 材质能被看穿的程度。严格来说它不属于 PBR 规范，但在很多情况下都很有用。1 为完全不透明，0 为透明。请注意，不透明度和折射是两回事，Nomad 中的折射是通过折射材质来实现的。

如果选择了材质预设，会同时绘制 3 个通道（不透明度通常会被有意排除在外）。也就是说，您画的不只是“红色”，而是“一种粗糙的红色金属”或“一种光滑的白色塑料”。

方块是纹理槽，点击它可以为该属性使用纹理，而不是单一的数值。颜色纹理会给颜色着色，而粗糙度、金属度或不透明度纹理会取代滑块的数值（它的标签会显示删除线以示区别）。对于不透明度纹理，`使用 Alpha 作为数值` 会读取纹理的 Alpha 通道，而不是它的灰度值。

使用 VDM 工具时，如果印章自带材质，纹理槽旁边会多出一个槽来显示它。轻点它可以选择使用或忽略印章的这个通道。

滑块旁边的笔刷图标会把该属性填充到整个物体上。

复选框用来启用或停用对应的属性，例如您可以只画颜色，或者只画粗糙度和不透明度。

下面是一些不同粗糙度和金属度的示例：

|                | 金属度 0%                      | 金属度 100%               |
| :------------: | :-------------------------------: | :--------------------------: |
| 粗糙度 0%   | ![](/images/dielectric_r0.webp)   | ![](/images/metal_r0.webp)   |
| 粗糙度 50%  | ![](/images/dielectric_r50.webp)  | ![](/images/metal_r50.webp)  |
| 粗糙度 100% | ![](/images/dielectric_r100.webp) | ![](/images/metal_r100.webp) |

::: warning
粗糙度和金属度需要[光照 (PBR)](shading.md#pbr)着色模式。在[材质捕捉](shading.md#matcap)或[不受光](shading.md#unlit)模式下它们会被忽略，菜单中也会显示警告。
:::

::: tip
用纹理进行 PBR 绘画时，换用 `图章` 这类工具，或者在笔触菜单中使用点状以外的模式，通常会很有帮助，否则纹理可能会被涂花。

![](/videos/paint_color_texture.mp4)  
:::

::: tip
如果您要在面数较低的物体上绘制金属表面，可以考虑[全局](settings.md#smooth-shading)或[按物体](material.md#smooth-shading)开启 `平滑阴影`。
:::

## ![](/icons/paint.webp) 全部上色 {#paint-all}

![](/images/paint_paint_all.webp)

将当前材质应用到所选物体上：用 `全部上色` 以标准模式应用，或者用 `全部上色 + 三平面` 以三平面投影的方式应用。尚未确认的基本体不能使用三平面版本。

颜色/金属度/粗糙度/不透明度滑块旁的复选框会被遵循，任何被停用的属性都不会被填充。

额外的按钮用来控制全部上色还会受到哪些影响。大多数按钮会显示一个百分比，当它们不会产生任何效果时会显示为灰色：

| 图标                        | 说明                                   |
| :-------------------------: | :-------------------------------------------: |
| ![](/icons/shield.webp)    | 被蒙版的区域不受影响。               |
| ![](/icons/tool_hide.webp) | 隐藏的区域不受影响。               |
| ![](/icons/opacity.webp)   | 使用上面工具的绘画系数。           |
| ![](/icons/layer.webp)     | 图层中未绘制的区域不受影响。 |
| ![](/icons/triplanar.webp) | `顶点`：三平面版本还会按所示的工具强度，用 Alpha 让表面产生偏移。 |
| ![](/icons/cog.webp)       | 打开三平面设置                   |

### ![](/icons/cog.webp) 三平面设置 {#triplanar-settings}
![](/images/paint_triplanar_settings.webp)

与[材质菜单中的三平面设置](material.md#triplanar)类似，您可以控制投影的混合、平铺和偏移。

使用这个菜单顶部的预览复选框，可以在调整数值时保持持续预览。
