# ![](/icons/sun.webp) 渲染模式 {#shading}

这个菜单控制 Nomad 使用的着色模式、灯光属性、环境和材质捕捉，以及雾。

![](/images/shading_overview.webp)



您可以在几种渲染模式之间选择：

| 模式                        | 含义                    | 说明                                                     |
| :-------------------------: | :------------------------: | :-------------------------------------------------------------: |
| [光照 (PBR)](#pbr)           | 基于物理的渲染 | 灯光、阴影、环境，以及绘制的金属度和粗糙度   |
| [材质捕捉](#matcap)           | 材质捕捉（Material Capture）           | 适合雕刻的快速模式，GPU/CPU 占用比 PBR 更低        |
| [不受光](#unlit)             | 表面颜色              | 只显示表面颜色，没有着色和光照                  |
| [对象 ID](#object-id)     | 对象 ID                  | 每个对象一种随机颜色，在绘画软件中很有用。    |
| [实例 ID](#instance-id) | 实例 ID                | 每个实例一种随机颜色，用来识别共享的网格   |

如果您想进一步了解金属度和粗糙度，请参阅[顶点绘画](painting.md)一节。

---

![](/images/shading_second.webp)

### ![](/icons/group_gray.webp) 面组 {#face-group}
叠加显示面组颜色。面组是带颜色的多边形选区，可以用[面组](tools#facegroup)工具创建，大多数基本体也会自动生成面组。

当面组可见时，有些工具会自动按面组进行过滤。

### ![](/icons/palette.webp) 显示绘画 {#show-paint}
Nomad 可以把颜色、粗糙度、金属度存储在雕塑的顶点中。您可以用这个复选框全局切换这些属性的显示。

注意，如果同时有顶点属性和纹理，并且两者都已启用，它们的值会相乘。

### ![](/icons/shield.webp) 显示蒙版 {#show-mask}
切换[蒙版工具](tools#mask)的灰度蒙版叠加显示。停用时，蒙版也会随之停用。这样您可以在没有蒙版的情况下快速修改，之后再启用它，蒙版也不会丢失。

### ![](/icons/tool_hide.webp) 使用隐藏 {#use-hide}

切换隐藏的面。注意，只有在您**不在**隐藏工具中时才有效！

### ![](/icons/image.webp) 使用纹理 {#use-textures}

在 Nomad 中，可以通过[材质](material)菜单给对象指定纹理。如果已经指定了纹理，可以用这个复选框全局切换它们。

您无法在 Nomad 中创建或编辑纹理，但导入文件中的纹理可以使用。不透明度纹理在光照、材质捕捉和不受光模式下有效；法线贴图在光照和材质捕捉模式下有效；颜色在光照和不受光模式下有效；自发光、粗糙度和金属度只在光照模式下有效。场景中没有纹理时，这个按钮会显示为灰色。

### PBR 和灯光概述 {#pbr}
本手册不会深入讲解基于物理的渲染（PBR）的细节。

需要记住的重要一点是，光照和材质是完全分开的。
也就是说，您可以绘制对象的颜色、粗糙度和金属度，而光照则独立处理。
这样您可以先给对象上色，之后再调整光照，而不会破坏模型的整体外观。

灯光、环境和雾只在 [PBR 模式](#pbr)下可用。
出于性能考虑，移动端最多只能有 4 盏灯，桌面端最多 6 盏。

::: tip
您可以加载包含更多灯光的 glTF 文件，Nomad 会保留所有灯光。
不过性能未必理想。
:::

::: tip
您可以让对象不受光或自发光，再在[后期处理](postprocess)菜单中启用全局光照，以此模拟出许多灯光。
:::

### 灯光类型概述 {#light-types-overview}

目前支持以下几种灯光类型：

| 模式                        | 说明                                             | 能否投射阴影 |
| :-------------------------: | :-----------------------------------------------------: | :--------------: |
| [定向光](#directional) | 无限远处的太阳光                           | 能              |
| [环境](#env-light)   | 与环境 HDR 相匹配的远处光源  | 能              |
| [聚光灯](#spot)               | 锥形的灯光                                      | 能              |
| [点光源](#point)             | 向四面八方发光的点光源                         | 能              |

#### ![](/icons/sun.webp) 定向光 {#directional}
它从无限远处发出强度均匀的光。
它在场景中的 3d 位置无关紧要，只有它的朝向才有影响。

您可以把这盏灯附加到相机上，这样光照就会保持一致。
例如，可以用它来做一盏轮廓光（从模型背后朝相机方向照射的强光），让它始终照亮模型的背面。

#### ![](/icons/panorama.webp) 环境光 {#env-light}
使用[环境 HDR](#environment) 很适合营造整体的柔和光照，但如果 HDR 中有一个明显的强烈光源，它产生的阴影会非常柔和，常常根本看不出来。把定向光与环境 HDR 搭配使用会有帮助，但很难让两者对齐。

这盏灯会替您完成这项工作。它会自动旋转，对准 HDR 中最亮的部分，然后您可以分别控制它的强度和角度（阴影的柔和度）。

#### ![](/icons/spotlight.webp) 聚光灯 {#spot}
聚光灯朝单一方向发光，光线被限制在一个锥形范围内。

#### ![](/icons/light.webp) 点光源 {#point}
点光源向所有方向发光，也能投射阴影。

#### 阴影 {#shadows}
每盏灯都能投射阴影，您可以在它的[设置](#light-extra-controls)中选择阴影的计算方式。如果看到阴影瑕疵，那里的 `容差` 滑块可以帮上忙。

阴影的质量取决于对象相对于整个场景的大小。
如果场景中有一个不需要投射阴影的大对象（例如一块大平面），请务必在它的[材质设置](material.md#casts-shadows)中关闭投射阴影。

## ![](/icons/sun.webp) 灯光 {#lights}

![](/images/shading_lights.webp)

### ![](/icons/checked.webp) 灯光复选框 {#lights-checkbox}

切换场景中所有直接光源的开关。



### 添加灯光 {#add-light}

向场景添加一盏灯，移动端最多 4 盏，桌面端最多 6 盏。添加灯光后，会显示带有按钮的灯光列表，视口顶部也会出现一个灯光工具栏。

![](/images/shading_lights_icons.webp)

* 文字显示灯光的名称和亮度。点击它即可选中这盏灯。
* 眼睛图标用于切换可见性。
* 铅笔图标可以重命名这盏灯。
* 垃圾桶图标会删除这盏灯。
* 复制图标会复制这盏灯。
* 三点图标会打开完整的灯光编辑器。其中大部分功能也可以在视口中出现的工具栏里找到。

您也可以在列表中拖动灯光来调整顺序。

### ![](/icons/spotlight.webp)  图标 {#icons}

切换视口中灯光图标的显示。

### 灯光工具栏 {#light-toolbar}
![](/images/shading_lights_toolbar.webp) 

选中一盏灯时，这个工具栏会出现在视口顶部。

* `可见` 用于切换灯光的可见性。
* 定向光/环境/聚光灯/点光源用于更改灯光类型。点击可循环切换，长按可显示菜单。
* 强度控制灯光的强弱，数值可以超过 1.0 以获得非常强的灯光，配合后期处理中的全局光照使用时很有用。
* 点击色块会打开颜色选择器。Nomad 提供了多种选择颜色的方式。开尔文控件提供了一种自然的方式来选择暖色或冷色的光照。
* 阴影用于切换阴影。
* 角度（_定向光和环境光_）或尺寸（_聚光灯和点光源_）设置灯光的宽度。灯光越宽，投射的阴影越柔和，光照越柔和，对象上的高光也越柔和。
* 跟随方式（_仅定向光_）、锥角和柔和度（_仅聚光灯_）会在下文的[灯光编辑器](#light-extra-controls)中介绍。
* ... 会打开 `克隆`、`重新定位` 和 `删除`，以及阴影设置。

### 灯光的更多控制 {#light-extra-controls}

![](/images/shading_extra_controls.webp) 

列表中某盏灯的三点图标会打开它的完整编辑器。注意，有些选项只适用于特定的灯光类型。

* `定向光/环境/聚光灯/点光源` 可以更改灯光类型。
* 点击 `色块` 会打开颜色选择器。
* `强度` 控制灯光的强弱。
* `跟随方式`（_仅定向光_）设置灯光是固定在世界中（`固定`），还是跟随相机（`随相机移动`）。例如，如果您在角色背后用一盏定向光作为轮廓光，选择跟随相机后，无论怎样旋转相机，灯光始终都在角色背后。
* `柔和度`（_仅聚光灯_）控制聚光灯锥形边缘的锐利程度。0 表示边缘非常锐利；1 表示非常柔和，从边缘向光锥中心渐变。在视口中，可以拖动聚光灯锥上的蓝色小圆点来交互式地设置柔和度。
* `锥角`（_仅聚光灯_）控制聚光灯的张开角度。角度小时是一束很细的光，170 时光线会非常宽地散开。在视口中，可以拖动橙色圆点来交互式地设置锥角。
* `角度`（_仅定向光和环境光_）是灯光的视大小，可以理解为太阳在天空中看起来有多大。角度越大，阴影越柔和，高光越宽。
* `尺寸`（_仅聚光灯和点光源_）是灯光的宽度。灯光越大，阴影越柔和。
* `显示阴影` 用于切换当前灯光的阴影。
* 阴影类型决定阴影的计算方式。`阴影贴图` 从灯光的视角渲染场景，所以相机看不到的几何体也能投下阴影。`屏幕空间` 只使用屏幕上已经可见的内容：开销更小，但仍属于实验性功能。一般来说，阴影贴图更可靠。
* `容差`（_仅屏幕空间_）：如果出现阴影瑕疵（阴影看起来没有贴合表面，或者阴影中有噪点和花纹），调整容差可以帮助解决这些问题。
* `接触阴影` 会在物体相互接触的短距离内添加更精确的阴影。设为 `自动` 时，只有场景中最主要的灯光才有接触阴影；`否` 和 `是` 则强制为这盏灯关闭或开启接触阴影。它的 `容差` 滑块与上面的用法相同。

视口工具栏的 `...` 按钮中有同样的阴影设置，另外还有：

* `克隆` 会复制这盏灯。
* `重新定位` 会把灯光移到相机前方，并保持它的朝向。
* `删除` 会删除这盏灯。


## ![](/icons/panorama.webp) 环境 {#environment}

![](/images/shading_environment.webp)

现实世界中的光来自四面八方：天空的蓝、草地的绿、建筑的红，所有这些来自“环境”的光，都可以用环境贴图来模拟。

用标题旁边的复选框开启或关闭环境光照。

Nomad 自带多张室内和室外的示例环境贴图，色调和亮度各不相同。多试几张，看看哪一张最能突显您雕塑的细节。

点击图像即可查看可用的环境贴图。在该对话框中选择 `导入…` 可以加载您自己的贴图。最好使用高动态范围（HDR）图像，格式为经纬度（latlong）或等距柱状投影（equirectangular），文件为 .hdr 或 .exr。浏览器还可以直接从 [Poly Haven](https://polyhaven.com/hdris) 下载环境贴图，那里有大量免费的环境贴图。

### 曝光 {#env-exposure}
调整环境贴图的亮度。与普通灯光一起使用时，环境贴图往往会太亮，降低曝光有助于平衡，尤其是在[后期处理](postprocess)设置中使用全局光照时。

### 旋转 {#env-rotation}

由于环境贴图捕捉了来自所有方向的光，您可以旋转它，让反射和整体光照与雕塑更好地配合。您也可以在视口中用三根手指水平拖动来旋转环境。

### 环境跟随相机 {#env-attached}
把环境附加到相机上。

这会让光照保持一致，在雕刻时会很有用。

### 背景模糊 {#env-background-blur}
只有当[背景](background.md)设为环境时，这个滑块才会显示。它会模糊模型背后的环境图像，而不改变光照。


## ![](/icons/fog.webp) 雾 {#fog}

雾能为场景增添大气纵深感，并让光束变得可见。用标题旁边的复选框启用它。与灯光和环境一样，它只在[光照 (PBR)](#pbr) 模式下可用。

::: tip 更明显的光束
调低雾的 `环境`，并使用明亮的聚光灯或点光源。增大 `密度`，直到雾清晰可见。如果想在较淡的雾中看到光束，把 `散射方向` 设为较高的正值，并让相机朝向灯光。
:::

### 颜色 {#fog-color}
雾的颜色，以及它散射出的光的颜色。

### 密度 {#fog-density}
雾随距离变浓的速度。

### 最大不透明度 {#fog-opacity}
限制雾最多能遮住场景的程度，即使密度很高也不会超过。

### 散射方向 {#fog-scattering}
雾散射光线的方向（也叫各向异性）。正值时，朝灯光方向看雾会更亮；负值时，背向灯光看雾会更亮；为零时，光线向各个方向均匀散射。

### ![](/icons/panorama.webp) 环境 {#fog-environment}
[环境](#environment)对雾的照亮程度。环境关闭时，它会显示为灰色。

### 噪声 {#fog-noise}
在雾中混入噪声，把它打散成一块一块的，而不改变整体密度。噪声大于 0 时，会出现一个 `大小` 滑块来设置图案的大小。

### 形状 {#fog-shape}
雾在场景中填充的范围：

* `均匀` - 填满整个场景。
* `垂直` - 把雾限制在一条边缘柔和的垂直区间内。`底部` 和 `顶部` 滑块设置它下边缘和上边缘的高度，它们的眼睛按钮会在您调整时在视口中显示这个区间。


## ![](/icons/sphere_smooth.webp) 材质捕捉 {#matcap}

![](/images/shading_matcap.webp)

顾名思义（MATerial CAPture，材质捕捉），材质捕捉用一张图像同时包含了光照和材质信息。
由于材质本身已经包含在材质捕捉中，粗糙度和金属度的绘画通道会被忽略。
绘画颜色会与材质捕捉相乘，也就是说，如果您用的是黑色或灰色的材质捕捉，用白色颜料也不会让它变亮。

艺术家们在雕刻时往往偏爱这个模式，因为它能让人专注于形状和几何体本身。

点击球体会打开一个图像浏览器。您也可以添加自己的材质捕捉：一般来说，任何紧密裁剪成正方形的球体照片、渲染图，甚至球体的绘画都可以使用。网上有许多材质捕捉库，[nidorx matcap 库](https://github.com/nidorx/matcaps)是一个很实用的资源。

### 使用全局材质捕捉 {#matcap-global}

艺术家们通常会给整个雕塑使用同一个材质捕捉，但如果停用这个开关，选中的对象就可以拥有自己的材质捕捉。这可以用来做出引人注目的艺术效果。

::: tip
停用此选项，给角色的眼睛用一张眼球的图像吧！
:::

### 旋转 {#matcap-rotation}
材质捕捉是一种特殊的环境贴图，所以和环境贴图一样可以旋转。您也可以随时在视口中用三根手指左右拖动来旋转它。

滑块旁边的锁定按钮会锁定旋转，这样三指拖动就不会意外转动材质捕捉。



## ![](/icons/circle_fill.webp) 不受光 {#unlit}

这个模式只显示表面颜色。当您想确认对象的表面颜色是否符合预期，而不被灯光、阴影、反射、透明度分散注意力时，它会很有用。

这个模式也可以用于非写实的渲染，做出平涂的卡通风格。

## ![](/icons/cube.webp) 对象 ID {#object-id}

所有光照和表面信息都会被忽略，每个对象都以一种独特的纯色显示。如果把它与 PBR 渲染图一起渲染出来，就可以在绘画软件中按颜色选择，从而对特定对象进行颜色校正。

注意，这些颜色也会出现在[场景菜单的树状视图](scene#tree-view)中。

### 随机化 ID {#object-random}

重新生成一组随机颜色。

## ![](/icons/link.webp) 实例 ID {#instance-id}

与对象 ID 相同，但实例会使用相同的颜色。

### 随机化 ID {#instance-random}

重新生成一组随机颜色。
