# ![](/icons/layer.webp) 图层 {#layers}

这个菜单包含图层堆栈，它能以非破坏性的方式保存您对物体所做的修改，还提供了许多组合和再利用图层的方法。

![](/images/layers_overview.webp) 

## 概述 {#overview}

Nomad 的图层有多种用途。

绘画信息（颜色、粗糙度、金属度、不透明度）在图层中的工作方式与 2d 绘画应用类似。您可以新建一个图层，然后在模型上绘画。图层可以开启或关闭、调整不透明度、复制，可以在图层堆栈中调整顺序，也可以调整混合模式。

Nomad 也把图层用于雕刻。图层既可以存储皱纹这样的精细细节，也可以存储大幅度的形体变化，让它们像其他 3d 应用中的混合形状（blendshape / shape key / morph target）一样使用。例如，您可以在不同的图层上雕刻不同的面部表情，再调整图层滑块，把它们组合成新的表情。

在这种情况下，图层中存储的变化纯粹是叠加的，图层顺序不像绘画那样重要。

可以通过[擦除](tools.md#delete-layer)工具局部擦除图层，还可以根据图层中存储的不同信息来创建蒙版。

![](/videos/layer.mp4)

::: tip
与大多数雕刻软件不同，更改网格的拓扑不会丢弃图层。您可以使用[体素网格重构](topology.md#voxel-remesher)、[多分辨率](topology.md#multiresolution)，或者[裁切](tools.md#trim)/[分割](tools.md#split)工具，但请注意，使用[体素网格重构](topology.md#voxel-remesher)时，图层的质量会受到影响。
:::

::: tip
如果您把图层用作混合形状/morph target，[场景菜单](scene.md#object-menu)中还有额外的图层功能：可以把图层分离成物体，也可以把相互匹配的物体合并成图层。
:::
----

## 图层菜单 {#layer-menu}

![](/images/layers_menu.webp)

标题显示所选物体的名称。基本体上不能使用图层，所以请先确认基本体。

按 `添加图层` 创建新图层。`合并图层` 会把所有图层合并到基底网格中，图标旁的数字表示图层的数量。

每个图层都有名称、一个控制强度/系数的滑块，以及一些选项按钮。轻点一个图层即可把它设为当前图层：雕刻和绘画都会写入这个图层。轻点 `基底` 可以重新在基底网格上工作。

### ![](/icons/sort_right.webp) 展开列表 {#ui-expand-list}

默认情况下，图层列表只显示每个图层的可见性、混合模式和强度，当前图层会展开显示全部控件。标题左侧的箭头可以展开所有图层的全部控件。

![](/images/layers_expand.webp)

### 选项 {#options}

| 操作       | 图标                         | 说明                                         |
| :----------: | :--------------------------: | :-------------------------------------------------  |
| 可见      | ![](/icons/eye_open.webp)   | 显示/隐藏图层                                 |
| 混合模式   | ![](/icons/opacity.webp)    | Photoshop 风格的混合模式。4 个图标分别显示颜色、粗糙度、金属度、不透明度的模式。                                 |
| 重命名    | ![](/icons/pencil.webp)     | 编辑图层名称                                 |
| 删除       | ![](/icons/trash.webp)      | 删除图层                                    |
| 复制    | ![](/icons/clone.webp)      | 复制图层                                 |
| 向下合并   | ![](/icons/merge_down.webp) | 将图层与下方的图层（或基底网格）合并 |
| 更多         | ![](/icons/more.webp)       | [更多……](#more)选项                            |

当图层没有展开时，`重命名`、`删除`、`复制` 和 `向下合并` 位于它的[更多……](#more)菜单中。

要把图层移到图层堆栈的其他位置，请按住它的名称，然后拖动。

### 基底 {#base}

`基底` 一行的三点按钮中有一个 `基底 → 图层` 按钮，可以把基底网格上的绘画移到一个新图层中。之后基底会重置为背景材质。如果您在创建任何图层之前已经画了很多，这个功能会很方便。

* 旁边的蒙版和隐藏按钮可以让被蒙版和被隐藏的区域保持不变。
* `抽壳` - 要移动的通道：`颜色`、`不透明度`、`粗糙度` 和 `金属度`。
* `背景材质` - 启用后，只移动与该材质不同的数值。可以用滑块设置它，或者用吸管从模型上拾取。

### ![](/icons/more.webp) 更多…… {#more}

“更多……”按钮会显示当前图层的额外选项，分为两个标签页：设置（齿轮图标）和抽壳（立方体图标）。

![](/images/layers_more.webp) 

#### 通道系数 {#channel-factors}

这些控件可以缩放图层中雕刻/颜色/粗糙度/金属度/不透明度的量。这些数值会与图层系数滑块相乘，例如图层强度为 1，而颜色通道系数为 0.5，那么显示的颜色就是 0.5 的强度。

`偏移` 控制图层的雕刻强度。颜色/粗糙度/金属度被限制在 0 到 1 之间，而偏移可以是任何值，正负都可以。

::: tip
偏移可以把一层凸起变成一层凹陷，或者把笑脸变成皱眉：
![](/videos/layer_happysad.mp4)


对称的图层可以先克隆，再用擦除工具分成左右两个形状：
![](/videos/layer_leftright.mp4)

偏移系数为负的图层可以烘焙到空图层中，得到新的正向形状。

偏移系数大于 1 的图层可以用来尝试更夸张的混合形状。
:::

::: warning
目前图层的 3 个通道（颜色/金属度/粗糙度）共用同一个不透明度通道。
如果您合并多个图层，而这些图层的各通道强度并非全部为满，最终结果可能会看起来不一样。

也许将来每个通道都会有自己的 Alpha 通道，以消除这个限制。
:::


#### ![](/icons/shield.webp) 蒙版 {#mask}
每个滑块旁的蒙版按钮会根据该通道创建蒙版。这类似于在绘画应用中用图层来创建选区，让您可以把在图层中完成的工作再用于其他操作。

#### ![](/icons/preview.webp) 预览 {#preview}
![](/images/layers_preview.webp) 

以下选项位于“更多……”菜单的抽壳标签页中。

启用后，会预览这个图层的抽壳设置（见下一部分）。

`X光` 用来选择预览期间哪些物体变为透明（`无`、`未选择`、`已选` 或 `全部`），让抽出的形状保持实心显示。如果您使用的是负的抽壳高度，这会很有用。

#### ![](/icons/mask_extract.webp) 抽壳 {#extract}
![](/images/layers_extract.webp) 

![](/videos/layer_shell.mp4)

`抽壳` 按钮会把图层的内容复制成一个新物体，通常带有下一部分中由您设定的厚度。

`关闭操作` 决定复制的方式：

* `无` - 只抽出这部分，不尝试生成侧面或填补任何孔洞。
* `填补` - 用三角形填补孔洞并做平滑处理。不要在平坦的表面上使用这个选项。
* `抽壳` - 使用厚度值和方向选项来封闭抽出的形状。
* `层` - 抽出图层的差异部分。

#### ![](/icons/height.webp) 高度 {#thickness}
![](/images/layers_thickness.webp) 

外壳挤出的深度。正值从表面向外长出，负值向表面内部长入。当关闭操作为 `层` 时，这个选项会隐藏。

数值旁边的加号/减号用来设置挤出的方向：
* 减号（-）从当前表面开始向下挤出。
* 加号（+）从当前表面开始向上挤出。
* 加减号（±）会把挤出的顶面和底面以相同的距离向两侧推开，使它有一半嵌在原表面中。

#### 侧面 {#edge-loop-side}
![](/images/layers_edgeloop.webp) 

当关闭操作为 `抽壳` 时，会显示这一部分。

`侧壁分段` 设置外壳侧面上的分段数。开启它的 `自动` 开关后，Nomad 会自动计算循环边的数量，以生成接近正方形的多边形。

#### 平滑度 {#smoothness}
![](/images/layers_smoothness.webp) 

如果要抽出区域的边缘参差不齐，启用这个选项可以把它们平滑成更好看的形状。`全部` 会平滑整个抽出的表面，`仅边界` 只平滑它的边缘。`迭代次数` 设置平滑的强度。

_“更多……”子菜单到此结束。_

### ![](/icons/cog.webp) 高级设置 {#advanced}
![](/images/layers_advanced.webp)

当物体有图层后，菜单底部会出现 `高级设置` 按钮。

#### 保留顶层图层细节 {#keep-top-layers-details}

确保在对下层做大幅修改时，上层的细小细节仍然可见。雕刻时，来自上层的形变会被忽略，但它们的细节保持可见。只有当这些上层保存的是相对较小的细节时，效果才会好。

默认情况下，如果您在一个图层上雕刻了细小的皱纹，然后又去对基底层做了大幅修改，这些皱纹就会丢失。开启这个开关后，这些细小细节会始终浮在下层的大幅变化之上。在下面的视频中可以看到，默认情况下皱纹细节会被抹掉，而启用“保留顶层图层细节”后，它们仍然可见：

![](/videos/layers_details.mp4)


#### 同步变换 {#sync-transform}

开启后，当您使用轴向变换或自由变换工具时，所有未选中的图层都会根据变换的旋转、缩放和倾斜进行调整。它可以设置为 `自动`、`否` 或 `是`。

如果其他图层不应该受到您正在应用的新变换影响，请关闭这个选项。

设置为 `自动` 时，只调整可见的图层。
