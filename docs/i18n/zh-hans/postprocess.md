# ![](/icons/postprocess.webp) 后期处理 {#post-process}

这个菜单控制着 Nomad 的许多方面，用来改变渲染的观感。

![](/images/postprocess_overview_drac.webp)

使用后期处理可以大幅改变场景的最终观感。

![](/images/postprocess_overview.webp)
*同一个场景在后期处理前后的对比，没有添加额外的灯光，也没有修改材质。*

后期处理可能会严重影响性能，具体取决于您的设备。
有一个全局的 `后期处理` 复选框可以关闭所有后期处理，这样您就能快速回到雕刻和建模，又不会丢失预设。
进行 PBR 渲染时，应该启用[环境光遮蔽](#ambient-occlusion-ssao)、[反射](#reflection-ssr)和[色调映射](#tone-mapping)。

不过，大多数时候您在雕刻时会希望关闭后期处理，把注意力集中在形体本身上。


## 质量 {#quality}

![](/images/postprocess_quality.webp)

这些选项会以牺牲性能为代价提升渲染质量。

### 最大帧采样量 {#max-frame-sampling}
Nomad 渲染单帧时只会计算一定量的后期处理，画面可能会有噪点。这个控件决定渲染多少帧，再把它们混合在一起，以去除大部分噪点。有些效果不需要额外的采样（例如调色），而软阴影和全局光照等效果可能需要数百次采样才能完全没有噪点。

在视口中，只要不去操作 Nomad 就能看到这个过程：图像质量会逐渐提高，直到达到最大采样数，然后停止。停止之后 Nomad 就不再做任何计算，可以节省电量。在[文件菜单](files)的渲染部分点击“导出 PNG”时，也会使用这个计算次数。

滑块旁边的复选框用来开启或关闭帧采样。

### 实时渲染分辨率 {#resolution-multiplier}
这个滑块控制渲染的分辨率。x1.0 表示按设备的像素分辨率进行渲染。x0.5 表示以一半的分辨率渲染，速度快但质量低。大于 1 的值会先以更大的尺寸渲染，再缩小。这样质量更高、噪点更少，但渲染时间更长。

它对性能影响很大，所以尽量保持在 x1.25 或以下。这个值不会保存在设置中，而且[像素画](#pixel-art)效果会覆盖它。

### ![](/icons/intensity.webp) 最大采样值 {#max-samples}

提高后期处理效果的质量，但会牺牲性能。

### ![](/icons/material_dithering.webp) 抖动 {#dithering}

对像素进行抖动，减少色带瑕疵（例如渐变或晕影中的色带）。通常应该启用，但在某些特定操作中可以关闭（例如导出深度图或其他与数据相关的操作）。

### ![](/icons/denoise.webp) 去噪器 (oidn) {#oidn}

在所有帧累积完成后对图像进行去噪。这样您就可以使用低得多的采样数。去噪非常消耗处理器资源，所以只在图像有噪点时才启用它。并非所有设备都支持这个功能。

## 预设浏览器 {#preset-browser}
![](/images/postprocess_presets.webp)
点击 `后期处理` 标题下方的图像，会显示一组后期处理预设。使用 `新建` 可以根据当前设置创建预设。内置预设只能克隆：要定义自己的预设，请选中一个预设，点击 `克隆`，然后进行修改。当预设有尚未保存的更改时，会显示 `更改未保存！`；要保存，请点击预设图像，在预设浏览器中再点击一次，然后选择 `保存`。

## 快捷栏 {#shortcut-bar}
启用后期处理后，菜单底部会有一个列出所有效果的栏（`SSR`、`SSGI`、`SSAO`、`DoF`、`泛光效果`……）。轻点其中一个即可跳转到对应部分。已关闭的效果显示为灰色，因此这个栏也是对当前预设效果的快速概览。

## ![](/icons/postprocess_ssr.webp) 屏幕空间反射（SSR） {#reflection-ssr}
启用这个选项后，物体可以反射场景中的其他物体，前提是这些物体在屏幕上可见。
如果场景中有金属感强、有光泽的物体，那么很可能应该使用这个选项。
这个选项需要[光照 (PBR)](shading.md#pbr)着色模式。

## ![](/icons/postprocess_ssgi.webp) 全局光照（SSGI） {#global-illumination-ssgi}

全局光照模拟光线在表面之间的反弹，例如红色的墙会把红色投射到附近的白色物体上。与环境光遮蔽和反射一起使用时，可以大大增强渲染的真实感。和反射一样，它需要[光照 (PBR)](shading.md#pbr)着色模式。

`强度` - 全局光照的强度。

## ![](/icons/postprocess_ssao.webp) 环境光遮蔽（SSAO） {#ambient-occlusion-ssao}
环境光遮蔽会让光线较难到达的区域（角落等）变暗。
这个效果只取决于模型的几何形状。

* `强度` - 效果的强度。
* `范围` - 效果扩散的范围。
* `厚度` - 假定遮挡物在深度上有多厚，以 `范围` 的百分比表示。
* `色调` - 与遮蔽相乘的颜色，用于创意效果。


| 关闭 SSAO                    | 开启 SSAO                    |
| :-------------------------: | :------------------------: |
| ![](/images/ssao_off.webp) | ![](/images/ssao_on.webp) |

::: tip
AO 在主要由环境光照亮的区域最明显。处于强烈直射光下的区域，AO 效果会弱很多。

:::

## ![](/icons/postprocess_dof.webp) 景深 {#depth-of-field-dof}
为焦点以外的区域添加模糊效果。

只需轻点模型即可更改焦点。

* `光圈模式` - 用单一的相机光圈来控制模糊，而不是使用下面两个模糊滑块。
* `光圈`（_仅限光圈模式_） - 镜头的光圈值（f 值），和真实相机一样。数值越小，光圈开得越大，模糊越强。
* `远景模糊` - 焦点远侧的模糊程度。
* `近景模糊` - 焦点与相机之间的模糊程度。


| 关闭景深                   | 焦点在远处的圆环       | 焦点在近处的圆环    |
| :-----------------------: | :-------------------------: | :------------------------: |
| ![](/images/dof_off.webp) | ![](/images/dof_near.webp) | ![](/images/dof_far.webp) |


## ![](/icons/sun.webp) 泛光效果 {#bloom}
泛光会让场景中明亮的区域发光。

* `强度` - 效果的强度。
* `范围` - 效果扩散的范围。
* `阈值` - 像素要多亮才会开始泛光。为 0 时所有东西都会泛光，设置得越高，只有最亮的像素才会泛光。
* `色调` - 可以添加到泛光中的颜色，用于创意效果。

| 关闭泛光                    | 泛光范围为 0         | 泛光范围为 1         |
| :--------------------------: | :-------------------------: | :-------------------------: |
| ![](/images/bloom_off.webp) | ![](/images/bloom_r0.webp) | ![](/images/bloom_r1.webp) |


## ![](/icons/postprocess_tone.webp) 色调映射 {#tone-mapping}
色调映射是一种把 HDR 数值重新映射到 `[0, 1]` 范围的操作。
如果不使用它（或者选择 `无`），任何大于 1 的颜色分量都会被截断。
超出这个范围的颜色变化也就会丢失。

* `无/中性/Agx/ACES` - 使用哪种色调映射器。`无` 不做任何重新映射（但其他控件仍然有效）。其他选项就像选择不同的胶片，会以不同方式处理过曝的数值和颜色。这是一个很深的话题，想了解更多，可以搜索色调映射、Agx、ACES！
* `曝光` - 图像的整体亮度，类似于调整相机的光圈。这是一种整体提亮或压暗图像的快捷方法。
* `饱和度` - 颜色的浓度。1 为不变，0 为单色，大于 1 的值饱和度越来越高。
* `对比度` - 让暗部更暗、亮部更亮。请谨慎使用，数值较高时可能会产生瑕疵。

请注意，关闭 `色调映射` 后，一些细节会因为像素过亮而消失。

| 关闭色调映射            | 开启色调映射            |
| :-------------------------: | :------------------------: |
| ![](/images/tone_off.webp) | ![](/images/tone_on.webp) |

::: tip
色调映射可以增强全局光照的效果。如果调低环境贴图的强度、调高主光源，就可以提高色调映射的 `曝光`，看到更多反弹光的效果。
:::

## ![](/icons/postprocess_cavity.webp) 曲率描边 {#curvature}
检测曲率急剧变化的地方，并给这些区域上色。

* `系数` - 效果的整体强度
* `凸起` - 检测尖锐凸起变化的程度，并在那里放置所选颜色（默认为白色）
* `凹陷` - 检测凹陷变化的程度，并在那里放置所选颜色（默认为黑色）
* `厚度` - 检测到的边缘有多宽。

`凸起` 和 `凹陷` 旁边有一个颜色色块用于选择颜色，还有一个小按钮用于选择该颜色与图像的混合方式。


| 关闭曲率描边                    | 开启曲率描边                   |

| ![](/images/curvature_off.webp) | ![](/images/curvature_on.webp) |
