# ![](/icons/camera.webp) 相机 {#camera}

在这个菜单中，您可以创建和修改相机，还可以控制与相机交互的方式。

![](/images/camera_overview2.webp)

Nomad 中的相机有多种用途：

* 设置好视角，以便从精确的角度进行雕刻
* 像照相机一样为物体取景
* 作为第一人称视角的相机在场景中漫游
* 作为正交相机，用于等距视角游戏或工业风格的渲染。

## 控制相机 {#control}

### 旋转 {#rotation}
用*一根*手指在背景上拖动即可旋转相机。
如果手指在模型上拖动，则会开始雕刻操作。

::: tip 如果碰不到背景，还能旋转相机吗？
可以。把*两根*手指放在屏幕上（就像要开始平移/缩放手势那样），然后松开*一根*手指即可。
:::

### 聚焦/重置 {#focus}
在模型上*双击*，可以聚焦到点中的位置。
如果在背景上*双击*，相机会改为聚焦到所选网格或整个场景，参见[双击背景](#dtap-tap-background)。


### 平移 {#translation}
移动*两根*手指即可平移相机。


### 缩放 {#zooming}
使用双指捏合手势可以放大/缩小。


### 滚转 {#rolling}
旋转*两根*手指可以*滚转*视图。
::: warning
这个手势只在 `轨迹球` 旋转模式下可用。
:::

### 桌面端操作 {#desktop}

在桌面端，alt/opt 键用来控制相机：

* 笔尖在空白处拖动 = 旋转相机
* alt + 笔尖拖动 = 平移
* alt + 笔尖拖动，然后松开 alt = 缩放（与 ZBrush 相同）

如果您使用的 Wacom 数位板的笔上有 2 个或更多按键，可以在 Wacom 设置中这样配置笔尖和按键：

* 笔尖 = 左键单击
* 下侧按键 = 中键单击
* 上侧按键 = 右键单击

这样设置后，只用笔就能操作相机：

* 按住上侧按键并悬停移动 = 旋转相机
* 按住下侧按键并悬停移动 = 平移

## 相机控制 {#camera-controls}

![](/images/camera_list.webp)

### 视图 {#views}
使用 `添加视角` 可以保存相机视角。
点击视角的名称，相机就会恢复到该视角。


::: tip
保存的视角会同时保存[投影类型](#projection)设置和[参考图像](background.md)。  
如果您想在带有不同背景的正面/侧面/背面参考视图之间来回切换，这会很有用。
:::

| :---------: | :---------------------------: | :-------------------------------------------------------------------------: |
| 可见性  | ![](/icons/eye_open.webp)    | 开关相机。隐藏的相机会被“上一个/下一个”按钮跳过 |
| 名称        |                               | 选择相机                                                           |
| 图像       | ![](/icons/image.webp)       | 与相机关联的参考图像的缩略图              |

### ![](/icons/camera_add.webp) 添加视角 {#add}
根据当前视图创建一个新相机。

### ![](/icons/camera.webp) 图标 {#icons-test}

切换是否在视口中显示相机图标。有了相机之后，这个按钮会出现在 `添加视角` 旁边。被选中的相机，其图标始终可见。

### 投影类型 {#projection}
在 `透视视图` 和 `正交视图` 之间选择。

在透视模式下，您可以更改相机的 `垂直视角`（视野）。滑块上方会显示对应的 35mm 相机焦距，如果您熟悉摄影，这会很方便。
雕刻时通常建议使用较小的视角，这有助于把握比例。  
`正交视图` 模式大致相当于视角为 0。

### 第一人称视角 {#fps}
仅限透视模式。启用后，旋转中心直接设在相机上，而不是雕刻作品上。在背景上拖动手指时，相机位置保持锁定，只改变朝向，就像第一人称游戏那样。适合雕刻场景环境，而不是单个物体。

![](/images/camera_rotation_ortho_view.webp)

### 旋转类型 {#rotation-type}
相机默认使用 `转盘` 旋转模式。
这意味着您只有两个自由度，更直观，但有些情况下您会需要更大的灵活性。  
您可以切换到 `轨迹球`，这样就能在视口中旋转*两根*手指来*滚转*视图。`轨迹球` 有两种模式：第一种像在手指下滚动一个球那样转动视图，第二种（带箭头图标）则根据拖动的水平和垂直移动来转动视图，有些用户可能会觉得更顺手。

### 吸附到正交视图 {#orthographic}

启用后，如果您有键盘，在旋转视图时按住 Shift，相机就会吸附到最近的前/后/上/下/左/右视图，并切换为正交相机。点击导航器吸附到前/后/左/右/上/下视图时，相机同样会切换为正交。

### 重置视图 {#reset}

把相机移到正面，并让整个场景适配视图

### 吸附视图 {#snap}
吸附到最近的前/后/左/右/上/下视图。如果已经处于其中一个视图，再次点击会转动 180 度，吸附到对面。

### 相机速度 {#speed}

如果觉得相机移动太慢或太快，可以为 `旋转`、`缩放` 和 `平移` 设置速度倍数。当雕刻作品非常大或非常小时会很有用。

### 轴心概述 {#pivot}

旋转相机时，您会看到一个粉色小点，这就是相机的轴心。  
了解轴心在哪里非常重要，这样您就不会在操作相机时迷失方向或感到烦躁。

默认情况下，轴心会通过以下操作更新：
- 在模型上双击
- 在背景上双击（新的轴心会位于网格的中心）
- 把*两根*手指放在屏幕上（平移/缩放/滚转）时，轴心会更新到*两根*手指的中点

### 更新轴心… {#update-pivot}

您可以通过以下选项进一步自定义轴心的更新方式：

* `相机开始移动时` - 开始与相机交互时更新轴心。
* `隔空新建轴心` - 即使缩放到物体表面以外，也允许设置新的轴心。需要开启 `相机开始移动时`。
* `双击后更改` - 在物体表面上双击时更新旋转轴心。
* `雕刻（笔触）` - 雕刻时更新轴心。

::: tip
熟悉之后，您可以在[设置](settings.md)菜单中隐藏这个（提示用的）粉色小点。
:::

### 缩小视图时居中视图 {#center-view-when-zooming-out}
缩小视图时，相机不会横向平移，只会向后移动，因此视图始终保持居中。

### 双击对象 {#dtap-object}
启用后，双击物体会让相机聚焦到点中的位置。

### 双击背景 {#dtap-tap-background}
启用后，双击背景会让相机聚焦到：
* `选区` - 所选的物体。
* `场景` - 整个场景。
* `切换` - 每次双击时在两者之间切换。有两个 `切换` 选项，区别在于先聚焦哪一个，图标上有显示。
