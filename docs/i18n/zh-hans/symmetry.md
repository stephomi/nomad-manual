# ![](/icons/symmetry.webp) 对称 {#symmetry}

这个菜单控制笔触如何沿镜像平面、以径向或以瓦片方式重复，还提供了让不对称的物体恢复对称的方法。

![](/images/symmetry_overview.webp) 

## 概述 {#overview}
对称有多种用法：

* 作为镜像，沿 X（左/右）、Y（上/下）、Z（后/前）或它们的组合来翻转您的操作。
* 可以在 X、Y、Z 上设置径向对称并指定重复次数，例如用来雕刻海星。
* 瓦片会在物体上重复您的笔触，让雕刻结果无缝拼接。
* 镜像可以围绕原点（称为世界模式）或围绕物体的中心（称为本地模式）进行。
* 一开始不对称的雕刻作品，可以强制让它变得对称。

左侧快捷面板上也有一个开关对称的快捷按钮（*“对称”*）。上面的小字“L/W”表示 Nomad 当前处于本地（Local）还是世界（World）对称模式。您也可以长按，或朝屏幕中心轻扫，调出一个菜单。

![](/images/symmetry_button.webp) 

对称设置随每个物体一起保存，菜单标题会显示您正在编辑的物体的名称。
雕刻工具共用同一个开关状态，而变换类工具（[自由变换](tools.md#transform)和[轴向变换](tools.md#gizmo)）有各自独立的开关状态。

::: tip
对称菜单主要用于控制笔触的对称。您还可以通过[场景菜单中的重复器](scene#repeaters)来镜像和重复物体。
:::

## ![](/icons/symmetry.webp) 启用 {#enabled}
开关镜像模式，与左侧快捷面板中的 `对称` 按钮作用相同。关闭时会有一个警告图标提醒您；如果当前工具不适用对称，菜单也会告诉您。

## 平面 {#planes}

启用对称平面，并设置径向对称的重复次数。请注意，不必只选择一个平面，您可以同时启用 1 个、2 个或全部 3 个平面，实现复杂的对称。

`径向` 一行设置绕每个轴进行径向对称的重复次数。同样，它们也不限于单个轴，甚至可以与平面对称组合使用，非常快速地生成丰富的细节。（重复的总次数上限为 200）

![](/videos/symmetry_demo.mp4) 

## 瓦片 {#tile}

沿某个轴以固定的间隔重复您的笔触，让雕刻结果无缝拼接。适合制作图案、砖块，或打算重复使用的纹理。

用 `瓦片` 按钮为每个轴开启瓦片，然后设置 `数量`（在物体上重复多少次）或 `距离`（两次重复之间的间隔）。轻点左侧的开关可以在两者之间切换。

## 类型 {#method}
镜像可以是 `本地` 的，随物体一起移动；也可以是 `世界` 的，保持不动。如果不确定需要哪种模式，可以观察叠加在物体上的镜像平面和径向指示线。在本地模式下，如果您使用变换类工具（`轴向变换` 或 `自由变换`）移动模型，镜像指示线也会随之移动。在世界模式下，镜像指示线保持固定，物体会从中滑过。

## 镜像 {#mirroring}
![](/images/symmetry_mirroring.webp)

在对称平面附近雕刻时，有些笔刷的对称效果不够完美。在这一部分，您可以把雕刻作品的一侧复制到另一侧，从而恢复对称。

`方向` - `镜像` 标题旁的两个箭头按钮决定把哪一侧复制到另一侧。Nomad 会根据当前视口来计算这一点，因此无论从哪个方向观察模型，屏幕上的那一侧都保持不变。

![](/icons/shield.webp) `蒙版` - 蒙版按钮可以限定镜像的范围：给目标一侧加蒙版可以保护该区域，给源一侧加蒙版则可以阻止该区域被镜像到目标一侧。

![](/icons/tool_hide.webp) `隐藏` - 启用后，源一侧被隐藏的区域不会被镜像到目标一侧。

`镜像`（保持拓扑）会尝试判断镜像两侧的拓扑是否相同，如果相同，就只移动顶点。这是更常见的情况。径向对称会被忽略。如果拓扑不对称，Nomad 会提示改用 `切割 • 镜像` 来强制镜像。

`切割` 按钮会沿对称平面切开物体。它们会改变拓扑，因此比 `镜像` 更具破坏性。每个按钮上的数字表示您会得到多少个物体：

* `切割` - 移除物体的一侧。
* `切割 • 镜像` - 切开物体，复制其中一侧，镜像到另一侧，并沿镜像处焊接顶点。如果模型在镜像两侧差异很大，有时就需要使用这种方法。
* `切割 • 分割` - 切开物体，并把每一侧保留为单独的物体。
* `切割 • 镜像 • 分割` - 与 `切割 • 镜像` 类似，但每一侧都会成为单独的物体。

如果选中了多个物体，`镜像` 和[翻转对象](#flip-object)会应用到所有选中的物体上。

### 翻转对象 {#flip-object}
![](/images/symmetry_flip.webp)
沿 `X`、`Y` 或 `Z` 把左侧变成右侧，右侧变成左侧。效果看起来就像在轴向变换工具菜单中把 X 上的缩放设为 -1。

## 重设与编辑 {#reset-and-edit}

![](/images/symmetry_edit.webp)

对称的位置和朝向是可以编辑的（但不推荐！）。如有需要，`世界中心`（本地模式下为 `对象中心`）和 `方向` 会把对称的位置和朝向重设为默认值。

Nomad 通常知道该把对称平面放在哪里。不建议手动调整，但 `编辑Gizmo` 按钮为高级用户提供了这个功能。点击这个按钮后，会显示一个轴向变换控件，让您平移和旋转对称平面。如果想恢复默认的中心和朝向，请使用上面的重设按钮。

`从枢轴` 会把对称平面放到[轴向变换](tools.md#gizmo)工具的轴心上。只有在 `轴向变换` 工具处于激活状态时才可用。

这些选项的行为会因您所处的空间（*本地/世界*）而不同。
所以，如果效果和预期不一样，请检查自己是否处于正确的空间。

::: tip
用轴向变换控件编辑对称平面还有点实验性质，您大概用不到它！
:::

## 显示选项 {#show-options}
![](/images/symmetry_show.webp)


`显示线条` 和 `显示平面` 用来开关对称位置在视口中的叠加显示。请注意，关闭这些选项后，要等对称菜单关闭时才会生效。
