# ![](/icons/scene.webp) 场景 {#scene}

此菜单用于管理 Nomad 中的对象、灯光、相机和重复器。它以树状视图显示场景层级，让您可以修改对象的许多属性。您还可以在这里创建新对象，并以多种方式合并和拆分对象。


![](/images/scene_menu_summary.webp)

### 树状视图标题栏 {#tree-view-header}

列表上方的一行有几个辅助按钮：

* ![](/icons/sort_down.webp) - 一次性折叠或展开所有组。

### 树状视图操作 {#tree-view-manipulation}

在树状视图中长按某一项，直到它高亮显示。然后您就可以在树状视图中上下移动它，也可以把它拖到另一项上，使其成为那一项的子项。

选中多项时，其中一项是主选择，显示得更亮。长按并拖动其中任意一项，可以一次移动所有选中的对象。

选中一个父项时，默认它的所有子项也会被选中。再次点击父项，可以在“只选父项”和“选中父项及子项”之间切换。

双击某一项，相机会聚焦到它上面（见[高级设置](#focus-on-item)）。

### 多选 {#multiselection}
选择多个对象主要有两个用途：
- 用轴向变换工具一次移动多个对象
- 通过合并和布尔运算组合对象。

在树状视图中，点击每个对象的选择图标，或沿选择列拖动。点击名称时，按住`蒙版`快捷按钮（或键盘上的 `Ctrl`）可以添加或移除单个对象；按住`平滑`快捷按钮（或 `Shift`）可以选中当前对象和您点击的对象之间的所有对象。

::: tip 快速多选
您也可以在视口中按住`平滑`快捷按钮（或 `Shift`）再点击另一个网格来进行多选。

再次点击一个对象可以取消选中它（仅当选中的对象多于一个时）。
:::

轴向变换会把所有选中的对象一起移动，参见[轴向变换](tools.md#gizmo)。


## ![](/icons/merge.webp) 合并 {#join}
这个选项会把选中的多个对象合成一个对象条目。
距离小于[焊接半径](#weld-radius)的点和 UV 会被合并。

您可以在[拆分](#separate)部分的视频中看到示例。

## ![](/icons/bool_subtract_circle.webp) 布尔 {#boolean}
![](/images/scene_boolean_menu.webp) 
把多个对象组合成一个表面。

`体素合并`会保留对象的体积，并在表面上计算出分布均匀的新多边形。由于有这一计算步骤，体素合并可以处理复杂的几何体，但如果目标分辨率不够高，可能会丢失精细细节。

`布尔`会尽量保留多边形原有的布线，只在对象重叠处缝合多边形。这样得到的结果会比体素合并干净、锐利得多，但它要求网格是“水密”的：对象中不能有孔洞或畸形的形状。如果布尔失败，通常改用体素合并就能成功。

### 布尔运算 {#boolean-operations}
体素合并和布尔都通过对象的可见性来控制运算方式，弹窗底部的提示也写明了这一点：

#### 并集 {#union}
两个对象都可见时进行布尔**并集**运算，对象的外表面会合在一起，内部不留任何表面。 ![](/images/boolean_union.webp)

#### 相减 {#subtract}
一个对象不可见 = 布尔**相减**，不可见的对象会从可见的对象中减去。 ![](/images/boolean_subtract.webp)

#### 相交 {#intersect}
两个对象都不可见 = 布尔**相交**，只在两个对象重叠的地方生成新形状。 ![](/images/boolean_intersect.webp)


### ![](/icons/voxel.webp) 体素合并 {#voxel-merge-button}
按下这个按钮，会对所选对象进行体素合并。如果只对一个对象使用，它会把对象重新拓扑为分布均匀的多边形，适合多边形被拉伸的对象。下面的选项与[体素网格重构](topology.md#voxel-remesher)中的相同。

### 分辨率 {#resolution}
计算时使用的体素 3d 网格的分辨率。修改这个数值时，对象上会叠加一层棋盘格图案，用来预览多边形的大小。

滑块旁边的吸管会根据您手指下的网格密度拾取细节。再旁边的按钮会把滑块切换为`边长`，即世界中的尺寸：这样同一个数值在任何对象上都能得到相同的细节。

### 构建多分辨率 {#build-multiresolution}
在目标分辨率之下创建多分辨率级别。比如分辨率为 400、构建多分辨率为 3 时，您会得到一个新网格，大约有 296,000 个多边形，同时在其下还有 3 个细分级别，分别约为 74,000、18,500 和 4,600。

### 加厚细薄部分 {#thicken-thin-parts}
把对体素网格来说太薄的部分加厚，避免它们断开。启用`硬边`或`硬边界`时不可用。

### 孔洞 {#holes}
合并之前如何封闭开放对象上的孔洞：
* `填补` - 每个孔洞从其边界开始单独封闭。
* `形状` - 顺着周围的表面来封闭孔洞，相互重叠的开放部件会连接在一起。

### ![](/icons/angle.webp) 保留硬边 {#keep-sharp-edges}
`硬边`按钮会把体素网格吸附到对象的锐利边缘上。它最适合简单的形状，在某些区域可能会带来变形。

### ![](/icons/group.webp) 硬边界 {#sharp-border}
新的面会顺着面组边界分布，在表面沿边界形成折痕的地方，边界会保持锐利。

### ![](/icons/group_separate.webp) 保持面组分离 {#keep-groups-separate}
每个面组单独重构：面组之间永远不会合并，每个面组都保持为自己组内的一个封闭部件。此模式下不会构建多分辨率。

### ![](/icons/bool_subtract_circle.webp) 布尔按钮 {#boolean-button}
按下这个按钮，会使用 Emmett Lalish 开发的 Manifold 库进行多边形布尔运算。

### ![](/icons/bool_unite_circle.webp) 清理重叠 {#clean-overlaps}
只选中一个对象时，`布尔`按钮会变为`清理重叠`：它会把对象中相互穿插的部分合并成一个干净的表面。


## ![](/icons/separate.webp) 拆分 {#separate}
如果一个对象由多个互不相连的部分组成，您可以把它拆分成多个对象。
这可以看作[合并](#join)的反向操作。

`拆分...`弹窗提供三种拆分所选对象的方式：
* `按部分拆分` - 为每个互不相连的部分创建一个单独的对象。
* `按面组拆分` - 为每个面组创建一个单独的对象。
* `按图层拆分` - 为基础网格和每个图层分别创建单独的对象。

### 基本体工具栏 {#primitive-toolbar}

![](/images/scene_primitive_toolbar.webp)

创建基本体后，会出现一个工具栏，用来控制它的参数。

* `转换` 把基本体固化为标准对象，这样就可以雕刻和绘画了。
* `镜像` 开关在基本体之上放置一个镜像重复器。
* `全部`（眼睛图标） 选择直接显示在基本体上、用来控制其参数的手柄，例如立方体的宽度或圆柱体的孔半径：`无`、`全部`，或根据基本体只显示某一类（半径、孔洞、轮廓……）。
* `分段数` 基本体的分段数，这里是长方体沿 X 方向的分段。
* `恒定密度` 用轴向变换沿某个轴拉伸基本体时，它的尺寸和分段会一起增加，而不是把多边形拉长，因此面保持方正。适用于长方体、平面和圆柱体。
* `...` 显示基本体菜单。

不同的基本体在工具栏上还有额外的选项：

* `球体` 球体是由细分的立方体构成的，这样更适合雕刻，但也意味着它不是完美的圆形。这个选项会强制让形状更接近完美的球体。二十面体也有这个选项。
* `盖帽` 开关形状两端的盖子，例如圆柱体可以在顶部、底部、两端都有盖子，或者都没有。
* `孔洞` 开关是否在形状中心打一个贯穿的孔。会在无孔、单一半径的孔、顶部和底部半径不同的孔之间循环切换。
* `半径` 切换圆柱体是使用单一半径，还是顶部和底部使用不同的半径。
* `圆盘` 切换平面是四边形还是圆形。

主工具栏下方的小工具栏可以在基本体的参数手柄和用于变换的轴向变换之间切换。

::: tip

点击工具栏的标题，可以把它切换到屏幕顶部或底部。点击角落的箭头可以将其折叠。

:::


### 基本体菜单 {#primitive-menu}

![](/images/scene_primitive_menu.webp)

这里包含所选基本体的全部参数。参数是对形状的基本描述。比如要描述一个圆环，您需要描述它的外半径、内半径以及多边形数量。

大多数基本体参数都一目了然，此外还有一些所有基本体共用的参数：

* `UV` 菜单顶部的小 UV 按钮可以开关 UV 坐标的生成
* `转换` 小转换按钮会把基本体固化为标准对象，这样就可以雕刻和绘画了。
* `面数限量` 设置对象多边形数量的上限，以免设备崩溃。
* `后期细分` 应用拓扑菜单多分辨率部分中所选数量的细分。配合较低的拓扑分段数，可以制作出平滑、圆角的基本体。例如，把长方体的拓扑分段设为 2、后期细分设为 4，就能得到一个圆角长方体。
* `线性细分` 设置在使用常规平滑细分之前，先进行多少级线性细分。可以用来控制细分曲面上转角的锐利或柔和程度。例如，把长方体的拓扑分段设为 2、后期细分设为 4，然后把线性细分在 0 到 4 之间调整，长方体的转角会从柔和变为锐利。

### 拓扑参数 {#topology}

这里控制基本体的多边形数量。通常这些控件是联动的，所以调整那一个活动滑块，就会均匀地调整所有多边形。您可以点击取消链接按钮，分别控制形状在 X/Y/Z 方向上的分段。

### 几何 {#geometry}

这里控制基本体的整体尺寸：方形的形状以 X/Y/Z 单位表示，圆形的形状以半径表示。


### ![](/icons/circle.webp) UV球体 {#uv-sphere}
::: warning
UV 球体不太适合雕刻，尤其是在两极处。

请优先使用四边形球、长方体或二十面体[基本体](#primitives)，并配合`投影到球体`选项。

注意，如果把`分段数`滑块设得很低，它的拓扑也还可以用来雕刻。
之后再用`整体细分`滑块提高多边形数量。

虽然不适合一般的雕刻，但它很适合用来做眼睛：把球体旋转到让两极对准瞳孔，多边形的布线就会自然地适合绘制和雕刻虹膜与瞳孔。
:::


### ![](/icons/triplanar.webp) 三平面 {#triplanar}
这个基本体比较特殊，您需要在它上面使用[蒙版工具](tools.md#mask)来塑造几何体。

![](/videos/triplanar.mp4)


::: tip
双击某个平面，相机就会聚焦到这个平面上。
不过，如果您用轴向变换旋转过这个基本体，这个功能就不起作用了。
:::

三平面利用 3 个平面上的蒙版信息填充一个体素网格，然后再将其多边形化（借助[体素网格重构](topology.md#voxel-remesher)）。

每个平面都有自己的对称平面。

::: warning
每次修改三平面基本体的大小，蒙版绘制的质量都会下降。

目前还没有把绘制“锁定”在单个平面上的选项，也许以后会有。
您可以借助[连接拓扑](stroke.md#connected-topology)稍作改善：如果光标正好落在某一个平面上，就不会影响其他平面。
:::

## 重复器 {#repeaters}
![](/images/scene_primitive_repeaters.webp)

重复器是一种节点，会为其下的对象创建实例。

### ![](/icons/array.webp) 阵列 {#array}
![](/images/scene_primitive_array.webp)

对象成为这个节点的子项后，可以按网格布局进行实例化。选中它时，有以下控件：
* `内部适配` - 开启时，所有副本都放在阵列的范围之内；关闭时，滑块用来设置副本之间的间距
* `X/Y/Z 数量` - 每个轴上的实例数量
* `尺寸 X/Y/Z` - 网格沿各轴的尺寸；关闭`内部适配`时，则是副本之间的距离
* `随机化...` - 为副本添加随机变化，参见下面的[随机化](#curve)。

### ![](/icons/curve.webp) 曲线 {#curve}
![](/images/scene_primitive_curve.webp)
这会创建一条曲线，该节点的子项会沿曲线重复。选中它时，有以下控件：
* `曲线` - 编辑曲线：在曲线上添加点，以及移动曲线上的点。
* `显示` - 显示或隐藏曲线及其点。
* `吸附` - 把曲线点吸附到其他几何体上。
* `对称` - 对称地编辑曲线。
* `闭合` - 切换曲线首尾相连，或保持为开放曲线。
* `B样条` - 切换实例是精确沿着曲线分布，还是使用效果更平滑的 B 样条插值。
* `弯曲贴合` - 让每个副本沿曲线弯曲，使副本与相邻的副本相接（`平滑`会弯曲它们的侧面，让它们无棱角地相接）。
* `对齐` - 旋转副本，让它们沿着曲线的方向。
* `轴心` - 副本的轴心：曲线本身（`自身`）或其子项。
* `数量` - 实例数量。旁边的模式按钮可以切换为`距离`：副本之间使用固定间距，数量随曲线长度变化。
* `半径` - 每个曲线点上用来设置实例缩放的控件。
* `扭曲` - 每个曲线点上用来设置实例扭转角度的控件。
* `交替` - 每隔一个副本绕曲线翻转一次：链环用 90°，叶片或拉链齿用 180°，绕您选择的`轴`旋转。
* `螺旋...` - 让副本缠绕在曲线周围，可以分成多股（绳索、辫子、缎带……）。
* `随机化...` - 为副本添加随机变化；每一行也可以改为在每个副本上增加相同的量。

在工具栏下方，`（合并）`开关会在您把一个点拖到另一个点上时将两者合并。`IK`（反向动力学）让您可以给曲线摆姿势：拖动一个点，相连的点会跟着移动。点击一个点可以锁定或解锁它，长按可以锁定或解锁所有点；被锁定的点会保持不动。

### ![](/icons/radial.webp) 径向 {#radial}
![](/images/scene_primitive_radial.webp)

该节点的子项会按圆形排列进行实例化。移动子对象可以改变这个重复器的半径。选中它时，有以下控件：
* 径向 X/Y/Z - 选择这些按钮可以设置径向的轴，并设置实例的数量。



### ![](/icons/mirror.webp) 镜像 {#mirror}
![](/images/scene_primitive_mirror.webp)

该节点的子项会沿某个轴镜像。选中它时，有以下控件：
* 轴向变换 - 启用轴向变换来设置镜像的中心。它也可以旋转和缩放。完成后，再次点击轴向变换即可显示标准控件。
* X/Y/Z - 设置镜像平面

### ![](/icons/surface.webp) 表面 {#surface}

该节点的子项会被复制到某个对象的表面上：每个面、每条边或每个顶点放一个副本，或者随机散布。选中它时，有以下控件：
* 模式 - 把副本放在`面`、`边`或顶点上，或者`散布`它们。
* 每隔 - 每隔 N 个面、边或顶点放一个副本。`随机`会改为随机挑选，`重新随机`则重新抽取一组随机位置。
* 间距 - 散布时，两个副本之间的最小距离。
* 对齐 - 副本顺着表面法线立在表面上，而不是保持原对象的朝向。
* 吸附 - 把原对象投影到最近的表面点上，副本也会跟着移动。
* 匹配尺寸、剪切 - 缩放和拉伸副本，使其贴合每个面的形状。
* 弯曲贴合 - 让每个副本弯曲贴合到它的面上或沿它的边弯曲，使相邻的副本无缝相接。

所有重复器都有一个`转换`控件，它会把重复器的结果固化下来，并询问您如何固化：
* 组合子项 - 实例会合并成一个对象
* 保持实例 - 实例仍然是实例，但不再有重复器作为“父级”
* 去实例 - 实例会被转换为独立的对象

`全部展平`还会把嵌套在这个重复器里面的重复器一起固化，让每个副本都变成普通对象。

::: tip 提示：组合使用重复器
重复器之间可以互相作为父子级，多个对象也可以同时成为重复器的子项，从而做出复杂的效果。

![](/images/scene_repeater_combine.webp)
:::

::: tip 提示：重复器的轴心

有些重复器会尝试自动设置子对象的轴心，所以即使您用轴向变换工具移动或旋转子对象，它们也不会动。如果您需要改变这种行为，可以在重复器和子对象之间插入一个组。这样您就可以独立于重复器来移动子形状了。
:::

## ![](/icons/cog.webp) 高级设置 {#advanced}
面板左下角的`高级设置`按钮会打开一个弹窗，其中有两个标签页：`常规`和`同步`。

### ![](/icons/focus.webp) UI：双击聚焦项目 {#focus-on-item}
在场景列表中双击某一项，相机会在 3d 视图中以该项为中心。

### ![](/icons/eye_open.webp) 同步可见性 {#sync-visibility}
启用后，使用某个选中项的眼睛图标时，会影响所有选中的项。

### ![](/icons/bang.webp) 高亮 {#highlight}
选择发生变化时，在视口中高亮显示所选对象。

### ![](/icons/link.webp) 显示（实例） {#instance-show}
在场景列表左侧显示一个彩色胶囊，用来标示实例。

### ![](/icons/preview.webp) 对象预览 {#object-previews}
在场景列表中为每个对象显示一个渲染缩略图。与列表上方的预览按钮作用相同。

### 焊接半径 {#weld-radius}
在`合并`标题下，有`位置焊接半径`和`UV 焊接半径`：距离小于这些半径的点和 UV 会被合并。每一项都可以用它的勾选框关闭。这适用于合并、布尔、裁切、网格简化、重构以及文件导入。

### 图标 {#icons}
设置视口中组、灯光、相机和重复器图标的最小和最大`尺寸`以及`不透明度`。

### ![](/icons/hierarchy.webp) 层级线 {#hierarchy-lines}
在视口中显示父项与其子项之间的连线。启用后，您还可以设置：
* `使用 Nomad 轴心` - 连线从自由变换和轴向变换工具使用的轴心出发。关闭时，使用对象原本的基础轴心，它可能离对象中心很远。
* `厚度` - 连线的宽度。滑块旁边的按钮可以为连线添加轮廓。
* 连线的颜色。

### ![](/icons/link.webp) 同步 {#sync}
`同步`标签页为每种操作（`添加`、`删除`、`锁定`、`克隆`、`实例`、`去实例`、`合并`、`拆分`和`布尔`）设置它是否作用于所选对象的每个实例：
* `自动` - 跟随场景菜单顶部的`同步`勾选框。
* `否` - 只作用于所选对象。
* `是` - 总是作用于每个实例。

默认情况下，`合并`、`拆分`和`布尔`为`是`，其余为`自动`。`重置`会恢复这些默认值。
