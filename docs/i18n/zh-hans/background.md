# ![](/icons/image.webp) 背景 {#background}

这个菜单用来设置 Nomad 的背景颜色，以及要使用的参考图像。

![](/images/background_overview.webp)

## 类型 {#type}
![](/images/background_selector.webp)

视口背景有三种选项。

* `环境` - 显示在 [渲染模式](shading.md) 中选择的环境贴图。还可以用 `模糊` 和 `曝光`（亮度）滑块进一步调整。
* `颜色` - 由您选择的纯色。
* `颜色渐变` - 两种颜色之间的过渡。`系数` 滑块可以移动渐变的中点。

### 渐变类型 {#gradient-type}
选择 `颜色渐变` 后，可以选择它的形状：
* `线性` - 直线渐变，方向由 `角度` 滑块设置。
* `径向` - 从屏幕中心向外的圆形渐变。
* `天空` - 固定在世界地平线上的渐变，所以当您向上或向下看时，它会跟着相机变化。

每种颜色都有一个重置按钮和一个取色器，可以从屏幕上吸取颜色。

## ![](/icons/lock.webp) 与相机锁定同步 {#sync-on-camera-lock}
用 [导航器](settings.md#snap-cube) 锁定相机后，参考图像会跟随相机移动，始终与您的雕塑保持对齐。

* `允许滚转（轨迹球）` - 离开相机锁定时，允许相机滚转。
* `解锁时重置视图` - 离开相机锁定时重置视图。

## 参考图像 {#reference}

![](/images/background_reference.webp)

您可以在背景上添加一张自选的图片作为参考。轻点 `导入…` 添加图片，然后勾选 `参考图像` 让它显示出来。
您可以调整它的位置和缩放，比如把它移到屏幕一角。

### ![](/icons/tool_transform.webp) 变换 {#transform}

这个按钮让您以交互方式摆放参考图像。用双指平移、缩放、旋转参考图像，把它放到合适的位置。`重置参数` 会把图像恢复到默认位置。最终的摆放结果会反映在下方的滑块中：

* `覆盖` - 为 0% 时，参考图像始终在对象后面；为 100% 时则在对象前面。
* `不透明度` - 图像的透明程度。
* `后期处理` - 对参考图像应用后期处理效果。关闭它可以保留原始颜色。
* `X轴位置` / `Y轴位置` - 图像在 X 和 Y 方向上的位置。
* `缩放` - 图像的缩放。
* `旋转` - 图像的旋转。


::: tip

相机和参考图像是关联在一起的。

也就是说，如果您已经把参考图像和雕塑对齐，那么在 [相机菜单](camera.md) 中创建相机时，参考图像的位置、旋转和缩放也会一并保存到这个相机中。之后您可以关闭参考图像，转到别的视角。当您再次通过这个相机观察时，参考图像会以您当时的设置重新启用。

甚至可以为不同的相机选择不同的图像！

:::
