# ![](/icons/material.webp) 材质 {#material}

在这个菜单中，您可以更改当前物体的材质、设置物体和材质的渲染属性，并为材质指定纹理。

![](/images/material_overview.webp)

材质决定了物体的外观，它控制物体对光线和其他物体的反应。物体的外观由以下属性控制：

* `材质类型`
* `颜色`
* `粗糙度`
* `金属度`
* `不透明度`
* `反射率`
* `自发光/不受光`

组合这些属性，可以得到从照片级写实、卡通风格到实验性效果的各种结果。

颜色、粗糙度、金属度和不透明度都可以绘制，详见[顶点绘画选项](painting.md)。

材质类型、反射率、自发光/不受光属于材质属性，下面会逐一介绍。

菜单顶部的 `复制` 和 `粘贴` 按钮可以把材质从一个物体复制到另一个物体上。

请注意，Nomad 的渲染器是实时渲染器：它功能强大，但在某些效果上会优先考虑速度而非精确度。

## 材质类型 {#material-types}

![](/images/material_types.webp)

Nomad 的材质类型有：不透明、次表面、正常混合、叠加、折射、抖动和阴影捕捉器。

### ![](/icons/material_opaque.webp) 不透明 {#opaque}
默认模式，把表面当作一种简单材质处理，支持绘制的颜色、粗糙度、金属度和不透明度。绘制的不透明度、不透明度纹理或颜色纹理的 Alpha 通道仍然能让物体变得透明（通过抖动实现），只有主不透明度滑块会被忽略。

### ![](/icons/material_subsurface.webp) 次表面 {#subsurface}
这种模式可以模拟光线在内部模糊、散射的材质，比如皮肤、蜡、玉石。

它需要 PBR 着色模式。想要最好的效果，请至少使用一盏平行光或聚光灯，环境光最好暗一些。

颜色色块设置散射光的颜色。

`深度` 控制光线从正面进入表面之下、再从正面射出时散射的距离。它会柔化生硬的阴影，并让表面细节变得模糊。

`半透明` 控制光线从形体正面散射到背面的程度，就像光线透过叶子背面，或耳朵被强烈背光照射时那样。您需要一盏投射阴影的灯光才能看到这个效果。

### ![](/icons/material_blending.webp) 正常混合 {#blending}

与不透明类似，但支持不透明度滑块，可以让材质在实心和透明之间过渡。这里只有一个简单的不透明度滑块，而不透明材质支持的是可绘制的不透明度。

::: warning
在复杂或相互穿插的形体上，正常混合模式可能会出现闪烁和跳变。
:::

### ![](/icons/material_additive.webp) 叠加 {#additive}
使用这种材质可以让网格变成半透明。它和正常混合材质类似，但正常混合会与周围环境混合，而叠加总是比它后面的物体更亮，适合光束、火焰、爆炸这类明亮的效果。

不透明度可以设置为大于 1 的值，这样物体会更亮。  
如果您想使用[泛光效果](postprocess.md#bloom)，并配合 `阈值` 参数只让这个物体像自发光物体一样发光，这会很有用。

这种模式产生的瑕疵往往比[正常混合](#blending)少（与顺序无关的透明度）。

### ![](/icons/material_refraction.webp) 折射 {#refraction}
这种模式可以用来模拟玻璃材质。它需要 PBR 着色模式。由于实时渲染的限制，自身折射和多层折射的效果比较有限。

模型绘制的粗糙度会影响折射的模糊程度。
默认情况下，在 Nomad 中创建的每个物体的粗糙度都在 25% 左右，因此折射不会完全清晰，而是略带模糊。
您可以使用 `漆面效果` 按钮把模型的粗糙度和金属度重新绘制为 0（颜色不受影响）。

这里有两种粗糙度在起作用：一种决定表面反射的模糊程度，另一种决定内部（折射）的模糊程度。  
不过，Nomad 中只有一个绘制粗糙度通道，所以内部和外部的粗糙度会共用同一个值。  
如果需要不同的值（例如表面光滑但内部模糊的棒棒糖），可以使用 `覆盖粗糙度` 下的 `表面` 和 `内部` 滑块来覆盖绘制的粗糙度。

![](/videos/refraction.mp4)

#### 折射率 {#index-of-refraction}
光线进入物体时弯折的程度。数值越高弯折越明显，就像一块厚透镜。

#### 吸收效果 {#absorption}
模拟光线穿过体积时被吸收的效果，颜色由色块决定，强度由 `吸收系数` 设置。较薄的部分透光更多，因此更亮；较厚的区域则更暗。这里只使用了物体厚度的近似值，所以效果在很大程度上取决于形状。


### ![](/icons/material_dithering.webp) 抖动 {#dithering}
随机丢弃一部分像素，让物体呈现半透明。

### ![](/icons/material_shadow_catcher.webp) 阴影捕捉器 {#shadow-catcher}

让物体不可见，只接收灯光投下的阴影。适合把 Nomad 的渲染结果与其他图像合成，通常用在平面上。颜色色块设置阴影的颜色。

场景中必须有一盏投射阴影的灯光，否则阴影捕捉器不会起任何作用。`金属度 → 0%` 和 `金属度 → 100%` 按钮会重新绘制物体：完全金属化时，只要启用了[屏幕空间反射（SSR）](postprocess.md#reflection-ssr)后期处理，阴影捕捉器还能反射场景。

::: tip

关于透明度和混合模式的更多信息，请参阅 https://support.fab.com/s/article/Transparency-Opacity

:::

## 控制 {#controls}

![](/images/material_controls.webp)

### ![](/icons/circle_fill.webp) 不受光显示 {#always-unlit}
启用后，物体会忽略 PBR 和 Matcap，直接显示绘制的颜色，不带任何明暗。
请注意，如果您使用的是[叠加](#additive)，可以直接用黑色来绘制透明度。

### 不透明度 {#opacity}
物体看起来有多实、多不透明：100% 为完全实心，0% 为完全透明。正常混合、叠加、抖动和阴影捕捉器类型会显示这个滑块。您也可以绘制不透明度来进行更精细的控制。

### 预折射通道 {#pre-refract-pass}
仅适用于正常混合和叠加。在折射通道之前绘制这个透明物体。当折射物体位于其他透明表面前方时很有用。

### 反射率 {#reflectance}
控制非金属材质接收的反射量。大多数情况下使用默认值即可（对应法线方向上 4% 反射光的标准值），但也可以调高，例如用来增强角色眼睛中的反射和高光。它需要 PBR 着色模式。

### ![](/icons/culling.webp) 反向剔除 {#inverse-culling}
翻转表面的法线。通常用不到，但如果模型看起来里外颠倒，就可以用它；或者与关闭的 `双面显示` 配合使用，制作室内场景，让最靠近相机的那面墙始终隐藏。

以下选项可以设置为 `自动`、`否` 或 `是`。设置为 `自动` 时，箭头会显示实际使用的值。

### ![](/icons/sphere_smooth.webp) 平滑阴影 {#smooth-shading}
参见[全局选项](settings.md#smooth-shading)。  
`自动` 会使用全局选项的值。

### ![](/icons/culling.webp) 双面显示 {#two-sided}
面从两侧都可见。参见[全局选项](settings.md#two-sided-quick)。  
`自动` 会使用全局选项的值。

### ![](/icons/culling.webp) 背面着色 {#coloured-backface}
参见[全局选项](settings.md#two-sided-quick)。
`自动` 会使用全局选项的值。

### ![](/icons/shadow_cast.webp) 投射阴影 {#casts-shadows}
透明物体也会投射阴影（以抖动图案模拟混合阴影）。  
如果场景中有不需要投射阴影的大物体（例如一大块地面），记得关闭它的阴影投射。

### ![](/icons/shadow_receive.webp) 接收阴影 {#recieve-shadows}
是否在这个物体上显示其他物体投下的阴影。

### ![](/icons/wireframe.webp) 线框 {#wireframe}
参见[全局选项](settings.md#wireframe)。  
`自动` 会使用全局选项的值。

### ![](/icons/trash.webp) 重置法线 {#reset-normals}
只有当导入的物体自带法线时才会显示（例如使用了 `保留拓扑`）。它会移除这些法线，让着色使用根据表面计算出的法线。

## 纹理 {#textures}

![](/images/material_textures.webp)

如果物体有 UV，除了顶点颜色、粗糙度、金属度和不透明度之外，还可以为材质应用纹理。这些纹理通常来自纹理烘焙，但在 Nomad 之外制作的图像也同样可以使用。标题旁边的 `UV:✓` 或 `UV:✗` 会告诉您物体是否有 UV。

纹理可以应用于：

* 颜色
* 法线
* 粗糙度
* 金属度
* 不透明度
* 位移
* 自发光

当导入的物体带有环境光遮挡纹理时，还会出现一行 `环境光遮挡`，但 Nomad 不会使用它。

每一行的滑块设置其纹理的应用强度，从完全不应用到完全应用。`颜色` 和 `自发光` 还有一个用于给纹理着色的颜色色块，`自发光` 还可以设置发光强度。

`位移` 设置位移贴图把表面推出的距离。它的 `应用` 按钮会按位移移动顶点，然后移除贴图。结果会写入当前图层。

标题旁边的调色板按钮会打开[绘画](painting.md)菜单中的材质预设：轻点其中一个，即可把它的纹理复制到物体上。在桌面端，当您切换回 Nomad 时，导入的图像会与原始文件同步，标题旁边的同步按钮也可以重新加载它们。

点击纹理槽会弹出选择器。为材质槽指定纹理后，再次点击会打开纹理面板：

### 纹理面板选项 {#texture-panel-options}

![](/images/material_texture_panel.webp)

面板会显示图像尺寸和纹理预览。

### ![](/icons/open.webp) 打开 {#open}
选择另一张纹理。在桌面端，`浏览` 会在文件浏览器中显示该图像文件。

### ![](/icons/circle_cross.webp) 无 {#none}
移除纹理

### 不透明度 {#texture-opacity}

仅限颜色纹理。如果图像有 Alpha 通道，您可以选择用它作为不透明度，或者忽略它。

### 格式 {#normal-format}
仅限法线纹理。法线贴图有两种格式：`OpenGL (+Y)` 和 `DirectX (-Y)`。如果细节看起来是反的，试试另一种。

### 高度 {#displacement-height}
仅限位移纹理。
* `本地` - 高度会随物体的缩放而变大或变小。
* `世界` - 无论物体如何缩放，高度都保持不变。

### 正片叠底 {#multiply}
仅限粗糙度、金属度和不透明度纹理。将纹理的数值相乘。当它不是 100% 时，数值会显示在纹理槽上。

### ![](/icons/link.webp) 链接图标 {#chainlink-icon}

在下面几个部分中，启用链接图标后，所使用的选项会与其他同样启用了链接图标的纹理（颜色、法线、粗糙度、金属度、不透明度、自发光）共享。

这样，如果您的纹理是对齐的，即使修改参数或投影类型，它们也会保持对齐。


### 投影 {#projection}
![](/images/material_projection.webp)

设置纹理以何种方式应用到物体上。

* `自动` - 如果物体有 UV，使用 UV，否则使用三平面
* `UV` - 使用网格的 UV 坐标来应用纹理。如果网格和纹理来自 Nomad 之外，或者要从 Nomad 导出到其他地方使用，UV 是正确的选择。
* `三平面` - 沿 X、Y、Z 轴投影纹理，并融合接缝。

### 三平面 {#triplanar}
![](/images/material_triplanar.webp)

三平面投影是一种强大又简单的纹理应用方式。

三平面就像有 6 台播放同一张图像的投影仪，分别从前、后、左、右、上、下照向您的物体。

如有需要，之后还可以把它烘焙到 UV 或顶点颜色中。


![](/images/material_triplanar_example.webp)

#### 模式 {#method}

* `本地` - 投影会随物体的变换一起移动
* `世界` - 投影保持固定，移动物体时，物体会在投影中滑过。

#### 硬度 {#hardness}

各个投影之间如何混合。100% 时不进行混合，投影的边缘会很锐利。0% 时会在很大的角度范围内混合边缘。默认值为 90%，混合程度足以隐藏边缘，同时让投影的其余部分保持清晰。

### 均匀 {#uniform}

勾选后，所有投影使用相同的硬度。取消勾选后，会额外显示 X、Y、Z 投影各自的硬度控制。


### 参数 {#parameter}
![](/images/material_parameter.webp)

#### 过滤 {#filtering}
纹理使用的过滤方式，默认为 `自动`，可选方式有 `最近邻`、`线性`、`Mipmap`。最近邻不做任何过滤，因此近距离观看时纹理可能出现锯齿。线性和 Mipmap 的过滤效果更好，近距离观看时纹理会显得模糊而不是有锯齿。

#### 平铺 - X {#tiling-x}
当缩放参数大于 1，使纹理比物体的 UV 更小时，纹理沿 X 轴如何平铺。`无` 表示不重复。`重复` 会复制纹理。`镜像` 也会复制纹理，但每隔一个副本就会翻转一次，有助于隐藏平铺产生的瑕疵。

#### 平铺 - Y {#tiling-y}
与平铺 - X 相同，但作用于 Y 轴。

### 变换 {#transform}
![](/images/material_transform.webp)

在 UV 空间中对纹理额外进行 2d 变换。重置按钮会恢复默认值；选中颜色以外的纹理时，链接图标可以将变换与颜色纹理链接或取消链接，使其保持一致。

#### 位移 {#translation}
纹理在 X 和 Y 方向上的偏移

#### 旋转 {#rotation}
纹理的旋转

#### 缩放 {#scale}
纹理的缩放，数值越大，纹理在物体上显得越小，可以用平铺 - X 和平铺 - Y 选项来控制超出部分的处理方式。

### 等比缩放 {#uniform-scale}
关闭后，Nomad 会分别显示 X 缩放和 Y 缩放的控制。
