# ![](/icons/multires.webp) 拓扑 {#topology}

此菜单用于控制 Nomad 中对象的拓扑，还提供在对象之间、在纹理之间烘焙和传递细节的工具。

![](/images/topology_overview.webp)

Nomad 基于多边形，用三角形和四边形来构成几何体。
所谓拓扑，既指面的数量，也指点（顶点）之间的连接方式。

留意拓扑很重要，尤其是当您想雕刻或绘制精细细节时。

::: tip 如何留意拓扑？
您可以显示[线框](settings.md#wireframe)，或者直接关闭[平滑阴影](settings.md#smooth-shading)。
:::

![](/images/topology_top.webp)

Nomad 的拓扑菜单有多个标签页，分为两行：

| 方法                                | 图标                         | 说明                                                      |
| :-----------------------------------: | :--------------------------: | :--------------------------------------------------------------: |
| [多分辨率](#multiresolution)   | ![](/icons/multires.webp)   | 通过细分来编辑多个细节级别                 |
| [体素网格重构](#voxel-remesher)     | ![](/icons/voxel.webp)      | 重新计算出密度均匀的新拓扑                    |
| [动态拓扑](#dynamic-topology) | ![](/icons/dynamic.webp)    | 雕刻或绘画时实时在局部添加/移除面 |
| [杂项](#misc)                         | ![](/icons/topo_extra.webp) | 封闭孔洞、强制流形以及转换为三平面             |
| [基本体](#primitive)               | ![](/icons/dot.webp)        | 基本体选项                                                |
| [网格简化](#decimation)               | ![](/icons/decimate.webp)      | 在保持形状的同时减少面数            |
| [四边形重构](#quad-remesh)           | ![](/icons/quad.webp)       | 用整洁的四边形布线重建对象                      |
| [UV自动展开](#uv-unwrap)               | ![](/icons/uv.webp)         | 为贴图创建 UV                                         |
| [烘焙](#bake)                         | ![](/icons/bake.webp)       | 将细节和绘画烘焙到纹理、顶点或 VDM 印章       |


## 多边形统计 {#polygon-stats}

![](/images/topology_stats.webp)

每个标签页的顶部区域显示所选对象的多边形数量；场景中有多个对象时，还会显示整个场景的数量。各列依次是顶点数、三角形数、四边形（四条边的多边形）数和 UV 坐标数（对象没有 UV 时为 0）。

点击这一区域，可以列出场景中的每个对象及其精确数量，包括面组的数量。

## ![](/icons/cog.webp) 齿轮菜单 {#gear-menu}
有些区域（例如[四边形重构](#quad-remesh)和[烘焙](#bake)标签页中的区域）带有额外选项。点击区域标题旁的齿轮图标即可打开。

## ![](/icons/multires.webp) 多分辨率 {#multiresolution}

![](/images/topology_multires_menu.webp)

### 什么是多分辨率？ {#what-is-multiresolution}
多分辨率功能主要用于两种场景：
- 通过平滑细分算法提高对象的面数
- 管理多个分辨率级别，让您可以在小尺度和大尺度的修改之间来回切换

![](/videos/multiresolution.mp4)

#### 多分辨率工作流程 {#multiresolution-workflow}
多分辨率的一大要点是：您可以回到较低的分辨率修改对象，然后再回到最高分辨率，而不会丢失高分辨率的细节。所有高分辨率细节都会自动投影回来。

[图层](layers.md#layers)在每个分辨率上都可以使用。

::: warning
如果您使用了会改变对象拓扑的工具，对象的其他所有分辨率都会丢失！
发生这种情况前，您通常都会看到警告，例如在使用以下功能时：
- [体素网格重构](#voxel-remesher)
- [动态拓扑](#dynamic-topology)
- [裁切工具](tools.md#trim)
- [分割工具](tools.md#split)
:::


### 多分辨率滑块 {#multiresolution-slider}
这个滑块显示当前对象的细分级别数。有 6 根竖条，就表示有 6 个细分级别。圆圈表示当前显示的细分级别。

滑块上方的小图标表示每个级别使用了哪些选项（`锁定级别 0`、`线性`、`硬边界`、`保留三角形`）。

### 取消分割 {#reverse}
处于最低细分级别时，取消分割按钮会尝试在当前级别之下再创建一个级别。注意，通常只有当对象本身就是通过细分创建的（比如在 Nomad 或其他支持多分辨率细分曲面的 3d 应用中）时，这才能成功。

### 细分 {#subdivide}
*细分*按钮会让多边形数量变为 4 倍，所以请留意面数，它可能增长得非常快！当结果会非常庞大时，Nomad 会请您确认。
*细分曲面*的一个重要特点是：它会逐渐收敛为一个*平滑曲面*。
想了解它的原理，可以在一个只有少量多边形的对象上试试*细分*按钮。

您可以用`线性`选项关闭这种*平滑*效果。

### 删除低模 {#delete-lower}
如果当前显示级别之下还有细分级别，就将其删除。如果误删了，可以用取消分割按钮重新创建。

### 删除高模 {#delete-higher}
如果当前显示级别之上还有细分级别，就将其删除。

### ![](/icons/lock.webp) 锁定级别 0 {#lock-lv0}
在较高级别上雕刻时，保持最低细分级别的形状不变。绘画仍然会传递到级别 0。如果您的对象来自其他应用，且基础对象必须保持不变，这一点就很重要。

此选项只在第一次细分之前可用。关闭时，在较高细分级别上做出的大幅修改会让级别 0 跟着移动。

### ![](/icons/linear.webp) 线性 {#linear-subdivision}
细分网格时不进行任何平滑。

### ![](/icons/group.webp) 硬边界 {#sharp-border}
如果对象有面组，启用此选项可以让面组边界保持锐利。每个细分级别都可以单独设置（细分滑块会在该级别上方显示一个小图标）。

### ![](/icons/triangle.webp) 保留三角形 {#keep-triangles}
大多数标准细分曲面系统在细分时都会尝试把所有多边形转换为四边形。此开关会强制细分改用三角形。

::: tip

细分默认会把所有锐利的边都变得平滑。想让边缘保留一点锐度，可以试试在前 2 个细分级别使用`线性`或`硬边界`，然后在更高的级别关闭它。这样就能得到一个半锐利的细分网格。

:::

### 显示最高级别 {#show-highest-level}
在较低级别上雕刻时，显示带有全部细节的最高级别。做大幅修改时，可以随时看到最终效果，非常方便。

### 线框：仅限级别 0 {#wireframe-level-0-only}
开启[线框](settings.md#wireframe)时，只显示最低级别的线框。高级别的密集线框可能会遮住形状。


## ![](/icons/voxel.webp) 体素网格重构 {#voxel-remesher}
![](/images/topology_voxel_menu.webp)
使用`体素网格重构`时，整个网格的拓扑会被强制变为统一的分辨率，也就是说所有多边形的大小都差不多。如果您不想操心拓扑，只想自由地雕刻，这个功能非常有用。

典型的雕刻流程可以先用`体素网格重构`，以较低的分辨率搭出大致形状。
当网格被拉伸得太厉害时，时不时点一下*重构*按钮，就能避免过度变形。

![](/videos/voxel_remesher.mp4)


::: tip 体素？
如前所述，Nomad 是一款多边形软件，但`体素网格重构`是个例外：它会（临时）采用另一种方式来完成重构。

一大区别是，体素方式不允许自相交，所以自相交会被消除。
它也不支持带孔的网格。

这里说的孔，并不是`亏格孔`（甜甜圈中间的`孔`），而是不`水密`/`封闭`的网格。
通常这意味着，在重构之前，所有孔洞都会被填补，类似于[裁切工具](tools.md#trim)或[孔洞填补功能](#holes)。下面的[孔洞](#voxel-holes)选项决定填补的方式。
:::

### ![](/icons/voxel.webp) 重构 {#voxel-remesh}
执行体素重构。按钮上的小图标会提醒您下面哪些选项已开启。

### 分辨率 {#voxel-resolution}
计算时使用的体素大小，数值越高，细节越多。调整这个参数时，网格上会叠加一层棋盘格图案，用来预览结果。

吸管会根据您点击处的网格密度拾取分辨率。旁边的立方体按钮会把数值切换为以世界单位表示的`边长`：这样同一个数值在任何对象上都能得到相同的细节。

### 构建多分辨率 {#build-multiresolution}
为体素重构创建较低的多分辨率级别。如果您借助棋盘格图案设置了分辨率，并把构建多分辨率设为 2，最终结果的细节会与分辨率滑块一致；到多分辨率标签页中查看，它会处于级别 2，也就是说在级别 1 和级别 0 还有较低分辨率的多分辨率网格。这样既能生成多边形均匀的整洁网格，又能得到一个低分辨率的控制网格。

在高分辨率下，它的速度也更快，占用的内存更少。但如果分辨率低而级别多，就会丢失细节。

::: tip 提示：构建多分辨率与稳定平滑

此选项有时会在几何体中产生难以平滑的“环”，形成小疙瘩。遇到这种情况时，请在平滑工具的选项中启用“稳定平滑”。

:::

### 加厚细薄部分 {#thicken-thin-parts}
比体素还薄的部分在重构时可能会断开或消失。此选项会把它们加厚，让它们保留下来，数值越高加厚越多。启用`硬边`或`硬边界`时不可用。

### 孔洞 {#voxel-holes}
重构前如何封闭孔洞：

* `填补` - 每个孔洞从其边界开始单独封闭。
* `形状` - 顺着周围的表面来封闭孔洞，相互重叠的开放部件会连接在一起。

### ![](/icons/angle.webp) 硬边 {#keep-sharp-edges}
把新的点吸附到原始网格的锐利边缘上。主要适用于简单基本体的布尔运算，可能会带来变形。

### ![](/icons/group.webp) 硬边界 {#voxel-sharp-border}
新的面会顺着面组边界分布，在表面沿边界形成折痕的地方，边界会保持锐利。

### ![](/icons/group_separate.webp) 保持面组分离 {#keep-groups-separate}
每个面组单独重构：面组之间永远不会合并，每个面组都保持为自己组内的一个封闭部件。此模式下不会构建多分辨率。对象有多个面组时可用。

## ![](/icons/dynamic.webp) 动态拓扑 {#dynamic-topology}

![](/images/topology_dyntopo_menu.webp)
多分辨率和体素重构是业界常用的拓扑控制方法，但两者都要求您留意，不要把多边形拉伸得太开，或挤压得太密。

动态拓扑是另一种方法。在您雕刻时，Nomad 会在笔触过程中自适应地添加和移除多边形：雕刻细小的细节时，会在需要的地方添加许多小多边形；在其他地方平滑时，则会减少多边形。

注意，动态拓扑使用的是三角形而不是四边形。这看起来可能有点乱，但最好干脆别看线框，专心雕出好看的作品，不用担心拓扑；之后再用 Nomad 的其他重构工具生成整洁的四边形网格。

请看下面的视频演示。

![](/videos/dynamic.mp4)

### 启用 {#enabled}
开启动态拓扑。画笔半径和强度滑块下方会出现一个动态拓扑图标，方便您为每个工具单独开关动态拓扑。它可能会明显影响性能，图层也会正确更新。

### 细节等级 {#dyn-detail}
控制细节的多少，其行为取决于“细节等级模式”的选择，见下文。在`屏幕分辨率`模式下，标签会显示目标三角形的大小（以像素为单位）。在`固定`模式下，可以用吸管根据您点击处的网格密度拾取细节。

### 细节等级模式 {#detail-based-on}
| 方法   | 说明                                                     |
| :------: | :-------------------------------------------------------------: |
| 屏幕分辨率   | 细节等级取决于对象在屏幕上的大小。细节滑块为 100% 或更高时细节精细，生成小三角形；为 1% 时细节较低，生成大三角形。  |
| 半径   | 由工具半径决定细节的多少。工具半径小，细节精细；工具半径大，细节较低。细节滑块是这一比例的倍数。                     |
| 固定 | 由细节滑块决定细节的多少，不受屏幕大小或工具大小影响。它与`重构`的[细节](#all-detail)滑块是同一个数值。             |

::: tip 提示：半径模式

想更好地理解半径模式，可以用一根手指拖动细节滑块，同时用另一根手指改变工具半径。您会看到两者是联动的。

:::

### 偏向于… {#prefer}
| 方法  | 说明       |
| :-----: | :---------------: |
| 速度   | 优先性能 |
| 质量 | 优先质量     |

偏向`质量`时，主要有 2 点不同：
- 细化会在雕刻之前进行，所以在绘制或雕刻非常小的细节时，插值造成的瑕疵会更少
- 细化会一直进行，直到收敛到正确的细节等级，而不是逐步增加。
 
这样一来，即使您雕刻非常小的细节或快速划过，拓扑也总能按预期细化。


### ![](/icons/pressure.webp) 在半径上使用压感 {#use-pressure-on-radius}
仅在启用`半径`时有效。启用后，即使画笔大小受到触控笔压感影响，细节等级也会始终跟随画笔大小。

### 使用笔触衰减 {#use-stroke-falloff}

在动态拓扑的计算中也考虑画笔的衰减曲线和 Alpha。

### 模式 {#method}
选择动态拓扑修改网格的方式，无论是在您雕刻时，还是使用[重构](#dyn-remesh)时：

| 方法         | 说明                                                           |
| :------------: | :-------------------------------------------------------------------: |
| 均匀化 | 可以添加和移除面，上面视频中用的就是这种模式 |
| 细分    | 只添加新面，不能移除面                            |
| 简化     | 只移除面，不能添加新面                            |

### ![](/icons/shield.webp) 保护蒙版区域 {#protect-masked-area}
启用后，蒙版区域的拓扑会受到保护，不会被改变。

### ![](/icons/normal.webp) 顶点扩张 {#vertex-extrapolation}
把点放在一个顺着周围曲率的平滑曲面上，而不是平放在现有的面上。

### 细节 {#all-detail}
重构操作使用的分辨率。如果动态拓扑处于“固定”模式，它与本菜单顶部的细节等级滑块是同一个数值。吸管会根据您点击处的网格密度拾取细节。

### 重构 {#dyn-remesh}
用动态拓扑算法对整个对象进行重构。通常，完整的重构应该使用[体素网格重构](#voxel-remesher)。

不过，它相比体素方式有一个优点：网格不需要是封闭的，而且蒙版区域会受到保护，所以您能更好地控制哪里密、哪里疏。



## ![](/icons/topo_extra.webp) 杂项 {#misc}

![](/images/topology_misc_menu.webp)

这个标签页汇集了清理或转换网格的工具：封闭孔洞、强制流形，或转换为三平面。

### ![](/icons/hole.webp) 孔洞 {#holes}
![](/images/topology_holes_menu.webp)
大多数时候，您的对象应该都是水密的，也就是说网格是“封闭”的。

如果对象有孔洞，您可以将其填补。

![](/videos/hole_filling.mp4)

::: tip
运行体素网格重构时，所有孔洞都会自动封闭，无论您是对 1 个还是多个网格使用它。
:::

#### 封闭孔洞 {#close-holes}
执行封闭孔洞操作。

#### 选项 {#holes-gear-menu}
这些选项会改变孔洞的填补方式：

##### 面组 {#fill-face-group}
选择新面所属的面组：

* `混合` - 被单个面组包围的孔洞沿用该面组，接触多个面组的孔洞则获得一个新面组。
* `新建` - 填补的孔洞获得一个新面组。
* `复用` - 每个孔洞使用周围占比最大的面组。

##### 细节 {#fill-detail}
填补孔洞时使用的多边形密度。拖动这个滑块时，模型上会显示棋盘格图案，用来提示应使用的三角形大小。勾选框可以关闭它，此时只使用现有的点，通常会在孔洞上产生又长又细的三角形，很难雕刻。

##### 桥接 {#fill-non-manifold}
把一个孔洞和其中的孤岛作为一个整体曲面来填补，而不是逐个边界单独填补。角度越大，越能桥接弯曲的孔洞。勾选框可以将其关闭。

### ![](/icons/cog.webp) 强制流形 {#force-manifold}
![](/images/topology_forcemanifold_menu.webp)
尝试清理非流形边。如果外部软件不支持被 2 个以上的面共用的边，这会很有用。

#### 清理 {#clean}
执行清理操作。

#### 选项 {#force-manifold-gear-menu}
这个选项会改变网格的清理方式：

##### 删除小面 {#delete-small-faces}
用于移除并合并小多边形的阈值。用它的勾选框来启用。


### ![](/icons/triplanar.webp) 三平面 {#triplanar}
![](/images/topology_triplanar_menu.webp)
把网格转换为[三平面](scene.md#triplanar)基本体。
这个过程中您很可能会丢失大量细节：图层、绘画和多分辨率也会丢失。

#### 强制转换为立方体 {#force-cubic}
让三平面成为一个立方体。否则，三平面会贴合对象周围最接近的包围盒。

#### 转换 {#convert}
执行三平面转换操作。

#### 分辨率 {#triplanar-resolution}
三平面网格的分辨率，数值越高，保留的细节越多。

## ![](/icons/decimate.webp) 网格简化 {#decimation}

![](/images/topology_decimation.webp)

在尽可能保留细节的同时减少多边形数量，结果使用三角形。

如果您要导出用于 3d 打印，这个功能会很有用。
不过，如果您还想在上面继续雕刻，最好不要使用它，因为它可能产生大小不均的三角形。

注意，蒙版区域不会被简化。

![](/videos/decimate.mp4)

::: tip

对高面数对象使用[四边形重构工具](tools.md#quad-remesher)可能要计算很久，结果也难以控制。先用[面组](tools.md#facegroup)和网格简化对网格进行预处理，可以让四边形重构快得多，并能更好地控制拓扑。

* 给网格划分面组，定义您理想的四边形走向。
* 用面组的规整功能让面组边界变得平滑。
* 网格简化。这样可以确保面组边缘上没有细长或变形的面。在`保留边界`下，确保启用了`面组`。这会让三角形的边精确地沿着面组边缘分布。
* 在四边形重构的选项中，确保关闭规整（因为您已经规整过网格），这样应该就能得到不错的结果。

:::

## ![](/icons/quad.webp) 四边形重构 {#quad-remesh}
![](/images/topology_quadremesh_menu.webp)
用整洁的四边形布线重建对象。这个标签页有好几种重构器，每种都有自己的`重构`按钮、`目标四边形`滑块和齿轮菜单。在您的对象上都试一试吧，它们的结果差别相当大！

### Quad Remesher {#quad-remesher}
与 [Quad Remesher](tools.md#quad-remesher) 工具相同的重构器，由 [Exoside](https://exoside.com/) 开发。它只在部分平台上提供，并需要购买：购买之前，`重构`按钮上会显示一个购物车图标。

`选择工具`会切换到 Quad Remesher 工具，用来绘制引导线和绘制密度。齿轮菜单中有`自适应四边形数量`、`自适应大小`（为 100% 时四边形大小跟随曲率，为 0% 时四边形大小均匀）、`自动检测硬边`和`重投影顶点`。

::: tip
在可用的平台上，Quad Remesher 通常能给出最好的结果，控制也最灵活。
:::

### AutoRemesher {#autoremesher}
另一种四边形重构器，带有让四边形大小和形状适应表面的选项。

#### ![](/icons/cog.webp) AutoRemesher 齿轮菜单 {#autoremesher-gear-menu}
齿轮菜单中有以下高级选项：

##### 边缩放 {#edge-scaling}
缩放四边形的大小，数值越高，四边形越大。

##### 自适应性 {#adaptivity}
让四边形密度适应曲率。0 生成均匀的四边形，1 会在弯曲区域生成更小的四边形。

##### 各向异性 {#anisotropy}
沿表面最平坦的方向拉伸四边形。0 生成方正的四边形，1 会在管状和脊状部位生成细长的四边形。

##### 锐边 {#sharp-edge}
弯折超过这个角度的边会作为锐利特征保留下来。

##### 平滑法线 {#smooth-normal}
0 会在重构过程中保持表面的棱面效果。数值越高，越会把顶点法线考虑进来，让表面更平滑。

##### 最大填洞 {#autoremesher-max-fill-hole}
算法有时会产生不需要的孔洞。如果一个孔洞的顶点数少于这个数值，它就会被填补。

### Instant Mesh {#quad-remesh-instant}
使用 [Wenzel Jakob、Marco Tarini、Daniele Panozzo、Olga Sorkine-Hornung 的 Instant Meshes 算法](https://igl.ethz.ch/projects/instant-meshes/)进行重构。它会分析网格的走向，生成整洁的四边形拓扑。

#### 重构 {#instant-remesh}
开始重构操作。

#### 目标四边形 {#target-quads}
重构器尝试生成的四边形数量。

#### ![](/icons/cog.webp) Instant Mesh 齿轮菜单 {#quad-remesh-instant-gear-menu}
齿轮菜单中有以下高级选项：

##### 折痕角度 {#crease-angle}
锐角的阈值，用来帮助引导重构操作。用它的勾选框来启用。

##### 最大填洞 {#max-fill-hole}
算法有时会产生不需要的孔洞。如果一个孔洞的顶点数少于这个数值，它就会被填补。

### QuadriFlow {#quadriflow}
使用 QuadriFlow 算法进行重构，这是获得整洁四边形布线的另一种方式。

#### ![](/icons/cog.webp) QuadriFlow 齿轮菜单 {#quadriflow-gear-menu}
齿轮菜单中有以下高级选项：

##### 保留边界 {#quadriflow-preserve-boundary}
保护孔洞的边界。

##### 保留锐边 {#keep-sharp}
让四边形与表面的锐利边缘对齐。

##### 最小费用流 {#min-cost-flow}
用最小费用流求解器来计算四边形布线。速度较慢，但可以得到更规则的拓扑。

## ![](/icons/uv.webp) UV自动展开 {#uv-unwrap}
为所选对象计算纹理坐标（UV）。Nomad 有两种方法：`UVAtlas` 和 `BFF`，各有自己的`展开`按钮。

![](/videos/unwrap.mp4)

::: tip UV？
关于 UV，有个常见的比喻是包礼物：怎样裁剪包装纸，才能把物体完全包住，又没有重叠？

UV 也类似，只不过不是裁剪纸，而是裁剪物体。想象一下，如果您的模型是用薄塑料做的，您要怎样把它剪开、摊平，在摊平的状态下给它上色，然后再拼回去？

再想象一下，模型的表面是有弹性的莱卡布料。您可以把它拉平，也可以剪开，或者两者结合。但如果您在摊平的状态下画上棋盘格，重新拼回去时棋盘格就会变形。哪种方法更好呢：剪得多、变形少，还是剪得少、变形多？

UV 就是告诉 3d 软件在贴纹理时如何“剪开和拉伸”对象的说明。UV Atlas 工具通常采用“剪得多、变形少”的方式。


:::

::: tip UV、Nomad 与其他应用

您在网上找到的大多数带纹理的模型都是通过 UV 贴图的。Nomad 可以通过[材质](material.md#textures)面板导入并显示它们。

在 Nomad 中制作模型时，您可以直接在没有 UV 的对象上绘画。如果需要把它们导出到其他应用，例如 [Procreate](https://procreate.art/)，可以通过 UV 把 Nomad 的颜色信息“烘焙”到纹理中。

:::

### UVAtlas {#uv-unwrap-uvatlas}

![](/images/topology_uvatlas_menu.webp)
UVAtlas 通常倾向于多做切割、生成更多的岛，以尽量减少变形。

#### 展开 {#unwrap}
为所选对象计算 UV。

#### 选项 {#uvatlas-gear-menu}
`展开`旁边的按钮：

##### 面组 {#atlas-face-group}
显示`是`时，由面组决定 UV 的切割位置。此设置与 BFF 共用。

##### 删除UV {#delete-uvs}
垃圾桶按钮会删除对象的 UV。

##### 检查 {#uv-inspect}
在背景中显示对象的 UV。

#### 最大拉伸 {#max-stretch}
数值低时变形少、岛多，数值高时变形多、岛少。

#### 岛屿间距 {#island-spacing}
岛之间的留白大小。数值低时浪费的空间少，但纹理有在岛之间渗色的风险。

::: warning
计算 UV 可能需要一些时间，网格最好少于 10 万个顶点。
:::

### BFF {#uv-unwrap-bff}
![](/images/topology_uvbff_menu.webp)

BFF 的 UV 倾向于“剪得少、变形多”的方式。

#### 选项 {#uv-bff-gear-menu}
`展开`旁边有与 [UVAtlas](#uvatlas-gear-menu) 相同的`面组`、删除和`检查`按钮。

##### 面组 {#bff-face-group}

用面组来定义 UV 的切割位置。

#### 锥体数量 {#cone-count}
定义使用的主投影数量。数值越低，岛越少，但变形越多。数值越高，计算时间越长。

#### 无缝补丁 {#seamless-patches}
影响 UV 补丁的布局，可能会带来明显的变形。在精心划分的面组上效果最好。

::: warning
如果网格有柄（比如甜甜圈中间的孔），BFF 可能会生成重叠的 UV。
:::

### ![](/icons/preview.webp) 展开后显示 UV {#show-uv-after-unwrap}
展开后打开 UV 检查视图，让您可以马上查看结果。

### ![](/icons/bake.webp) 烘焙：纹理 → 纹理 {#unwrap-bake-texture}
仅当对象的材质带有纹理时可用。重新展开时，纹理会被转移到新的 UV 上，因此依然贴合。它的分辨率默认为`自动`，与最大的纹理一致，您也可以自己设置。

## ![](/icons/bake.webp) 烘焙 {#bake}
这个标签页用于在对象之间、在顶点和纹理之间传递细节和绘画。

`从高分辨率`以其他对象作为来源，括号中的数字是来源对象的数量。Nomad 按以下方式挑选它们：

- 使用所有选中的对象，主选中对象作为目标（在[场景](scene.md)菜单中高亮最明显的那个）
- 如果只选中了一个对象，Nomad 会改用所有可见对象
- 如果其他对象全部被隐藏（例如使用了独显），则使用整个场景

### ![](/icons/bake.webp) 烘焙 → 纹理 {#bake-texture}
![](/images/topology_bake_menu.webp)

纹理烘焙会把场景中其他可见对象投影到所选对象的 UV 上，从而生成纹理。对象需要带有 UV。

烘焙的典型流程如下：
- 您有一个带有精细细节和绘画的网格
- 克隆它
- 对它进行网格简化（把`保留绘画`设为 0）
- 展开它的 UV
- 烘焙！

现在您应该得到了一个低分辨率网格，它保留了原对象的大部分绘画和细节。

操作完成后，顶点颜色会被移到一个新的、已停用的图层中，以免干扰纹理。

#### 从本身 {#tex-from-itself}
把对象烘焙到它自己的 UV 上：它的绘画会变成纹理；如果它有多分辨率级别，最高级别的细节会被烘焙到当前级别上（此时按钮上会显示多分辨率图标）。这种方式设置起来很简单，但您常常需要更多控制，这时下一个选项更有用。

#### 从高分辨率 {#tex-from-high-res}
从其他对象烘焙到所选对象。括号中的数字表示有多少个其他对象会被用作高分辨率来源，烘焙到当前这个带 UV 的低分辨率对象中。其他对象不需要在布局或拓扑上与被烘焙的对象相似，因此烘焙流程非常灵活。

#### 分辨率 {#tex-bake-resolution}
烘焙纹理的分辨率。烘焙出的纹理总是正方形的，所以 1024 会生成一张 1024x1024 的图像。

下方的按钮是常用分辨率的快捷方式。作为参考，512x512 比较小，适合网页图形和简单的几何体。4096x4096（简称 4k）适合高质量渲染。

#### 颜色、粗糙度、金属度、法线、位移、自发光、不透明度 {#tex-normal-roughness-metalness-color-emissive-opacity}
这些按钮决定要烘焙哪些属性，每种属性烘焙到单独的贴图中。烘焙完成后，它们会作为纹理添加到当前对象的材质中。`位移`会把细节的高度烘焙为位移贴图。

#### ![](/icons/cog.webp) 烘焙齿轮菜单 {#tex-bake-gear-menu}
![](/images/topology_bake_gear_menu.webp)
齿轮菜单中有以下高级选项：

##### 备份 {#tex-backup}
要预览烘焙出的纹理，需要停用对象的绘画信息。`备份（绘画 → 图层）`会把所有绘画信息转移到一个新图层中作为备份，方便随时启用或停用。

##### 使用多分辨率 {#tex-use-multires}
用于带有多分辨率级别的对象的`从本身`烘焙。Nomad 通过细分级别读取高分辨率，而不是投射射线：这样更快，也没有投影误差。关闭它就会使用下面的选项来烘焙。

##### 平滑基底 {#tex-smooth-base}
用于带有多分辨率级别的对象的`位移`烘焙。从细分后的基底而不是从其平坦的面来测量位移。如果位移贴图要用在细分网格上（比如 Blender 的自适应细分），请保持开启。

##### 搜索距离 {#tex-cage-radius}
查找来源表面时使用的最大距离。默认情况下这个距离较小，以避免瑕疵；如果目标对象离烘焙对象较远，可以调大。

##### 投影 {#tex-projection}
如何查找来源表面：

* `射线` - 沿表面法线投影。
* `射线 + 最近点` - 使用法线射线，射线未命中时改用最近的表面。
* `最近邻` - 投影到来源表面上最近的点。

##### 射线偏移 {#tex-ray-offset}
调整烘焙计算在烘焙对象上的起始位置。离表面稍微偏移一点，可以避免最常见的瑕疵。如果目标对象离烘焙对象非常远，可能需要加大这个偏移。`最近邻`不使用它。


### ![](/icons/bake.webp) 重新投影 → 顶点 {#reproject-to-vertex}

![](/images/topology_reproject_menu.webp)

把雕刻细节、绘画、图层、纹理投影为顶点数值。

可以把它看作烘焙的逆操作：烘焙是把顶点属性传递到纹理，重新投影则是把纹理（以及其他属性）
 传递回顶点。

::: tip
使用`烘焙 → 纹理`或`重新投影 → 顶点`时，顶点颜色和材质纹理都会被考虑在内。
:::

#### 从本身 {#vertex-from-itself}
把材质中的纹理转换为顶点数值。只有当对象带有 UV、且材质中启用了纹理时，这个按钮才可用。

::: tip 提示：纹理绘画
Nomad 不直接支持绘制和编辑纹理，但可以通过以下方式达到非常相似的效果：先把纹理投影为顶点数值，在顶点上绘画，再把顶点烘焙回纹理：

1. 准备一个带 UV 的低面数对象
1. 把纹理加载到它的材质中
1. 细分到足以绘画的程度
1. 在`从本身`模式下执行`重新投影 → 顶点`，此时纹理已被转换为顶点数值
1. 绘画、平滑、涂抹、盖印，进行任何您需要的编辑
1. 在`从本身`模式下执行`烘焙 → 纹理`。这些编辑会被转换回纹理。
:::

#### 从高分辨率 {#vertex-from-high-res}
把其他对象转换为所选对象上的顶点数值。按钮上的数字表示来源对象的数量。它主要也是用在高分辨率网格上，通常是拓扑整洁的网格。

::: tip
重新投影其他对象不仅可以用来传递其他对象的颜色信息，还可以把顶点投影到其他对象上，例如把绷带投影到角色身上。
:::

#### 顶点、颜色、粗糙度、金属度、不透明度、蒙版、图层、面组 {#vertex-vertices-roughness-metalness-color-opacity-opacity-mask-mask-layers-face-group}
这些按钮决定要把哪些属性投影到所选对象上。`图层`会把其他对象的图层转移到所选网格上。

#### ![](/icons/cog.webp) 重新投影齿轮菜单 {#vertex-reproject-gear-menu}
齿轮菜单中有以下高级选项：

##### 不透明度 → 蒙版 {#vertex-opacity-to-mask}
把来源的不透明度转换为所选对象上的蒙版。

##### 迭代次数 {#vertex-iterations}
重新投影时应用规整操作的次数。仅在开启`顶点`时使用。

##### 规整网格 {#vertex-relax}
可以对所选网格的布线进行一定程度的平滑或规整，让它更好地贴合重新投影的目标。`平滑`更适合高面数网格，`规整网格`更适合低面数网格。`自动`会让 Nomad 自己选择最合适的方法。

##### 搜索距离 {#vertex-cage-radius}
查找来源表面时使用的最大距离。默认情况下这个距离较小，以避免瑕疵；如果目标对象离所选对象较远，可以调大。

##### 投影 {#vertex-projection}
如何查找来源表面：

* `射线` - 沿表面法线投影。
* `自适应混合` - 根据距离和`射线偏好`来混合法线射线和最近表面的结果。其中一个未命中时，使用另一个。
* `最近邻` - 投影到来源表面上最近的点。

##### 射线偏好 {#vertex-ray-bias}
仅用于`自适应混合`。数值越高，混合越偏向法线射线的结果；数值越低，越偏向最近点。

##### 射线偏移 {#ray-vertex-offset}
调整烘焙计算在所选对象上的起始位置。离表面稍微偏移一点，可以避免某些瑕疵。如果目标对象离烘焙对象非常远，可能需要加大这个偏移。`最近邻`不使用它。

### ![](/icons/bake.webp) 烘焙 → VDM {#bake-vdm}
用所选对象创建一个 VDM（矢量位移）印章，并添加到 VDM 库中。系统会请您输入一个名称。

典型流程如下：
- 添加一个平面，或在 VDM 选择器中选择`新建 VDM`，添加一个已配置好的平面（即 [VDM](scene.md#add-menu) 基本体）
- 在上面雕刻出您的形状，保持边缘平坦
- 烘焙！

平面的 UV 决定了烘焙的正方形区域，因此对象需要带有 UV。用`分辨率`选择印章的大小，并用`颜色`、`粗糙度`、`金属度`和`不透明度`选择印章除位移之外还带有哪些信息。

::: tip
不要在平面上使用动态拓扑，它会破坏平面的 UV，导致印章变形。在图层中雕刻能得到最精确的结果，因为下面的平坦平面依然保留着。绘画也需要放在图层中，否则材质会被盖印到整个正方形上，而不只是您绘画过的地方。
:::

## ![](/icons/dot.webp) 基本体 {#primitive}
所选基本体的参数。大多数参数也可以通过基本体视口工具栏上的 `…` 按钮访问。

![](/images/topology_primitive_screenshot.webp)
