# ![](/icons/history.webp) 历史记录 {#history}
![](/images/history_overview.webp)

和大多数创作工具一样，您在 Nomad 中的所有编辑都可以撤销和重做。
历史记录可能会变得很大，所以您可以控制有多少留在内存中、有多少保存在存储空间里，以及是否随项目一起保存。

::: tip
您可以用快捷手势来撤销和重做：
- 双指轻点：撤销
- 三指轻点：重做
:::

## ![](/icons/history.webp) 历史记录 {#history-panel}
![](/images/history_history.webp)

这个面板显示历史记录栈：步骤编号、操作名称、操作所作用的对象，以及该步骤占用的内存。

轻点某一条目即可跳回（或跳到）那个状态。长按某一条目会永久删除它以及所有更早的历史记录，当您对雕塑满意后，这是释放内存的快捷方法。

### ![](/icons/speed.webp) 回放 {#replay}
左下角的播放按钮会先回到起点，再逐一重做每个操作，用来观看雕塑一步步成形非常有趣。滑块设置速度，单位为每秒操作数。再次轻点按钮即可停止，撤销、重做或轻点某一条目也会让它停下。

开始之前，会弹出一个窗口让您选择：
* `取消分割` - 从当前状态撤销回起点，而不是从起点开始回放。
* `恢复相机视角` - 相机跟随回放的操作移动，即使 [恢复相机视角](#restore-camera) 处于关闭状态。
* `相机平滑` - 相机在视角之间平滑过渡，而不是直接跳到每个视角。数值越高，相机越平稳。

::: warning
回放功能尚处于实验阶段。
:::

## 包含操作 {#include-actions}

历史记录面板底部的图标用来选择哪些类型的编辑会被记录到历史中：

| 操作      | 图标                          | 说明                                                                         |
| :---------- | :---------------------------: | :---------------------------------------------------------------------------------- |
| 灯光      | ![](/icons/light.webp)        | 灯光的编辑。用轴向变换工具移动灯光总是会被记录，因为它可能影响场景层级中的其他对象 |
| 渲染模式     | ![](/icons/sun.webp)          | PBR、MatCap 和 Unlit 模式，以及 MatCap 和 HDRI                                   |
| 后期处理 | ![](/icons/postprocess.webp)  | 后期处理的编辑                                                                   |
| 选区   | ![](/icons/tool_lattice.webp) | 格子工具的选区编辑，例如点击、套索选择和取消选择          |

## 设置 {#settings}
![](/images/history_settings.webp)

### ![](/icons/camera.webp) 恢复相机视角 {#restore-camera}
每个操作都会保存当时的相机视角。
启用此选项后，撤销或重做操作时，相机会回到保存的视角。

### ![](/icons/history.webp) 保存历史记录 {#save-history}
保存项目时一并保存撤销历史，这样重新打开项目后历史依然在。关闭它可以让项目文件更小。

### ![](/icons/ram.webp) 内存限制 {#history-limit-mb}
保留在内存中的历史记录上限。较早的状态会被移到存储空间中，需要时再重新载入，并不会被删除。

### ![](/icons/save.webp) 存储空间限制 {#storage-limit}
此项目的历史记录可占用的存储空间上限。达到上限后，最早的操作会被永久删除。

::: tip
新的限制会在下一次编辑、撤销或重做之后生效。
:::

### ![](/icons/undo.webp) 撤销警告 {#maximum-undoable}
一次跳回超过这个数量的操作时，会先请您确认。如果之后再做编辑，该位置之后的所有操作都会丢失，所以这个选项可以防止您不小心点到列表很靠下的位置。
