# ![](/icons/open.webp) 文件 {#files}

文件菜单可以保存和加载 Nomad 项目、导入和导出 3d 模型、导出渲染图像，以及把 Nomad 与其他应用连接起来。它有三个选项卡：`文件`、`渲染` 和 `连接`。

![](/images/file_menu.webp)

## 项目 {#project}
![](/images/file_project.webp)

顶部的缩略图显示当前项目，旁边是它的文件大小、自动保存和已保存的历史记录。点击缩略图会打开一个小型项目浏览器，再点击某个项目，就会出现一个菜单，可以打开、添加、覆盖、克隆、重命名或删除它。

当项目有尚未保存的更改时，缩略图下方会显示 `更改未保存！`。

### 范围 {#scope}
在桌面端，可以选择项目保存的位置：
* `内部` - 默认选项，与移动端相同。项目只保存在 Nomad 的主文件夹内。
* `原位置` - 当您打开 Nomad 文件夹之外的项目时，保存会覆盖原始文件。这类外部项目无法使用自动保存。

### ![](/icons/nomad.webp) 预设 {#preset}
浏览一系列演示和角色组件。选中一个，再点一次即可选择 `打开` 它或 `添加到场景`。您也可以在这个浏览器中从 Poly Haven 下载免费模型。

![](/images/file_preset_preview.webp)

### ![](/icons/history.webp) 历史记录... {#history}
快速打开项目的历史记录选项，例如 `保存历史记录`，它会在保存项目时保留您的撤销历史。按钮上的绿色标记表示历史记录会随项目一起保存。详见[历史记录](history.md#save-history)。

### ![](/icons/save.webp) 保存 {#save}
保存 Nomad 项目。如果项目从未保存过，会要求您输入一个名称。

### ![](/icons/save_as.webp) 另存为... {#save-as}
以新名称把项目另存为一个新项目。

### ![](/icons/save_as.webp) 覆盖... {#overwrite}
打开项目浏览器，把当前场景保存到另一个项目上，覆盖它。启用 `只导出选择部分` 可以只保存选中的对象，而不是整个场景。浏览器中还有一个 `另存为...` 按钮，可以改为另存为新项目。

### ![](/icons/pencil.webp) 重命名 {#rename}
显示一个文本框，用来重命名当前项目。

### ![](/icons/open.webp) 打开... {#open}
打开项目浏览器，从中打开一个项目。

### ![](/icons/add_file.webp) 添加到场景... {#add}
打开项目浏览器，选中一个项目后，它的内容会合并到当前场景中。

### ![](/icons/trash.webp) 删除... {#delete}
打开项目浏览器，选中的项目都会从文件系统中删除。

### ![](/icons/new_file.webp) 新建 {#new}
开始一个新项目；如果有未保存的更改，会要求您确认。在确认窗口中，您可以选择 `保留` 或 `重置` `背景`、`环境`、`材质捕捉` 和 `X光` 设置，并选择新项目是否使用 `保存历史记录`。

### ![](/icons/autosave.webp) 自动保存... {#auto-save}
用来控制自动保存选项的菜单。启用 `自动保存` 后，项目会定期保存到一个单独的文件中。按钮上的标记会显示它是否已开启。

Nomad 之所以不在后台保存，是因为 3d 文件可能相当大，在您雕刻时会造成明显的卡顿。

此外，为了避免内存不足，场景通常会在保存前先压缩。
这种压缩和解压同样会拖慢保存速度。

### 保存间隔 {#timer-pop-up}
Nomad 每两次自动保存之间等待的分钟数。

### 显示倒计时 {#popup-timeout}
每次自动保存前显示倒计时，如果您正忙着做某件事，可以取消这次保存。停用后，Nomad 会在您停止雕刻时立即保存。

### ![](/icons/trash.webp) 删除自动保存的数据 {#discard-autosave}
如果某个项目存在自动保存文件，打开时会自动加载它，而不是原始项目。如果您不需要它，这个按钮会删除自动保存文件。之后加载该文件时，就会加载项目最后一次手动保存的版本。

### ![](/icons/open.webp) 打开过时的保存 {#open-outdated-save}
当一个项目同时有自动保存和手动保存时，这个按钮会打开两者中较旧的那个（`打开过时的自动保存` 或 `打开过时的手动保存`），并显示其日期。如果最新的保存不是您想要的，这会很方便。

### ![](/icons/storage.webp) 最近删除... {#recently-deleted}
对于离开项目文件夹的项目数据，以及被导入替换掉的文件，Nomad 会保留若干天后才彻底删除。导入失败的文件会一直保留，直到您删除它们。这个列表会显示它们的大小和日期，您可以逐个删除，也可以用 `全部删除` 一次删光。

## 导入 {#import}

### ![](/icons/add_file.webp) 导入 {#import-button}
用于导入非 Nomad 项目的 3d 文件。

把外部场景文件导入 Nomad 时，您可以选择*添加*它，或者用它开始一个*新*项目。

添加文件只是把其中的对象加入当前场景。
选择 `新建` 则会创建一个包含这些新对象的 Nomad 新项目。

导入窗口会列出您选择的每个文件，每个文件都有自己的导入选项。图像也可以用这种方式导入：为每张图像选择它是作为 `HDRI`、`材质捕捉`、`参考图像`、`Alpha`、`纹理` 还是 `VDM`。

Nomad 可以导入以下格式：
- Nomad (.nom)
- glTF (.glb, .gltf)
- OBJ (.obj)
- STL (.stl)
- PLY (.ply)
- FBX (.fbx)
- ZBrush (.ztl, .zpr)
- USD (.usd, .usdz, .usda, .usdc)，需平台支持

### ![](/icons/cog.webp) 设置 {#advanced}
项目缩略图旁边的 `设置...` 按钮会显示主要的导入选项。这些设置不会被保存，导入窗口会显示适用于您正在导入的文件的选项。

### 所有格式 {#project-gltf-obj-stl-fbx}
#### ![](/icons/nomad.webp) 保留拓扑 {#keep-topology}
Nomad 默认会在加载时尝试修复有问题的几何体。启用此选项后，Nomad 将不会重新排序顶点和面、合并重复项，也不会删除未使用的顶点。

::: warning
启用 `保留拓扑` 后，布尔、合并、网格简化或流形等操作可能不会合并重复的顶点。
:::

#### ![](/icons/image.webp) 忽略纹理 {#skip-textures}
对于 glTF 等支持嵌入纹理的格式，不加载文件中嵌入的纹理。

### Nomad / glTF {#project-gltf}
#### ![](/icons/sliders.webp) 加载界面设置 {#keep-gui-settings}
打开或导入项目文件时，加载其中保存的所有界面设置。

### OBJ {#obj}
#### ![](/icons/group_gray.webp) 按组拆分OBJ {#split-obj-by-groups}
把 OBJ 中的组拆分为单独的对象。

#### ![](/icons/vertex.webp) 合并重复位置 {#merge-duplicate-positions}
合并位置相同的顶点。

#### ![](/icons/uv.webp) 合并重复的 UV {#merge-duplicate-uvs}
合并 UV 相同的纹理坐标。

#### ![](/icons/paint.webp) 色彩空间 {#color-space}
设置从文件中解读颜色的模式：`自动`、`线性` 或 `sRGB`。如果颜色看起来不对，可以试着切换这个选项。

#### ![](/icons/image.webp) 格式 {#normal-format}
纹理的法线贴图格式：`自动`、`OpenGL (+Y)` 或 `DirectX (-Y)`。如果法线贴图的细节看起来是反的，就换另一个试试。

### PLY / STL {#ply}
#### ![](/icons/paint.webp) 色彩空间 {#color-space-ply}
设置从文件中解读颜色的模式：`自动`、`线性` 或 `sRGB`。


### FBX {#fbx}
#### ![](/icons/uv.webp) 合并重复的 UV {#merge-duplicate-uvs-fbx}
合并 UV 相同的纹理坐标。

#### ![](/icons/paint.webp) 色彩空间 {#color-space-fbx}
设置从文件中解读颜色的模式：`自动`、`线性` 或 `sRGB`。

#### ![](/icons/image.webp) 格式 {#normal-format-fbx}
纹理的法线贴图格式：`自动`、`OpenGL (+Y)` 或 `DirectX (-Y)`。

### USD {#usd}
#### ![](/icons/paint.webp) 色彩空间 {#color-space-usd}
设置从文件中解读颜色的模式：`自动`、`线性` 或 `sRGB`。

#### ![](/icons/image.webp) 格式 {#normal-format-usd}
纹理的法线贴图格式：`自动`、`OpenGL (+Y)` 或 `DirectX (-Y)`。

![](/images/file_export.webp)

不同的文件格式支持的功能不同，可用的选项会根据所选文件类型而变化。

### ![](/icons/export.webp) 导出按钮 {#export-button}
点击它，按所选设置导出几何体。按钮上会显示所选的格式和预估的文件大小。在 Android 上，旁边的 `分享` 按钮可以把文件直接发送到另一个应用。

### 文件格式 {#file-format}
选择要导出的格式：`NOMAD`、`glTF`、`OBJ`、`FBX`、`PLY`、`STL` 或 `USD`。NOMAD 是 Nomad 自己的格式，其他软件无法加载，所以主要用于重新导入 Nomad。

### 包括 {#allvisibleselected}
选择要导出哪些对象：`全部`、`可见` 或 `已选`。每个选项旁边的数字表示将导出多少个对象。

### 每个对象一个文件 {#one-file-per-object}
把每个对象导出为单独的文件。数字表示将写入多少个文件。

### 类型 {#type}
当导出会写入多个文件时（每个对象一个文件，或带纹理的 OBJ），可以把它们保存在 `文件夹` 或 `压缩文件` 中。有些应用（Google Drive、One Drive 等）不支持导入文件夹，这时可以改用压缩文件。

### 嵌入历史记录 {#embed-history}
仅限 NOMAD。把撤销历史包含在文件中，在 Nomad 中打开该文件时会恢复。它会增大文件大小，并且需要把整个场景导出为单个文件。

### 嵌入资源 {#embed-assets}
仅限 NOMAD。把您自定义的材质捕捉、环境和字体包含在文件中。内置资源不会被嵌入。

### 顶点颜色 {#vertex-colors}
如果文件格式支持，则导出顶点颜色。有些 3d 软件可以读取它们，但并非全部都可以。

对于 OBJ，您可以选择：
* `无` - 不导出颜色。
* `RGB` - 颜色附加在顶点之后。
* `MRGB (ZBrush)` - 另一种编码颜色的方式，还支持蒙版数据。

### 色彩空间 {#color-space-export}
仅限 OBJ，且顶点颜色为 `RGB` 时。以 `线性` 或 `sRGB` 写入颜色。

### PBR绘画 {#pbr-paint}
导出粗糙度、金属度和蒙版的绘画数据。其他软件可能会忽略这些数据。
PBR 顶点颜色会作为第二组顶点颜色属性导出。
各通道的打包方式如下：

|           | 通道  |
| :-------: | :------: |
| 粗糙度 | R        |
| 金属度 | G        |
| 蒙版   | B        |


### 图层 {#layers}
图层通过 glTF 的变形目标（morph targets）来支持。这是 glTF 官方支持的功能，所以在其他软件中应该也能使用。
Nomad 还会导出每个图层的颜色、粗糙度和金属度，但其他软件会忽略它们。

### 图层绘画 {#layer-painting}
导出图层绘画，通常会被其他软件忽略。

### 面组 {#face-group}
导出面组，导出后有时可能会干扰其他软件。

### 写入对象 {#write-objects}
仅限 OBJ。保持对象相互分离。关闭它可以把所有内容导出为单个对象，例如为了使用 Substance Painter 的“Mesh ID / Polygroup”功能。

### 法线 {#normals}
导出法线信息。注意，导入其他文件格式时，Nomad 总是会自己重新计算法线。

### 正切 {#tangents}
导出切线信息，模型带有法线贴图时会用到。

### 纹理 {#textures}
如果材质中添加了纹理，它们会被导出。注意，这不会烘焙纹理，烘焙要通过拓扑菜单中的烘焙选项完成。

### 格式 {#fbx-format}
仅限 FBX。`二进制` 文件更小，但可能不是所有应用都能用；`Ascii` 是文本文件。

### 已压缩 {#compressed}
仅限 FBX。减小文件大小，代价是导出和导入会变慢。

### 预设 {#usd-preset}
仅限 USD。选择您要导出到的应用：`OpenUSD`、`Apple`、`Procreate` 或 `Zbrush`。有些选项只在某些预设下可用。

### 实例 {#instance}
仅限 USD。把实例化的对象导出为实例，而不是复制它们的几何体。

### 允许倾斜 {#allow-skew}
仅限 USD。允许矩阵变换中包含倾斜。停用后，Nomad 会把倾斜的变换拆分为单独的缩放变换和旋转变换。

### 重复器 {#repeater}
仅限 USD。把重复器生成的副本导出为实例。

### 合并副本 {#join-copies}
每个对象和它的重复器副本合并为一个对象。

::: tip 提示：把粗糙度和金属度导入 Blender

Blender 可以导入 glTF/glb，但不会自动识别表示金属度和粗糙度的顶点属性。要使用它们，请在材质编辑器中创建一个“Vertex Color”（顶点颜色）节点，把它的属性设为下一个颜色属性（通常是 Col.001）。再连接一个“Separate XYZ”（分离 XYZ）节点，把 X 接到粗糙度（Roughness），把 Y 接到金属度（Metallic）。

这个视频展示了整个过程：

![](/videos/blender_pbr.mp4)

::: 

::: tip 提示：USD 功能支持

USD 是一种复杂的格式，它的规范支持很多功能，但并非所有 3d 软件都支持这些功能。例如 OSX/iOS 不支持顶点颜色。USD 导出器中的预设模式会尽量猜测与 OpenUSD、Apple、Procreate、Zbrush 的最佳兼容方式。

::: 

## ![](/icons/screen.webp) 渲染 {#render}

导出一张图像，它融合了项目中的所有设置（灯光、材质、后期处理等）。

![](/images/file_render.webp)
### ![](/icons/preview.webp) 预览 {#preview}

菜单标题旁边的 `预览` 按钮会让界面变得透明，方便您预览最终结果的构图。

### ![](/icons/home.webp) 聚焦 {#focus}
调整场景或选区的取景，让它适合渲染尺寸。再点一次可在两者之间切换。

### ![](/icons/map.webp) 高度图 {#heightmap}
把场景渲染为从相机看去的灰度高度图，越近的部分越亮。启用后会切换到 `正方形` 尺寸，并对选区取景。视口中的一个小滑条可以调整渐变的 `聚焦`。

开启 `高度图` 后，导出按钮旁边会出现一个 `另存为 Alpha` 按钮，可以把渲染结果保存为新的笔刷 Alpha，而不是导出文件。

### ![](/icons/opacity.webp) 透明背景 {#transparent-background}
为渲染启用 Alpha 通道，方便在 2d 软件中把渲染结果与其他图像组合。注意，不支持半透明。

### ![](/icons/sliders.webp) 显示界面 {#show-interface}
在渲染中包含 Nomad 的界面。

### 渲染尺寸 {#final-size}
渲染使用的分辨率：`屏幕分辨率`、`720`、`1080`、`4096`、`正方形` 或 `自定`。

当文件菜单处于打开状态时，如果渲染区域与屏幕分辨率不一致，视口中会绘制一个虚线框来标出渲染区域。

### 宽度 / 高度 {#render-ratio}
选择 `自定` 时，可以设置图像的宽度和高度。两个滑块之间的链接按钮会在您修改其中一个时保持宽高比。选择 `正方形` 时，只能设置宽度。

### ![](/icons/export.webp) 导出 → PNG {#export-png}
点击此按钮开始渲染。完成后，您可以选择如何保存或分享图像。尺寸非常大时会先要求确认：请先保存项目，以防设备内存不足。

## ![](/icons/network.webp) 连接 {#link}

把 Nomad 与另一台设备或另一个应用连接起来，用来发送和接收对象，或实时同步您的编辑。由一台设备作为主机创建会话，其他设备加入。

### 启用 GoZ {#enable-goz}
仅限桌面端。与本机上的 ZBrush 交换网格。`发送` 会把网格导入 ZBrush，`获取` 则从正在运行的 ZBrush 导入：`选区` 获取当前活动的子工具，`场景` 获取所有子工具。您也可以随时在 ZBrush 中按 GoZ。

### 模式 {#link-mode}
* `关闭` - 不连接。
* `主机` - 本设备作为主机创建会话，并等待其他设备加入。
* `加入` - 搜索附近的设备，然后点击主机的名称加入。

要连接两个 Nomad，在一台设备上选择 `主机`，在其他设备上选择 `加入`。要与 Blender 连接，Nomad 应作为主机：`连接` 标题旁边的帮助按钮会说明如何安装 Nomad Blender Link 扩展。

### ![](/icons/network.webp) 网络端口 {#network-port}
连接使用的网络端口。只有当其他应用已经占用该端口时才需要修改。

### 发送 / 获取 {#send-get}
连接后，可以把您的 `选区` 或整个 `场景` `发送` 到另一台设备，或者从它那里 `获取`。`替换` 会删除当前场景，然后获取另一台设备的场景。

### ![](/icons/link.webp) 实时同步 {#live-sync}
在您工作时把编辑实时传送到另一台设备。`工作视图` 还会同步相机。`场景编辑` 设置由哪台设备发送编辑：`自动` 会让最近有操作的一方来发送。然后选择要同步的内容：`物体与几何体`、`材质`、`灯光`、`相机`，以及在对方支持时的 `渲染模式` 和 `后期处理`。

::: tip
已有的对象需要先 `发送` 或 `获取` 一次，把它们连接起来，实时同步才能更新它们。
:::
