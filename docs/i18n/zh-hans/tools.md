## 概览 {#overview}

工具在右侧的 `工具箱` 中选择，在左侧的 `工具控制栏` 中调节。更多设置位于右上角菜单中的 `工具` 菜单。

画笔类工具可以调节大小和强度。选区类工具提供几种不同的选区方式。工具控制栏底部是常用操作的快捷按钮（平滑、蒙版、隐藏、面组、轴向变换、颜色、Alpha）。

Nomad 的工具在工具箱中按颜色区分（在 [界面](interface.md) 菜单中关闭 `彩色工具` 即可显示为普通标签）：

* <span class=brush>**画笔类工具**</span>（黏土、画笔、平滑、图层、膨胀、擦除、Quad Remesher）
* <span class=move>**移动类工具**</span>（移动、拖拽、弹性、微移）
* <span class=mask>**蒙版工具**</span>（蒙版）
* <span class=paint>**绘画类工具**</span>（绘画、涂抹）
* <span class=flatten>**铲平类工具**</span>（铲平、平面、抛光）
* <span class=pinch>**捏合类工具**</span>（褶皱、捏合）
* <span class=stamp>**图章类工具**</span>（图章、VDM）
* <span class=selection>**基于选区的工具**</span>：先画出一个 2d 蒙版，再执行操作（裁切、分割、投影）
* <span class=creation>**创建类工具**</span>（圆管、车削、插入）
* <span class=transform>**变换类工具**</span>（自由变换、轴向变换、排列、格子）
* <span class=misc>**其他工具**</span>（面组、隐藏）
* <span class=view>**查看类工具**</span>（浏览模式、测量、选择）



其中很多工具都可以通过 [笔触](stroke.md) 菜单自定义不同的画笔行为、压感、纹理等。


### 画笔控制 {#brush-controls}

左侧工具栏有半径和强度滑块，下面是各类工具特有的控制项，详见下文。

![](/images/tool_left_panel.webp)

### 反向模式 {#sub-mode}
强度滑块正下方的按钮是 `反向` 按钮。它的标签和功能随工具而变，按下后会切换到另一种（通常是相反的）行为。例如对于 [绘画](#paint) 是擦除模式，对于 [褶皱](#crease) 则是做出凸起的边而不是凹痕，等等。

默认情况下它是一个“按住生效”的按钮：按住时临时启用，松开后就会关闭。如果轻点一下，反向模式就会一直保持开启。

### 快捷按钮 {#shortcuts}
左侧工具栏底部是 [平滑](#smooth)、[蒙版](#mask)、[隐藏](#hide)、[面组](#facegroup)、[轴向变换](#gizmo)、[颜色](painting.md#pbr-sliders)、[Alpha](stroke.md#alpha) 的快捷按钮。

默认情况下它们都是“按住生效”的按钮：按住时临时启用，松开后就会关闭。如果轻点一下，对应的快捷模式就会一直保持开启。

### 选区控制 {#selection-controls}

[蒙版](#mask)、[绘画](#paint)、[裁切](#trim)、[分割](#split)、[投影](#project)、[面组](#facegroup)、[隐藏](#hide) 和 [选择](#select) 工具都使用类似的控制方式来选择网格上的区域。

![](/images/tools_shape_selector_panel.webp)

轻点左侧工具栏中的形状按钮（它显示当前的形状，默认为 `套索`），会弹出一个形状列表。对于同时也能用画笔操作的工具（蒙版、绘画、面组、隐藏），这个弹出窗口里还有笔触类型。

* `视图` - 没有形状，工具不做任何事，就像相机模式一样。
* `套索` - 徒手画出的形状。
* `多边形` - 由曲线和/或直线组合而成的封闭形状。详见下方的 [形状编辑](#shape-editing)。
* `曲线` -（仅限投影）用于投影的徒手曲线。
* `路径` -（仅限投影）由点定义的曲线。详见下方的 [形状编辑](#shape-editing)。
* `直线` - 拖出一条直线来定义一个平面切割。默认情况下会立即作用于网格，如果不想这样，可以更改 `编辑` 选项（在直线图标上长按或滑动）。
* `条带` - 两条平行参考线之间的带状区域，横跨其上有一个渐变。`延伸` 会让远端参考线之外的区域保持完整数值，而不是在条带处停止；`翻转` 会交换渐变的起始参考线。
* `矩形` - 拖出一条对角线，定义矩形的两个角。长按或滑动可显示 `编辑` 选项、强制为正方形的 `正方形`，以及让第一次点击作为矩形中心的 `中心`。
* `椭圆` - 拖出一条对角线，定义椭圆的大小。长按或滑动可显示 `编辑` 选项、强制为圆形的 `圆形`，以及让第一次点击作为椭圆中心的 `中心`。
* `翻转` - 反转形状蒙版，或反转投影工具的方向。

大多数工具都有一个 `编辑` 选项，决定画完形状后会发生什么：
* `编辑：关` - 松开时立即执行操作。
* `编辑：开` - 形状保持可编辑状态。形状旁会出现一个绿色按钮，用来执行操作。这样您可以先调整形状、调整视角，准备好后再按下绿色按钮。
* `编辑：按住` - 松开时执行操作，除非您在笔画末端按住不放，这样可以继续编辑形状。

### 形状编辑 {#shape-editing}
多边形编辑和曲线编辑的操作方式类似：

* 首先拖出一条线来定义 2 个点，然后从线的中间向外拖动，形成多边形或曲线。
* 点击某个点可以在平滑和尖锐之间切换。
* 在曲线或线段上点击并拖动可以创建新的点。
* 要删除一个点，把它拖到相邻的点上，直到它变成红色。
* 多边形或路径图标角上的垃圾桶图标会删除这个形状。

### ![](/icons/tool_brush.webp) 画笔 {#brush}
标准画笔。`反向` 会去除材料。

![](/videos/tool_brush.mp4)

### ![](/icons/tool_move.webp) 移动 {#move}
画笔下方的区域会粘在画笔上，从而产生弹性变形。移动过程中选中的区域保持不变，所以如果您把画笔移开再移回起点，就会看不到任何变形。

反向模式是 `法线方向`，会让画笔下的区域沿表面法线移动。

这个画笔既适合大范围的变形，也适合细致的小幅变形。

#### 移动设置 {#move-settings}

* `半径（背景）` - 离开模型边缘多远时仍然可以雕刻，处理物体的轮廓时很有用。取消勾选后，只有从模型上开始拖动时才会抓取。
* `仅同侧顶点` - 忽略朝向与变形方向相反的顶点。
* `方向` - 供 `法线方向` 反向模式使用，决定拖动是推还是拉表面：
    * `自动选择` - 根据表面法线的角度，自动从下面两种方法中选一种。
    * `3D 法线` - 把指针在屏幕上的位置与从相机看到的表面法线进行比较。
    * `XY` - 根据指针在屏幕上的位置（上下、左右）来决定推还是拉。
    * `阈值` - 使用 `自动选择` 时，决定采用哪种方法的角度界限。
* `滚转速度` - 移动时可以同时扭转抓住的区域：双指旋转、转动触控笔的笔杆，或在用鼠标拖动时按住修饰键（Alt、Ctrl、Shift 或 Cmd）。手指、触控笔和鼠标各有一个滑块；取消勾选即可关闭对应的输入方式。


![](/videos/tool_move.mp4)

### ![](/icons/tool_drag.webp) 拖拽 {#drag}
画笔下方的区域会粘在画笔上，从而产生弹性变形。与移动画笔不同，在一笔之中选中的区域会持续更新，所以可以拉出更长的、像蛇一样的形状，开启动态拓扑时尤其如此。

反向模式是 `法线方向`，会让画笔下的区域沿表面法线移动。

这个画笔适合更随意、更有动势的形体调整。

#### 拖拽设置 {#drag-settings}

拖拽的设置与 [移动](#move-settings) 相同：`半径（背景）`、`仅同侧顶点`、`方向` 和 `滚转速度`。

![](/videos/tool_drag.mp4)

### ![](/icons/tool_elastic.webp) 弹性 {#elastic}
像 [移动](#move) 一样抓住并拉动表面，但变形是弹性的：拉力不会在画笔边缘戛然而止，而是随着距离在整个物体上平滑衰减，有点像拉伸橡胶。画笔半径决定拉动的范围有多宽。

反向模式是 `法线方向`，会让画笔下的区域沿表面法线移动。

这个画笔适合做大幅度、柔和且保持平滑的比例调整。

#### 弹性设置 {#elastic-settings}

弹性的设置与 [移动](#move-settings) 相同，只是没有 `仅同侧顶点`。`半径（背景）` 默认关闭。

### ![](/icons/tool_smooth.webp) 平滑 {#smooth}
通过平均各点的位置来平滑区域。这个工具的效果很大程度上取决于多边形密度。
所以多边形越多，平滑效果就越弱。

反向模式是 `规整网格`，只平滑线框，同时尽量保留几何细节。

#### 平滑设置 {#smooth-settings}

![](/images/tool_smooth_settings.webp)

##### 面组 {#smooth-facegroup}

* `规整网格` - 平滑面组的边界。把强度设到 100% 以上可以快速平滑边界。`自动` 只在开启面组预览时才平滑，`否` 为关闭，`是` 为开启。

##### 顶点 {#vertex}
* `保持体积` - 平滑时不会让表面收缩，所以反复平滑也不会让形体瘪下去。旁边的齿轮按钮里是为此使用的 `收缩` 和 `膨胀` 数值。
* `保留边界` - 对于有开放边的网格（例如平面），平滑可能会把角抹掉。启用此选项后，网格边界上的顶点会保持不动。
* `稳定平滑` - 尽量让平滑效果不受拓扑影响。在拓扑密度不均匀、平滑强度较高时效果最好。
* `规整网格` - 与左侧工具栏中的规整网格反向模式相同。

##### 绘画 {#painting}
* `屏幕平滑` - 使用此选项可以获得与拓扑无关的平滑效果，即使面数很高也一样。可选 `自动`、`否` 或 `是`。
* `屏幕样本` - 平滑的质量，数值越高越平滑，但速度也越慢。

::: tip
多边形密度较高时，可能需要把强度调到 100% 以上。非常高的数值（300%、500%）也很适合当作雕刻工具使用，能让画笔下的区域迅速变平、变光滑，就像用木槌敲打黏土一样！
:::

### ![](/icons/tool_mask.webp) 蒙版 {#mask}
这个工具用来给顶点添加蒙版。被蒙版遮住的顶点不会受到雕刻或绘画的影响。

反向模式是 `消除蒙版`，会擦除已经画上的蒙版。

和 2d 绘画软件中的选区类似，蒙版可以用画笔绘制，也可以用形状选区（`套索`、`矩形`、`条带`……）创建，还可以模糊或锐化。在左侧工具栏的笔触弹出窗口中选择画笔或形状，详见 [选区控制](#selection-controls)。

与 2d 绘画软件不同的是，蒙版还可以通过面组来创建，并且可以用类似挤出/抽取的操作，利用蒙版生成新的几何体。

![](/videos/tool_mask1.mp4)

#### 蒙版设置 {#mask-settings}
![](/images/tool_mask_settings.webp)

![](/videos/tool_mask2.mp4)

蒙版设置主要用来根据蒙版创建几何体。顶部的选项卡用来选择操作：[抽壳](#extract)、[分离](#split-mask) 或 [雕刻](#carve)。下面的选项会随操作而变化。

* `预览` - 调整设置时显示新几何体的效果。
* `X光` - 预览时哪些对象以 X 光方式显示：`无`、`未选择`、`已选` 或 `全部`。

##### 抽壳 {#extract}
* `抽壳` - 把抽取出的几何体创建为一个新对象。
* `关闭操作` - 抽取出的形状如何闭合。`无` 会把有蒙版的多边形复制成一个新形状，并保持开放。`填补` 同样会复制，并在背面填补和平滑孔洞（不要在平坦的表面上使用）。`抽壳` 会按照 `高度` 数值把形状闭合，这是默认选项。

::: tip

如果开启了带 X 光的预览，第一次点击抽壳按钮时可能会让人困惑。因为菜单仍处于激活状态，它会尝试在您的新形状上预览抽取，并用 X 光显示原来的表面。但是新表面上没有蒙版，无法预览抽取，于是 Nomad 会提示“没有可抽取的内容！”。

这是正常的。关闭蒙版设置菜单，就能看到新形状和原来的形状；如果需要清除蒙版或绘制新的蒙版，请重新选中原来的表面。
:::

##### 分离 {#split-mask}
* `分离` - 把有蒙版和没有蒙版的区域都抽取成新的形状。
* `关闭操作`（有蒙版）- 有蒙版部分的闭合方式，与抽壳一样有 `无`、`填补` 和 `抽壳` 可选。
* `关闭操作`（无蒙版）- 无蒙版部分的闭合方式，选项相同。

##### 雕刻 {#carve}
* `雕刻` - 效果就像按 `高度` 的深度切入表面一样，类似切下一片橘子皮。`高度` 不能为 0。

##### 高度 {#thickness}
* `高度` - 抽取出的形状的高度。加/减按钮可以在向外挤出、向内挤出和两侧挤出之间切换。

##### 平滑度 {#smoothness}
启用后会平滑抽取出的形状，多边形数量较多时效果更好。
* `全部` / `仅边界` - 平滑整个形状，或只平滑边界，保持顶面的形状不变。
* `迭代次数` - 选择 `全部` 时的平滑程度。数值高会得到非常平滑的圆弧边缘，但会开始偏离蒙版的形状。
* `侧壁` - 选择 `仅边界` 时，侧壁的平滑程度。它的按钮可以在 Relax（保留硬角）和 Smooth（同时把角也磨圆）之间切换。
* `内部` - 选择 `仅边界` 时，顶面被整平的程度。它的按钮可以在 Relax 和 Smooth 之间切换：Relax 保留雕刻的细节，只统一挤出方向（这样细节就不会产生尖刺）；Smooth 则平滑表面本身。

##### 侧面 {#edge-loop-side}
* `直线` - 抽取形状的侧面为普通的直壁。
* `倒角` -（仅限抽壳操作，且关闭操作为 `抽壳` 时）在正面边缘加一圈斜边。`倒角` 设置它的宽度，单位为 `高度` 的百分比或世界单位（用旁边的按钮切换），`倒角分段` 对它进行细分（默认 `自动`），还可以用曲线调整它的轮廓。
* `轮廓` - 用轮廓曲线塑造侧壁形状，`宽度` 的单位为 `高度` 的百分比或世界单位。
* `蒙版` - 高度跟随蒙版变化：蒙版模糊的部分高度更低，可以做出柔和、高度有变化的形状。
* `侧壁分段` - 侧面的循环边数量。选择 `自动` 时，Nomad 会自动选择合适的分段数，生成与蒙版区域多边形大小相匹配的方形多边形。

### ![](/icons/tool_planar.webp) 平面 {#planar}
把各点投影到平均平面上使其共面，但堆积感比铲平画笔弱，能做出更干净的硬边表面。快速的笔触会更多地推拉表面；从已经平整的区域开始、再慢慢向外扩展的笔触，则更能保持平面。

反向模式是 `填充`，会以最高点确定一个平面，倾向于把各点向上拉。

平面工具其实就是开启了 `锁定平面方向` 的 `铲平`，所以它更容易做出稳定的硬边表面，而铲平则更偏雕塑感，可以用来做半平坦的区域。

![](/videos/tool_planar.mp4)

反向模式是 `填充`，与铲平相同。

抛光的设置与 [铲平](#flatten-settings) 相同：`锁定平面方向` 和 `锁定平面原点`。

### ![](/icons/tool_crease.webp) 褶皱 {#crease}
褶皱工具适合雕刻细小的切痕或凹痕。

反向模式是 `反转`，会做出凸起的褶皱。

#### 褶皱设置 {#crease-settings}

* `力度` - 把顶点向画笔两侧收拢的程度。如果力度为 1、偏移因子为 0，表面深度不会改变，只会改变拓扑，把边拉向笔触。
* `偏移因子` - 在深度方向上推/拉顶点的程度。如果力度为 0、偏移因子为 1，会做出很深的褶皱或凸起的凹痕，但看起来会有锯齿，因为没有足够的几何体被拉向褶皱，无法准确定义褶皱的侧面或底部。

![](/videos/tool_crease.mp4)

### ![](/icons/tool_trim.webp) 裁切 {#trim}
裁切工具会切掉网格的一部分，并提供几种处理切口的方式。它使用 [选区控制](#selection-controls) 来定义裁切范围。

反向模式是 `翻转`，会反转形状，从而切掉另一侧。

::: tip
由于这个工具是从相机方向投影的，如果相机处于透视模式，您会收到一条警告。

在正交模式下，穿过网格的切面与视图平行，这通常正是大家所期望的。如果用透视相机来切，物体远端和近端的切口看起来会不一样。
:::

#### 裁切设置 {#trim-settings}

这些设置都归在 `孔洞填补` 下：

* `笔触绘画` - 如果在绘画菜单中启用了绘画，补上的区域会用当前选中的颜色填充。
* `布尔` - 用四边形区域填补裁切留下的孔洞。填补的区域是平的。
* `传统` - 用三角面区域填补裁切留下的孔洞。填补的区域是平的。
* `填充` - 用三角面区域填补孔洞。填补的区域是弯曲的表面，就像肥皂泡的薄膜一样。
* `无` - 不填补孔洞。

选择 `布尔` 时，`细节` 部分包括：

* `形状` - 裁切后形状一侧所用四边形和三角形的大致尺寸。
* `孔洞` - 填补孔洞时所用三角形或多边形的大致尺寸。`细节` 旁边的链接按钮会让它与 `形状` 保持同步，取消链接即可单独设置。
* `保留拓扑` - 不平滑、不简化切口边界，保留有蒙版和隐藏面附近的原始网格拓扑。

选择 `传统` 时：

* `细节` - 裁切所用三角形的大致尺寸。
* `平滑孔洞` - 填补区域中三角形的规整程度。
* `填充阈值` - 可以调整这个数值来改善传统孔洞填补算法的效果。

选择 `填充` 时：

* `细节` - 裁切所用三角形的大致尺寸。

![](/videos/tool_trim.mp4)

### ![](/icons/tool_layer.webp) 图层 {#layer}
抬高表面，但限制高度。

如果您保持笔不抬起，在同一区域反复涂抹，图层工具会抬高到一定高度后就不再升高，而其他工具则会不断累积高度。

请注意，默认情况下这个高度限制只针对单个笔触！如果开始新的一笔，它会从新的表面高度继续堆积。

如果想在多个笔触之间保持固定的最大高度，请把图层工具与 Nomad 的 [图层](layers.md) 系统一起使用。

先创建一个图层，再使用这个工具。这时最大高度由图层决定，所以无论涂抹多少笔，高度都会保持一致。

`反向` 会使用最小深度，做出凹槽。

#### 图层设置 {#layer-settings}

* `使用图层数据` - 启用后，如果选中了一个图层，就用图层数据来设置最大高度。没有选中图层时会有警告提醒您。
* `膨胀` - 启用后会调整图层工具的作用方向，得到更平滑的效果。
* `规整网格（法线）` - 启用 `膨胀` 后，对法线施加的平滑程度。

### ![](/icons/tool_stamp.webp) 图章 {#stamp}

点击并拖动，可以按所选 Alpha 的形状抬高雕塑上的一块区域。

它其实就是把笔触类型设为 `锁定 + 半径` 的 [画笔工具](#brush)。

`反向` 会把图章压进表面，而不是从表面拉出来。

::: tip
图章通常在高分辨率几何体上效果最好。上网搜索“wrinkles alpha”（皱纹 Alpha）、“pores alpha”（毛孔 Alpha）、“scales alpha”（鳞片 Alpha）等，这些 Alpha 纹理配合图章工具，是给角色雕塑添加自然细节的好办法。

两种笔触模式各有用处。

* `锁定 + 半径` 的*高度*固定，拖动可以调整图章的宽度和旋转。适合皮肤纹理，这类纹理需要深度/高度一致，但旋转和大小各不相同，以免出现明显的重复图案。
* `锁定 + 强度` 的*宽度*固定，拖动可以调整图章的旋转和高度。适合铆钉，铆钉的大小都必须一样，但旋转和高度可以不同。

:::

![](/videos/tool_stamp.mp4)

### ![](/icons/tool_vdm.webp) VDM {#vdm}

盖印一张矢量置换贴图（VDM）。Alpha 只能把表面向上或向下推，而 VDM 保存的是完整的 3d 形状，所以能盖印出耳朵、角或卷曲的叶子这类有悬垂结构的形状。它的用法与 [图章](#stamp) 相同，同样有 `锁定 + 半径` 和 `锁定 + 强度` 两种笔触模式。

`反向`（`反转`）会翻转图章的深度，像模具一样把它压进表面。

VDM 本身在 [Alpha](stroke.md#alpha) 菜单中选择，该菜单还有一个 `高度` 滑块，只缩放图章的高度，横向的置换保持不变。

左侧工具栏中的 `创建` 按钮可以用来制作自己的图章：

* `新建 VDM…` - 添加一个为 VDM 雕刻准备好的平面。在上面雕刻出形状，然后用 `拓扑 -> 烘焙 -> VDM` 烘焙：Nomad 会把新图章添加到 VDM 库中并选中它。
* `捕获 VDM` -（实验性功能）在模型表面上拖动，抓取该区域并把它变成一个 VDM 图章。`容差` 会把捕获区域的边界平滑地压平。

::: tip
雕刻 VDM 平面时不要使用动态拓扑，它会破坏平面的 UV，导致图章变形。雕刻内容也要远离平面的边界，否则图章会出现生硬的边缘。
:::

反向模式是 `反转`，会稍微加强图层，而不是擦除它。

### ![](/icons/tool_tube.webp) 圆管 {#tube}
画一条曲线来创建圆管。
![](/images/tool_tube_new.webp)

创建圆管后，可以在 3d 空间中编辑它的路径，操作方式与标准的 [形状编辑](#shape-editing) 和曲线编辑工具类似。

![](/videos/tool_tube.mp4)

#### 圆管左侧工具栏 {#tube-left-toolbar}

![](/images/tool_tube_left_toolbar.webp)

左侧工具栏有以下选项：

* `同步` - 如果当前圆管是实例，并且各实例之间圆管的子节点不一致，这个按钮会重新同步它们。
* `吸附` - 启用后，曲线和路径模式在绘制时会吸附到其他对象上。关闭时，只有第一个点会吸附，圆管的其余部分会在该深度上绘制。
* `偏移` - 设置吸附的深度：0% 时圆管截面的中心吸附在表面上，正值会把它抬离表面，负值会让它沉入表面。100% 等于圆管的半径。
* `视图` - 不绘制，可以自由移动相机。
* `曲线` - 徒手画出圆管。它有一个小的弹出菜单：
    * `编辑` - 画完笔触后会发生什么，详见 [选区控制](#selection-controls)：立即创建圆管；保持曲线可编辑，旁边有一个绿色的确认圆圈；或者在笔画末端 `按住` 以继续编辑。
    * `闭合` - 让圆管首尾相连成环。
    * `继续绘制` - 确认一个圆管后，仍留在工具中绘制下一个。
    * `精度` - 把画出的路径转换为圆管时使用多少个曲线点。0% 使用最少的点，但会漏掉路径中细小的弯曲变化。100% 非常精确，会使用很多点。
* `路径` - 通过点击定义曲线点来创建圆管。轻点绿色圆圈确认路径。它有一个小的弹出菜单：
    * `B样条` - 另一种曲线绘制方式，曲线点通常不直接落在曲线上，但能得到比默认方式更平滑的结果。
    * `闭合` - 让圆管首尾相连成环。
    * `屏幕` - 启用后，路径会“钉”在屏幕上，您可以移动视图和对象，而路径保持不动。关闭时，路径是 3d 场景的一部分，会随相机和对象移动。
* `截面` - 曲线变成环绕形状的一个圆环，沿着您当前的观察方向，穿过曲线的两个点切出。

##### 圆管顶部工具栏 {#tube-top-toolbar}
![](/images/tool_tube_toolbar.webp)
选中圆管后，视口顶部会出现一个工具栏，提供更多控制项。点击工具栏的标题可以折叠/展开它，点击右上角的箭头可以把它移到视口的顶部或底部。

* `转换` - 把圆管烘焙成普通的多边形，以便雕刻。
* `编辑` - 显示曲线点，以便调整。
* `镜像` - 为这条曲线添加一个镜像重复器作为父级。
* `吸附` - 把曲线点吸附到附近的表面上。
* `闭合` - 把曲线的起点和终点连起来，形成一个环。
* `B样条` - 在 Catmull-Rom 和 B 样条插值之间切换。
* `盖帽` - 在两端都加盖、只在起点或终点加盖、不加盖之间循环切换。
* `孔洞` - 给圆管增加厚度，把它变成一根管子。在两端都开孔、只在终点开孔、不开孔之间循环切换。
* `半径` - 在统一半径、起点和终点各一个半径、每个曲线点一个半径之间循环切换。用曲线上的橙色控制柄来编辑。
* `扭曲` - 在无扭曲、统一扭曲、起点和终点各一个扭曲、每个曲线点一个扭曲之间循环切换。用曲线上的粉色控制柄来编辑。
* `轮廓` - 在无轮廓（即圆形轮廓）、统一轮廓、起点和终点各一个轮廓、每个点一个轮廓之间循环切换。
* `轮廓编辑` - 显示轮廓编辑器。它的用法与 [形状编辑](#shape-editing) 工具类似，可以保存和加载轮廓预设，还有一个开关可以在 3d 空间中编辑轮廓。
* `螺旋` - 打开一个菜单，为圆管添加螺旋扭转。这个菜单有 `扭转角度`、`偏移`、`缩放` 和 `角度偏移` 选项。
* `X 分段数` - 圆管一周的分段数，例如 4 段会得到一根方管。
* `恒定密度` - 启用后会保持多边形为方形。关闭后可以设置沿圆管长度方向的 `Y 分段数`。
* `...` - 圆管设置菜单。

#### 曲线点删除开关 {#curve-point-delete-toggle}

![](/images/tool_tube_delete_toggle.webp)

工具栏下方有一个曲线点删除开关。当您把一个曲线点拖到另一个点附近时，它会变成红色，表示如果松手，这个点就会被删除。如果您在做细微的调整，不想删除点，可以用这个按钮关闭删除点的行为。



#### 圆管设置 {#tube-settings}
* `基本体` - 用于启用/禁用 UV 或转换圆管的按钮。
* `后期细分` - 转换前设置多分辨率级别的快捷方式。
* `线性细分` - 转换前设置线性细分级别的快捷方式。
* `分段数 X` - 与工具栏中的 X 分段数相同。
* `分段数 Y` - 与工具栏中的 Y 分段数相同。

::: tip
分段数设为 4、后期细分设为 3，可以做出两端圆润的光滑圆管，很适合做蠕虫、蛇和身体部位。

### ![](/icons/tool_insert.webp) 插入 {#insert}
把一个对象放到另一个对象的表面上。用起来和图章工具很像，只不过放置的是完整的 3d 形状。

如果在左侧工具栏中选择一个基本体，在任意表面上点击并拖动，就会在点击处放置这个基本体，拖动的距离决定它的大小。拖动结束后，插入工具会切换到 [自由变换](#transform) 模式。

在实例模式下，拖动会创建一个新实例并让它在表面上滑动。大小沿用第一个形状，这样就可以在其他表面上放置许多同样大小的对象实例。

不只是基本体可以插入！在大纲视图中选中*任意*形状，只要插入工具处于实例或克隆模式，就可以把选中对象的副本拖放到任何其他表面上。

如果对象有自定义的轴心，它会被用作锚点。请看下面的视频。

左侧工具栏还有 `视图`，用来移动相机而不插入任何东西；以及 `同步`：当目标对象是实例时，新对象也会被添加到所有其他实例上。

### ![](/icons/tool_transform.webp) 自由变换 {#transform}
用单指或双指直接移动/旋转/缩放模型，通常是在另一个对象的表面上进行。

左侧工具栏有以下按钮：

* `克隆` / `实例` - 复制对象或创建对象的实例，参见 [轴向变换](#left-menu-toolbar) 工具栏。
* `移动` - 单指拖动可以移动对象。启用吸附时，对象会沿着手指下方的表面滑动。
* `旋转` - 单指拖动可以旋转对象。启用吸附时，会绕手指下方表面的法线旋转。
* `缩放` - 单指拖动可以缩放对象。

视口顶部的工具栏有：

* `目标` - 工具移动的是对象、它所在的组，还是它的顶点，与 [轴向变换](#left-menu-toolbar) 相同。
* `表面吸附` - 把模型吸附到其他表面上。
* `表面` / `顶点` - 启用 `表面吸附` 时，吸附到表面上，或吸附到最近的顶点上。

自由变换工具可以用双指快速操作其中两种模式：

* 拖动对象来放置它。第一根手指停止移动，但不要离开屏幕。
* 第一根手指保持按住，第二根手指触碰屏幕。拖动第二根手指时，对象会缩放。
* 抬起第二根手指，继续拖动第一根手指，对象就回到移动模式。

您也可以用第二根手指轻点的手势来切换第二种模式：

* 拖动对象来放置它，停止移动，但手指不要离开屏幕。
* 第一根手指保持按住，用第二根手指轻点一下。
* 工具切换到旋转模式。拖动第一根手指来设置旋转。
* 像之前一样用第二根手指轻点，工具就会切换回移动模式。

这样就有了一种在另一个对象上快速克隆对象的工作流程，例如在地形上摆放石头。注意，克隆按钮也在左侧工具栏中，方便使用：

* 用自由变换工具把一块石头移到合适的位置。
* 松开手指，按下克隆按钮。
* 移动这块石头，按需要旋转/缩放。
* 松开手指，按下克隆按钮。
* 移动这块石头，如此重复。

![](/videos/tool_transform.mp4)

### ![](/icons/tool_gizmo.webp) 轴向变换 {#gizmo}
这个工具可以移动、旋转和缩放对象，还可以调整对象的轴心。

视口中的控制柄有以下功能：

* `移动` - 拖动带箭头的轴线，沿 X/Y/Z 移动。拖动轴向变换控制柄中间的桃色圆点，可以在屏幕空间中自由平移。点击红、绿、蓝色方块，可以在 X/Y/Z 平面上平移。
* `旋转` - 拖动红/绿/蓝色圆环，绕 X/Y/Z 旋转。拖动圆环内的球体可以自由旋转。
* `缩放` - 拖动外侧的红/绿/蓝色圆点，沿 X/Y/Z 缩放。拖动外侧的红/绿/蓝色圆锥，在 X/Y/Z 平面上缩放。拖动外侧的桃色圆环可以等比缩放。

![](/images/tool_gizmo.webp)

#### 节点和顶点 {#nodes-and-vertices}

Nomad 中的每个对象都由一个节点和若干顶点组成：

* `节点` - 对象的“把手”，保存它的平移、旋转和缩放，也就是它的变换矩阵。
* `顶点` - 定义对象表面的点，保存位置和绘画信息。

假设有一个由 8 个顶点组成的简单立方体，您可以通过修改它的变换矩阵来移动它，也可以通过修改顶点位置来移动它。雕刻时通常要修改的是顶点；用轴向变换工具移动对象时，通常要修改的是节点。Nomad 两种方式都支持。

#### 轴向变换工具栏 {#left-menu-toolbar}

左侧工具栏有：

* `克隆` - 为当前对象创建一个独立的副本，可以用轴向变换控制柄把它拖开。
* `实例` - 为当前对象创建一个实例副本。这些对象相互关联，所以在一个对象上做的雕刻改动会出现在所有实例上。
* `轴心` -（锁形图标，位于 `反向` 按钮的位置）启用后，可以移动和旋转轴向变换控制柄而不移动对象。和 `反向` 一样，按住可以临时切换，轻点则保持开启。

视口顶部的工具栏有其他控制项：

* `目标` - 设置轴向变换作用于对象的节点还是顶点：
    * `自动选择` - 默认选项，效果与 `组` 相同，但如果网格有蒙版或启用了对称，则效果与 `顶点` 相同。
    * `顶点` - 把变换作用于顶点，会考虑蒙版和对称。对未转换的基本体无效，实例也会受到影响。
    * `对象` - 只移动当前对象，忽略对称和蒙版。子对象保持不动。
    * `组` - 移动对象及其层级中的其他部分，忽略对称和蒙版。
    * `实例` -（对象和组）同上，但对象的所有实例都会一起移动。
* `轴心` - 一个用于快速放置轴心的弹出窗口，详见 [下文](#pivot)。
* `全部` / `移动` / `旋转` / `缩放` - 显示所有控制柄，或只显示移动、旋转或缩放控制柄。
* `钉住` - 默认情况下，轴向变换控制柄会移到所选对象的轴心处。启用钉住后，控制柄会停留在当前位置。
* `对齐` - 切换轴心与当前对象对齐，还是与世界对齐。
* `角度吸附` - 启用后，旋转数值会按增量吸附，启用时会显示吸附数值，并且可以编辑。它的 `磁吸` 选项会让旋转经过某个步进时停在那里，然后再继续自由移动；关闭它则会从一个步进直接跳到下一个。
* `移动吸附` - 启用后，平移数值会按增量吸附，启用时会显示吸附数值，并且可以编辑。

#### ![](/icons/reset.webp) 轴心 {#pivot}
顶部工具栏中的 `轴心` 弹出窗口可以快速更改轴心。轴心的位置和朝向决定了轴向变换控制柄的位置和朝向。

**重置**
* `自动` - 对象的中心，与对象的变换对齐。
* `中心` - 把轴心移到对象的中心，保持朝向不变。
* `底部` - 把轴心移到对象底部的中心。再点一次则改用世界包围盒。
* `顶部` - 把轴心移到对象顶部的中心。再点一次则改用世界包围盒。
* `对象` - 把轴心移到对象的原点，与对象的变换对齐。
* `蒙版` - 把轴心移到无蒙版区域的中心。再点一次则切换到有蒙版的区域。
* `对齐` - 把旋转重置为与世界对齐，保持位置不变。
* `视图` - 把轴心与当前视图对齐，保持位置不变。之后它不会跟随相机。

**点击（轴心模式）**

只在 `轴心` 开启时有效，用来设置在网格表面上轻点一下时会发生什么：
* `无` - 轻点对象时什么也不做。
* `法线方向` - 移动并旋转轴心，使其与轻点处的表面对齐。
* `首个交点` - 把轴心移到（但不旋转）轻点处的表面上。
* `中点` - 把轴心移到对象内部的中间位置，位于轻点处表面的下方。

#### 轴向变换设置 {#gizmo-settings}

![](/images/tool_gizmo_settings.webp)

* `紧凑` - 切换控制柄的布局，把额外的控制柄放在旋转球体的外面或里面。
* `部件尺寸` - 控制柄的大小。
* `厚度` - 控制柄上线条的粗细。
* `不透明度` - 控制柄的不透明度。
* `自动隐藏` - 切换拖动时是否暂时隐藏控制柄。

-----

* `线性旋转阈值` - 控制拖动圆环控制柄绕 X/Y/Z 旋转时的行为。如果这个值为 0，旋转就像转动表盘一样，需要拖着控制柄画圈。如果这个值为 90，旋转就像拉溜溜球的绳子一样，朝着或背离第一次点击的位置直线拖动即可。0 到 90 之间的值会结合两种方式：低于该值时为直线拖动，高于该值时为画圈拖动。
* `数值输入` - 启用后，在控制柄上轻点一下会弹出一个窗口，可以为所点的控制轴输入精确的数值。

::: warning
[轴向变换](#gizmo) 和 [自由变换](#transform) 工具有自己独立的对称复选框，与雕刻用的对称是分开的！

默认情况下，这个对称是关闭的。
:::

##### 矩阵 {#matrix}
对象的精确变换数值已经不在轴向变换设置里了，而是移到了右上角菜单中的 `自由变换` 菜单。它的 `矩阵` 部分包括：

* ![](/icons/target.webp) `移至原点` - 移动对象，使它的轴心位于场景的中心，即原点。
* ![](/icons/bake.webp)  `烘焙` - 把对象固定在当前位置，并把平移/旋转数值设为 0，缩放设为 1。
* ![](/icons/bake.webp) -> ![](/icons/tool_gizmo.webp) `轴心` - 烘焙轴心：让矩阵数值对应轴向变换控制柄在世界中的位置。
* ![](/icons/reset.webp) `重设` - 一个快捷按钮，把平移数值设为 0、旋转数值设为 0、缩放设为 1，会移动和旋转对象。

::: tip 烘焙与烘焙到轴心
创建一个立方体，选择轴向变换工具，打开并钉住 `自由变换` 菜单。默认情况下，平移和旋转为 0，缩放为 1。

启用轴心模式，把控制柄移到一侧，再关闭轴心模式。轴心已经改变了，但请注意，平移数值仍然是 0。

如果想知道轴心*实际*在哪里，点击烘焙 `轴心` 按钮。这时平移数值就会更新。请注意，在这个操作中以及在轴心模式下，立方体都没有移动。

把立方体移动并旋转到某个位置，然后轻点 `移至原点`。它会移动对象，让轴心位于世界中心，但旋转保持不变。

点击 `重设`，旋转也会被设为 0。

再次移动并旋转立方体，这次点击 `烘焙`。轴心停在原处，立方体也停在原处，但平移和旋转数值被设为 0。

多练习几次！要理解轴心的数值是隐藏的，Nomad 会替您处理好；但如果您需要把轴心设到空间中的真实位置，烘焙轴心可以帮您做到。

:::

* `位移` - X、Y、Z 平移数值。
* `旋转` - X、Y、Z 旋转数值。
* `缩放` - 启用等比缩放时为统一缩放值，关闭时为 X、Y、Z 缩放值。
* `剪切` - X、Y、Z 剪切（切变）数值，仅在对象已经有剪切时显示。
* `等比缩放` - 切换是等比缩放，还是在各轴上独立缩放。

在左侧可以移动轴向变换控制柄的轴心，可以看下面的视频演示。

### ![](/icons/tool_faceGroup.webp) 面组 {#facegroup}

面组可以把对象划分成不同颜色的面。在 Nomad 中，这些分组有很多用途：

* 快速选择蒙版区域
* 隐藏/显示对象的某些部分
* 整理对象，而不必把它拆成单独的部件
* 定义 UV 区域
* 引导四边形重构
* 为平滑之类的工具提供额外的控制。

#### 面组左侧工具栏 {#facegroup-left-toolbar}

* `组` - 这个按钮显示当前的面组。轻点它可以把可用的面组显示为色块并从中选择。轻点某个色块可以重命名、更改颜色或删除它。`移除未使用` 会删除未使用的色块，`重置` 会全部删除。加号图标可以创建新的色块。
* `点` - 在对象上涂抹来定义面组。启用“+ 面组”后，每一笔都会自动创建一个新的面组，便于快速划分区域。轻点一下会填满所选区域。滑块设置点的半径。
* `规整网格` - 平滑面组的边界。在为四边形重构定义干净的边缘，或为硬表面建模划分面板时非常有用。滑块控制规整操作的半径和强度。
* 形状 - 用形状而不是画笔来创建面组，可选 `锁定 + 半径`、`套索`、`多边形`、`直线`、`矩形` 和 `椭圆`。详见 [选区控制](#selection-controls)。
* `选取` - 反向模式。启用后，会选取笔触起点所在的色块，并在整个笔触中使用这个色块。整理面组区域时非常有用：如果某个面组扩展得太远，启用 `选取`，从该面组色块正确的位置开始下笔，拖到边界处，就能重新分配正确的色块。

#### 面组顶部工具栏 {#facegroup-top-toolbar}

视口顶部的工具栏有更多控制项：

* `规整网格（全部）` - 拖动可一次性规整所有面组的边界。
* `前` / `可见` / `连接` - 与 [蒙版](#mask) 工具栏中相同的笔触过滤选项。
* `从法线` - 根据面与面之间的角度创建面组。弹出窗口中有 `角度`，还可以根据 `面数` 或 `表面积` 跳过较小的组，并在确认前 `预览`。
* `从部分` - 为每个不相连的部分各创建一个面组。
* `从 UV` - 为每个 UV 岛各创建一个面组。
* `从蒙版` - 根据有蒙版的区域创建一个面组。
* `点击` - 选择轻点某个面组时的效果：用当前面组填充它、隐藏它、给它添加蒙版，或者 `姿态`（轻点的组以及它后面的部分会去除蒙版，轴向变换控制柄会落在关节处，还有一个用于蒙版的 `模糊` 滑块）。网格有蒙版时，还有第二个 `点击` 开关，可以把轻点的作用限制在蒙版同一侧的面上。
* [隐藏](#hide) 和 [蒙版](#mask) 工具的 `清除` 按钮，不用离开当前工具就能取消全部隐藏或清除蒙版。

#### 面组设置 {#facegroup-settings}

`工具` 菜单可以把面组抽取成新的对象，选项与 [蒙版设置](#mask-settings) 中的 `抽壳` 相同。顶部的 `面组` 按钮用来选择要抽取哪些组，另外还有一个 `间隙` 滑块：它会沿表面把每条边界向内收，负值则向外扩，形成重叠。对于相邻的面板，请使用所需间隙的一半。

### ![](/icons/tool_hide.webp) 隐藏 {#hide}
隐藏或孤立对象的某些部分。

主要模式在左侧菜单中控制：

* `点` - 在对象上涂抹来隐藏对象的某些部分。
* 形状 - 用形状而不是画笔来隐藏，可选 `套索`、`多边形`、`直线`、`矩形` 和 `椭圆`。详见 [选区控制](#selection-controls)。
* `显示` - 反向模式，反转操作，所选模式会显示而不是隐藏对象的部分。

视口顶部会出现一个工具栏，提供更多控制项：

* `清除全部` - 恢复对象，所有隐藏的部分都会重新显示。如果其他对象也有隐藏的部分，会多出一个 `清除` 按钮，只恢复选中的对象。
* `反转` - 交换隐藏和未隐藏的部分。
* `删除` - 删除对象中隐藏的部分。
* `拆分` - 把对象中隐藏的部分拆分成一个新的形状。
* `前` / `可见` / `连接` - 与 [蒙版](#mask) 工具栏中相同的笔触过滤选项。
* `点击`（面组）- 用面组快速隐藏某些部分，轻点一个面组就会隐藏整个面组。
* `点击`（蒙版）- 如果有蒙版，轻点会隐藏有蒙版的部分。

### ![](/icons/tool_measure.webp) 测量 {#measure}
拖动来测量两点之间的距离。放置之后，还可以拖动端点来调整测量。

左侧工具栏用来选择测量距离的方式：

* `直线` - 两点之间的直线距离。
* `表面` - 沿表面的距离，沿着从相机看去穿过两点的切线测量。
* `截面` - 穿过两点的横截面的周长，就像用卷尺绕手臂量一圈。
* `顶点` - 把端点吸附到最近的顶点上。
* `黄金比例` - 在测量线的黄金比例点上显示一个黄色圆点。
* `?` 按钮会显示所选对象的体积、表面积和尺寸。

### ![](/icons/tool_arrange.webp) 排列 {#arrange}
一次对齐和排布多个对象，就像 2d 设计软件中的对齐工具一样。先选中这些对象；如果只选了一个对象，排列会作用于它的各个独立部分。选区周围会画出一个框，拖动框上的控制柄可以缩放。

视口顶部的工具栏有以下控制项：

* `世界` / `屏幕` - 沿世界坐标轴排列，或沿屏幕方向（左、右、上、下）排列。
* `对齐` - 在每个轴上按最小值、中心或最大值对齐对象。
* `分布` - 按最小值、中心或最大值，把对象在最外侧两个对象之间均匀分布。至少需要 3 个对象。
* `直线` - 把对象沿某个轴排成一行。
* `网格` - 把对象排成网格，可设置 `X`、`Y` 和 `Z` 方向上的对象数量。
* `圆形` -（仅限世界）把对象绕 `X`、`Y` 或 `Z` 轴排成一圈。
* `球体` -（仅限世界）把对象排布在一个球面上。

`直线`、`网格`、`圆形` 和 `球体` 都有一个 `间距` 滑块，用来设置对象之间的间隔。

* `点` - 这个画笔用来设置目标密度。强度为 100% 时涂成红色，这些区域会使用两倍的目标四边形密度。强度为 0% 时涂成青色，这些区域会使用一半的目标四边形密度。强度为 50% 时涂成灰色，会使用默认的目标四边形密度。

#### Quad Remesher 顶部工具栏 {#quad-remesher-top-toolbar}
![](/images/tool_quadremesher_toolbar.webp)

视口顶部会出现一个工具栏，提供更多控制项：


* `<数量>` - 点击这里开始四边形重构，这个数字表示目标四边形数量。
* `四边形` - 左右滑动来设置目标四边形数量，或轻点输入一个精确的数字。请注意，这只是一个参考值而非固定数字，Quad Remesher 的各种控制项往往会让结果与目标不完全一致。
* `一半` - 把目标数量设为当前面数一半的快捷按钮。
* `相同` - 把目标数量设为当前面数的快捷按钮。
* `引导线` - 切换使用或忽略引导线。有引导线时，会多出第二个 `引导线` 按钮显示它们的数量，轻点即可全部删除。
* `密度` - 切换使用或忽略密度绘制。有密度绘制时，会多出第二个 `密度` 按钮用来清除它。
* `面组` - 切换是否用面组来引导 Quad Remesher。
* `规整网格` - 切换是否在四边形重构时自动规整面组边界。如果您已经规整/平滑过面组边界，请关闭此选项。
* `规整网格滑块` - 规整面组边界的快捷滑块。
* `硬边` - 切换是否尽量保留硬边。
* `重投影顶点` - 切换是否把新的布局重新投影到输入网格上。
* `对称` - 切换是否生成对称的结果。注意，对称始终以世界 X 轴为中心计算，所以如果想得到对称的结果，请确保模型位于原点。
* `...` - Quad Remesher 设置弹出窗口。

#### Quad Remesher 设置菜单 {#quad-remesher-settings-menu}

顶部工具栏末尾的 `...` 按钮会打开一个包含其余设置的弹出窗口：

* `自适应四边形数量` - 切换是否在曲率高的区域使用较小的四边形，在曲率低的区域使用较大的四边形。
* `自适应大小` - 设置自适应的程度。100% 允许最大程度的自适应尺寸，0% 时四边形大小均匀。

::: tip

一个能得到良好四边形重构、并尽量减少瑕疵的配方：

* 给网格划分面组，定义理想的四边形走向。
* 用面组规整功能让面组边界变得平滑。
* 网格简化。这样可以确保面组边缘上没有细长或扭曲的面。在网格简化设置中，确保启用了面组。这会让三角形的边精确地沿着面组边缘走。

在四边形重构选项中，确保关闭了规整网格（因为您已经规整过网格），这样就能得到不错的结果。

:::

### ![](/icons/tool_select.webp) 选择 {#select}
使用形状模式（`套索`、`矩形`、`椭圆`）来选择场景中的对象。`取消选中` 会把对象从选区中移除。

### ![](/icons/tool_lattice.webp) 格子 {#lattice}
用围绕对象的控制点笼子来变形对象，而不是雕刻它的表面。移动笼子上的几个点，就能平滑地弯曲、扭转或拉伸整个对象，非常适合在不改动拓扑的情况下调整比例或摆姿势。在确认之前，变形会一直保持可调。

左侧工具栏用来选择编辑笼子的方式：

* `点` - 直接拖动笼子的点和边。轻点一个点即可选中它。
* `视图` - 移动相机而不编辑笼子。
* `规整网格` - 一个画笔，会规整它下方的笼子点。
* `弹性` - 一个画笔，以弹性衰减拉动笼子点，就像 [弹性](#elastic) 工具一样。
* `轴向变换` - 用轴向变换控制柄移动、旋转和缩放选中的点。它的反向模式是 `轴心`。
* `套索` - 用套索选择笼子点，`取消选中` 会把它们从选区中移除。

形状弹出窗口中还有 `软半径`，可以让拖动点时邻近的点也跟着移动（以网格单元计，0 表示只移动选中的点），以及 `反转选择`。

视口顶部的工具栏有：

* `转换` - 把变形应用到对象上，并移除笼子。
* `重置` - 移除笼子及其变形。
* `不透明度` - 笼子的显示不透明度。
* `镜面` - 开启对称时，循环切换显示和可选取的是笼子的哪一侧镜像，隐藏的一侧有自己的 `不透明度`。
* `网格点` - 笼子上哪些点可以移动：完整网格、表面和中心点，或者只有表面。
* `刚性` - 变形的硬度，从平滑（0%）到刚性的线性变形（100%）。
* `衰减` - 变形在笼子外衰减的范围。
* `对齐` - 让笼子与对象对齐，或与世界对齐。
* `X`、`Y`、`Z` `分段数` - 笼子在每个轴上的单元数。旁边的模式按钮设置它们之间的关系：`x = y = z` 在 3 个轴上使用相同的数量，`均匀` 让每个轴上点与点的间距保持一致，`自定义` 可以自由设置每个轴。

#### 格子设置 {#lattice-settings}
* `滚转速度` - 与 [移动](#move-settings) 工具相同的滚转选项，拖动笼子点时使用。

### ![](/icons/tool_view.webp) 浏览模式 {#view}
这个“工具”不做任何事，只是让您在不修改场景的情况下查看模型。

#### 浏览模式设置 {#view-settings}
浏览模式工具处于激活状态时，这些设置会覆盖部分显示选项，方便您获得干净的画面来展示或检查模型：

* `基本体（编辑）`、`重复器（编辑）`、`灯光（编辑）`、`相机（编辑）` - 允许在浏览模式下在视口中编辑基本体、重复器、灯光和相机。关闭它们可以避免不小心碰到它们的控制柄。
* `相机快捷键（始终）` - 始终在视口中显示相机快捷按钮。
* `显示蒙版`、`轮廓`、`使未选对象变暗` - 显示蒙版、显示选中对象的轮廓，或让未选中的对象变暗。`自动` 沿用您平时的设置，`否` 和 `是` 则强制关闭或开启。
* `显示线条（对称）`、`显示平面（对称）` - 显示对称线或对称平面，同样有 `自动`、`否` 和 `是` 可选。
* `图标` - 在视口中显示组、重复器、灯光、相机的图标以及层级关系，选项同上。


## 工具箱右键菜单 {#toolbox-context-menu}

![](/images/tools_context_menu.webp)

在工具箱中的某个工具上点击右键或长按，会弹出一个菜单。这个菜单有以下选项：

* `保存` - 保存您对工具所做的修改。
* `克隆` - 把工具复制成一个新的工具快捷方式。
* `上次保存` - 恢复到上次保存的工具版本。
* `图标` - 更改工具的图标。如果工具已有自定义图标，这个按钮会移除它。
* `→ ...` - 把工具移到工具箱的另一个文件夹，或移到一个新文件夹。
* `重置` - 把工具重置为默认设置。

克隆出来的工具还有 `重命名` 和 `删除`。
