# ![](/icons/brush.webp) 笔触 {#stroke}

---
![](/images/stroke_overview.webp) 

## 概述 {#overview}

大多数工具笔刷的笔触行为都可以自定义。
这些设置与 2d 绘画软件中的设置大同小异，不过也有一些选项是雕刻和 3d 特有的。

这些选项分布在 5 个子菜单中：

| 名称     | 图标                         | 说明                                                        |
| :------: | :--------------------------: | :----------------------------------------------------------------: |
| 笔触     | ![](/icons/brush.webp)      | 控制笔触如何作用到模型上                   |
| Alpha    | ![](/icons/alpha.webp)      | 如何用灰度纹理作为笔刷的印章形状               |
| 衰减     | ![](/icons/falloff.webp)    | 控制笔刷强度从中心到边缘的变化 |
| 过滤器   | ![](/icons/filter.webp)     | 模型的几何形状如何影响笔刷                    |
| 压感     | ![](/icons/pressure.webp)   | 控制对触控笔压感的响应                                   |

::: tip
并非所有笔触选项都适用于所有工具。当前工具用不到的笔触选项会被停用或隐藏。
:::


## ![](/icons/brush.webp) 笔触 {#stroke-1}

### ![](/icons/radius.webp) 半径 {#radius}

![](/images/stroke_radius.webp)

半径选项是全局设置：对所有工具都生效。

#### 空间 {#size}

* `屏幕` - 半径以屏幕单位设置。如果您把半径设为 100 像素宽，无论放大还是缩小视图，它都保持 100 像素宽。
* `世界（3D）` - 半径以 3d 单位设置。例如，您创建一个球体并把半径调到与球体一样大，那么无论放大还是缩小视图，半径都和球体保持一样大。

#### ![](/icons/link.webp) 同步快捷键 {#sync-shortcut}

启用后，切换到快捷笔刷（`平滑`、`蒙版` 或 `隐藏`）时，半径和轮廓线设置会保持同步。这样，快速平滑或快速蒙版时用的就是您刚才那个工具的笔刷大小。

#### ![](/icons/link.webp) 共享半径 {#share-radius}

启用后，所有工具都使用同一个半径；默认情况下，每个工具都有自己的半径。


### 笔触类型 {#stroke-type}

![](/images/stroke_strokemode.webp)

笔触有多种模式：

### ![](/icons/stroke_dot.webp) 点 {#dot}
像普通的绘画笔触一样拖动。
![](/videos/stroke_dot.mp4) 

### ![](/icons/stroke_roll.webp) 滚动 {#roll}
笔刷的 Alpha 会随笔触方向旋转，适合制作布料的缝线。
![](/videos/stroke_roll.mp4) 

### ![](/icons/radius.webp) 锁定 + 半径 {#lock-radius}
以固定的**_高度_**盖印一个笔触。拖动可设置缩放和旋转。
![](/videos/stroke_lock_radius.mp4) 

### ![](/icons/normal.webp) 锁定 + 强度 {#lock-intensity}
以固定的**_半径_**盖印一个笔触。拖动可设置高度和旋转。
![](/videos/stroke_lock_intensity.mp4) 

::: tip
`锁定 + 半径` 和 `锁定 + 强度` 模式会忽略[压感](#pressure)设置，因为拖动本身已经决定了大小和强度。
:::

![](/images/stroke_strokemodemove.webp)

`移动` 和 `拖拽` 工具有它们自己的 3 个选项：

### ![](/icons/snake.webp) 拖拽 {#drag}

在笔触过程中不断更新笔刷半径内的内容。快速划过时表面会被甩在后面，慢慢划时则能牵住材料，拉出更长的形状。这是 `拖拽` 工具的默认模式。配合 `动态拓扑`，可以用来做出蛇形的挤出效果。
![](/videos/stroke_drag.mp4) 


### ![](/icons/grab.webp) 抓取 {#grab}
在笔触开始时选中笔刷半径内的内容，并在整个过程中保持这个选择。这适合更精确的移动操作：您可以仔细调整移动的距离，而不会意外移动到超出最初选择范围的部分。这是 `移动` 工具的默认模式。
![](/videos/stroke_grab.mp4) 


### ![](/icons/radius.webp) 锁定 + 半径（拖拽） {#lock-radius-drag}
忽略您设定的半径，改为根据笔触离起点拖出的距离动态设置半径。距离小 = 半径小，距离大 = 半径大。用强度滑块控制衰减的形状。适合快速搭出圆润、有弹性的有机形体。
![](/videos/stroke_lockradius_drag.mp4) 

还有一些工具会在这里列出它们自己的笔触类型，例如平滑类工具的 `规整网格`、`平滑` 和 `涂抹`，或者基于选区的工具的 `套索`、`曲线` 等形状。这些会在各个[工具](tools.md)中介绍。


### 调整间隔强度 {#adjust-spacing-intensity}
![](/images/stroke_space_smooth.webp)

间距较小（低于 50%）的笔触会迅速叠加，比间距大的笔触更强。这个开关会对此进行补偿，让笔触无论间距多少，强度都大致相同。

### 笔触间距 {#stroke-spacing}
拖动时每次盖印笔刷之间的距离。低于 100% 的值会相互重叠，看起来像一笔连续的笔触。高于 100% 的值则会开始出现间隙，适合雕刻缝线或拉链之类的细节。

### 拉绳稳定器 {#lazy-rope-stabilizer}
笔触会以一定距离落后于指针位置。可以用来画出平滑的线条。
![](/videos/stroke_lazy_rope.mp4) 

### 笔触平滑 {#stroke-smoothing}
对多个指针位置取平均，让笔触更平滑。
数值较高时，笔触会落后于指针，但最终会追上。
这对画平滑的线条很有用。

### 续接笔刷范围 {#snap-radius}
当指针在上一笔结束位置附近开始时，让笔触接上上一笔。这个半径决定了在多大范围内寻找上一笔的终点。画长而连续的线条、中途又要频繁停顿时，这会很有用。

### ![](/icons/trail.webp) 拖尾效果 {#trail}

启用后，每次新的盖印都会把笔触身后最近的几个点再施加一遍。`拖尾数量` 设置重新施加多少个点，`拖尾强度` 设置它们有多强，`拖尾半径` 设置它们变大多少。

拖尾效果只适用于 `点` 笔触类型，且不能与 `山脊` [衰减影响力](#influence)一起使用。

### ![](/icons/silhouette.webp) 轮廓线 {#silhouette}
![](/images/stroke_silhouette.webp)
默认情况下，笔触只影响笔刷半径内的模型表面。启用轮廓线后，笔触会穿透整个模型进行投射。这在模型初期的大形搭建阶段非常有用，也适合那些需要侧面保持垂直的形状。

投射方向可以明确指定：

* `X`、`Y`、`Z` - 沿固定轴投射。
* `视图` - 沿相机方向投射。
* `如果已对准` - 沿相机方向投射，但仅在相机对准到某个视图时生效；否则仍是普通笔触。
* `最近的` - 沿最接近相机方向的轴投射。这是默认选项。

![](/videos/stroke_silhouette.mp4) 

### ![](/icons/dice.webp)随机化 {#randomize}

![](/images/stroke_randomize.webp)

笔触的 `强度`、`偏移`、`旋转` 和 `缩放` 都可以分别随机化。用每一行的复选框来开启或关闭。这可以做出各种效果，例如配合绘画工具随机化可以画出斑驳的颜色，配合褶皱工具随机化可以做出皮肤细节。

`周期（更慢）` 设置随机循环的长度：调大可得到缓慢起伏的变化，调小则得到快速的噪点。每一行旁边的小按钮只缩放该行的周期。

![](/videos/stroke_randomize.mp4) 

### ![](/icons/paint.webp) 随机化 - HSV {#randomize-hsv}

对于会绘画的工具，颜料颜色的 `色相`、`饱和度` 和 `明度` 也可以随机化，并有各自的周期。很适合给皮肤或石头增加细微的颜色变化。

### 笔触偏移 {#stroke-offset}

给笔触加一个固定的偏移，这样手指就不会挡住它。这在小屏幕上很有用。这是一项全局设置：用它的复选框启用后，会对所有工具生效。


## ![](/icons/alpha.webp) Alpha {#alpha}
![](/images/stroke_alpha.webp) 

`Alpha` 是一张用来调节笔刷行为的纹理。
它是一张灰度图像，黑色像素表示没有变形，白色像素表示完全变形。

点击 Alpha 图像即可更换。除了内置的 Alpha 和您自己导入的图像，Alpha 列表还可以从 Poly Haven 下载置换贴图。

点击材质预览，可以从材质预设中加载 Alpha。您也可以在这里保存材质预设，并选择是否把纹理嵌入到工具中。

::: tip
纹理永远不会被缩小，所以过大的纹理可能会拖慢性能。
:::

### ![](/icons/blend_contrast.webp) 修正 Alpha {#invert-pixels}
导入的 Alpha 上的 `修正...` 按钮会打开一个弹窗，用来修正图像本身：它的中间值、反转像素（黑变白、白变黑）、旋转 90°，以及水平或垂直翻转。图像文件会被重写，所以其他应用看到的也是修正后的图像。

::: tip

Nomad 自带的内置 Alpha 无法修正。

:::

### 投影 {#projection}

Alpha 如何投射到模型上：

* `表面` - Alpha 贴在笔刷下方的表面上，跟随表面的朝向。
* `屏幕` - Alpha 直接从视图方向投射。
* `瓦片` - Alpha 从视图方向投射，并在您涂抹时固定不动，就像模板一样，这样重复的图案就能无缝衔接。旋转会被锁定，笔压也不会改变图案大小。
* `三平面` - Alpha 沿 3 个轴投射。下方的缩放、旋转和平铺选项会被三平面纹理设置取代。

### ![](/icons/diagonal.webp) 形状缩放 {#scaling}

Nomad 中的笔刷是一个半径由您设定的圆。而纹理通常是正方形或长方形的，`形状缩放` 参数让您决定纹理如何适配这个圆。对于正方形纹理，数值为 0.7 时纹理正好放进圆内；数值为 1 时纹理会被放大，让圆落在纹理内部，纹理的边缘会被裁掉。

![](/images/alpha_scaling.webp) 

启用 `形状缩放 Y` 后，可以在垂直方向上拉伸 Alpha。此时第一个滑块会变成 `形状缩放 X`。

![](/images/alpha_scaling_y.webp) 

`水平翻转` 会把 Alpha 左右镜像。

### 旋转 {#rotation}

Alpha 纹理会随笔触方向旋转。您可以加一个旋转偏移量；如果启用了锁定图标，纹理会相对于屏幕锁定在这个旋转角度上。

旁边的笔形按钮可以在您转动触控笔（笔杆旋转）时旋转 Alpha，适用于旋转未锁定时的 `锁定 + 半径` 和 `锁定 + 强度` 笔触。只有支持此功能的触控笔硬件才能使用。

### 形状平铺 {#tiling}
![](/images/stroke_tiling.webp) 

纹理在笔刷轮廓内重复的频率。`平铺 - X` 和 `平铺 - Y` 模式可以让笔触内只有一张纹理（`无`），或者重复纹理（`重复`），或者镜像，即每隔一张纹理翻转一次，用来制作图案或帮助做出无缝纹理（`镜像`）。它们在使用 `滚动` 笔触、`瓦片` 投影，或 `形状平铺` 大于 1 时可用。

`紧密适配（非方形图像）` 只对非正方形的 Alpha 和笔刷纹理有影响。启用后，每张图像各自平铺，没有间隔。关闭它可以在宽高比不同时，让 Alpha 和其他图像保持同步。

![](/videos/alpha_tiling.mp4) 



### 中间值 {#mid-value}

默认情况下，黑色像素表示没有变形，白色像素表示完全的正向变形。例如，一个使用岩石 Alpha 纹理的黏土笔刷，只会在 Alpha 不是黑色的地方把表面向外拉。

如果您希望笔刷把表面向内推，或者既向内推又向外拉，可以修改中间值。比如把它设为 0.5，那么 Alpha 中的中灰色不产生任何效果，黑色向内推，白色向外拉。

有两个按钮可以帮您找到合适的值：方形按钮从图像边框读取中间值，取色器则让您直接在 Alpha 上拾取。




## ![](/icons/falloff.webp) 衰减 {#falloff}

![](/images/falloff_menu.webp) 

它和 [Alpha](#alpha) 类似，只不过是用一条曲线来控制强度。它会与 Alpha 组合起来使用：您可以用纹理表现细节，用衰减控制工具边缘的渐隐和中心的强度。

曲线在顶部时表示完全变形，在底部时笔刷不起作用。

您可以把这条曲线看作笔刷尖端的横截面。下方区域会预览笔刷单次“盖印”在模型表面上的样子；如果笔刷有 Alpha 纹理，也会一并显示，方便预览衰减和 Alpha 如何相互作用。

### ![](/icons/fx.webp) 预设 {#preset}
选中 `预设...` 时，点击曲线图会弹出一个预设菜单。圆润的曲线效果更柔和，有棱角的曲线效果更锐利。左侧工具栏中的 `反向` 按钮实际上会把衰减反过来，让曲线顶部变成向内推入表面，而不是向外拉出，反之亦然。

### ![](/icons/curve_catmull.webp) Catmull-Rom {#catmull-rom}
选中后，您可以自己绘制衰减曲线。这个曲线编辑器的用法与 Nomad 中其他地方的曲线相同：

* 点击曲线即可新建一个点
* 拖动一个点可以改变它的位置
* 点击一个点可以在尖锐和平滑之间切换
* 把一个点拖到相邻的点上即可删除它

### ![](/icons/curve_bspline.webp) B样条 {#b-spline}
选中后，您可以自己绘制衰减曲线。编辑器的用法与 Catmull-Rom 相同，但曲线点是影响曲线的控制点，而不是直接位于曲线上，这有助于做出更平滑的曲线形状。

### ![](/icons/curve_bevel.webp) 倒角 {#bevel}
各个点之间用直线连接，拐角是圆角，圆角大小取决于每个点的锐度。很适合做顶部平坦、边缘带干净倒角的笔刷。

曲线编辑器有 3 个按钮：

| 项目     | 图标                        | 说明                                  |
| :------: | :-------------------------: | :------------------------------------------: |
| 最大化   | ![](/icons/maximize.webp)  | 展开曲线编辑器                      |
| 重置     | ![](/icons/reset.webp)     | 把曲线恢复为默认状态        |
| 对称     | ![](/icons/symmetric.webp) | 把曲线显示为对称的“笔刷尖端” |


### 影响力 {#influence}

* `球体`（3d） - 影响力根据顶点到笔刷中心的距离计算。
* `圆形`（2d） - 先把顶点投影到区域平面上，再计算它到笔刷中心的距离。这与 Alpha 的采样方式类似。
* `圆柱体` - 影响力以圆柱体的形式穿透该区域进行投射。这与启用下方的[轮廓线](#silhouette-1)相同。
* `山脊` - 衰减沿笔触的横向测量，于是曲线就成了整条笔触的横截面。此时 `对称` 按钮会让轮廓在笔触两侧镜像：编辑一侧，另一侧随之变化。关闭时，曲线从笔触的左侧一直延伸到右侧。基于铲平的工具无法使用。

### ![](/icons/silhouette.webp) 轮廓线 {#silhouette-1}
默认情况下，笔触只影响笔刷半径内的模型表面。启用轮廓线后，笔触会穿透整个模型进行投射。这在模型初期的大形搭建阶段非常有用，也适合那些需要侧面保持垂直的形状。它的投射选项与笔触选项卡中的[轮廓线](#silhouette)相同。



## ![](/icons/filter.webp) 过滤器 {#filter}

![](/images/filter_menu.webp) 

### ![](/icons/accumulate.webp) 叠加笔触 {#accumulate-stroke}
不限制每一笔能添加或移除多少材料。例如 `黏土` 工具启用了此选项，所以材料可以不断堆积；而 `画笔` 工具没有启用，所以如果您在网格的同一区域反复涂抹同一笔，笔触就不会再继续添加材料。

### ![](/icons/culling.webp) 仅正面顶点 {#front-facing-vertex-only}
此选项会忽略背面的顶点。
当您想在较薄的几何体上绘画一部分、又不影响另一面时，它会很有用。
它也适用于雕刻，但可能会出现一些瑕疵。

### ![](/icons/eye_open.webp) 仅可见顶点 {#visible-vertex-only}
从相机角度看，忽略被其他表面遮挡的顶点。此选项会出现在蒙版、绘画、`面组` 和 `隐藏` 工具的形状笔触（套索、矩形……）中。

### ![](/icons/dynamic.webp) 允许动态拓扑 {#allow-dynamic-topology}
只有当您的网格处于[动态拓扑](topology.md#dynamic-topology)模式时，此选项才可用。您可以按工具分别启用或停用动态拓扑。

### ![](/icons/connect.webp) 连接拓扑 {#connected-topology}
只雕刻与工具触碰到的表面相连的顶点。例如配合 `移动` 工具使用时，即使某个部件与另一个部件相交，您也能单独移动它。
![](/videos/connected_topology.mp4)

### 保护区域 {#protect-area}
![](/images/filter_protect_area.webp) 

这些选项会在各种条件下阻止工具影响网格的某些部分。每一项都可以设为 `自动`、`否` 或 `是`，旁边的小箭头会显示 `自动` 当前对应的是哪个值。

* `隐藏` - 如果网格的某些部分被隐藏工具隐藏了，设置它们是否受保护。设为 `自动` 时，隐藏的面会受保护，除非它们的线框可见（参见[线框](settings.md#wireframe)设置）。
* `蒙版` - 如果网格的某些部分被蒙版遮住了，设置它们是否受保护。设为 `自动` 时，只要蒙版在[渲染模式](shading)菜单中可见，被蒙版的部分就会受保护。
* `面组` - 设置是否只能在第一个触碰到的面组内使用工具。设为 `自动` 时，取决于面组在[渲染模式](shading)菜单中是否可见。

`(All)` 按钮设置这些保护是全局的（所有工具共享），还是按工具分别设置。


### 区域采样 {#area-sampling}
有些笔刷或笔触选项需要知道表面的平面法线和平面位置才能工作。

您可以把采样区域设为工具半径的一个比例，以此控制这个平均平面的计算方式。

为 100% 时，选择圆内的每个点都会被计算在内。

为 0% 时，只计算最近的顶点或三角形。`法线半径` 和 `位置半径` 的值可以链接在一起，也可以解锁后分别设置。

### 区域法线过滤 {#keep-sharp-edges}
排除法线与表面法线偏差过大的点。

它会改变平面区域的计算方式（区域采样），所以主要适用于黏土类或铲平类工具，或者您想给一个大致平坦的表面上色、又不想溢色时。

`最小值` 和 `最大` 角度控制从被排除到完全受影响之间的过渡，旁边的小彩色圆盘会显示出来。

![](/videos/filter_keep_sharp_edges.mp4)

### 衰减法线过滤 {#falloff-normal-filter}
和[区域法线过滤](#keep-sharp-edges)一样，它会排除法线与表面法线偏差过大的点，但它作用于笔刷衰减，而不是平面计算。适合在褶皱或凸起处绘画。


### 深度过滤 {#depth-masking}
![](/images/stroke_depthmask.webp)

排除位于计算出的平面（区域采样）上方或下方超过一定距离的点。

可以用它只在凸起区域绘画，或只在凹陷区域绘画。

图表表示表面的横截面：水平线是表面所在的位置，圆圈表示绘画衰减半径相对于表面上方和下方的范围。`高度偏移` 是相对表面向上或向下的百分比，从这里开始计算遮罩。启用 `深度衰减` 后，`顶部区域` 和 `底部区域` 可以缩放偏移点上方和下方的衰减。

#### 示例：在凹陷处绘画 {#example-paint-in-cavities}
要只在凹陷区域绘画，把高度偏移设为 -100%，并调整顶部区域滑块，让它离开水平线。这样第一次点击会设定“零”深度，之后只有低于这个深度的区域才会受到影响。

![](/videos/stroke_depth_cavity.mp4)

#### 示例：在凸起处绘画 {#example-paint-on-bumps}
要只在高处绘画，把高度偏移设为 +90%，让圆圈底部与水平线稍微相交。当您点击某个“高”区域的顶部时，就会设定深度：处于这个深度、稍低于它以及高于它的地方都会被绘画，而深的凹陷会被跳过。
![](/videos/stroke_depth_bump.mp4)


## ![](/icons/pressure.webp) 压感 {#pressure}
![](/images/pressure_menu.webp) 

控制触控笔压感如何影响笔刷。

### 使用全局压感设置 {#use-global-settings}

默认启用 `使用全局压感设置`，即所有笔刷共享同一组压感值。取消勾选，即可让当前工具拥有自己的压感设置。

### ![](/icons/radius.webp) 半径 {#pressure-radius}

这条曲线控制压感如何影响笔刷半径。默认是线性关系，所以如果您的触控笔响应平滑，半径的变化也会感觉平滑。不过，很多触控笔的响应是非线性的，您可以用这条曲线来弥补。例如，如果感觉用力按下时半径达不到最大值，可以选择“out-pow3”这类弯曲朝上的曲线预设，让半径更早变大。

这个对话框与衰减曲线的显示类似：您可以点击曲线窗口使用预设，也可以用 `Catmull-Rom`、`B样条` 和 `倒角` 模式自己绘制曲线。

如果您想要固定的半径，请停用这一部分。

### ![](/icons/intensity.webp) 强度 {#pressure-intensity}

与半径曲线类似，但用于控制强度。如果您想要固定的强度，请停用这一部分。

### 限制压力为100% {#limit-pressure}

确保触控笔压力永远不超过 100%。这是一项全局设置。

### 压力平滑 {#pressure-smoothing}

对触控笔的压力事件取平均，让结果更平滑。
