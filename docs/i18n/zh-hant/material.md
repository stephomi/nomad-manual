# ![](/icons/material.webp) 材質 {#material}

這個選單讓你修改目前物件的材質、物件和材質的算繪屬性，以及為材質指定貼圖。

![](/images/material_overview.webp)

材質決定物件的外觀，它控制物件如何對光線和其他物件產生反應。物件的外觀由以下屬性控制：

* `型別`
* `顏色`
* `粗糙度`
* `金屬度`
* `不透明度`
* `反射率`
* `自發光／不受光`

組合這些屬性，可以做出從寫實、卡通到實驗性的各種效果。

顏色、粗糙度、金屬度和不透明度都可以用繪畫的方式設定，詳情請參考[頂點繪畫選項](painting.md)。

材質型別、反射率、自發光／不受光則是材質屬性，說明如下。

這個選單上方的 `複製` 和 `貼上` 按鈕，可以把材質從一個物件複製到另一個物件。

注意 Nomad 的算繪器是即時算繪器：它雖然強大，但在某些效果上會優先考慮速度，而不是精確度。

## 材質型別 {#material-types}

![](/images/material_types.webp)

Nomad 的材質型別有不透明、次表面散射、正常混合、加法、折射、抖色、陰影捕捉器。

### ![](/icons/material_opaque.webp) 不透明 {#opaque}
預設模式，把表面當作簡單的材質，支援繪畫的顏色、粗糙度、金屬度、不透明度。繪畫的不透明度、不透明度貼圖或顏色貼圖的 Alpha 通道，仍然可以透過抖色讓物件呈現透明。只有主要的不透明度滑桿會被忽略。

### ![](/icons/material_subsurface.webp) 次表面散射 {#subsurface}
這個模式可以模擬光線在內部模糊和散射的材質，例如皮膚、蠟、玉石。

它需要 PBR 算繪模式。為了得到最好的效果，至少使用一盞平行光或聚光燈，最好搭配較暗的環境。

色票用來設定散射光的顏色。

`深度` 控制光線從正面進入表面底下，再從正面射出的散射距離。這會讓生硬的陰影變柔和，並讓表面細節變模糊。

`半透明` 控制光線從形狀正面散射到背面的程度，就像光線穿透葉片背面，或是耳朵被強烈背光照射時的效果。需要有會投射陰影的燈光才看得到。

### ![](/icons/material_blending.webp) 正常混合 {#blending}

和不透明類似，但支援不透明度滑桿，讓材質可以在實心和透明之間混合。這是一個簡單的不透明度滑桿，不同於不透明材質所支援的可繪畫不透明度。

::: warning
在複雜或互相交錯的形狀上，正常混合模式可能會造成閃爍和跳動。
:::

### ![](/icons/material_additive.webp) 加法 {#additive}
你可以用這個材質讓網格變得半透明。它和正常混合材質類似，但正常混合會和周圍融合，而加法則一定會比後方的物件更亮，很適合光束、火焰、爆炸這類明亮的效果。

你可以把不透明度設得比 1 還高，這表示物件會更亮。  
如果你想用[泛光效果](postprocess.md#bloom)和 `臨界值參數`，讓只有這個物件像自發光物件一樣發亮，這會很有用。

這個模式產生的瑕疵通常比[正常混合](#blending)少（與順序無關的透明度）。

### ![](/icons/material_refraction.webp) 折射 {#refraction}
這個模式可以用來模擬玻璃材質。它需要 PBR 算繪模式。由於即時算繪的限制，自我折射和多層折射的效果會有些受限。

模型上繪畫的粗糙度會影響折射的模糊程度。
預設情況下，Nomad 中建立的每個物件粗糙度大約是 25%，所以折射不會很完美，而是有點模糊。
你可以用 `漆面效果` 按鈕，把模型重新繪畫成粗糙度和金屬度都是 0（顏色不受影響）。

這裡有兩種粗糙度在作用：一種決定表面反射的模糊程度，另一種決定內部（折射）的模糊程度。  
不過 Nomad 只有一個繪畫粗糙度通道，所以內部和外部的粗糙度會共用同一個數值。  
如果要讓兩者不同（例如表面清晰但內部模糊的棒棒糖），可以用 `覆寫粗糙度` 下方的 `表面` 和 `內部` 滑桿來覆寫繪畫的粗糙度。

![](/videos/refraction.mp4)

#### 折射率 {#index-of-refraction}
光線進入物件時彎折的程度。數值越高，彎折越多，就像一片很厚的透鏡。

#### 吸收效果 {#absorption}
模擬光線穿過體積時被吸收的情況，顏色由色票決定，強度則由 `吸收係數` 設定。較薄的部分會比較亮，因為能讓更多光線通過；較厚的區域則比較暗。這裡只使用物件厚度的近似值，所以效果很依賴形狀。


### ![](/icons/material_dithering.webp) 抖色 {#dithering}
隨機捨棄部分像素，讓物件呈現半透明。

### ![](/icons/material_shadow_catcher.webp) 陰影捕捉器 {#shadow-catcher}

讓物件變成隱形，只接收燈光投下的陰影。適合用來把 Nomad 的算繪結果和其他圖片合成，通常會用在一個平面上。色票用來設定陰影的顏色。

場景中必須有會投射陰影的燈光，否則陰影捕捉器沒有任何作用。`金屬度 → 0%` 和 `金屬度 → 100%` 按鈕會重新繪畫物件：完全金屬時，只要啟用[螢幕空間反射（SSR）](postprocess.md#reflection-ssr)後製效果，陰影捕捉器也能反射場景。

::: tip

關於透明度和混合模式的更多資訊，請參考 https://support.fab.com/s/article/Transparency-Opacity

:::

## 控制項 {#controls}

![](/images/material_controls.webp)

### ![](/icons/circle_fill.webp) 一律不受光 {#always-unlit}
啟用後，物件會忽略 PBR 和材質捕捉，只顯示繪畫的顏色，不帶任何明暗。
注意，如果你使用[加法](#additive)，可以直接用黑色來繪畫透明度。

### 不透明度 {#opacity}
物件看起來有多實心或不透明：100% 是實心，0% 是透明。正常混合、加法、抖色和陰影捕捉器型別會顯示這個滑桿。你也可以用繪畫的方式設定不透明度，做更細緻的控制。

### 預折射通道 {#pre-refract-pass}
僅限正常混合和加法。在折射通道之前先繪製這個透明物件。當折射物件位於其他透明表面前方時很有用。

### 反射率 {#reflectance}
控制非金屬材質所接收的反射量。大多數時候應該使用預設值（相當於垂直角度下標準 4% 的反射光），但也可以調高來增強反射和高光，例如角色的眼睛。它需要 PBR 算繪模式。

### ![](/icons/culling.webp) 反向剔除 {#inverse-culling}
反轉表面的法線。通常不需要，但如果模型看起來內外顛倒就可以使用；或是搭配停用 `雙面顯示`，做出最靠近相機的牆面永遠隱藏的室內場景。

以下選項可以設為 `自動`、`否` 或 `是`。設為 `自動` 時，箭頭會顯示實際使用的數值。

### ![](/icons/sphere_smooth.webp) 平滑著色 {#smooth-shading}
請參考[全域選項](settings.md#smooth-shading)。  
`自動` 會使用全域選項。

### ![](/icons/culling.webp) 雙面顯示 {#two-sided}
從兩側都能看到面。請參考[全域選項](settings.md#two-sided-quick)。  
`自動` 會使用全域選項。

### ![](/icons/culling.webp) 背面著色 {#coloured-backface}
請參考[全域選項](settings.md#two-sided-quick)。
`自動` 會使用全域選項。

### ![](/icons/shadow_cast.webp) 投射陰影 {#casts-shadows}
透明物件也會投射陰影（以抖色圖樣模擬混合的陰影）。  
如果場景中有不需要投射陰影的大型物件（例如一大片地板），記得停用投射陰影。

### ![](/icons/shadow_receive.webp) 接收陰影 {#recieve-shadows}
是否要在這個物件上繪製其他物件投下的陰影。

### ![](/icons/wireframe.webp) 線框 {#wireframe}
請參考[全域選項](settings.md#wireframe)。  
`自動` 會使用全域選項。

### ![](/icons/trash.webp) 重設法線 {#reset-normals}
只有在匯入的物件帶有自己的法線時才會顯示（例如使用 `保留拓樸` 匯入時）。它會移除這些法線，讓著色改用從表面計算出的法線。


## 貼圖 {#textures}

![](/images/material_textures.webp)

如果物件有 UV，除了頂點的顏色／粗糙度／金屬度／不透明度之外，還可以為材質套用貼圖。這些貼圖通常是貼圖烘焙的結果，但也可以使用在 Nomad 以外製作的圖片。標題旁的 `UV:✓` 或 `UV:✗` 會告訴你物件有沒有 UV。

貼圖可以套用到

* 顏色
* 法線
* 粗糙度
* 金屬度
* 不透明度
* 位移
* 自發光

當匯入的物件帶有環境光遮蔽貼圖時，還會出現 `環境光遮蔽` 這一列，但 Nomad 不會使用它。

每一列的滑桿設定該貼圖套用的強度，從完全不套用到完全套用。`顏色` 和 `自發光` 還有可以為貼圖染色的色票，而 `自發光` 則用來設定發光的強度。

`位移` 設定位移貼圖把表面推出去的距離。它的 `套用` 按鈕會依位移移動頂點，然後移除這張貼圖。結果會存入目前圖層。

標題旁的調色盤按鈕會開啟[繪畫](painting.md)選單的材質預設：點選其中一個，就能把它的貼圖複製到物件上。在桌面版上，當你切回 Nomad 時，匯入的圖片會和原始檔案同步，標題旁的同步按鈕也可以重新載入它們。

點一下貼圖槽會開啟選擇器。為材質槽指定貼圖之後，再點一次就會開啟貼圖面板：

### 貼圖面板選項 {#texture-panel-options}

![](/images/material_texture_panel.webp)

面板會顯示圖片尺寸和貼圖的預覽。

### ![](/icons/open.webp) 開啟 {#open}
選擇另一張貼圖。在桌面版上，`瀏覽` 會在檔案瀏覽器中顯示這個圖片檔。

### ![](/icons/circle_cross.webp) 無 {#none}
移除貼圖

### 不透明度 {#texture-opacity}

僅限顏色貼圖。如果圖片有 Alpha 通道，可以選擇把它用作不透明度，或是忽略它。

### 格式 {#normal-format}
僅限法線貼圖。法線貼圖有兩種格式：`OpenGL (+Y)` 和 `DirectX (-Y)`。如果細節看起來是反的，就試試另一種。

### 高度 {#displacement-height}
僅限位移貼圖。
* `本地` - 高度會隨物件的縮放變大或變小。
* `世界` - 不論物件怎麼縮放，高度都保持不變。

### 相乘 {#multiply}
僅限粗糙度、金屬度和不透明度貼圖。把貼圖的數值乘上這個倍率。不是 100% 時，貼圖槽上會顯示這個數值。

### ![](/icons/link.webp) 連結圖示 {#chainlink-icon}

以下各區中的連結圖示啟用時，表示你所使用的選項會和其他同樣啟用連結圖示的貼圖（顏色、法線、粗糙度、金屬度、不透明度、自發光）共用。

這樣能確保對齊好的貼圖，即使你修改參數或投影類型，也會保持對齊。


### 投影 {#projection}
![](/images/material_projection.webp)

設定貼圖套用到物件上的方式。

* `自動` - 物件有 UV 時使用 UV，否則使用三平面
* `UV` - 使用網格的 UV 座標來套用貼圖。如果網格和貼圖來自 Nomad 以外，或是之後要從 Nomad 匯出到其他地方使用，UV 才是正確的選擇。
* `三平面` - 沿 X、Y、Z 軸投影貼圖，並混合接縫。

### 三平面 {#triplanar}
![](/images/material_triplanar.webp)

三平面投影是一種強大又簡單的方式，可以把貼圖套用到物件上。

三平面就像有 6 台投影機播放同一張圖片，分別照向物件的正面、背面、左側、右側、上方和下方。

之後如果需要，可以把它烘焙到 UV 或頂點顏色上。


![](/images/material_triplanar_example.webp)

#### 模式 {#method}

* `本地` - 投影會跟著物件的變換一起移動
* `世界` - 投影保持固定，移動物件時，物件會從投影中滑過。

#### 硬度 {#hardness}

投影之間如何混合。100% 完全不混合，投影的邊緣會很銳利。0% 會在很大的角度範圍內混合邊緣。預設值是 90%，混合程度足以隱藏邊緣，同時讓投影的其他部分保持清晰。

### 均勻 {#uniform}

勾選時，所有投影都使用相同的硬度。取消勾選時，會額外顯示 X、Y、Z 投影各自的硬度控制項。


### 參數 {#parameter}
![](/images/material_parameter.webp)

#### 過濾 {#filtering}
要使用的貼圖過濾方式，預設為 `自動`，可選的方式有 `最鄰近`、`線性`、`Mipmap`。最鄰近不做任何過濾，所以近看時貼圖可能會出現鋸齒。線性和 Mipmap 的過濾效果較好，近看時貼圖會顯得模糊，而不是有鋸齒。

#### 拼貼 - X {#tiling-x}
當縮放參數大於 1，讓貼圖比物件的 UV 還小時，貼圖沿 X 軸要如何拼貼。`無` 表示不重複。`重複` 會複製貼圖。`鏡像` 也會複製貼圖，但每隔一份就會反轉，有助於隱藏拼貼的痕跡。

#### 拼貼 - Y {#tiling-y}
和拼貼 - X 相同，但作用在 Y 軸。

### 變換 {#transform}
![](/images/material_transform.webp)

在 UV 空間中對貼圖額外套用的 2d 變換。重設按鈕會恢復預設值；選取顏色以外的貼圖時，連結圖示可以讓變換和顏色貼圖連結或取消連結。

#### 位移 {#translation}
貼圖在 X 和 Y 方向的偏移

#### 旋轉 {#rotation}
貼圖的旋轉

#### 縮放 {#scale}
貼圖的縮放，數字越大，貼圖在物件上就越小，可以用拼貼 - X 和拼貼 - Y 選項來控制接下來的效果。

### 等比縮放 {#uniform-scale}
關閉時，Nomad 會分別顯示縮放 X 和縮放 Y 的控制項。
