# ![](/icons/camera.webp) 相機 {#camera}

這個選單讓你建立和修改相機，也能控制你操作相機的方式。

![](/images/camera_overview2.webp)

Nomad 的相機有好幾種用途：

* 設定視角，從精確的角度進行雕刻
* 像照相機一樣，為物件取景構圖
* 當作第一人稱視角的相機，在場景中四處移動
* 當作正交相機，用於等角視角的遊戲或工業風格的算繪。

## 控制相機 {#control}

### 旋轉 {#rotation}
用*一根*手指在背景上拖曳，就能旋轉相機。
如果手指是在模型上拖曳，則會開始雕刻。

::: tip 點不到背景時，還能旋轉相機嗎？
可以。把*兩根*手指放在螢幕上（就像要開始平移或縮放手勢一樣），然後放開其中*一根*手指即可。
:::

### 聚焦／重設 {#focus}
在模型上*點兩下*，就會聚焦到點選的位置。
如果在背景上*點兩下*，相機則會聚焦到選取的網格或整個場景，請參考[雙擊背景](#dtap-tap-background)。


### 平移 {#translation}
移動*兩根*手指就能平移相機。


### 縮放 {#zooming}
用雙指捏合手勢就能放大或縮小。


### 滾轉 {#rolling}
旋轉*兩根*手指，可以*滾轉*視角。
::: warning
這個手勢只在 `軌跡球` 旋轉模式下才能使用。
:::

### 桌面版操作 {#desktop}

在桌面版上，用 Alt/Option 鍵來控制相機：

* 在空白處用筆尖拖曳 = 旋轉相機
* Alt + 筆尖拖曳 = 平移
* Alt + 筆尖拖曳，然後放開 Alt = 縮放（和 ZBrush 相同）

如果你的 Wacom 繪圖板的筆上有 2 個以上的按鈕，可以在 Wacom 設定中這樣設定筆尖和按鈕：

* 筆尖 = 左鍵
* 下側按鈕 = 中鍵
* 上側按鈕 = 右鍵

這樣設定後，就能只用筆來操作相機：

* 按住上側按鈕並懸空移動 = 旋轉相機
* 按住下側按鈕並懸空移動 = 平移

## 相機控制 {#camera-controls}

![](/images/camera_list.webp)

### 視角 {#views}
你可以用 `新增視角` 儲存相機的視角。
點一下視角名稱，相機就會回到該視角。


::: tip
儲存的視角會一併儲存[投影類型](#projection)設定和[參考圖片](background.md)。  
如果你想在正面、左側、背面等不同背景的參考視角之間切換，這會很好用。
:::

| :---------: | :---------------------------: | :-------------------------------------------------------------------------: |
| 可見性  | ![](/icons/eye_open.webp)    | 切換相機的顯示。隱藏的相機會在使用上一個／下一個按鈕時被跳過 |
| 名稱        |                               | 選取這台相機                                                           |
| 圖片       | ![](/icons/image.webp)       | 若相機有連結參考圖片，這裡會顯示它的縮圖              |

### ![](/icons/camera_add.webp) 新增視角 {#add}
以目前的視角建立一台新相機。

### ![](/icons/camera.webp) 圖示 {#icons-test}

切換相機圖示是否在視窗中顯示。建立相機後，這個按鈕會出現在 `新增視角` 旁邊。被選取的相機，它的圖示總是會顯示。

### 投影類型 {#projection}
在 `透視檢視` 和 `正交檢視` 之間選擇。

在透視檢視中，你可以修改相機的 `垂直視野`（FoV）。滑桿上方會顯示相對應的 35mm 相機焦距，如果你熟悉攝影會很方便。
雕刻時通常建議使用較低的 FOV，有助於掌握比例。  
`正交檢視` 模式大致等同於 FOV 為 0。

### 第一人稱視角 {#fps}
僅限透視檢視。讓軸心直接位於相機上，而不是在雕刻作品上。在背景上拖曳手指時，相機位置會保持固定，只改變旋轉方向，就像第一人稱遊戲一樣。適合用來雕刻場景環境，而不是單一物件。

![](/images/camera_rotation_ortho_view.webp)

### 旋轉類型 {#rotation-type}
相機預設使用 `轉盤` 旋轉模式。
這表示只有兩個自由度，比較直覺，但有時你會需要更大的彈性。  
你可以切換到 `軌跡球`，這樣就能在視窗中旋轉*兩根*手指來*滾轉*視角。`軌跡球` 有兩種模式：第一種會像手指底下有顆球一樣滾動視角；第二種（箭頭圖示）則依照拖曳的水平和垂直移動來轉動視角，對某些使用者來說可能比較習慣。

### 吸附到正交檢視 {#orthographic}

啟用後，如果你有鍵盤，在旋轉視角時按住 Shift，相機就會吸附到最近的正面／背面／上方／下方／左側／右側視角，並切換為正交相機。點選導航器來吸附到正面／背面／左側／右側／上方／下方時，相機也會切換為正交。

### 重設檢視 {#reset}

把相機移到正面，並讓整個場景填滿畫面

### 吸附檢視 {#snap}
吸附到最近的正面／背面／左側／右側／上方／下方視角。如果你已經在其中一個視角，再點一次就會轉 180 度到相反的一側。

### 相機速度 {#speed}

如果覺得相機移動得太慢或太快，可以為 `旋轉`、`縮放` 和 `平移` 設定速度倍率。當你的雕刻非常大或非常小時特別有用。

### 軸心概覽 {#pivot}

旋轉相機時，你會看到一個粉紅色小點，那就是相機的軸心。  
了解軸心在哪裡非常重要，這樣才不會在操作相機時迷失方向或感到挫折。

預設情況下，軸心會在以下操作時更新：
- 在模型上點兩下
- 在背景上點兩下（新的軸心會位於網格的中心）
- 把*兩根*手指放到螢幕上（平移／縮放／滾轉）時，軸心會更新到*兩根*手指的中間

### 更新軸心… {#update-pivot}

你可以用以下選項進一步自訂軸心的更新方式：

* `相機開始移動時` - 開始操作相機時更新軸心。
* `隔空新增軸心` - 即使縮放的位置在物件表面之外，也允許設定新的軸心。需要開啟 `相機開始移動時`。
* `雙擊後更改` - 在物件表面上點兩下時更新旋轉軸心。
* `雕刻（筆觸）` - 雕刻時更新軸心。

::: tip
習慣之後，你可以到[設定](settings.md)選單中隱藏這個（提示用的）粉紅色小點。
:::

### 縮小時置中檢視 {#center-view-when-zooming-out}
縮小時，相機不會往側邊平移，只會往後退，讓視角保持置中。

### 雙擊物件 {#dtap-object}
啟用後，在物件上點兩下，相機就會聚焦到點選的位置。

### 雙擊背景 {#dtap-tap-background}
啟用後，在背景上點兩下，相機會聚焦到：
* `選區` - 選取的物件。
* `場景` - 整個場景。
* `切換` - 每次點兩下就在兩者之間切換。`切換` 有兩個選項，差別在於哪一個先出現，從圖示就能看出來。
