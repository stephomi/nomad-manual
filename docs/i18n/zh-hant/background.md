# ![](/icons/image.webp) 背景 {#background}

這個選單用來設定 Nomad 的背景顏色，以及要使用的參考影像。

![](/images/background_overview.webp)

## 類型 {#type}
![](/images/background_selector.webp)

視埠背景有三種選擇。

* `環境` - 顯示在[著色](shading.md)中選擇的環境貼圖。可再用 `模糊` 與 `曝光`（亮度）滑桿進一步調整。 
* `顏色` - 自行挑選的單一純色
* `顏色漸層` - 兩種顏色之間的漸變。`係數` 滑桿可移動漸層的中點。  

### 漸層類型 {#gradient-type}
選擇 `顏色漸層` 時，可以挑選漸層的形狀：
* `線性` - 直線漸層，方向由 `角度` 滑桿決定。
* `徑向` - 從螢幕中央向外擴散的圓形漸層。
* `天空` - 固定在世界地平線上的漸層，因此當您上下觀看時，它會跟著相機變化。

每種顏色都有一個重設按鈕和一個取色器，可直接從螢幕上吸取顏色。

## ![](/icons/lock.webp) 與相機鎖定同步 {#sync-on-camera-lock}
當相機透過[方位檢視](settings.md#snap-cube)鎖定時，參考影像會跟著相機移動，始終與您的雕刻對齊。

* `允許滾轉（軌跡球）` - 離開相機鎖定時，允許相機滾轉。
* `解鎖時重設檢視` - 離開相機鎖定時，重設檢視。

## 參考影像 {#reference}

![](/images/background_reference.webp)

您可以在背景加入任何一張影像作為參考。點選 `匯入…` 加入影像，再勾選 `參考影像` 讓它顯示出來。
您可以調整它的位置與縮放，例如想把它移到螢幕角落時。

### ![](/icons/tool_transform.webp) 變換 {#transform}

這個按鈕可以讓您以互動方式擺放參考影像。用雙指平移、縮放、旋轉參考影像，把它放到定位。`重設參數` 會讓影像回到預設位置。最後的擺放結果會反映在下方的滑桿上：

* `疊加` - 0% 時參考影像永遠在物件後方，100% 時則在前方。 
* `不透明度` - 影像的透明程度。
* `後製` - 對參考影像套用後製效果。關閉它可保留影像原本的顏色。
* `X軸位置` / `Y軸位置` - 影像的 X 與 Y 位置。
* `縮放` - 影像的縮放比例。
* `旋轉` - 影像的旋轉角度。


::: tip

相機和參考影像是連動的。 

也就是說，如果您把參考影像調整到與雕刻對齊，然後從[相機選單](camera.md)建立一台相機，參考影像的位置、旋轉與縮放也會一併儲存在這台相機中。之後您可以關閉參考影像，轉到其他視角。當您再次透過這台相機觀看時，參考影像就會以當時的設定重新啟用。

甚至可以為不同的相機選用不同的影像！

:::
