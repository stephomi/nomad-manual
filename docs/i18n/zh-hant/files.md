# ![](/icons/open.webp) 檔案 {#files}

檔案選單可以儲存和載入 Nomad 專案、匯入和匯出 3d 模型、匯出算繪的影像，以及將 Nomad 和其他應用程式連結。它有三個分頁：`檔案`、`算繪` 和 `連結`。

![](/images/file_menu.webp)

## 專案 {#project}
![](/images/file_project.webp)

頂端的縮圖顯示目前的專案，旁邊附有檔案大小、自動儲存和已儲存的歷史記錄。點一下縮圖會開啟一個小型的專案瀏覽器，再點一下某個專案，就會出現選單，可以開啟、新增、覆寫、複製、重新命名或刪除它。

當專案有尚未儲存的變更時，縮圖下方會顯示 `更改未儲存！`。

### 範圍 {#scope}
在桌面版上，選擇專案要儲存在哪裡：
* `內部` - 預設值，和行動裝置上相同。專案只會儲存在 Nomad 主資料夾內。
* `原始檔案` - 從 Nomad 資料夾以外的地方開啟專案時，儲存會覆寫原始檔案。這些外部專案無法使用自動儲存。

### ![](/icons/nomad.webp) 預設 {#preset}
提供一系列示範作品和角色零件。選取一個，再選一次，就能選擇 `開啟` 或 `新增到場景`。您也可以從這個瀏覽器下載 Poly Haven 的免費模型。

![](/images/file_preset_preview.webp)

### ![](/icons/history.webp) 歷史記錄... {#history}
快速存取專案的歷史記錄選項，例如 `儲存歷史記錄`，它會在儲存專案時一併保留復原記錄。按鈕上的綠色標記表示歷史記錄會和專案一起儲存。詳情請參閱 [歷史記錄](history.md#save-history)。

### ![](/icons/save.webp) 儲存 {#save}
儲存 Nomad 專案。如果專案從未儲存過，會請您輸入名稱。

### ![](/icons/save_as.webp) 另存為... {#save-as}
以新名稱將專案儲存為一個新專案。

### ![](/icons/save_as.webp) 覆寫... {#overwrite}
開啟專案瀏覽器，將目前的場景儲存覆蓋到另一個專案上。啟用 `僅匯出所選項目` 可以只儲存選取的物件，而不是整個場景。瀏覽器裡也有一個 `另存為...` 按鈕，可以改為儲存成新專案。

### ![](/icons/pencil.webp) 重新命名 {#rename}
顯示一個文字方塊，用來重新命名目前的專案。

### ![](/icons/open.webp) 開啟... {#open}
開啟專案瀏覽器來開啟專案。

### ![](/icons/add_file.webp) 新增到場景... {#add}
開啟專案瀏覽器，選取某個專案後，它的內容會合併到目前的場景中。

### ![](/icons/trash.webp) 刪除... {#delete}
開啟專案瀏覽器，選取的專案都會從檔案系統中刪除。

### ![](/icons/new_file.webp) 新增 {#new}
開始一個新專案；如果有未儲存的變更，會請您確認。確認時可以選擇 `保留` 或 `重設` `背景`、`環境`、`材質捕捉` 和 `X光` 設定，並選擇新專案是否使用 `儲存歷史記錄`。

### ![](/icons/autosave.webp) 自動儲存... {#auto-save}
控制自動儲存選項的選單。啟用 `自動儲存`，會定期將專案儲存到另一個獨立的檔案。按鈕上的標記會顯示它是否開啟。

Nomad 不在背景儲存的原因，是 3d 檔案可能相當大，在您雕刻時可能造成明顯的卡頓。

此外，為了避免記憶體不足的問題，場景通常會在儲存前先壓縮。
這個壓縮與解壓縮的過程也會讓儲存變慢。

### 儲存間隔 {#timer-pop-up}
Nomad 每次自動儲存之間要等待幾分鐘。

### 顯示倒數計時 {#popup-timeout}
在每次自動儲存前顯示倒數計時，如果您正在忙，就可以取消。停用時，Nomad 會在您一停止雕刻時就儲存。

### ![](/icons/trash.webp) 刪除自動儲存的資料 {#discard-autosave}
如果某個專案有自動儲存檔，開啟時會自動載入它，而不是原本的專案。如果不需要，這個按鈕會刪除自動儲存檔。之後載入檔案時，就會載入專案最後一次手動儲存的版本。

### ![](/icons/open.webp) 開啟較舊的存檔 {#open-outdated-save}
當專案同時有自動儲存和手動儲存時，這個按鈕會開啟兩者中較舊的那一個（`開啟較舊的自動儲存` 或 `開啟較舊的手動儲存`），並顯示其日期。如果最新的存檔不是您想要的，這就很方便。

### ![](/icons/storage.webp) 最近刪除... {#recently-deleted}
對於已離開專案資料夾的專案資料，以及被匯入取代的檔案，Nomad 會保留一段天數後才永久刪除。匯入失敗的檔案則會一直保留，直到您刪除為止。這個清單會顯示它們的大小和日期，您可以逐一刪除，或用 `全部刪除` 一次清除。

## 匯入 {#import}

### ![](/icons/add_file.webp) 匯入 {#import-button}
用來匯入不是 Nomad 專案的 3d 檔案。

將外部場景檔匯入 Nomad 時，您可以選擇*新增*它，或用它開始一個*新*專案。

新增檔案只會把物件加入目前的場景。
選擇 `新增` 則會建立一個包含這些新物件的 Nomad 新專案。

匯入視窗會列出您挑選的每個檔案，各自有自己的匯入選項。影像也可以用這種方式匯入：為每一張選擇要變成 `HDRI`、`材質捕捉`、`參考影像`、`Alpha`、`貼圖` 還是 `VDM`。

Nomad 可以匯入以下格式：
- Nomad (.nom)
- glTF (.glb, .gltf)
- OBJ (.obj)
- STL (.stl)
- PLY (.ply)
- FBX (.fbx)
- ZBrush (.ztl, .zpr)
- USD (.usd, .usdz, .usda, .usdc)，在支援的平台上

### ![](/icons/cog.webp) 設定 {#advanced}
專案縮圖旁的 `設定...` 按鈕會顯示主要的匯入選項。這些設定不會被儲存，而匯入視窗會顯示適用於您正在匯入之檔案的選項。

### 所有格式 {#project-gltf-obj-stl-fbx}
#### ![](/icons/nomad.webp) 保留拓樸 {#keep-topology}
Nomad 預設會在載入時嘗試修正有問題的幾何形狀。啟用此選項後，Nomad 就不會重新排序頂點和面、合併重複項目，以及移除未使用的頂點。

::: warning
使用 `保留拓樸` 時，布林、合併、網格簡化或流形等操作，可能不會合併重複的頂點。
:::

#### ![](/icons/image.webp) 忽略貼圖 {#skip-textures}
不載入檔案內嵌的貼圖，適用於支援內嵌貼圖的格式，例如 glTF。

### Nomad / glTF {#project-gltf}
#### ![](/icons/sliders.webp) 載入介面設定 {#keep-gui-settings}
開啟或匯入專案檔時，載入其中儲存的所有介面設定。

### OBJ {#obj}
#### ![](/icons/group_gray.webp) 依群組分割 OBJ {#split-obj-by-groups}
啟用後，會將 OBJ 的群組分割成各自獨立的物件。

#### ![](/icons/vertex.webp) 合併重複位置 {#merge-duplicate-positions}
合併位置相同的頂點。

#### ![](/icons/uv.webp) 合併重複的 UV {#merge-duplicate-uvs}
合併 UV 相同的貼圖座標。

#### ![](/icons/paint.webp) 色彩空間 {#color-space}
設定從檔案讀取顏色時採用的模式：`自動`、`線性` 或 `sRGB`。如果顏色看起來不對，可以試著切換這個選項。

#### ![](/icons/image.webp) 格式 {#normal-format}
貼圖的法線貼圖格式：`自動`、`OpenGL (+Y)` 或 `DirectX (-Y)`。如果法線貼圖的細節看起來是反的，就試試另一個。

### PLY / STL {#ply}
#### ![](/icons/paint.webp) 色彩空間 {#color-space-ply}
設定從檔案讀取顏色時採用的模式：`自動`、`線性` 或 `sRGB`。


### FBX {#fbx}
#### ![](/icons/uv.webp) 合併重複的 UV {#merge-duplicate-uvs-fbx}
合併 UV 相同的貼圖座標。

#### ![](/icons/paint.webp) 色彩空間 {#color-space-fbx}
設定從檔案讀取顏色時採用的模式：`自動`、`線性` 或 `sRGB`。

#### ![](/icons/image.webp) 格式 {#normal-format-fbx}
貼圖的法線貼圖格式：`自動`、`OpenGL (+Y)` 或 `DirectX (-Y)`。

### USD {#usd}
#### ![](/icons/paint.webp) 色彩空間 {#color-space-usd}
設定從檔案讀取顏色時採用的模式：`自動`、`線性` 或 `sRGB`。

#### ![](/icons/image.webp) 格式 {#normal-format-usd}
貼圖的法線貼圖格式：`自動`、`OpenGL (+Y)` 或 `DirectX (-Y)`。

![](/images/file_export.webp)

不同的檔案格式支援的功能不同，可用的選項會依所選的檔案類型而改變。

### ![](/icons/export.webp) 匯出按鈕 {#export-button}
點這個按鈕，就會以所選的設定匯出幾何形狀。按鈕上會顯示所選的格式和預估的檔案大小。在 Android 上，旁邊的 `分享` 按鈕可以直接把檔案傳送到另一個應用程式。

### 檔案格式 {#file-format}
選擇要匯出的格式：`NOMAD`、`glTF`、`OBJ`、`FBX`、`PLY`、`STL` 或 `USD`。NOMAD 是 Nomad 自己的格式，其他軟體無法載入，所以主要用於重新匯入 Nomad。

### 包含 {#allvisibleselected}
選擇要匯出哪些物件：`全部`、`可見` 或 `已選取`。每個選項旁的數字會顯示將匯出多少個物件。

### 每個物件一個檔案 {#one-file-per-object}
將每個物件匯出成各自的檔案。數字會顯示將寫入多少個檔案。

### 型別 {#type}
當匯出會寫入多個檔案時（每個物件一個檔案，或含貼圖的 OBJ），可以選擇存成 `資料夾` 或 `壓縮檔案`。某些應用程式（如 Google Drive、One Drive 等）不支援匯入資料夾，這時就可以改用壓縮檔案。

### 嵌入歷史記錄 {#embed-history}
僅限 NOMAD。將復原記錄包含在檔案中，在 Nomad 中開啟檔案時會一併還原。這會增加檔案大小，而且整個場景必須匯出成單一檔案。

### 嵌入資源 {#embed-assets}
僅限 NOMAD。將您自訂的 MatCap、環境和字型包含在檔案中。內建的資源不會被嵌入。

### 頂點顏色 {#vertex-colors}
如果檔案格式支援，就匯出頂點顏色。有些 3d 軟體可以讀取，但不是全部都可以。

OBJ 可以選擇：
* `無` - 沒有顏色。
* `RGB` - 顏色附加在頂點資料之後。
* `MRGB (ZBrush)` - 另一種編碼顏色的方式，也支援遮罩資料。

### 色彩空間 {#color-space-export}
僅限 OBJ，並使用 `RGB` 頂點顏色時。將顏色寫成 `線性` 或 `sRGB`。

### PBR繪畫 {#pbr-paint}
匯出粗糙度、金屬度和遮罩的繪畫。其他軟體可能會忽略這些資料。
PBR 頂點顏色會以第二組頂點顏色屬性的形式匯出。
各通道的打包方式如下：

|           | 通道  |
| :-------: | :------: |
| 粗糙度 | R        |
| 金屬度 | G        |
| 遮罩   | B        |


### 圖層 {#layers}
圖層是透過 glTF 的 morph target 來支援。這是 glTF 官方支援的功能，所以在其他軟體中應該也能運作。
Nomad 也會匯出每個圖層的顏色、粗糙度和金屬度，但其他軟體會忽略它們。

### 圖層繪畫 {#layer-painting}
匯出圖層繪畫，其他軟體通常會忽略。

### 面群組 {#face-group}
匯出面群組，匯出後有時可能會干擾其他軟體。

### 寫入物件 {#write-objects}
僅限 OBJ。讓物件保持分開。停用時會把所有東西匯出成單一物件，例如要使用 Substance Painter 的「Mesh ID / Polygroup」功能時。

### 法線 {#normals}
匯出法線資訊。請注意，匯入其他檔案格式時，Nomad 一律會自行計算法線。

### 切線 {#tangents}
匯出切線資訊，在模型有法線貼圖時會用到。 

### 貼圖 {#textures}
如果材質中加入了貼圖，就會將它們匯出。請注意，這不會烘焙貼圖，烘焙要透過拓樸中的烘焙選項來完成。

### 格式 {#fbx-format}
僅限 FBX。`二進位` 檔案較小，但可能不是每個應用程式都能讀取；`ASCII` 則是文字檔。

### 已壓縮 {#compressed}
僅限 FBX。可以減少檔案大小，代價是匯出和匯入會比較慢。

### 預設 {#usd-preset}
僅限 USD。選擇您要匯出到哪個應用程式：`OpenUSD`、`Apple`、`Procreate` 或 `Zbrush`。有些選項只在某些預設下可用。

### 實例 {#instance}
僅限 USD。將實例化的物件匯出為實例，而不是複製它們的幾何形狀。

### 允許傾斜 {#allow-skew}
僅限 USD。允許矩陣變換中含有傾斜。停用時，Nomad 會把傾斜的變換拆成各自獨立的縮放和旋轉變換。

### 重複器 {#repeater}
僅限 USD。將重複器產生的副本匯出為實例。

### 合併副本 {#join-copies}
每個物件和它的重複器副本會合成單一物件。

::: tip 提示：將粗糙度和金屬度匯入 Blender

Blender 可以匯入 glTF/glb，但不會自動識別代表金屬度和粗糙度的頂點屬性。若要使用它們，請在材質編輯器中建立一個 Vertex Color 節點，把它的屬性設為下一個顏色屬性（通常是 Col.001）。接上一個「Separate XYZ」節點，將 X 連到粗糙度，Y 連到 Metallic。

這段影片示範了整個流程：

![](/videos/blender_pbr.mp4)

::: 

::: tip 提示：USD 的功能支援

USD 是很複雜的格式，它的規格支援許多功能，但不是所有 3d 軟體都支援。例如 OSX/iOS 就不支援頂點顏色。USD 匯出器中的預設模式，會盡量猜測如何與 OpenUSD、Apple、Procreate、Zbrush 相容。

::: 

## ![](/icons/screen.webp) 算繪 {#render}

匯出一張結合專案中所有設定（燈光、材質、後製等）的影像。 

![](/images/file_render.webp)
### ![](/icons/preview.webp) 預覽 {#preview}

選單標題旁的 `預覽` 按鈕會讓介面變成半透明，方便預覽最終結果的構圖。

### ![](/icons/home.webp) 聚焦 {#focus}
將場景或選取的物件框入畫面，使其符合算繪尺寸。再點一下可以在兩者之間切換。

### ![](/icons/map.webp) 高度圖 {#heightmap}
將場景從相機視角算繪成灰階高度圖，越靠近的部分越亮。啟用後會切換成 `正方形` 尺寸，並框住選取的物件。視埠中的一個小橫條可以讓您調整漸層的 `聚焦`。

開啟 `高度圖` 時，匯出按鈕旁會出現 `另存為 Alpha` 按鈕，可以將算繪結果存成新的筆刷 Alpha，而不是匯出檔案。

### ![](/icons/opacity.webp) 透明背景 {#transparent-background}
為算繪結果加上 Alpha 通道，方便在 2d 程式中與其他影像合成。請注意，不支援半透明。

### ![](/icons/sliders.webp) 顯示介面 {#show-interface}
在算繪結果中包含 Nomad 的介面。

### 算繪尺寸 {#final-size}
算繪使用的解析度：`螢幕解析度`、`720`、`1080`、`4096`、`正方形` 或 `自訂`。

開啟檔案選單時，如果算繪範圍與螢幕解析度不同，視埠中會畫出虛線框來標示算繪範圍。

### 寬度 / 高度 {#render-ratio}
使用 `自訂` 時，可以設定影像的寬度和高度。兩個滑桿之間的連結按鈕，會在您調整其中一個時保持比例。使用 `正方形` 時，只能設定寬度。

### ![](/icons/export.webp) 匯出 → PNG {#export-png}
點這個按鈕開始算繪。完成後，您可以選擇如何儲存或分享影像。尺寸非常大時會先要求確認：請先儲存專案，以防裝置記憶體不足。

## ![](/icons/network.webp) 連結 {#link}

將 Nomad 與另一台裝置或應用程式連結，用來傳送和接收物件，或即時同步您的編輯。由一台裝置主持工作階段，其他裝置加入。

### 啟用 GoZ {#enable-goz}
僅限桌面版。與這台電腦上的 ZBrush 交換網格。`傳送` 會將網格匯入 ZBrush，`取得` 則從執行中的 ZBrush 匯入：`選區` 取得作用中的 SubTool，`場景` 取得所有 SubTool。您也可以隨時在 ZBrush 中按下 GoZ。

### 模式 {#link-mode}
* `關閉` - 不連結。
* `主機` - 這台裝置主持工作階段，等待其他裝置加入。
* `加入` - 搜尋附近的裝置，然後點一下主機的名稱來加入。

要連結兩台 Nomad，在一台裝置上選擇 `主機`，其他裝置選擇 `加入`。要與 Blender 連結時，Nomad 必須是主機：`連結` 標題旁的說明按鈕會告訴您如何安裝 Nomad Blender Link 擴充功能。

### ![](/icons/network.webp) 網路連接埠 {#network-port}
連結使用的網路連接埠。只有在其他應用程式已經使用這個連接埠時才需要更改。

### 傳送 / 取得 {#send-get}
連線後，可以 `傳送` 您的 `選區` 或整個 `場景` 到另一台裝置，或從那台裝置 `取得` 它們。`取代` 會刪除目前的場景，然後取得另一台裝置的場景。

### ![](/icons/link.webp) 即時同步 {#live-sync}
在您工作時，將編輯即時傳送到另一台裝置。`工作檢視` 也會同步相機。`場景編輯` 設定由哪一台裝置傳送編輯：`自動` 會依最近的操作決定方向。接著選擇要同步的內容：`物件與幾何`、`材質`、`燈光`、`相機`，以及在另一端支援時的 `著色` 和 `後製`。

::: tip
既有的物件需要先 `傳送` 或 `取得` 一次，將它們連結起來，即時同步才能更新它們。
:::
