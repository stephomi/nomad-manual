# ![](/icons/brush.webp) 筆觸 {#stroke}

---
![](/images/stroke_overview.webp) 

## 概覽 {#overview}

大多數工具的筆刷，都可以自訂筆觸的行為。
這些設定和 2d 繪圖應用程式裡的大同小異，不過也有一些選項是雕刻與 3d 專屬的。

這些選項分成 5 個子選單：

| 名稱     | 圖示                         | 說明                                                        |
| :------: | :--------------------------: | :----------------------------------------------------------------: |
| 筆觸   | ![](/icons/brush.webp)      | 控制筆觸如何作用在模型上                   |
| Alpha    | ![](/icons/alpha.webp)      | 如何用一張灰階貼圖作為筆刷的印章形狀               |
| 衰減  | ![](/icons/falloff.webp)    | 控制筆刷強度從中心到邊緣如何變化 |
| 過濾器   | ![](/icons/filter.webp)     | 模型的幾何形狀如何影響筆刷                    |
| 壓感 | ![](/icons/pressure.webp)   | 控制觸控筆的壓感反應                                   |

::: tip
並非每個工具都會用到所有筆觸選項。目前工具用不到的筆觸選項，會被停用或隱藏。 
:::


## ![](/icons/brush.webp) 筆觸 {#stroke-1}

### ![](/icons/radius.webp) 半徑 {#radius}

![](/images/stroke_radius.webp)

半徑選項是全域設定：會套用到所有工具。

#### 空間 {#size}

* `螢幕` - 半徑以螢幕單位設定。如果把半徑設為 100 像素寬，不論您放大或縮小畫面，它都會維持 100 像素寬。
* `世界（3D）` - 半徑以 3d 單位設定。舉例來說，如果您建立一個球體，並把半徑調成和球體一樣大，那麼不論畫面放大或縮小，半徑都會和球體保持相同大小。

#### ![](/icons/link.webp) 同步快速操作 {#sync-shortcut}

啟用後，當您切換到快速操作的筆刷（`平滑`、`遮罩` 或 `隱藏`）時，半徑和輪廓線設定會保持同步。這樣一來，快速平滑或遮罩一下時，筆刷大小就和您剛才使用的工具一樣。

#### ![](/icons/link.webp) 共享半徑 {#share-radius}

啟用後，所有工具都會使用同一個半徑；預設是每個工具各有自己的半徑。


### 筆觸類型 {#stroke-type}

![](/images/stroke_strokemode.webp)

筆觸有好幾種模式：

### ![](/icons/stroke_dot.webp) 點 {#dot}
像一般繪圖筆觸那樣拖曳。 
![](/videos/stroke_dot.mp4) 

### ![](/icons/stroke_roll.webp) 滾動 {#roll}
筆刷的 Alpha 會隨著筆觸方向旋轉，很適合用來做布料的縫線。 
![](/videos/stroke_roll.mp4) 

### ![](/icons/radius.webp) 鎖定 + 半徑 {#lock-radius}
以固定的**_高度_**蓋印一筆筆觸。拖曳可以設定縮放與旋轉。
![](/videos/stroke_lock_radius.mp4) 

### ![](/icons/normal.webp) 鎖定 + 強度 {#lock-intensity}
以固定的**_半徑_**蓋印一筆筆觸。拖曳可以設定高度與旋轉。
![](/videos/stroke_lock_intensity.mp4) 

::: tip
`鎖定 + 半徑` 和 `鎖定 + 強度` 模式會忽略 [壓感](#pressure) 設定，因為大小和強度已經由拖曳決定了。
:::

![](/images/stroke_strokemodemove.webp)

`移動` 和 `拖曳` 工具有自己的 3 個選項：

### ![](/icons/snake.webp) 拖曳 {#drag}

在筆觸過程中，會持續更新筆刷半徑內的範圍。快速劃過時，表面會被甩在後面；慢慢劃過時則會抓住材料，拉出較長的形狀。這是 `拖曳` 工具的預設模式。搭配 `動態拓樸`，可以拉出像蛇一樣的擠出形狀。 
![](/videos/stroke_drag.mp4) 


### ![](/icons/grab.webp) 抓取 {#grab}
在筆刷開始時選取筆刷半徑內的範圍，並在整個筆觸中保持這個選取。這適合需要更精確的移動操作，因為您可以仔細調整移動的距離，而不會不小心移動到比原本選取更多的部分。這是 `移動` 工具的預設模式。
![](/videos/stroke_grab.mp4) 


### ![](/icons/radius.webp) 鎖定 + 半徑（拖曳） {#lock-radius-drag}
使用者設定的半徑會被忽略，改為依筆觸從起點拖曳出去的距離動態決定。距離短＝半徑小，距離長＝半徑大。用強度滑桿控制衰減的形狀。很適合用來勾勒有機、帶點橡膠感的大形。
![](/videos/stroke_lockradius_drag.mp4) 

有些其他工具也會在這裡列出自己的筆觸類型，例如平滑類工具的 `規整網格`、`平滑` 和 `塗抹`，或是選取類工具的 `套索`、`曲線` 等形狀。這些會在各個 [工具](tools.md) 中說明。


### 調整間隔強度 {#adjust-spacing-intensity}
![](/images/stroke_space_smooth.webp)

間距較小（低於 50%）的筆觸會很快疊加，效果比間距大的筆觸更強烈。這個開關會補償這一點，讓不論間距多少，筆觸的強度都大致相同。

### 筆觸間距 {#stroke-spacing}
拖曳時，每一下筆刷之間相隔多遠。低於 100% 的值會互相重疊，看起來就像一條連續的筆觸。高於 100% 的值會開始留下空隙，很適合雕刻縫線或拉鍊這類細節。

### 拉繩穩定器 {#lazy-rope-stabilizer}
筆觸會落後游標位置一段距離。可以用來畫出平順的線條。
![](/videos/stroke_lazy_rope.mp4) 

### 筆觸平滑 {#stroke-smoothing}
將多個游標位置取平均，讓筆觸更平滑。
數值高時，筆觸會落後游標，但最後會追上。
適合用來畫平順的線條。

### 續接筆刷範圍 {#snap-radius}
當游標起點靠近上一筆的結尾時，讓筆觸接續上一筆。半徑決定要在多遠的範圍內尋找上一筆的結尾。畫長的連續線條、中途又常常停頓時，這個功能很好用。

### ![](/icons/trail.webp) 拖尾效果 {#trail}

啟用後，每蓋一個新的印章，也會重新套用筆觸後方最近的幾個點。`拖尾數量` 設定要重新套用幾個點，`拖尾強度` 設定它們的強度，`拖尾半徑` 設定它們要放大多少。

拖尾效果只能搭配 `點` 筆觸類型使用，而且不支援 `山脊` [衰減影響力](#influence)。

### ![](/icons/silhouette.webp) 輪廓線 {#silhouette}
![](/images/stroke_silhouette.webp)
預設情況下，筆觸只會影響筆刷半徑內的模型表面。啟用輪廓線後，筆觸會投射穿過整個模型。這在模型一開始的大形塊面階段非常好用，也適合需要側面保持垂直的形狀。

投射方向可以明確指定：

* `X`、`Y`、`Z` - 沿著固定的軸投射。
* `檢視` - 沿著相機方向投射。
* `如果已對準` - 沿著相機方向投射，但只在相機對準某個視角時才生效。否則筆觸就是一般的筆觸。
* `最近的` - 沿著最接近相機方向的軸投射。這是預設值。

![](/videos/stroke_silhouette.mp4) 

### ![](/icons/dice.webp)隨機化 {#randomize}

![](/images/stroke_randomize.webp)

筆觸的 `強度`、`偏移`、`旋轉` 和 `縮放` 都可以各自隨機化。用每一列的核取方塊來開啟或關閉。這可以做出各種效果，例如搭配繪畫工具隨機化，可以畫出斑駁的顏色；搭配褶皺工具隨機化，則可以做出皮膚細節。

`週期（更慢）` 設定隨機循環的長度：調高可以得到緩慢起伏的變化，調低則會變成快速的雜訊。每一列旁邊的小按鈕，只會縮放那一列的週期。

![](/videos/stroke_randomize.mp4) 

### ![](/icons/paint.webp) 隨機化 - HSV {#randomize-hsv}

對於會上色的工具，繪畫顏色的 `色相`、`飽和度` 和 `明度` 也可以隨機化，並有各自的週期。很適合為皮膚或石頭加上細微的色彩變化。

### 筆觸偏移 {#stroke-offset}

讓筆觸固定偏移一段距離，這樣手指就不會擋住它。在小螢幕上很實用。這是全域設定：用它的核取方塊啟用，就會套用到所有工具。


## ![](/icons/alpha.webp) Alpha {#alpha}
![](/images/stroke_alpha.webp) 

`Alpha` 是一張用來調變筆刷效果的貼圖。
它是一張灰階影像，黑色像素代表不變形，白色像素代表完全變形。

點一下 Alpha 圖片即可更換。除了內建的 Alpha 和您自己匯入的之外，Alpha 清單還可以從 Poly Haven 下載置換貼圖。

點一下材質預覽，可以從材質預設載入 Alpha。您也可以在這裡儲存材質預設，並選擇是否將貼圖嵌入工具中。

::: tip
貼圖永遠不會被縮小，所以太大的貼圖可能會拖慢效能。
:::

### ![](/icons/blend_contrast.webp) 修正 Alpha {#invert-pixels}
匯入的 Alpha 上的 `修正...` 按鈕，會開啟一個用來修正影像本身的視窗：可以調整它的中間值、反轉像素（黑變白、白變黑）、旋轉 90°，以及水平或垂直翻轉。影像檔案會被改寫，所以其他應用程式看到的也是修正後的影像。

::: tip

Nomad 內建的 Alpha 無法修正。

:::

### 投影 {#projection}

Alpha 投射到模型上的方式：

* `表面` - Alpha 貼在筆刷下方的表面上，並跟隨表面的方向。
* `螢幕` - Alpha 直接從視角投射。
* `瓦片` - Alpha 從視角投射，並在您塗抹時固定不動，就像模板一樣，因此重複的圖案能無縫接合。旋轉會被鎖定，筆的壓力也不會改變圖案大小。
* `三平面` - Alpha 沿著 3 個軸投射。下方的縮放、旋轉和拼貼選項，會換成三平面貼圖的設定。

### ![](/icons/diagonal.webp) 形狀縮放 {#scaling}

Nomad 的筆刷大小是一個半徑由使用者設定的圓。貼圖通常是正方形或長方形，`形狀縮放` 參數讓您決定貼圖要如何放進這個圓裡。對正方形貼圖來說，值為 0.7 時貼圖會剛好放進圓內。值為 1 時貼圖會放大到圓剛好在貼圖內，邊角會被裁掉。

![](/images/alpha_scaling.webp) 

啟用 `形狀縮放 Y` 可以垂直拉伸 Alpha。這時第一個滑桿會變成 `形狀縮放 X`。

![](/images/alpha_scaling_y.webp) 

`水平翻轉` 會將 Alpha 左右鏡像。

### 旋轉 {#rotation}

Alpha 貼圖會隨著筆觸方向旋轉。您可以加上旋轉偏移；如果啟用了鎖頭圖示，貼圖就會相對於螢幕固定在這個旋轉角度。

旁邊的筆按鈕，可以讓 Alpha 隨著您轉動觸控筆（筆身旋轉）而旋轉，適用於旋轉未鎖定時的 `鎖定 + 半徑` 和 `鎖定 + 強度` 筆觸。只有支援此功能的觸控筆硬體才能使用。

### 形狀拼貼 {#tiling}
![](/images/stroke_tiling.webp) 

貼圖在筆刷範圍內重複的次數。`拼貼 - X` 和 `拼貼 - Y` 模式可以讓筆觸內只有一張貼圖（`無`）、重複貼圖（`重複`），或是鏡像排列，每隔一張就翻轉一次，用來做出圖案或幫助製作無縫貼圖（`鏡像`）。這些模式在使用 `滾動` 筆觸、`瓦片` 投影，或 `形狀拼貼` 大於 1 時可用。

`緊密貼合（非方形影像）` 只對非正方形的 Alpha 和筆刷貼圖有作用。啟用後，每張影像各自拼貼，中間沒有間隔。如果 Alpha 和其他影像的長寬比不同，關閉它可以讓它們保持同步。

![](/videos/alpha_tiling.mp4) 



### 中間值 {#mid-value}

預設情況下，黑色像素代表不變形，白色像素代表完全向外變形。舉例來說，一支使用岩石 Alpha 貼圖的黏土筆刷，只會在 Alpha 不是黑色的地方把表面往外拉。

如果您想讓筆刷把表面往內推，或是同時往內推「和」往外拉，可以修改中間值。例如把值設為 0.5，Alpha 裡的中灰色就不會有作用，黑色會往內推，白色會往外拉。

有兩個按鈕可以幫您找到合適的值：方形按鈕會從影像的邊緣讀取中間值，而吸管則讓您直接在 Alpha 上選取。




## ![](/icons/falloff.webp) 衰減 {#falloff}

![](/images/falloff_menu.webp) 

這和 [Alpha](#alpha) 很類似，差別在於強度是由一條曲線控制。它會和 Alpha 結合，所以您可以用貼圖處理細節，再用衰減控制工具邊緣的淡出，以及中心的強度。

曲線在頂端時代表完全變形，在底部時筆刷就沒有效果。

您可以把這條曲線想成筆刷尖端的剖面。下方區域會預覽筆刷蓋一下「印章」時在模型表面上的樣子；如果筆刷有 Alpha 貼圖，也會一起顯示，讓您預覽衰減和 Alpha 如何互相作用。

### ![](/icons/fx.webp) 預設 {#preset}
選取 `預設...` 時，點一下曲線圖會開啟預設清單。圓滑的曲線效果較柔和，有稜角的曲線效果較銳利。左側工具列的 `反向` 按鈕實際上會反轉衰減，讓曲線頂端改為把表面往內推而不是往外拉，反之亦然。

### ![](/icons/curve_catmull.webp) Catmull-Rom {#catmull-rom}
選取後，使用者可以自行繪製衰減曲線。這個曲線編輯器的操作方式，和 Nomad 其他地方的曲線相同：

* 點一下曲線即可新增一個點
* 拖曳一個點即可移動它
* 點一下一個點即可在尖角和平滑之間切換
* 把一個點拖到相鄰的點上即可刪除它

### ![](/icons/curve_bspline.webp) B樣條 {#b-spline}
選取後，使用者可以自行繪製衰減曲線。編輯方式和 Catmull-Rom 相同，但曲線上的點是影響曲線，而不是直接位於曲線上，這有助於做出更平滑的曲線形狀。

### ![](/icons/curve_bevel.webp) 倒角 {#bevel}
點與點之間以直線相連，轉角是圓角，大小取決於每個點的銳利度。很適合做頂部平坦、邊緣有俐落倒角的筆刷。

曲線編輯器有 3 個按鈕：

| 項目     | 圖示                        | 說明                                  |
| :------: | :-------------------------: | :------------------------------------------: |
| 最大化 | ![](/icons/maximize.webp)  | 放大曲線編輯器                      |
| 重設    | ![](/icons/reset.webp)     | 將曲線恢復為預設狀態        |
| 對稱 | ![](/icons/symmetric.webp) | 將曲線顯示為對稱的「筆刷尖端」 |


### 影響力 {#influence}

* `球體`（3d） - 以頂點到筆刷中心的距離計算影響力。
* `圓形`（2d） - 先把頂點投影到區域平面上，再計算它到筆刷中心的距離。這和 Alpha 的取樣方式類似。 
* `圓柱體` - 影響力以圓柱體的形式穿過整個區域。這和啟用下方的 [輪廓線](#silhouette-1) 效果相同。
* `山脊` - 衰減改為橫跨筆觸來量測，所以曲線會變成整條筆觸的剖面。這時 `對稱` 按鈕會讓剖面沿著筆觸左右鏡像：編輯其中一側，另一側會跟著改變。關閉時，曲線從筆觸的左側一路延伸到右側。壓平類的工具無法使用。

### ![](/icons/silhouette.webp) 輪廓線 {#silhouette-1}
預設情況下，筆觸只會影響筆刷半徑內的模型表面。啟用輪廓線後，筆觸會投射穿過整個模型。這在模型一開始的大形塊面階段非常好用，也適合需要側面保持垂直的形狀。它的投射選項和筆觸分頁中的 [輪廓線](#silhouette) 相同。



## ![](/icons/filter.webp) 過濾器 {#filter}

![](/images/filter_menu.webp) 

### ![](/icons/accumulate.webp) 疊加筆觸 {#accumulate-stroke}
不限制每一筆可以增加或移除多少材料。例如 `黏土` 工具預設啟用此選項，所以材料可以不斷堆疊；而 `筆刷` 工具則是關閉的，所以如果您在網格的同一區域上來回塗同一筆，筆觸就不會再繼續增加材料。 

### ![](/icons/culling.webp) 僅正面頂點 {#front-facing-vertex-only}
這個選項會忽略背面的頂點。
想在薄的幾何形狀上只塗一面、不影響另一面時很好用。
雕刻時也能用，但可能會出現一些瑕疵。

### ![](/icons/eye_open.webp) 僅可見頂點 {#visible-vertex-only}
忽略從相機看過去被其他表面遮住的頂點。這個選項會出現在遮罩、繪畫、`面群組` 和 `隱藏` 工具的形狀筆觸（套索、矩形……）中。

### ![](/icons/dynamic.webp) 允許動態拓樸 {#allow-dynamic-topology}
只有當網格處於 [動態拓樸](topology.md#dynamic-topology) 模式時，才能使用這個選項。您可以針對每個工具個別停用或啟用動態拓樸。

### ![](/icons/connect.webp) 連線拓樸 {#connected-topology}
只雕刻與工具碰到的表面相連的頂點。例如搭配 `移動` 工具使用時，即使某個部分和另一個部分交疊，您也能單獨移動它。
![](/videos/connected_topology.mp4)

### 保護區域 {#protect-area}
![](/images/filter_protect_area.webp) 

這些選項會在各種條件下，避免工具影響到網格的某些部分。每個選項都可以設為 `自動`、`否` 或 `是`，旁邊的小箭頭會顯示 `自動` 目前代表哪一個。

* `隱藏` - 如果網格有部分被隱藏工具隱藏了，設定是否要保護它們。設為 `自動` 時，隱藏的面會受到保護，除非它們的線框是可見的（請參閱 [線框](settings.md#wireframe) 設定）。
* `遮罩` - 如果網格有部分被遮罩了，設定是否要保護它們。設為 `自動` 時，只要遮罩在 [著色](shading) 選單中是顯示的，被遮罩的部分就會受到保護。
* `面群組` - 設定是否只能在第一個碰到的面群組內使用工具。設為 `自動` 時，會依據面群組在 [著色](shading) 選單中是否顯示而定。

`(全部)` 按鈕設定這些保護是全域的、所有工具共用，還是每個工具各自設定。


### 區域取樣 {#area-sampling}
有些筆刷或筆觸選項，需要表面的平面法線和平面位置才能運作。

您可以將取樣區域設為工具半徑的一個比例，來控制這個平均平面的計算方式。

設為 100% 時，選取圓內的每個點都會被納入計算。

設為 0% 時，只會考慮最近的頂點或三角形。這些值可以讓 `法線半徑` 和 `位置半徑` 連動，也可以解除鎖定分別設定。

### 區域法線過濾 {#keep-sharp-edges}
排除法線與表面法線偏差太大的點。

它會改變平面區域的計算方式（區域取樣），所以主要適用於黏土或壓平類的工具，或是想替大致平坦的表面上色而不溢出時。

`最小值` 和 `最大` 角度控制從被排除到完全受影響的點之間的漸變，旁邊的彩色小圓盤會顯示這個範圍。

![](/videos/filter_keep_sharp_edges.mp4)

### 衰減法線過濾 {#falloff-normal-filter}
和 [區域法線過濾](#keep-sharp-edges) 一樣，它會排除法線與表面法線偏差太大的點，但作用在筆刷的衰減上，而不是平面的計算。適合用來替褶皺或凸起處上色。


### 深度過濾 {#depth-masking}
![](/images/stroke_depthmask.webp)

排除位於計算出的平面（區域取樣）上方或下方超過一定距離的點。

可以用來只在凸起的區域上色，或只在凹陷的區域上色。

圖表代表表面的剖面：水平線是表面所在的位置，圓形代表繪畫衰減半徑相對於表面上方與下方的範圍。`高度偏移` 是相對表面上方或下方的百分比，用來決定從哪裡開始計算遮罩。啟用 `深度衰減` 後，`頂部區域` 和 `底部區域` 可以讓您縮放偏移點上方與下方的衰減。

#### 範例：在凹陷處上色 {#example-paint-in-cavities}
若只想在凹陷區域上色，請把高度偏移設為 -100%，並調整頂部區域滑桿，讓它離開水平線。這表示第一次點擊會設定「零」深度，之後只有低於這個深度的區域會受到影響。

![](/videos/stroke_depth_cavity.mp4)

#### 範例：在凸起處上色 {#example-paint-on-bumps}
若只想在較高的區域上色，請把高度偏移設為 +90%，讓圓的底部稍微與水平線相交。當您點一下「高」區域的頂端時，就會設定深度，於是在這個深度、比它稍低一點，以及比它更高的地方都會被上色。較深的凹陷處則會被略過。
![](/videos/stroke_depth_bump.mp4)


## ![](/icons/pressure.webp) 壓感 {#pressure}
![](/images/pressure_menu.webp) 

控制觸控筆的壓力如何影響筆刷。

### 使用全域壓感設定 {#use-global-settings}

`使用全域壓感設定` 預設為啟用，表示所有筆刷共用同一組壓感值。取消勾選後，目前的工具就會有自己的壓感設定。

### ![](/icons/radius.webp) 半徑 {#pressure-radius}

這條曲線控制壓力如何影響筆刷半徑。預設是線性關係，所以如果您的觸控筆反應平順，半徑的變化也應該感覺平順。不過，很多觸控筆的反應是非線性的，您可以用這條曲線來補償。例如，如果感覺用力壓時半徑還是達不到最大值，可以使用像「out-pow3」這種彎曲朝上的曲線預設，讓半徑更早變大。

這個視窗和衰減曲線的顯示方式類似：您可以點一下曲線視窗來使用預設，或用 `Catmull-Rom`、`B樣條` 和 `倒角` 模式自行繪製曲線。

如果想要固定的半徑，請停用這個區塊。

### ![](/icons/intensity.webp) 強度 {#pressure-intensity}

和半徑曲線類似，不過是用來控制強度。如果想要固定的強度，請停用這個區塊。

### 限制壓力為100% {#limit-pressure}

確保觸控筆的壓力永遠不會超過 100%。這是全域設定。

### 壓力平滑 {#pressure-smoothing}

將觸控筆的壓力事件取平均，讓結果更平滑。
