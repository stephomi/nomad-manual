# ![](/icons/history.webp) 歷史記錄 {#history}
![](/images/history_overview.webp)

和大多數創作工具一樣，在 Nomad 中所做的每一項編輯都可以復原／重做。
歷史記錄可能會變得很龐大，因此您可以控制其中有多少保留在記憶體中、有多少存放在儲存空間裡，以及是否要隨專案一起儲存。

::: tip
您可以用快速手勢來復原／重做：
- 雙指輕點：復原
- 三指輕點：重做
:::

## ![](/icons/history.webp) 歷史記錄 {#history-panel}
![](/images/history_history.webp)

這個面板會顯示歷史記錄堆疊，列出步驟數、操作名稱、套用的物件，以及該步驟所佔用的記憶體大小。

點選某個項目，即可跳回（或跳到）該狀態。長按某個項目，則會永久刪除它以及所有更早的歷史記錄；當您對雕刻成果滿意時，這是快速釋放記憶體的好方法。

### ![](/icons/speed.webp) 重播 {#replay}
左下角的播放按鈕會先倒回最初狀態，再逐一重做每個操作，讓您欣賞作品一步步成形的過程，相當有趣。滑桿可設定速度，單位是每秒操作數。再點一次按鈕即可停止；執行復原／重做或點選某個項目也會讓它停止。

開始之前，會跳出一個視窗讓您選擇：
* `反細分` - 從目前狀態一路復原回最初狀態，而不是從最初狀態開始重播。
* `還原相機視角` - 相機會跟著重播的操作移動，即使[還原相機視角](#restore-camera)已關閉也一樣。
* `相機平滑` - 相機會在各個視角之間平順移動，而不是直接跳到每個視角。數值越高，相機移動越平穩。

::: warning
重播功能仍在實驗階段。
:::

## 包含操作 {#include-actions}

歷史記錄面板底部的圖示，用來選擇哪些類型的編輯要記錄到歷史記錄中：

| 操作      | 圖示                          | 說明                                                                         |
| :---------- | :---------------------------: | :---------------------------------------------------------------------------------- |
| 燈光      | ![](/icons/light.webp)        | 燈光的編輯。用軸向變換移動燈光時一律會被記錄，因為這可能會影響場景階層中的其他物件 |
| 算繪模式     | ![](/icons/sun.webp)          | PBR、MatCap 與 Unlit 模式，以及 MatCap 和 HDRI 的切換                                   |
| 後製 | ![](/icons/postprocess.webp)  | 後製的編輯                                                                   |
| 選區   | ![](/icons/tool_lattice.webp) | 晶格選取的編輯，例如點選、套索選取與取消選取          |

## 設定 {#settings}
![](/images/history_settings.webp)

### ![](/icons/camera.webp) 還原相機視角 {#restore-camera}
每個操作都會儲存當下的相機視角。
啟用此選項後，復原或重做操作時，相機會回到當時儲存的視角。

### ![](/icons/history.webp) 儲存歷史記錄 {#save-history}
儲存專案時一併保留復原歷史記錄，重新開啟專案後仍可使用。關閉它可讓專案檔案更小。

### ![](/icons/ram.webp) 記憶體限制 {#history-limit-mb}
保留在記憶體中的歷史記錄上限。較舊的狀態會移到儲存空間，需要時再重新載入，並不會被刪除。

### ![](/icons/save.webp) 儲存空間限制 {#storage-limit}
這個專案的歷史記錄可使用的儲存空間上限。達到上限時，最舊的操作會被永久刪除。

::: tip
新的限制會在下一次編輯、復原或重做後生效。
:::

### ![](/icons/undo.webp) 復原警告 {#maximum-undoable}
一次跳回超過這個數量的操作時，會先要求您確認。如果之後又進行了編輯，該時間點之後的所有操作都會遺失，因此這個設定能防止您不小心點到清單中很下方的項目。
