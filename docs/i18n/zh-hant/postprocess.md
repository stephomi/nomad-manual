# ![](/icons/postprocess.webp) 後製 {#post-process}

這個選單控制 Nomad 許多會影響算繪外觀的設定。

![](/images/postprocess_overview_drac.webp)

使用後製可以大幅改變場景最終的樣貌。

![](/images/postprocess_overview.webp)
*同一個場景在後製前後的樣子，沒有增加燈光，也沒有修改材質。*

依你的裝置而定，後製可能會大幅影響效能。
有一個全域的 `後製` 核取方塊可以停用所有後製效果，讓你能很快回到雕刻／建模，又不會失去你的預設。
進行 PBR 算繪時，應該啟用[環境光遮蔽](#ambient-occlusion-ssao)、[反射](#reflection-ssr)和[色調映射](#tone-mapping)。

不過大多數時候，雕刻時你會想停用後製，好專心在形狀本身上。


## 品質 {#quality}

![](/images/postprocess_quality.webp)

這些選項能提升算繪品質，代價是效能。

### 最大影格取樣數 {#max-frame-sampling}
Nomad 算繪單一影格時只會計算一定量的後製，看起來可能會有雜訊。這個控制項決定要算繪多少影格，再把它們混合在一起，以去除大部分的雜訊。有些效果不需要額外的取樣（例如調色），而柔和陰影、全域光照這類效果可能需要數百次取樣才能完全沒有雜訊。

在視窗中，只要讓 Nomad 靜置不動就能看到這個過程：畫質會逐漸提升，直到達到最大取樣數後停止。停止後 Nomad 就不再做任何運算，可以節省電力。在[檔案選單](files)的算繪區按下「匯出 PNG」時，也會使用這個計算次數。

滑桿旁的核取方塊用來開啟或關閉影格取樣。

### 即時算繪解析度 {#resolution-multiplier}
這個滑桿控制算繪的解析度。x1.0 表示以裝置的像素解析度算繪。x0.5 會以一半的解析度算繪，速度很快但品質較低。大於 1 的數值會以更大的尺寸算繪，再縮小顯示。這樣品質更高、雜訊更少，但算繪時間也更長。

它對效能的影響很大，所以盡量保持在 x1.25 以下。這個數值不會存進設定中，而且[畫素藝術](#pixel-art)效果會覆寫它。

### ![](/icons/intensity.webp) 最大取樣數 {#max-samples}

提升後製效果的品質，代價是效能。

### ![](/icons/material_dithering.webp) 抖色 {#dithering}

對像素做抖色處理，減少色帶瑕疵（例如漸層或暈影中的色帶）。通常應該啟用，但在特定操作時可以關閉（例如匯出深度圖或其他資料相關的操作）。

### ![](/icons/denoise.webp) 雜訊消除（oidn） {#oidn}

在所有影格累積完成後，對圖片套用雜訊消除。這能讓你使用低得多的取樣數。雜訊消除很耗處理器資源，所以只在圖片有雜訊時才啟用。並非所有裝置都能使用。

## 預設瀏覽器 {#preset-browser}
![](/images/postprocess_presets.webp)
點一下 `後製` 標題下方的圖片，就會顯示一系列後製預設。用 `新增` 可以根據目前的設定建立預設。內建的預設只能複製：要定義自己的預設，請選一個預設，點 `複製`，再做修改。當預設有尚未儲存的變更時，會顯示 `更改未儲存！`；要儲存的話，請點預設圖片，在預設瀏覽器中再點一次，然後選擇 `儲存`。

## 捷徑列 {#shortcut-bar}
啟用後製時，選單底部會有一列列出所有效果（`SSR`、`SSGI`、`SSAO`、`DoF`、`泛光效果`…）。點一下就能跳到該效果的區塊。關閉的效果會顯示為灰色，所以這一列也能讓你快速了解目前的預設做了哪些事。

## ![](/icons/postprocess_ssr.webp) 螢幕空間反射（SSR） {#reflection-ssr}
使用這個選項，物件就能反射場景中的其他物件，只要那些物件出現在螢幕上。
如果場景中有金屬或有光澤的物件，大概就該使用這個選項。
這個選項需要 [光照 (PBR)](shading.md#pbr) 算繪模式。

## ![](/icons/postprocess_ssgi.webp) 全域光照（SSGI） {#global-illumination-ssgi}

全域光照模擬光線在表面之間反彈的情況，例如紅色的牆會把紅色映照到旁邊的白色物件上。搭配環境光遮蔽和反射使用時，能大幅提升算繪的真實感。和反射一樣，它需要 [光照 (PBR)](shading.md#pbr) 算繪模式。

`強度` - 全域光照的強度。

## ![](/icons/postprocess_ssao.webp) 環境光遮蔽（SSAO） {#ambient-occlusion-ssao}
環境光遮蔽會讓光線較難照到的區域（例如角落）變暗。
這個效果只取決於模型的幾何形狀。

* `強度` - 效果的強度。
* `範圍` - 效果擴散的範圍。
* `厚度` - 假設遮擋物有多厚的深度，以 `範圍` 的百分比表示。
* `色調` - 和遮蔽相乘的顏色，用來做出創意效果。


| 關閉 SSAO                    | 開啟 SSAO                    |
| :-------------------------: | :------------------------: |
| ![](/images/ssao_off.webp) | ![](/images/ssao_on.webp) |

::: tip
AO 在主要受環境光照亮的區域最明顯。受到強烈直射光照射的區域，AO 效果會弱得多。

:::

## ![](/icons/postprocess_dof.webp) 景深 {#depth-of-field-dof}
為焦點以外的區域加上模糊效果。

只要點一下模型，就能改變焦點。

* `光圈模式` - 用單一的相機光圈來控制模糊，取代下方的兩個模糊滑桿。
* `光圈`（_僅限光圈模式_）- 鏡頭的光圈值（f 值），就像真正的相機一樣。數值越低，光圈開得越大，也越模糊。
* `遠景模糊` - 焦點後方要套用的模糊量。
* `近景模糊` - 焦點和相機之間要套用的模糊量。


| 關閉景深                   | 景深對焦在遠處的環       | 景深對焦在近處的環    |
| :-----------------------: | :-------------------------: | :------------------------: |
| ![](/images/dof_off.webp) | ![](/images/dof_near.webp) | ![](/images/dof_far.webp) |


## ![](/icons/sun.webp) 泛光效果 {#bloom}
泛光效果會讓場景中明亮的區域發光。

* `強度` - 效果的強度。
* `範圍` - 效果擴散的範圍。
* `臨界值` - 場景中的像素要多亮才會開始發光。設為 0 時所有東西都會發光，設得越高，就只有最亮的像素會發光。
* `色調` - 可以加到泛光上的顏色，用來做出創意效果。

| 關閉泛光效果                    | 泛光範圍為 0         | 泛光範圍為 1         |
| :--------------------------: | :-------------------------: | :-------------------------: |
| ![](/images/bloom_off.webp) | ![](/images/bloom_r0.webp) | ![](/images/bloom_r1.webp) |


## ![](/icons/postprocess_tone.webp) 色調映射 {#tone-mapping}
色調映射是把 HDR 數值重新映射到 `[0, 1]` 範圍的運算。
如果不使用它（或選擇 `無`），任何大於 1 的顏色分量都會被截斷。
超出這個範圍的顏色變化也就會遺失。

* `無/中性/Agx/ACES` - 要使用哪一種色調映射。`無` 不做任何重新映射（但其他控制項仍然有效）。其他選項就像選擇不同的底片，會以不同的方式處理過曝的數值和顏色。這是個很深的主題，想了解更多，可以搜尋 tone mapping、Agx、ACES！
* `曝光` - 圖片的整體亮度，類似調整相機的光圈。這是讓整張圖片變亮或變暗的快速方法。
* `飽和度` - 顏色的強度。1 是中性，0 是單色，大於 1 則越來越飽和。
* `對比度` - 讓暗部更暗、亮部更亮。請小心使用，數值太高可能會產生瑕疵。

注意，停用 `色調映射` 時，有些細節會因為像素太亮而消失。

| 關閉色調映射            | 開啟色調映射            |
| :-------------------------: | :------------------------: |
| ![](/images/tone_off.webp) | ![](/images/tone_on.webp) |

::: tip
色調映射可以增強全域光照的效果。如果把環境貼圖的強度調低、主要光源調高，就能提高色調映射的 `曝光`，看到更多反彈光的效果。
:::

## ![](/icons/postprocess_cavity.webp) 曲率描邊 {#curvature}
偵測曲率急遽變化的地方，並為這些區域加上顏色。

* `係數` - 效果的整體強度
* `凸起` - 偵測尖銳凸起變化的程度，並在那裡加上所選的顏色（預設為白色）
* `凹陷` - 偵測凹陷變化的程度，並在那裡加上所選的顏色（預設為黑色）
* `厚度` - 偵測到的邊緣有多寬。

`凸起` 和 `凹陷` 旁都有色票可以選擇顏色，還有一個小按鈕可以選擇該顏色和圖片的混合方式。
