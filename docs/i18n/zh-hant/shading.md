# ![](/icons/sun.webp) 著色 {#shading}

這個選單控制 Nomad 使用的著色模式、燈光屬性、環境與 MatCap，以及霧。

![](/images/shading_overview.webp)



您可以在幾種算繪模式之間選擇：

| 模式                        | 意思                    | 說明                                                     |
| :-------------------------: | :------------------------: | :-------------------------------------------------------------: |
| [光照 (PBR)](#pbr)           | 基於物理的算繪 | 燈光、陰影、環境，以及繪製的金屬度與粗糙度   |
| [材質捕捉](#matcap)           | 材質捕捉（Material Capture）           | 適合雕刻的快速模式，GPU/CPU 負擔比 PBR 低        |
| [不受光](#unlit)             | 表面顏色              | 只顯示表面顏色，沒有任何著色或光照                  |
| [物件 ID](#object-id)     | 物件 ID                  | 每個物件一種隨機顏色，方便在繪圖應用程式中使用。    |
| [實例 ID](#instance-id) | 實例 ID                | 每個實例一種隨機顏色，方便辨識共用的網格   |

如果想進一步了解金屬度和粗糙度，請參閱 [頂點繪畫](painting.md) 章節。

---

![](/images/shading_second.webp)

### ![](/icons/group_gray.webp) 面群組 {#face-group}
疊加顯示面群組的顏色。面群組是帶有顏色的多邊形選取範圍，可以用 [面群組](tools#facegroup) 工具建立，大多數基本體也會自動帶有面群組。

當面群組顯示時，有些工具會自動依面群組過濾。

### ![](/icons/palette.webp) 顯示繪畫 {#show-paint}
Nomad 可以把顏色、粗糙度、金屬度儲存在雕刻作品的頂點中。您可以用這個核取方塊，全域切換這些屬性的顯示。

請注意，如果同時有頂點屬性和貼圖，而且兩者都啟用，數值會互相相乘。

### ![](/icons/shield.webp) 顯示遮罩 {#show-mask}
切換 [遮罩工具](tools#mask) 的灰階遮罩疊加顯示。停用時，遮罩也會一併停用；這很適合在不受遮罩影響的情況下快速修改，之後再重新啟用，遮罩也不會遺失。

### ![](/icons/tool_hide.webp) 使用隱藏 {#use-hide}

切換隱藏的面。請注意，這只在您「不是」使用隱藏工具時才有作用！

### ![](/icons/image.webp) 使用貼圖 {#use-textures}

Nomad 可以從 [材質](material) 選單為物件指定貼圖。如果有指定貼圖，就可以用這個核取方塊全域切換它們。

您無法在 Nomad 中建立或編輯貼圖，但匯入檔案中的貼圖可以使用。不透明度貼圖在光照、材質捕捉和不受光模式下都有作用；法線貼圖在光照和材質捕捉下有作用；顏色貼圖在光照和不受光下有作用；而自發光、粗糙度和金屬度貼圖只在光照模式下有作用。當場景中沒有任何貼圖時，這個按鈕會呈現灰色。

### PBR 與燈光概覽 {#pbr}
本手冊不會深入探討基於物理的算繪（PBR）的細節。

有一件重要的事要記住：燈光和材質是完全分開的。
也就是說，您可以繪製物件的顏色、粗糙度和金屬度，而燈光則是獨立處理的。
這讓您可以先繪製物件，之後再調整燈光，而不會破壞模型的整體外觀。

燈光、環境和霧只能在 [PBR 模式](#pbr) 下使用。
基於效能考量，行動裝置上最多只能有 4 盞燈，桌面版則是 6 盞。

::: tip
您可以載入含有更多燈光的 glTF 檔案，Nomad 會保留所有燈光。
不過效能不一定會好。
:::

::: tip
您可以讓物件不受光／自發光，再到 [後製](postprocess) 選單中啟用全域光照，來模擬許多燈光的效果。
:::

### 燈光類型概覽 {#light-types-overview}

以下是目前支援的燈光類型：

| 模式                        | 說明                                             | 可投射陰影 |
| :-------------------------: | :-----------------------------------------------------: | :--------------: |
| [方向光](#directional) | 位於無限遠處的太陽光                           | 是              |
| [環境](#env-light)   | 與環境 HDR 對齊的遠距光源  | 是              |
| [聚光燈](#spot)               | 圓錐形的燈光                                      | 是              |
| [點光源](#point)             | 向所有方向發光的點狀光源                         | 是              |

#### ![](/icons/sun.webp) 方向光 {#directional}
從無限遠處發出強度均勻的光。
它在場景中的 3d 位置並不重要，只有方向才有影響。

您可以將這盞燈附加在相機上，讓光照保持一致。  
例如，可以用它來做輪廓光（從模型背後朝相機方向打過來的強光），讓模型的背面永遠被照亮。

#### ![](/icons/panorama.webp) 環境光 {#env-light}
使用 [環境 HDR](#environment) 很適合營造整體柔和的光照，但如果 HDR 中有一個強烈、銳利的光源，它產生的陰影會非常柔和，常常幾乎看不見。搭配方向光和環境 HDR 一起使用會有幫助，但要讓兩者對齊可能不太容易。

這盞燈會幫您做好這件事。它會自動旋轉，對準 HDR 中最亮的部分，然後您就可以分別控制它的強度和角度（陰影的柔和度）。 

#### ![](/icons/spotlight.webp) 聚光燈 {#spot}
聚光燈朝單一方向發光，範圍限制在一個圓錐形內。

#### ![](/icons/light.webp) 點光源 {#point}
點光源會向所有方向發光，也可以投射陰影。

#### 陰影 {#shadows}
每盞燈都可以投射陰影，您可以在它的 [設定](#light-extra-controls) 中選擇陰影的計算方式。如果看到陰影瑕疵，那裡的 `容許值` 滑桿可以幫上忙。

陰影的品質取決於物件相對於整個場景的大小。  
如果場景中有一個不需要投射陰影的大物件（例如一個大平面），請記得在它的 [材質設定](material.md#casts-shadows) 中停用投射陰影。

## ![](/icons/sun.webp) 燈光 {#lights}

![](/images/shading_lights.webp)

### ![](/icons/checked.webp) 燈光核取方塊 {#lights-checkbox}

切換場景中所有的直接光源。



### 新增燈光 {#add-light}

在場景中新增一盞燈，行動裝置上最多 4 盞，桌面版最多 6 盞。新增燈光後，會顯示帶有按鈕的燈光清單，並在視埠頂端加上一列燈光工具列。

![](/images/shading_lights_icons.webp)

* 文字顯示燈光的名稱和亮度。點一下即可選取這盞燈。
* 眼睛圖示可以切換顯示與否。
* 鉛筆圖示可以重新命名燈光。
* 垃圾桶圖示會刪除燈光。
* 複製圖示會複製一盞燈光。 
* 三個點的圖示會開啟完整的燈光編輯器。大部分功能也可以在視埠中出現的工具列裡找到。 

您也可以在清單中拖曳燈光來重新排序。

### ![](/icons/spotlight.webp)  圖示 {#icons}

切換視埠中燈光圖示的顯示

### 燈光工具列 {#light-toolbar}
![](/images/shading_lights_toolbar.webp) 

選取燈光時，這個工具列會出現在視埠頂端。

* `可見` 會切換燈光的顯示。
* 方向光／環境／聚光燈／點光源 會改變燈光類型。點一下可以循環切換，長按則會顯示選單。
* 強度控制燈光的強弱，數值可以超過 1.0 來做出非常強烈的燈光，搭配後製中的全域光照時很有用
* 點一下色票會開啟顏色選擇器。Nomad 提供好幾種選擇顏色的方式。色溫（Kelvin）控制可以自然地選擇暖色或冷色的光。
* 陰影會切換陰影。
* 角度（_方向光和環境_）或尺寸（_聚光燈和點光源_）設定燈光的寬度。越寬的燈光，投射的陰影、光照和物件上的高光都會越柔和。
* 跟隨方式（_僅限方向光_）、錐角和柔和度（_僅限聚光燈_）會在下方的 [燈光編輯器](#light-extra-controls) 中說明。
* ... 會開啟 `複製`、`重新定位` 和 `刪除`，以及陰影設定。

### 燈光進階控制 {#light-extra-controls}

![](/images/shading_extra_controls.webp) 

點一下清單中某盞燈的三個點圖示，會開啟它的完整編輯器。請注意，有些選項只適用於特定的燈光類型。

* `方向光/環境/聚光燈/點光源` 可以改變燈光類型。
* 點一下 `色票` 會開啟顏色選擇器。 
* `強度` 控制燈光的強弱。
* `跟隨方式`（_僅限方向光_）設定燈光要附加在世界上（`固定`），還是附加在相機上（`隨相機移動`）。例如，如果您把方向光放在角色背後當作輪廓光，選擇隨相機移動時，不管怎麼旋轉相機，燈光永遠都會在角色背後。
* `柔和度`（_僅限聚光燈_）控制聚光燈圓錐邊緣的銳利度。0 是非常銳利的邊緣。1 則非常柔和，會一路漸變到光錐中心。在視埠中，可以拖曳聚光燈圓錐上的藍色小點來即時調整柔和度。
* `錐角`（_僅限聚光燈_）控制聚光燈的擴散角度。角度小就是很細的光束，170 則是非常寬廣的光。在視埠中，可以拖曳橘色的點來即時調整錐角。
* `角度`（_僅限方向光和環境_）是燈光的視覺大小，可以想成太陽在天空中看起來有多大。角度越大，投射的陰影越柔和，高光也越寬。
* `尺寸`（_僅限聚光燈和點光源_）是燈光的寬度。燈光越大，投射的陰影越柔和。
* `顯示陰影` 會切換目前這盞燈的陰影。
* 陰影類型決定陰影的計算方式。`陰影貼圖` 會從燈光的位置算繪場景，所以相機看不到的幾何形狀也會產生陰影。`螢幕空間` 只使用畫面上已經看得到的內容：成本較低，但仍屬實驗性質。一般來說，陰影貼圖比較可靠。
* `容許值`（_僅限螢幕空間_）：如果看到陰影瑕疵（例如陰影似乎沒有貼合表面，或陰影中出現雜訊和紋路），調整容許值可以幫助修正這些問題。
* `接觸陰影` 會在短距離內、物件互相接觸的地方加上更精確的陰影。設為 `自動` 時，只有場景中最主要的燈光會產生接觸陰影；`否` 和 `是` 則會針對這盞燈強制關閉或開啟。它的 `容許值` 滑桿作用和上面那個相同。

視埠工具列的 `...` 按鈕也有相同的陰影設定，另外還有：

* `複製` 會複製這盞燈光。
* `重新定位` 會把燈光移到相機前方，並保持它的方向。
* `刪除` 會刪除這盞燈光。


## ![](/icons/panorama.webp) 環境 {#environment}

![](/images/shading_environment.webp)

真實世界中的光來自四面八方：天空的藍、草地的綠、建築物的紅，這些來自「環境」的光，都可以用環境貼圖來模擬。 

使用標題旁的核取方塊，可以開啟或關閉環境光照。

Nomad 內建了好幾張室內和室外的環境貼圖範例，色調和亮度各不相同。多試幾張，看看哪一張最能凸顯您雕刻作品的細節。

點一下影像即可查看可用的環境貼圖。在那個視窗中選擇 `匯入…` 就能載入您自己的貼圖。最好使用高動態範圍（HDR）影像，格式為經緯度（latlong）或等距長方投影（equirectangular），檔案為 .hdr 或 .exr。瀏覽器也可以直接從 [Poly Haven](https://polyhaven.com/hdris) 下載環境貼圖，那裡有很多不錯的免費環境貼圖。

### 曝光 {#env-exposure}
調整環境貼圖的亮度。和一般燈光一起使用時，環境貼圖常常會太亮，調低曝光有助於取得平衡，特別是搭配 [後製](postprocess) 設定中的全域光照時。

### 旋轉 {#env-rotation}

由於環境貼圖捕捉了來自所有方向的光，您可以旋轉它，讓反射和整體光照與雕刻作品搭配得更好。您也可以在視埠上用 3 指水平拖曳來旋轉環境。

### 環境跟隨相機 {#env-attached}
將環境附加在相機上。

這會讓光照保持一致，在雕刻時很有用。

### 背景模糊 {#env-background-blur}
只有當 [背景](background.md) 設為環境時，才會顯示這個滑桿。它會模糊模型後方的環境影像，但不會改變光照。


## ![](/icons/fog.webp) 霧 {#fog}

霧能為場景增添大氣的深度感，並讓光束變得可見。用標題旁的核取方塊啟用它。和燈光、環境一樣，霧只能在 [光照 (PBR)](#pbr) 模式下使用。

::: tip 更明顯的光束
調低霧的 `環境`，並使用明亮的聚光燈或點光源。提高 `密度`，直到霧清楚可見。若想在較稀薄的霧中看到光束，請把 `散射方向` 設為較高的正值，並讓相機朝向燈光。
:::

### 顏色 {#fog-color}
霧的顏色，以及它所散射的光的顏色。

### 密度 {#fog-density}
霧隨距離變濃的速度。

### 最大不透明度 {#fog-opacity}
限制霧最多能遮蓋場景的程度，即使密度很高也一樣。

### 散射方向 {#fog-scattering}
霧散射光線的方向（也稱為各向異性）。正值會在您朝向燈光看時讓霧變亮，負值則是在背對燈光時變亮，而零會讓光均勻地往各個方向散射。

### ![](/icons/panorama.webp) 環境 {#fog-environment}
[環境](#environment) 照亮霧的程度。關閉環境時，這個選項會呈現灰色。

### 雜訊 {#fog-noise}
在霧中混入雜訊，讓它分成一塊一塊的，但不改變整體密度。雜訊大於 0 時，`大小` 滑桿可以設定圖樣的大小。

### 形狀 {#fog-shape}
霧在場景中填充的範圍：

* `均勻` - 填滿整個場景。
* `垂直` - 把霧限制在一段邊緣柔和的垂直區間內。`底部` 和 `頂部` 滑桿設定下緣和上緣的高度，旁邊的眼睛按鈕會在您調整時，在視埠中顯示這個區間。


## ![](/icons/sphere_smooth.webp) 材質捕捉 {#matcap}

![](/images/shading_matcap.webp)

顧名思義（MATerial CAPture，材質捕捉），MatCap 用一張影像同時處理光照和材質資訊。
由於材質本身已經包含在 MatCap 中，粗糙度和金屬度的繪畫通道會被忽略。
繪畫的顏色會與 MatCap 相乘，也就是說，如果您使用黑色或灰色的 MatCap，塗上白色也不會讓它變亮。

藝術家通常偏好用這個模式雕刻，因為它能讓人專注在形狀和幾何本身。

點一下球體會開啟影像瀏覽器。您也可以加入自己的 MatCap，一般來說，任何球體的照片、算繪圖，甚至是一幅球體的畫作，只要裁成緊貼球體的正方形，都可以使用。網路上有許多 MatCap 素材庫，[nidorx matcap library](https://github.com/nidorx/matcaps) 是很實用的資源。

### 使用全域 MatCap {#matcap-global}

藝術家通常會在整件雕刻作品上使用同一個 MatCap，但如果停用這個開關，選取的物件就可以有自己的 MatCap。這在藝術表現上可以做出很搶眼的效果。

::: tip
停用這個選項，再為角色的眼睛使用一張眼球的影像！
:::

### 旋轉 {#matcap-rotation}
MatCap 是一種特殊形式的環境貼圖，所以和環境貼圖一樣可以旋轉。您也可以隨時在視埠中用 3 指左右拖曳來旋轉。

滑桿旁的鎖頭按鈕會鎖定旋轉，這樣 3 指拖曳就不會不小心轉動 MatCap。



## ![](/icons/circle_fill.webp) 不受光 {#unlit}

這個模式只會顯示表面顏色。想確認物件的表面顏色是否符合預期，而不受燈光、陰影、反射、透明度干擾時，這很有用。 

這個模式也可以用於非寫實的算繪，做出平塗的卡通風格。

## ![](/icons/cube.webp) 物件 ID {#object-id}

所有光照和表面資訊都會被忽略，每個物件都以一種獨特的純色著色。如果把它和 PBR 算繪一起輸出，就可以在繪圖程式中依顏色選取，進而針對特定物件做顏色校正。

請注意，這些顏色也會出現在 [場景選單的樹狀檢視](scene#tree-view) 中。

### 隨機化 ID {#object-random}

產生一組新的隨機顏色。 

## ![](/icons/link.webp) 實例 ID {#instance-id}

和物件 ID 相同，但同一組實例會是相同的顏色。 

### 隨機化 ID {#instance-random}

產生一組新的隨機顏色。
