# ![](/icons/symmetry.webp) 對稱 {#symmetry}

這個選單控制筆觸如何沿鏡像平面、以徑向或以瓦片方式重複，也提供讓不對稱物件恢復對稱的方法。

![](/images/symmetry_overview.webp) 

## 概覽 {#overview}
對稱有好幾種用法：

* 當作鏡子，沿 X（左／右）、Y（上／下）、Z（後／前）或它們的組合翻轉你的作品。
* 可以在 X、Y、Z 上設定徑向對稱和重複次數，例如雕刻海星。
* 瓦片會在物件上重複你的筆觸，讓雕刻能無縫拼接。
* 鏡像可以繞著原點運作（稱為世界模式），也可以繞著物件中心運作（稱為本地模式）。
* 一開始不對稱的雕刻，也可以強制變成對稱。

左側快捷面板上也有開關對稱的捷徑（*「對稱」*）。上面的小字「L/W」表示 Nomad 目前處於本地（Local）還是世界（World）對稱模式。你也可以長按它，或往螢幕中央滑動來叫出選單。

![](/images/symmetry_button.webp) 

對稱設定會隨每個物件一起儲存，選單標題會顯示你正在編輯的物件名稱。
雕刻工具共用同一個開關狀態，而變換工具（[自由變換](tools.md#transform)和[軸向變換](tools.md#gizmo)）則有各自的狀態。

::: tip
對稱選單主要用來控制筆觸的對稱。你也可以透過[場景選單中的重複器](scene#repeaters)來鏡像和重複物件。
:::

## ![](/icons/symmetry.webp) 啟用 {#enabled}
切換鏡像模式，和左側快捷面板上的 `對稱` 按鈕相同。關閉時會有警告圖示提醒你，選單也會告訴你目前的工具是否忽略對稱。

## 平面 {#planes}

啟用對稱平面，以及設定徑向對稱的重複次數。注意你不必只選一個平面，可以同時啟用 1、2 或 3 個平面，做出複雜的對稱。

`徑向` 這一列設定繞每個軸的徑向對稱重複次數。這些同樣不限於單一軸，甚至可以和平面對稱搭配使用，很快就能做出細緻的效果。（重複的總數上限為 200）

![](/videos/symmetry_demo.mp4) 

## 瓦片 {#tile}

沿著某個軸以固定間距重複你的筆觸，讓雕刻能無縫拼接。很適合做圖紋、磚塊，或打算重複使用的紋理。

用 `瓦片` 按鈕為每個軸開啟瓦片，然後設定 `數量`（物件上要重複幾次）或 `距離`（兩次重複之間的間隔）。點左側的切換鈕即可在兩者之間切換。

## 模式 {#method}
鏡像可以是 `本地`，跟著物件一起移動；也可以是 `世界`，固定不動。如果不確定該用哪種模式，可以觀察疊加在物件上的鏡像平面和徑向指示線。在本地模式下，如果你用變換工具（`軸向變換` 或 `自由變換`）移動模型，鏡像指示線也會跟著移動。在世界模式下，鏡像指示線會固定不動，物件則從中滑過。

## 鏡像 {#mirroring}
![](/images/symmetry_mirroring.webp)

在對稱平面附近雕刻時，有些筆刷的對稱效果並不完美。這一區讓你把雕刻的一側複製到另一側，藉此恢復對稱。

`方向` - `鏡像` 標題旁的兩個箭頭按鈕決定要把哪一側複製到另一側。Nomad 會根據你目前的視角來判斷，所以不論你從哪個方向看模型，螢幕上的那一側都保持一致。

![](/icons/shield.webp) `遮罩` - 遮罩按鈕讓你限定要鏡像的範圍：遮罩目標那一側可以保護該區域，遮罩來源那一側則可以讓該區域不被鏡像到目標側。

![](/icons/tool_hide.webp) `隱藏` - 啟用時，來源側被隱藏的區域不會被鏡像到目標側。

`鏡像`（保留拓樸）會嘗試判斷鏡像兩側的拓樸是否相同，如果相同，就只移動頂點。這是最常見的情況。徑向對稱會被忽略。如果拓樸不對稱，Nomad 會提議改用 `切割 • 鏡像` 來強制鏡像。

`切割` 按鈕會沿著對稱平面切開物件。它們會改變拓樸，所以比 `鏡像` 更具破壞性。每個按鈕上的數字是你會得到的物件數量：

* `切割` - 移除物件的一側。
* `切割 • 鏡像` - 切開物件，複製其中一側並鏡像到另一側，再沿著鏡像處焊接頂點。如果模型兩側差異很大，有時就必須用這個方法。
* `切割 • 分割` - 切開物件，並把兩側各自保留為獨立的物件。
* `切割 • 鏡像 • 分割` - 和 `切割 • 鏡像` 一樣，但每一側都會變成獨立的物件。

如果選取了多個物件，`鏡像` 和[翻轉物件](#flip-object)會套用到所有物件上。

### 翻轉物件 {#flip-object}
![](/images/symmetry_flip.webp)
沿著 `X`、`Y` 或 `Z` 把左側變成右側，右側變成左側。外觀上就像在軸向變換工具選單中把 X 的縮放設為 -1。

## 重設與編輯 {#reset-and-edit}

![](/images/symmetry_edit.webp)

你可以編輯對稱的位置和方向（但不建議這麼做！）。必要時，`世界中心`（本地模式下為 `物件中心`）和 `方向` 會把對稱的位置和方向重設為預設值。

Nomad 通常知道對稱平面該放在哪裡。不建議手動調整，但 `編輯Gizmo` 按鈕讓進階使用者可以這麼做。點選這個按鈕後，會出現一個控制器，讓你移動和旋轉對稱平面。如果想恢復預設的中心和方向，請使用上面的重設按鈕。

`從樞軸` 會把對稱平面放到[軸向變換](tools.md#gizmo)工具的軸心上。只有在 `軸向變換` 工具啟用時才能使用。

這些選項的行為會依你所在的空間（*本地／世界*）而不同。
所以如果結果不如預期，請確認你是否處於正確的空間。

::: tip
用控制器編輯對稱平面還有點實驗性質，你應該用不太到！
:::

## 顯示選項 {#show-options}
![](/images/symmetry_show.webp)


`顯示線條` 和 `顯示平面` 會切換視窗中對稱位置的疊加顯示。注意，關閉這些選項要等到對稱選單關閉後才會生效。
