## 總覽 {#overview}

工具從右側的 `工具箱` 中選取，並透過左側的 `工具控制` 操作。額外的設定位於右上方選單中的 `工具` 選單。

筆刷類工具可以控制大小與強度；選取類工具則提供數種選取方式的控制。工具控制的底部有常用操作的快捷按鈕（平滑、遮罩、隱藏、面群組、軸向變換、顏色、Alpha）。

Nomad 的工具在工具箱中以顏色區分（若想要單色標籤，可在[介面](interface.md)選單中關閉 `彩色工具`）：

* <span class=brush>**筆刷工具**</span>（黏土、筆刷、平滑、圖層、膨脹、擦除、Quad Remesher）
* <span class=move>**移動工具**</span>（移動、拖曳、彈性、微移）
* <span class=mask>**遮罩工具**</span>（遮罩）
* <span class=paint>**繪畫工具**</span>（繪畫、塗抹）
* <span class=flatten>**剷平工具**</span>（剷平、平面、拋光）
* <span class=pinch>**捏合工具**</span>（褶皺、捏合）
* <span class=stamp>**圖章工具**</span>（圖章、VDM）
* <span class=selection>**選取類工具**</span>：先繪製一個 2d 遮罩，再執行操作（裁切、分割、投影）
* <span class=creation>**建立工具**</span>（圓管、車削、插入）
* <span class=transform>**變換工具**</span>（自由變換、軸向變換、排列、晶格）
* <span class=misc>**其他工具**</span>（面群組、隱藏）
* <span class=view>**檢視工具**</span>（瀏覽模式、測量、選擇）



這些工具大多可以透過[筆觸](stroke.md)選單，自訂不同的筆刷行為、壓感、紋理等。

### 反向模式 {#sub-mode}
強度滑桿正下方的按鈕是 `反向` 按鈕。它的標籤和功能會隨工具而變，按下後會啟用另一種行為，通常是相反的效果。例如在[繪畫](#paint)中它會切換成擦除模式，在[褶皺](#crease)中則會做出凸起的稜線，而不是凹陷的褶痕等等。

預設情況下它是一個「按住生效」的按鈕：按住時暫時啟用，放開後就會關閉。如果輕點一下，反向模式就會持續啟用。

### 快捷按鈕 {#shortcuts}
左側工具列底部有[平滑](#smooth)、[遮罩](#mask)、[隱藏](#hide)、[面群組](#facegroup)、[軸向變換](#gizmo)、[顏色](painting.md#pbr-sliders)、[Alpha](stroke.md#alpha) 的快捷按鈕。 

預設情況下它們都是「按住生效」的按鈕：按住時暫時啟用，放開後就會關閉。如果輕點一下，該快捷模式就會持續啟用。

### 選取控制 {#selection-controls}

[遮罩](#mask)、[繪畫](#paint)、[裁切](#trim)、[分割](#split)、[投影](#project)、[面群組](#facegroup)、[隱藏](#hide)和[選擇](#select)工具，都使用類似的控制來選取網格上的區域。

![](/images/tools_shape_selector_panel.webp)

點選左側工具列中的形狀按鈕（它會顯示目前的形狀，預設是 `套索`），即可開啟形狀的彈出視窗。對於也能搭配筆刷使用的工具（遮罩、繪畫、面群組、隱藏），筆觸類型也放在同一個彈出視窗中。

* `檢視` - 不使用任何形狀，工具不會做任何事，就像相機模式一樣。
* `套索` - 徒手繪製的形狀
* `多邊形` - 由曲線和／或直線組合而成的封閉形狀。詳情請參閱下方的[形狀編輯](#shape-editing)。
* `曲線` -（僅限投影）用於投影的徒手曲線
* `路徑` -（僅限投影）由控制點定義的曲線。詳情請參閱下方的[形狀編輯](#shape-editing)。
* `直線` - 拖曳出一條直線，定義一個平面切割段。預設會立即作用在網格上；若不想這樣，可以變更 `編輯` 選項（在直線圖示上長按或滑動）
* `帶狀` - 介於兩條平行導引線之間的帶狀區域，橫跨其上有一道漸層。`延伸` 會讓遠端導引線之外也保持完整數值，而不是在帶狀區域結束；`翻轉` 則會交換漸層的起始導引線。
* `矩形` - 拖曳一條對角線，定義矩形的兩個角。長按或滑動可顯示 `編輯` 選項、強制畫成正方形的 `正方形`，以及讓第一個點成為矩形中心的 `中心`。
* `橢圓` - 拖曳一條對角線，定義橢圓的大小。長按或滑動可顯示 `編輯` 選項、強制畫成圓形的 `圓形`，以及讓第一個點成為橢圓中心的 `中心`。
* `翻轉` - 反轉形狀遮罩，或反轉投影工具的方向。

大多數工具都有 `編輯` 選項，決定畫完形狀後會發生什麼事：
* `編輯：關` - 一放開就立即執行操作。
* `編輯：開` - 形狀會保持可編輯狀態。形狀旁會出現一個綠色按鈕，按下它才會執行操作。這樣您就能先修改形狀、調整視角，準備好之後再按下綠色按鈕。
* `編輯：按住` - 放開時執行操作；若在筆畫結尾按住不放，則可以繼續編輯形狀。

### 形狀編輯 {#shape-editing}
多邊形編輯和曲線編輯的操作方式很類似：

* 一開始先拖曳出一條直線來定義 2 個點，再從線段中間往外拖曳，做出多邊形或曲線。
* 點選控制點可以在平滑與尖角之間切換。 
* 在曲線或直線段上點選並拖曳，可以新增控制點。
* 要刪除某個控制點，就把它拖向相鄰的控制點，直到它變成紅色。
* 多邊形或路徑圖示角落的垃圾桶圖示可以刪除整個形狀。

### ![](/icons/tool_move.webp) 移動 {#move}
筆刷下的區域會黏在筆刷上，產生有彈性的變形。移動過程中選取範圍會保持不變，所以如果您把筆刷移開，再移回起點，就會看到模型完全沒有變形。

反向模式是 `法線方向`，會讓筆刷下的區域沿著表面法線移動。

這支筆刷既適合大範圍的變形，也適合細膩的小幅調整。

#### 移動設定 {#move-settings}

* `半徑（背景）` - 筆刷離模型邊緣多遠仍然可以雕刻，在處理物件輪廓時很好用。取消勾選後，只有從模型上開始拖曳時才會抓取。
* `僅同側頂點` - 忽略朝向與變形方向相反的頂點。
* `方向` - 供 `法線方向` 反向模式使用，決定拖曳時是推入還是拉出表面：
    * `自動選擇` - 根據表面法線的角度，自動從下面兩種方式中挑選一種。
    * `3D 法線` - 比較指標在螢幕上的位置，與從相機看到的表面法線方向。
    * `XY` - 依照指標在螢幕上的位置（上／下、左／右）決定推入或拉出。
    * `臨界值` - 使用 `自動選擇` 時，決定採用哪種方式的角度界線。
* `滾轉速度` - 移動時可以同時扭轉抓住的區域：用雙指旋轉、轉動觸控筆的筆桿，或用滑鼠拖曳時按住修飾鍵（Alt、Ctrl、Shift 或 Cmd）。手指、觸控筆和滑鼠各有一個滑桿；取消勾選即可關閉該輸入方式。


![](/videos/tool_move.mp4)

### ![](/icons/tool_drag.webp) 拖曳 {#drag}
筆刷下的區域會黏在筆刷上，產生有彈性的變形。和移動筆刷不同的是，筆畫過程中選取範圍會持續更新，因此可以拉出更長、像蛇一樣的形狀，啟用動態拓樸時尤其如此。

反向模式是 `法線方向`，會讓筆刷下的區域沿著表面法線移動。

這支筆刷適合較隨性、手勢化的造型變化。

#### 拖曳設定 {#drag-settings}

拖曳的設定與[移動](#move-settings)相同：`半徑（背景）`、`僅同側頂點`、`方向` 和 `滾轉速度`。

![](/videos/tool_drag.mp4)

### ![](/icons/tool_elastic.webp) 彈性 {#elastic}
和[移動](#move)一樣可以抓住並拉動表面，但變形是有彈性的：拉力不會在筆刷邊緣停止，而是隨距離平滑地擴散到整個物件，有點像在拉扯橡膠。筆刷半徑決定拉動的範圍有多寬。

反向模式是 `法線方向`，會讓筆刷下的區域沿著表面法線移動。

這支筆刷適合大幅、柔和地調整比例，同時保持表面平順。

#### 彈性設定 {#elastic-settings}

彈性的設定與[移動](#move-settings)相同，但沒有 `僅同側頂點`。`半徑（背景）` 預設為關閉。

### ![](/icons/tool_smooth.webp) 平滑 {#smooth}
透過平均各點的位置來平滑區域。這個工具很受多邊形密度影響。
因此多邊形越多，平滑效果就越弱。

反向模式是 `規整網格`，只會整理網格線，同時盡量保留幾何細節。

#### 平滑設定 {#smooth-settings}

![](/images/tool_smooth_settings.webp)

##### 面群組 {#smooth-facegroup}

* `規整網格` - 平滑面群組的邊界。強度設在 100% 以上，可以快速把邊界整理平順。`自動` 只會在啟用面群組預覽時平滑，`否` 為停用，`是` 為啟用。 

##### 頂點 {#vertex}
* `保持體積` - 平滑時不會讓表面縮小，所以反覆平滑也不會讓形狀消風。旁邊的齒輪按鈕裡有這項功能使用的 `收縮` 與 `膨脹` 數值。
* `保留邊界` - 對於有開放邊緣的網格（例如平面），角落可能會被平滑掉。啟用此選項會讓網格邊界上的頂點保持不動。
* `穩定平滑` - 盡量讓平滑效果不受拓樸影響。在拓樸密度不均、且平滑強度較高時效果最好。
* `規整網格` - 與左側工具列中的規整網格反向模式相同。

##### 繪畫 {#painting}
* `螢幕平滑` - 使用此選項可以得到不受拓樸影響的平滑效果，即使面數很高也一樣。可選 `自動`、`否` 或 `是`。
* `螢幕取樣` - 平滑的品質，數值越高越平滑，但速度也越慢。

::: tip
多邊形密度較高時，可能需要把強度調到 100% 以上。非常高的數值（300%、500%）也很適合當作雕刻工具使用，能迅速把筆刷下的區域壓得又平又順，就像拿木槌敲打黏土一樣！
:::

### ![](/icons/tool_mask.webp) 遮罩 {#mask}
這個工具可以遮罩頂點。被遮罩的頂點不會受到雕刻或繪畫影響。 

反向模式是 `取消遮罩`，會擦除已畫上的遮罩。

和 2d 繪圖軟體中的選取範圍類似，遮罩可以用筆刷畫，也可以用形狀選取（`套索`、`矩形`、`帶狀`…）建立，還能模糊或銳化。在左側工具列的筆觸彈出視窗中選擇筆刷或形狀，請參閱[選取控制](#selection-controls)。

和 2d 繪圖軟體不同的是，遮罩也可以從面群組建立，而且還能透過擠出／擷取之類的操作，用遮罩來產生新的幾何體。 

![](/videos/tool_mask1.mp4)

 視埠頂端會出現一條工具列，提供額外的控制項。 

![](/images/tool_mask_toolbar.webp)

#### 遮罩設定 {#mask-settings}
![](/images/tool_mask_settings.webp)

![](/videos/tool_mask2.mp4)

遮罩設定主要用來從遮罩建立幾何體。頂端的分頁用來選擇操作：[擷取](#extract)、[分離](#split-mask)或[雕刻](#carve)。下方的選項會隨所選操作而改變。

* `預覽` - 調整設定時，即時顯示新幾何體的樣子。
* `X光` - 預覽時哪些物件以 X 光方式繪製：`無`、`未選取`、`已選取` 或 `全部`。

##### 擷取 {#extract}
* `擷取` - 將擷取出的幾何體建立為新物件。
* `封閉方式` - 擷取出的形狀要如何封閉。`無` 會把遮罩的多邊形複製成新形狀，並保持開放。`填補` 也一樣，但會把背面的孔洞填起來並平滑（不要用在平坦的表面上）。`外殼` 會依照 `高度` 數值把形狀封閉起來，這也是預設值。

::: tip

如果啟用了預覽並開啟 X 光，第一次點選擷取按鈕時可能會有點困惑。因為選單仍處於開啟狀態，它會試著在您的新形狀上預覽擷取效果，並以 X 光顯示原本的表面。但新表面上沒有遮罩，所以無法預覽擷取，Nomad 就會警告您「沒有可擷取的內容！」。 

這是正常的。關閉遮罩設定選單，就能看到新形狀和原本的形狀；如果需要清除遮罩或畫新的遮罩，請再次選取原本的表面。
:::

##### 分離 {#split-mask}
* `分離` - 將已遮罩和未遮罩的區域「都」擷取成新形狀。 
* `封閉方式`（已遮罩）- 已遮罩部分的封閉方式，與擷取一樣有 `無`、`填補` 和 `外殼` 可選。
* `封閉方式`（未遮罩）- 未遮罩部分的封閉方式，選項相同。

##### 雕刻 {#carve}
* `雕刻` - 效果就像依 `高度` 數值往表面內部裁切一樣，好比切下一片橘子皮。`高度` 不能為 0。

##### 高度 {#thickness}
* `高度` - 擷取出的形狀的高度。加號／減號按鈕可以在向外擠出、向內擠出或雙向擠出之間切換。 

##### 平滑度 {#smoothness}
啟用後會平滑擷取出的形狀，面數越高效果越好。 
* `全部` / `僅邊界` - 平滑整個形狀，或只平滑它的邊界，讓頂面的形狀保持不變。
* `迭代次數` - 使用 `全部` 時，套用的平滑程度。數值很高時會產生非常平順的圓弧邊緣，但會開始偏離遮罩的形狀。
* `側壁` - 使用 `僅邊界` 時，側壁的平滑程度。它的按鈕可以在「規整網格」與「平滑」之間切換：規整網格會保留尖銳的角，平滑則會把角也修圓。
* `內部` - 使用 `僅邊界` 時，頂面被整平的程度。它的按鈕可以在「規整網格」與「平滑」之間切換：規整網格會保留雕刻細節，只整平擠出方向（避免細節產生尖刺），平滑則會直接平滑表面本身。

##### 側面 {#edge-loop-side}
* `直線` - 擷取形狀的側面是平直的牆面。
* `倒角` -（僅限擷取搭配 `外殼`）在前緣做出斜面。`倒角` 設定它的寬度，可用 `高度` 的百分比或世界單位表示（旁邊的按鈕可切換）；`倒角分段` 用來細分倒角（預設為 `自動`），還可以用曲線調整倒角的輪廓。
* `輪廓` - 用輪廓曲線塑造側壁，`寬度` 可用 `高度` 的百分比或世界單位表示。
* `遮罩` - 高度會依照遮罩變化：遮罩模糊的部分高度較低，可以做出柔和、高低起伏的形狀。
* `側壁分段` - 側面的環狀邊數量。使用 `自動` 時，Nomad 會挑選適當的分段數，讓側面產生與遮罩區域多邊形相符的方形多邊形。

把各點投影到平均平面上，讓區域變平。

#### 剷平設定 {#flatten-settings}

* `鎖定平面方向` - 使用第一次點選時計算出的平面方向。預設為停用。
* `鎖定平面原點` - 以第一次點選的位置作為平面的中心。預設為停用，而且只能與 `鎖定平面方向` 一起啟用。

當其中之一或兩者都停用時，只要用較長的筆畫劃過不同深度和曲率的區域，就能逐漸加深剷平的程度，或改變平面的角度。搭配筆刷選單中的區域取樣選項，可以做到非常精確的控制。

::: tip
在曲率很大的區域工作時，例如想把臉頰剷平，工具卻一直影響到鼻子兩側，可以試著建立遮罩，保護剷平筆刷不該碰到的區域。

### ![](/icons/tool_planar.webp) 平面 {#planar}
把各點投影到平均平面上使其共平面，但堆積效果比剷平筆刷少，能做出更乾淨的硬邊表面。快速的筆畫會對表面產生較多的推拉；從已經平坦的區域開始、慢慢往外延伸的筆畫，則更能維持平面。

反向模式是 `填充`，會以最高點定義一個平面，傾向把各點往上拉。

平面其實和 `剷平` 是同一個工具，只是啟用了 `鎖定平面方向`，所以它傾向做出更穩定的硬邊表面；而剷平則更有雕塑感，可以用來做出半平坦的區域。

![](/videos/tool_planar.mp4)

### ![](/icons/tool_polish.webp) 拋光 {#polish}
剷平家族的另一位成員，專門用來把表面拋光成乾淨的平面。它和 `剷平` 是同一個工具，只是[筆觸](stroke.md)的預設值不同：啟用了 `拖尾效果`、`區域法線過濾` 和 `深度過濾`。

反向模式是 `填充`，與剷平相同。

拋光的設定與[剷平](#flatten-settings)相同：`鎖定平面方向` 和 `鎖定平面原點`。

### ![](/icons/tool_crease.webp) 褶皺 {#crease}
褶皺工具很適合雕刻細小的切痕或凹痕。

反向模式是 `反轉`，會做出凸起的稜線。

#### 褶皺設定 {#crease-settings}

* `力度` - 把頂點往筆刷側向拉近的程度。如果力度為 1、偏移為 0，表面深度不會改變，只會改變拓樸，把邊往筆觸拉近。
* `偏移因子` - 把頂點往深處推／往外拉的程度。如果力度為 0、偏移為 1，會做出很深的褶痕或凸起，但看起來會有鋸齒，因為被拉向褶痕的幾何體不夠，無法精確定義褶痕的側面或底部。

![](/videos/tool_crease.mp4)

### ![](/icons/tool_trim.webp) 裁切 {#trim}
裁切工具會移除網格的一部分，並提供多種選項來處理留下的缺口。它使用[選取控制](#selection-controls)來定義裁切範圍。

反向模式是 `翻轉`，會反轉形狀，改為移除另一側。

::: tip
因為這個工具是從相機投射，所以當相機處於透視模式時，您會收到警告。

在正交模式下，穿過網格的切面會與視角平行，這通常也是大家預期的結果。如果用透視相機裁切，物件遠側和近側的切面看起來會不一樣。
:::

#### 裁切設定 {#trim-settings}

這些設定都歸在 `孔洞填補` 之下：

* `筆觸繪畫` - 如果在繪畫選單中啟用了繪畫，補上的區域會以目前選取的顏色填滿。
* `布林` - 用四邊形區域填補裁切的孔洞。填補的區域是平的。
* `舊版` - 用三角化的區域填補裁切的孔洞。填補的區域是平的。
* `填充` - 用三角化的區域填補孔洞。填補的區域會是一個彎曲的表面，就像肥皂泡的薄膜。
* `無` - 不填補孔洞。

使用 `布林` 時，`細節` 區塊有：

* `形狀` - 裁切形狀那一側所用的四邊形與三角形的大致尺寸。
* `孔洞` - 填補孔洞所用的三角形或多邊形的大致尺寸。`細節` 旁的連結按鈕會讓它與 `形狀` 保持同步，取消連結即可單獨設定。
* `保留拓樸` - 不平滑、不簡化切割邊界，保留遮罩與隱藏面附近原本的網格拓樸。

使用 `舊版` 時：

* `細節` - 裁切所用三角形的大致尺寸。
* `平滑孔洞` - 填補區域上的三角形被整理平順的程度。
* `填充臨界值` - 可以調整這個數值，改善舊版孔洞填補演算法的結果。

使用 `填充` 時：

* `細節` - 裁切所用三角形的大致尺寸。

![](/videos/tool_trim.mp4)

### ![](/icons/tool_layer.webp) 圖層 {#layer}
把表面墊高，但限制高度。

如果筆不離開螢幕、在同一區域反覆塗抹，圖層工具墊高到一定高度後就不會再增加；其他工具則會持續累積高度。

請注意，預設情況下這個限制只針對單一筆畫！開始新的筆畫時，會從新的表面高度繼續堆疊。

若想讓多個筆畫都維持固定的最大高度，請將圖層工具搭配 Nomad 的[圖層](layers.md)系統使用。

建立一個圖層，再使用這個工具。此時最大高度是根據圖層來設定的，所以不管畫多少筆，高度都會一樣。

`反向` 會改用最小深度，刻出溝槽。

#### 圖層設定 {#layer-settings}

* `使用圖層資料` - 啟用後，在選取了圖層的情況下，會使用圖層資料來設定最大高度。沒有選取圖層時會出現警告提醒您。
* `膨脹` - 啟用後會調整圖層工具的作用方向，得到更平順的結果。
* `規整網格（法線）` - 啟用 `膨脹` 時，套用在法線上的平滑程度。

### ![](/icons/tool_stamp.webp) 圖章 {#stamp}

點選並拖曳，就能以選取的 Alpha 形狀把雕刻上的某個區域墊高。

其實它就是筆觸類型設為 `鎖定 + 半徑` 的[筆刷工具](#brush)。 

`反向` 會把圖章壓入表面，而不是從表面拉出。

::: tip
圖章通常在高解析度的幾何體上效果最好。在網路上搜尋「wrinkles alpha」、「pores alpha」、「scales alpha」等關鍵字，這些 Alpha 紋理搭配圖章，是為角色雕刻加上有機細節的好方法。

兩種筆觸模式各有不同的用途。 

* `鎖定 + 半徑` 的*高度*是固定的，拖曳時調整的是圖章的寬度和旋轉。適合皮膚紋理，因為它們需要相同的深度／高度，但旋轉和大小要有變化，才能掩飾重複的圖樣。
* `鎖定 + 強度` 的*寬度*是固定的，拖曳時調整的是圖章的旋轉和高度。適合鉚釘，因為它們的大小都要一樣，但旋轉和高度可以不同。 

:::

![](/videos/tool_stamp.mp4)

### ![](/icons/tool_vdm.webp) VDM {#vdm}

蓋上向量置換貼圖（VDM）。Alpha 只能把表面往上推或往下壓，VDM 則儲存了完整的 3d 形狀，所以可以蓋出耳朵、角或捲曲葉片這類有懸垂結構的造型。它的用法和[圖章](#stamp)一樣，也有 `鎖定 + 半徑` 和 `鎖定 + 強度` 兩種筆觸模式。

`反向`（`反轉`）會翻轉圖章的深度，像模具一樣把它壓進表面。

VDM 本身是在 [Alpha](stroke.md#alpha) 選單中選擇的，該選單中還有一個 `高度` 滑桿，只縮放圖章的高度，側向的置換則保持不變。

左側工具列的 `創建` 按鈕可以讓您製作自己的圖章：

* `新增 VDM…` - 新增一個專為 VDM 雕刻設定好的平面。在上面雕出形狀後，用 `拓樸 -> 烘焙 -> VDM` 烘焙它：Nomad 會把新圖章加入 VDM 圖庫並選取它。
* `擷取 VDM` -（實驗性功能）在模型表面上拖曳，抓取該區域並轉換成 VDM 圖章。`容差` 會把擷取範圍的邊界平滑地壓平。

::: tip
雕刻 VDM 平面時請避免使用動態拓樸，它會破壞平面的 UV，讓圖章變形。雕刻時也要和平面邊界保持距離，否則圖章會出現生硬的邊緣。
:::

反向模式是 `反轉`，會稍微加強圖層，而不是擦除它。

#### 圓管左側工具列 {#tube-left-toolbar}

![](/images/tool_tube_left_toolbar.webp)

左側工具列有以下選項：

* `同步` - 如果目前的圓管是實例，而且各實例之間的子節點有所不同，這個按鈕會重新同步它們。
* `吸附` - 啟用時，曲線和路徑模式在繪製時會吸附到其他物件上。停用時，只有第一個點會吸附，圓管的其餘部分會在該深度上繪製。
* `偏移` - 設定吸附的深度；0% 時圓管截面的中心會吸附在表面上，正值會讓它離開表面，負值則會讓它沉入表面。100% 等於圓管的半徑。
* `檢視` - 不繪製的模式，讓您可以自由移動相機。
* `曲線` - 徒手畫出圓管。它有一個小型的彈出選單：
    * `編輯` - 結束筆畫時要做什麼，請參閱[選取控制](#selection-controls)：立即建立圓管、保持曲線可編輯並在旁邊顯示綠色的確認圓圈，或在筆畫結尾 `按住` 以繼續編輯。
    * `閉合` - 讓圓管變成一個環。
    * `繼續繪製` - 確認一條圓管後，留在工具中繼續畫下一條。
    * `精確度` - 把畫出的路徑轉換成圓管時要使用多少個曲線控制點。0% 會使用最少的點，但會漏掉路徑上細小的曲率變化。100% 會非常精確，並使用大量的點。
* `路徑` - 點選定義曲線控制點來建立圓管。輕點綠色圓圈以確認路徑。它有一個小型的彈出選單：
    * `B樣條` - 另一種曲線繪製方式，曲線控制點通常不會落在曲線上，但能做出比預設方式更平順的結果。
    * `閉合` - 讓圓管變成一個環
    * `螢幕` - 啟用時，路徑會「釘」在螢幕上，即使移動視角和物件，路徑也會留在原處。停用時，路徑屬於 3d 場景的一部分，會隨相機和物件移動。
* `截面` - 曲線會變成環繞形狀的一圈，沿著您當時的觀看方向穿過它的兩個點切出。

##### 圓管頂部工具列 {#tube-top-toolbar}
![](/images/tool_tube_toolbar.webp)
選取圓管時，視埠頂端會出現一條工具列，提供額外的控制項。點選工具列的標題可以收合／展開，點選右上角的箭頭則可以把工具列移到視埠的頂端或底部。

* `轉換` - 把圓管烘焙成一般的多邊形，之後就能雕刻。
* `編輯` - 顯示曲線控制點，以便操作它們
* `鏡像` - 為這條曲線加上一個鏡像重複器作為父層
* `吸附` - 把曲線控制點吸附到附近的表面上
* `閉合` - 連接曲線的起點和終點，形成一個環
* `B樣條` - 在 Catmull-Rom 和 B 樣條插值之間切換。
* `端蓋` - 在圓管兩端加蓋、只在起點或終點加蓋，或不加蓋之間循環切換。

* `輪廓編輯` - 顯示輪廓編輯器。它的操作方式類似[形狀編輯](#shape-editing)工具，可以儲存和載入輪廓預設，還有一個切換開關，讓您在 3d 空間中編輯輪廓。
* `螺旋` - 開關一個選單，為圓管加上螺旋扭轉。這個選單有 `纏繞角度`、`偏移`、`縮放` 和 `角度偏移` 等選項。
* `分段數 X` - 圓管圓周方向的分段數，例如 4 個分段會做出方形的管子。 
* `恆定密度` - 啟用時，多邊形會保持方形。停用時，可以設定沿著圓管長度方向的 `分段數 Y`。
* `...` - 圓管設定選單。

### ![](/icons/tool_insert.webp) 插入 {#insert}
把一個物件放到另一個物件的表面上。用起來和圖章工具很像，只是對象是完整的 3d 形狀。

在左側工具列選擇一個基本體後，在任何表面上點選並拖曳，就會在點選處放置該基本體，拖曳的距離決定它的大小。拖曳結束後，插入工具會切換到[自由變換](#transform)模式。

在實例模式下，拖曳會建立一個新的實例，並讓它在表面上滑動。大小會沿用第一個形狀，這樣就能在其他表面上放置許多大小相同的物件實例。

不只是基本體可以插入！在場景清單中選取*任何*形狀，只要插入工具處於實例或複製模式，就能把選取物件的副本拖曳到任何其他表面上。

如果物件有自訂的軸心，它會被當作錨點使用。請看下方的影片。

左側工具列還有 `檢視`，可以移動相機而不插入任何東西；以及 `同步`：當目標物件是實例時，新物件也會加到其他所有實例上。

![](/videos/tool_insert.mp4)

### ![](/icons/tool_transform.webp) 自由變換 {#transform}
用單指和雙指直接移動／旋轉／縮放模型，通常是在另一個物件的表面上操作。

左側工具列有以下按鈕：

* `複製` / `實例` - 建立物件的副本或實例，請參閱[軸向變換](#left-menu-toolbar)工具列。
* `移動` - 單指拖曳可以移動物件。啟用吸附時，物件會沿著手指下方的表面滑動。
* `旋轉` - 單指拖曳可以旋轉物件。啟用吸附時，會繞著手指下方表面的法線旋轉。
* `縮放` - 單指拖曳可以縮放物件。

視埠頂端的工具列有：

* `目標` - 工具要移動的是物件、它的群組，還是它的頂點，與[軸向變換](#left-menu-toolbar)相同。
* `表面吸附` - 把模型吸附到其他表面上。
* `表面` / `頂點` - 使用 `表面吸附` 時，吸附到表面上，或吸附到最近的頂點。

用雙指操作，自由變換可以快速使用其中兩種模式：

* 拖曳物件來擺放它。停止移動第一根手指，但不要讓它離開螢幕。
* 第一根手指保持按住，把第二根手指放到螢幕上。拖曳第二根手指時，物件就會縮放。
* 抬起第二根手指，繼續拖曳第一根手指，物件就會回到移動模式。

您也可以用第二根手指輕點的手勢來切換第二種模式：

* 拖曳物件來擺放它，停止移動，但不要讓手指離開螢幕。
* 第一根手指保持按住，用第二根手指輕點一下
* 工具會切換到旋轉模式。拖曳第一根手指來設定旋轉。
* 像剛才一樣用第二根手指輕點，工具就會切換回移動模式。

這是在另一個物件上快速複製物件的工作流程，例如在地形上擺放石頭。請注意，複製按鈕也在左側工具列上，方便取用：

* 用自由變換工具把一塊石頭移到定位。
* 放開手指，按下複製按鈕
* 移動這塊石頭，視需要旋轉／縮放
* 放開手指，按下複製按鈕
* 移動這塊石頭，如此重複。

![](/videos/tool_transform.mp4)

### ![](/icons/tool_gizmo.webp) 軸向變換 {#gizmo}
這個工具可以移動、旋轉和縮放物件，也能修改物件的軸心。

視埠中的控制柄有以下功能：

* `移動` - 拖曳線段＋箭頭，沿 X／Y／Z 軸移動。拖曳控制柄中央的桃色圓點，可以在螢幕空間中自由平移。點選紅、綠、藍色的方塊，可以在 X／Y／Z 平面上平移。
* `旋轉` - 拖曳紅／綠／藍色的圓環，繞 X／Y／Z 軸旋轉。拖曳圓環內的球體可以自由旋轉。
* `縮放` - 拖曳外側紅／綠／藍色的圓點，沿 X／Y／Z 軸縮放。拖曳外側紅／綠／藍色的圓錐，在 X／Y／Z 平面上縮放。拖曳外側桃色的圓環可以等比縮放。

![](/images/tool_gizmo.webp)

#### 節點與頂點 {#nodes-and-vertices}

Nomad 中的每個物件都由一個節點和頂點組成：

* `節點` - 物件的「把手」，儲存它的位移、旋轉和縮放，也就是所謂的變換矩陣。
* `頂點` - 定義物件表面的點，儲存位置和繪畫資訊。

假設有一個由 8 個頂點組成的簡單方塊，您可以透過修改它的變換矩陣來移動它，也可以修改頂點的位置來移動它。雕刻時通常要修改的是頂點，而用軸向變換移動物件時，通常要修改的是節點。Nomad 兩者都能做到。 

#### 軸向變換工具列 {#left-menu-toolbar}

左側工具列有：

* `複製` - 建立目前物件的獨立副本，可以用軸向變換拖曳開來。
* `實例` - 建立目前物件的實例副本。這些物件彼此連結，所以在其中一個物件上的雕刻變化，會出現在所有實例上。
* `軸心` -（鎖頭圖示，位於 `反向` 按鈕的位置）啟用後，可以移動和旋轉軸向變換控制柄，而不會移動物件。和 `反向` 一樣，按住可以暫時切換，輕點則會持續啟用。

視埠頂端的工具列有其他控制項：

* `目標` - 設定軸向變換要影響物件的節點還是頂點：
    * `自動選擇` - 預設值，運作方式和 `群組` 相同，但如果網格有遮罩或啟用了對稱，就會改用 `頂點` 的方式。
    * `頂點` - 把變換套用在頂點上，並考慮遮罩和對稱。不適用於尚未轉換的基本體，而且實例也會一併受到影響。
    * `物件` - 只移動目前的物件，忽略對稱和遮罩。子物件會保持不動。
    * `群組` - 移動物件及其階層中的其他部分，忽略對稱和遮罩。
    * `實例` -（物件與群組）同上，但物件的每個實例都會跟著移動。
* `軸心` - 用來快速擺放軸心的彈出視窗，說明見[下方](#pivot)。
* `全部` / `移動` / `旋轉` / `縮放` - 顯示所有軸向變換控制柄，或只顯示移動、旋轉或縮放的控制柄。
* `釘住` - 預設情況下，軸向變換控制柄會移到選取物件的軸心。啟用釘住後，控制柄會留在目前的位置。
* `對齊` - 切換軸心要對齊目前的物件，還是對齊世界座標。
* `角度吸附` - 啟用後，旋轉數值會依固定增量吸附；啟用時會顯示吸附數值，並可編輯。它的 `磁吸` 選項會讓旋轉在經過某個刻度時黏住一下，然後再自由移動；關閉它則會一格一格地跳動。
* `移動吸附` - 啟用後，位移數值會依固定增量吸附；啟用時會顯示吸附數值，並可編輯。

#### ![](/icons/reset.webp) 軸心 {#pivot}
頂部工具列中的 `軸心` 彈出視窗可以快速變更軸心。軸心的位置和方向決定了軸向變換控制柄。

**重設** 
* `自動` - 物件的中心，對齊物件的變換。
* `中心` - 把軸心移到物件的中心，保持原本的方向。
* `底部` - 把軸心移到物件底部的中心。再輕點一次則改用世界座標的邊界框。
* `頂部` - 把軸心移到物件頂部的中心。再輕點一次則改用世界座標的邊界框。
* `物件` - 把軸心移到物件的原點，對齊物件的變換。
* `遮罩` - 把軸心移到未遮罩區域的中心。再輕點一次則切換到已遮罩的區域。
* `對齊` - 重設旋轉，使其對齊世界座標，位置保持不變。
* `檢視` - 讓軸心對齊目前的視角，位置保持不變。之後不會再跟著相機移動。

**點選（軸心模式）**

只在 `軸心` 啟用時有效，設定在網格表面上輕點一下時會發生什麼事：
* `無` - 輕點物件時不做任何事
* `法線方向` - 移動並旋轉軸心，對齊輕點處的表面
* `首個交點` - 把軸心移到輕點處的表面（但不旋轉）
* `中點` - 把軸心移到輕點處下方、物件內部的中間位置。

#### 軸向變換設定 {#gizmo-settings}

![](/images/tool_gizmo_settings.webp)

* `緊湊` - 切換軸向變換控制柄的版面，把額外的控制柄放在旋轉球體的外側或內側
* `部件尺寸` - 軸向變換控制柄的大小
* `厚度` - 控制柄上線條的粗細
* `不透明度` - 控制柄的不透明度
* `自動隱藏` - 切換拖曳時是否暫時隱藏控制柄

-----

* `線性旋轉臨界值` - 控制拖曳圓環控制柄繞 X／Y／Z 軸旋轉時的操作方式。數值為 0 時，旋轉就像轉動旋鈕，要繞著圓圈拖曳。數值為 90 時，旋轉就像拉溜溜球的繩子，要朝著第一次點選的位置直線拖近或拖遠。0 到 90 之間的數值則會結合兩者：低於該數值時為直線移動，高於該數值時為圓周移動。
* `數值輸入` - 啟用後，輕點一下控制柄會彈出一個視窗，讓您為輕點的軸輸入精確的數值。

::: warning
[軸向變換](#gizmo)和[自由變換](#transform)工具有自己的對稱勾選框，與雕刻用的對稱是分開的！

這個對稱預設為關閉。
:::

##### 矩陣 {#matrix}
物件的精確變換數值已經不在軸向變換設定中了：它們移到了右上方選單中的 `自由變換` 選單。其中的 `矩陣` 區塊有：

* ![](/icons/target.webp) `移至原點` - 移動物件，讓它的軸心位於場景的中心，也就是所謂的原點。
* ![](/icons/bake.webp)  `烘焙` - 把物件凍結在目前的位置，並把位移／旋轉數值設為 0，縮放設為 1。
* ![](/icons/bake.webp) -> ![](/icons/tool_gizmo.webp) `軸心` - 烘焙軸心：讓矩陣數值對應到控制柄在世界中的位置。
* ![](/icons/reset.webp) `重設` - 一個快捷按鈕，把位移數值設為 0、旋轉數值設為 0、縮放設為 1，物件會跟著移動和旋轉。

::: tip 烘焙與烘焙至軸心的差別
建立一個方塊，選擇軸向變換工具，開啟並釘選 `自由變換` 選單。預設情況下，位移和旋轉都是 0，縮放是 1。

啟用軸心模式，把控制柄移到一側，再停用軸心模式。軸心已經改變了，但請注意位移數值仍然是 0。 

如果想看看軸心*真正*的位置，請點選烘焙 `軸心` 按鈕。這時位移數值就會更新。請注意，在這個操作中以及軸心模式下，方塊都不會移動。

把方塊移動並旋轉到某處，然後輕點 `移至原點`。它會移動物件，讓軸心位於世界的中心，但旋轉保持不變。

點選 `重設`，旋轉也會被設為 0。

再次移動並旋轉方塊，這次點選 `烘焙`。軸心留在原處，方塊也留在原處，但位移和旋轉數值都被設為 0。

多練習幾次！要理解軸心數值是隱藏的，Nomad 會幫您處理好；但如果需要把軸心設定到空間中的實際位置，烘焙軸心就能幫您做到。

:::

* `位移` - X、Y、Z 的位移數值
* `旋轉` - X、Y、Z 的旋轉數值
* `縮放` - 啟用等比縮放時為統一的縮放值，停用時則為 X、Y、Z 各自的縮放值。
* `傾斜` - X、Y、Z 的傾斜（剪切）數值，只有在物件已經傾斜時才會顯示
* `等比縮放` - 切換是要等比縮放，還是在各軸上分別縮放

在左側可以移動軸向變換的軸心，請看下方影片中的實際操作。

### ![](/icons/tool_faceGroup.webp) 面群組 {#facegroup}

面群組可以把物件劃分成不同顏色的面。在 Nomad 中，這些群組有很多用途：

* 快速選取遮罩的方法
* 隱藏／顯示物件的某些部分
* 整理物件，而不必把它拆成分開的部分
* 定義 UV 區域
* 引導四邊形重構
* 為平滑等工具提供額外的控制。

#### 面群組左側工具列 {#facegroup-left-toolbar}

* `群組` - 這個按鈕會顯示目前的面群組。輕點它即可以色塊顯示可用的面群組並選擇其中一個。輕點某個色塊可以重新命名、變更顏色或刪除它。`移除未使用` 會刪除沒有用到的色塊，`重設` 則會全部移除。加號圖示可以建立新的色塊。
* `點` - 在物件上塗畫來定義面群組。啟用「+ 面群組」時，每一筆新的筆畫都會自動建立一個新的面群組，很適合快速劃分區域。輕點一下會填滿選取的區域。滑桿用來設定點的半徑。
* `規整網格` - 平滑面群組的邊界。在為四邊形重構定義乾淨的邊緣，或在硬表面建模中定義面板時非常有用。滑桿控制規整操作的半徑和強度。
* 形狀 - 用形狀而不是筆刷來建立面群組，可用 `鎖定 + 半徑`、`套索`、`多邊形`、`直線`、`矩形` 和 `橢圓`。詳情請參閱[選取控制](#selection-controls)。
* `選取` - 反向模式。啟用後，會選取筆畫起點所在的色塊，並在整個筆畫中套用該色塊。用來整理面群組區域非常方便：如果某個面群組延伸得太遠，就啟用 `選取`，從該面群組色塊正確的地方開始畫，一路拖到邊界，就能重新指定正確的色塊。

#### 面群組頂部工具列 {#facegroup-top-toolbar}

視埠頂端的工具列有額外的控制項：

* `規整網格（全部）` - 拖曳可以一次整理所有面群組的邊界。
* `正面` / `可見` / `連線` - 與[遮罩](#mask)工具列相同的筆觸過濾條件。
* `從法線` - 根據面與面之間的角度建立面群組。彈出視窗中有 `角度`，並可依照 `面數` 或 `表面積` 略過較小的群組，在確認之前還能 `預覽`。
* `從部分` - 為每個不相連的部分各建立一個面群組。
* `從 UV` - 為每個 UV 島各建立一個面群組。
* `從遮罩` - 從遮罩區域建立一個面群組。
* `輕點` - 選擇輕點面群組時要做什麼：以目前的面群組填滿、隱藏它、遮罩它，或對它進行 `姿態` 調整（輕點的群組及其後方的部分會被取消遮罩，軸向變換控制柄會落在關節處，並提供一個用於遮罩的 `模糊` 滑桿）。當網格有遮罩時，還會出現第二個 `輕點` 開關，把輕點的範圍限制在遮罩同一側的面。
* [隱藏](#hide)和[遮罩](#mask)工具的 `清除` 按鈕，不必離開工具就能取消所有隱藏或清除遮罩。

#### 面群組設定 {#facegroup-settings}

`工具` 選單可以把面群組擷取成新物件，選項與[遮罩設定](#mask-settings)的 `擷取` 相同。頂端的 `面群組` 按鈕用來選擇要擷取哪些群組，另外還有一個 `間隙` 滑桿：它會沿著表面把每條邊界往內移，負值則往外移，使其重疊。對於相鄰的面板，請使用所需間隙的一半。

### ![](/icons/tool_hide.webp) 隱藏 {#hide}
隱藏或單獨顯示物件的某些部分。 

主要模式在左側選單中控制：

* `點` - 在物件上塗畫，隱藏物件的某些部分。
* 形狀 - 用形狀而不是筆刷來隱藏，可用 `套索`、`多邊形`、`直線`、`矩形` 和 `橢圓`。詳情請參閱[選取控制](#selection-controls)。
* `顯示` - 反向模式，反轉操作，讓所選模式改為顯示物件的部分，而不是隱藏。

視埠頂端會出現一條工具列，提供額外的控制項：

* `清除全部` - 還原物件，所有隱藏的部分都會重新顯示。若其他物件也有隱藏的部分，會多出一個 `清除` 按鈕，只還原選取的物件。
* `反轉` - 交換隱藏和未隱藏的部分。
* `刪除` - 刪除物件中被隱藏的部分
* `分割` - 把物件中被隱藏的部分分割成新的形狀。
* `正面` / `可見` / `連線` - 與[遮罩](#mask)工具列相同的筆觸過濾條件。
* `輕點`（面群組）- 利用面群組快速隱藏區塊，輕點某個面群組就會隱藏整個面群組。
* `輕點`（遮罩）- 如果有遮罩，輕點就會隱藏已遮罩的部分。

### ![](/icons/tool_measure.webp) 測量 {#measure}
拖曳即可測量 2 點之間的距離。放置之後，還可以拖曳端點來調整測量。

左側工具列用來選擇距離的測量方式：

* `直線` - 兩點之間的直線距離。
* `表面` - 沿著表面的距離，依循從相機看過去穿過兩點的切線。
* `截面` - 穿過兩點的橫截面周長，就像用捲尺量手臂一圈。
* `頂點` - 把端點吸附到最近的頂點。
* `黃金比例` - 在測量線上的黃金比例位置顯示一個黃色圓點。
* `?` 按鈕會顯示選取物件的體積、表面積和尺寸。

### ![](/icons/tool_arrange.webp) 排列 {#arrange}
一次對齊並排列多個物件，就像 2d 設計軟體中的對齊工具。請先選取物件；如果只有一個物件，排列工具則會作用在它各個分開的部分上。選取範圍周圍會畫出一個方框，拖曳它的控制柄即可縮放。

視埠頂端的工具列有以下控制項：

* `世界` / `螢幕` - 沿著世界座標軸排列，或沿著螢幕方向（左、右、上、下）排列。
* `對齊` - 在每個軸上，依物件的最小值、中心或最大值對齊。
* `分佈` - 依最小值、中心或最大值，讓物件在最外側的兩個物件之間平均分佈。至少需要 3 個物件。
* `直線` - 沿著某個軸把物件排成一列。
* `格線` - 把物件排成格狀，並設定 `X`、`Y` 和 `Z` 方向上的物件數量。
* `圓形` -（僅限世界）把物件繞著 `X`、`Y` 或 `Z` 軸排成一圈。
* `球體` -（僅限世界）把物件分佈在球面上。

`直線`、`格線`、`圓形` 和 `球體` 都有一個 `間距` 滑桿，用來設定物件之間的間隔。

### ![](/icons/tool_lattice.webp) 晶格 {#lattice}
用包圍物件的控制點籠架來變形物件，而不是雕刻它的表面。移動籠架上的幾個點，就能讓整個物件平順地彎曲、扭轉或拉伸，很適合在不動到拓樸的情況下調整比例或擺姿勢。在確認之前，變形會一直保持可調整的狀態。

左側工具列用來選擇編輯籠架的方式：

* `點` - 直接拖曳籠架的點和邊。輕點一個點即可選取它。
* `檢視` - 移動相機，而不編輯籠架。
* `規整網格` - 一支筆刷，會整理筆刷下方的籠架點。
* `彈性` - 一支筆刷，以彈性衰減拉動籠架點，就像[彈性](#elastic)工具一樣。
* `軸向變換` - 用軸向變換控制柄移動、旋轉和縮放選取的點。它的反向模式是 `軸心`。
* `套索` - 用套索選取籠架點，`取消選取` 會把它們從選取範圍中移除。

形狀彈出視窗中還有 `軟半徑`，讓拖曳某個點時也能帶動相鄰的點（以格子為單位，0 表示只移動選取的點），以及 `反轉選擇`。

視埠頂端的工具列有：

* `轉換` - 把變形套用到物件上，並移除籠架。
* `重設` - 移除籠架及其變形。
* `不透明度` - 籠架的顯示不透明度。
* `鏡面` - 使用對稱時，循環切換要顯示籠架的哪一側鏡像、並可以選取其上的點，另一側隱藏的部分也有自己的 `不透明度`。
* `網格點` - 籠架上哪些點可以移動：整個格網、表面加上中心點，或只有表面。
* `剛性` - 變形的硬度，從平順（0%）到剛硬且線性（100%）。
* `衰減` - 變形在籠架外側淡出的距離。
* `對齊` - 讓籠架對齊物件，或對齊世界座標。
* `X`、`Y`、`Z` `分段數` - 籠架在各軸上的格子數量。旁邊的模式按鈕用來設定它們之間的關係：`x = y = z` 在 3 個軸上使用相同的數量，`均勻` 讓每個軸上的點間距保持一致，`自訂` 則可以分別自由設定每個軸。

#### 晶格設定 {#lattice-settings}
* `滾轉速度` - 與[移動](#move-settings)工具相同的滾轉選項，在拖曳籠架點時使用。

### ![](/icons/tool_view.webp) 瀏覽模式 {#view}
這個「工具」不會做任何特別的事，只是讓您檢視模型而不修改場景。

#### 瀏覽模式設定 {#view-settings}
使用瀏覽模式時，這些設定會覆寫部分顯示選項，讓您在展示或檢查模型時能得到乾淨的畫面：

* `基本體（編輯）`、`重複器（編輯）`、`燈光（編輯）`、`相機（編輯）` - 允許在瀏覽模式下於視埠中編輯基本體、重複器、燈光和相機。停用它們可以避免不小心移動到它們的控制柄。
* `相機快速操作（一律）` - 一律在視埠中顯示相機快速操作按鈕。
* `顯示遮罩`、`輪廓`、`使未選物件變暗` - 顯示遮罩、選取物件的輪廓，或讓未選取的物件變暗。`自動` 會沿用您平常的設定，`否` 和 `是` 則會強制關閉或開啟。
* `顯示線條（對稱）`、`顯示平面（對稱）` - 顯示對稱線或對稱平面，同樣有 `自動`、`否` 和 `是` 可選。
* `圖示` - 在視埠中顯示群組、重複器、燈光、相機的圖示以及階層，選項相同。


## 工具箱快顯選單 {#toolbox-context-menu}

![](/images/tools_context_menu.webp)

在工具箱中的工具上按右鍵或長按，會開啟快顯選單。這個選單有以下選項：

* `儲存` - 儲存您對工具所做的任何變更
* `複製` - 把工具複製成一個新的工具捷徑
* `上次儲存` - 還原到工具上次儲存的版本
* `圖示` - 變更工具的圖示。當工具有自訂圖示時，這個按鈕會將它移除。
* `→ ...` - 把工具移到工具箱的另一個資料夾，或新的資料夾
* `重設` - 把工具重設為預設值

複製出來的工具還有 `重新命名` 和 `刪除`。
