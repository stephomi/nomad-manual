# ![](/icons/paint.webp) 繪畫 {#painting}

控制繪畫筆觸的顏色、粗糙度、金屬度，可以一次填滿繪畫屬性，也能設定繪畫工具和圖層、遮罩、隱藏區域之間的互動方式。

![](/images/paint_overview.webp)  

## 概覽 {#overview}

Nomad 使用 PBR 頂點繪畫。這是什麼意思呢？

### PBR {#pbr}
PBR（Physically Based Rendering，基於物理的算繪）是電影、電視、遊戲和行動裝置上廣泛使用的電腦圖學技術。依據物理特性來處理光線，並透過顏色、粗糙度、金屬度來定義表面，就能做出各種寫實的外觀。

### 頂點繪畫 {#vertex-painting}

頂點繪畫的意思是，繪畫資訊儲存在模型的頂點上，而不是貼圖裡。因為 Nomad 能處理數十萬、甚至常常是數百萬個頂點的模型，你的模型可以擁有非常細緻的表面繪畫：只要你能雕出那個細節，就能畫出那個細節。

這也代表在 Nomad 裡繪畫不需要 UV 映射，而在其他 3d 軟體中，UV 映射往往是緩慢又技術性的流程。許多其他 3d 軟體無法處理 Nomad 這麼高的頂點數，不過 Nomad 也有好用的貼圖烘焙和網格簡化工具可以幫忙。

### 貼圖 {#texturing}

Nomad 支援貼圖，但貼圖必須來自匯入的模型，或是把頂點繪畫烘焙成貼圖。

貼圖其實就是一張圖片，但在 3d 的情境下，通常是指指定給某個物件的圖片。
要把圖片包覆到模型上，模型需要貼圖座標（UV）。

Nomad 可以[自動計算 UV](topology.md#uv-unwrap)，但你對整體品質沒有太多控制權。

::: tip
一個工作流程範例：
- 在 Nomad 中雕刻，然後[UV 展開](topology.md#uv-unwrap)
- 如果已經在 Nomad 中開始繪畫，可以[把頂點繪畫轉移到貼圖](topology.md#bake-texture)
- 匯出到 Procreate
- 在 Procreate 中繪製貼圖
- 再匯回 Nomad 進行算繪
:::

以上是概覽，接下來看看繪畫選單的各個區塊：


## 筆觸繪畫 {#stroke-painting}
![](/images/paint_intensity.webp)  

為這個工具啟用繪畫，適合需要同時雕刻和繪畫的時候。當工具可以繪畫但這個核取方塊沒有勾選時，標題旁會有警告圖示提醒你。

對於以繪畫為主要功能的工具（例如繪畫、塗抹、遮罩），則沒有這個核取方塊。

### ![](/icons/opacity.webp) 筆刷強度 {#paint-intensity}

這個滑桿讓繪畫可以使用和工具主要強度不同的強度。

旁邊的滑桿按鈕會在側邊列加上一個快速調整筆刷強度的滑桿，適合同時雕刻和繪畫的工具。

`Alpha`、`衰減` 和 `隨機化強度` 按鈕決定這些功能是否影響繪畫。例如，你可以為黏土工具開啟隨機化，但顏色不會被隨機化。

* `Alpha` - 停用時，繪畫會忽略 Alpha，涵蓋整個筆刷範圍。使用 VDM 工具時，這個按鈕會換成 `印章材質`，用來開啟或關閉儲存在印章中的材質。
* `衰減` - 停用時，繪畫直到筆刷邊緣都維持完整強度。
* `隨機化強度` - 筆觸隨機化中的強度部分是否影響繪畫。位置、旋轉和縮放的隨機化，則永遠會移動整個印章。

[全部上色](#paint-all)會忽略這些選項，但它的三平面版本會使用 Alpha。

### ![](/icons/link.webp) 全域材質 {#global-material}
啟用這個選項時，所選的材質會和其他工具相同。注意它只會考慮粗糙度、金屬度和顏色設定。停用它，就能讓這個工具擁有自己的材質。


## 材質 {#material}
![](/images/paint_material.webp) 

第一個圖示是材質預覽形狀。在 3d 材質預覽上拖曳可以旋轉它。

第二個圖示是繪畫筆觸的預覽，會套用所選的 Alpha 和衰減選項。

### ![](/icons/falloff.webp) 曲線 {#curves}

為 [PBR 滑桿](#pbr-sliders)的貼圖槽開啟曲線編輯器。它會在繪畫前重新映射貼圖的數值，而不會動到圖片檔本身。貼圖槽上如果有小小的曲線圖示，就表示它的曲線已經被編輯過。

### ![](/icons/cog.webp) 材質選項 {#material-options}

標題旁的 `材質` 按鈕裡有兩項設定。

`視埠材質預覽` 決定你調整顏色、粗糙度、金屬度、不透明度和強度滑桿時，所選物件上會發生什麼：

* `無` - 調整屬性時，模型上不會顯示任何預覽
* `材質` - 調整屬性時，會在物件上預覽材質的數值。
* `三平面` - 以三平面投影的方式預覽材質。

下方的顏色、粗糙度、金屬度和不透明度核取方塊，用來選擇[材質滴管](#material-picker)會替換哪些通道。

### ![](/icons/dropper.webp) 材質滴管 {#material-picker}

滴管會從場景中任何物件上，吸取游標下方的材質。只有在[材質選項](#material-options)中勾選的通道會被替換。

## 材質預設 {#material-presets}
點一下 3d 預覽形狀，就會叫出材質的預設選單，你可以複製這些預設，定義自己的預設。

![](/images/paint_presets.webp) 

`嵌入貼圖` 切換鈕會把這個材質所用貼圖的副本儲存在預設中。沒開啟的話，預設只會參照 Nomad textures/ 資料夾中的貼圖。想分享有貼圖的預設，又不想另外傳送貼圖時，就開啟它。

`包含 Alpha` 會把筆刷的 Alpha 也一併存到材質預設中。

## PBR 滑桿 {#pbr-sliders}
![](/images/paint_sliders.webp) 

[PBR](shading.md#pbr) 繪畫使用 4 個通道：
- `顏色` 要繪畫的顏色。可以用滴管從模型的其他部分或參考圖片中選取顏色。
- `粗糙度` 表示表面有多「粗糙」或多「光滑」。粗糙度的數值越低，反射就越清晰。
- `金屬度` 單純表示表面是不是金屬。大多數時候數值應該是 0% 或 100%，介於兩者之間的數值應該是例外。
- `不透明度` 材質可以被看穿的程度。嚴格來說它不屬於 PBR 規範，但在很多情況下都很有用。1 是完全不透明，0 是透明。注意不透明度和折射是兩回事，Nomad 中的折射是透過折射材質來處理的。

如果你選了某個材質預設，就會同時繪畫 3 個通道（不透明度通常會刻意排除在外）。也就是說，你不只是畫上「紅色」，而是在畫「粗糙的紅色金屬」或「光滑的白色塑膠」。

方塊是貼圖槽，點一下就能用貼圖來代替該屬性的固定數值。顏色貼圖會為顏色染色，而粗糙度、金屬度或不透明度貼圖則會取代滑桿的數值（它的標籤會加上刪除線表示這一點）。對不透明度貼圖來說，`使用 Alpha 作為數值` 會讀取貼圖的 Alpha 通道，而不是它的灰階值。

使用 VDM 工具時，如果印章本身帶有材質，貼圖槽旁會多出一個槽來顯示它。點一下即可使用或忽略印章的這個通道。

滑桿旁的筆刷圖示會把該屬性填滿整個物件。

核取方塊可以啟用或停用特定屬性，例如你可以只畫顏色，或只畫粗糙度和不透明度。

以下是一些不同粗糙度和金屬度的範例：

|                | 金屬度 0%                      | 金屬度 100%               |
| :------------: | :-------------------------------: | :--------------------------: |
| 粗糙度 0%   | ![](/images/dielectric_r0.webp)   | ![](/images/metal_r0.webp)   |
| 粗糙度 50%  | ![](/images/dielectric_r50.webp)  | ![](/images/metal_r50.webp)  |
| 粗糙度 100% | ![](/images/dielectric_r100.webp) | ![](/images/metal_r100.webp) |

::: warning
粗糙度和金屬度需要 [光照 (PBR)](shading.md#pbr) 算繪模式。在[材質捕捉](shading.md#matcap)或[不受光](shading.md#unlit)模式下，它們會被忽略，選單也會顯示警告。
:::

::: tip
用貼圖進行 PBR 繪畫時，通常改用 `圖章` 這類工具會比較好，或是在筆觸選單中改用點以外的模式，否則貼圖可能會被抹開。

![](/videos/paint_color_texture.mp4)  
:::

::: tip
如果你要在面數較低的物件上畫金屬表面，可以考慮[全域](settings.md#smooth-shading)或[針對單一物件](material.md#smooth-shading)開啟 `平滑著色`。
:::

## ![](/icons/paint.webp) 全部上色 {#paint-all}

![](/images/paint_paint_all.webp)

把目前的材質套用到所選物件上，可以用 `全部上色` 以一般模式套用，或用 `全部上色 + 三平面` 以三平面投影套用。尚未驗證的基本體無法使用三平面版本。

顏色／金屬度／粗糙度／不透明度滑桿旁的核取方塊會被遵守，任何停用的屬性都不會被填滿。

額外的按鈕控制全部上色還會受到哪些影響。大多數按鈕會顯示百分比，沒有作用時則會變成灰色：

| 圖示                        | 說明                                   |
| :-------------------------: | :-------------------------------------------: |
| ![](/icons/shield.webp)    | 被遮罩的區域不受影響。               |
| ![](/icons/tool_hide.webp) | 被隱藏的區域不受影響。               |
| ![](/icons/opacity.webp)   | 使用上方工具的繪畫係數。           |
| ![](/icons/layer.webp)     | 圖層中未繪畫的區域不受影響。 |
| ![](/icons/triplanar.webp) | `頂點`：三平面版本還會依顯示的工具強度，用 Alpha 讓表面產生位移。 |
| ![](/icons/cog.webp)       | 開啟三平面設定                   |

### ![](/icons/cog.webp) 三平面設定 {#triplanar-settings}
![](/images/paint_triplanar_settings.webp)

和[材質選單中的三平面設定](material.md#triplanar)類似，你可以控制投影的混合、平鋪和偏移。

勾選這個選單上方的預覽核取方塊，就能在調整數值時持續顯示預覽。
