# ![](/icons/multires.webp) 拓樸 {#topology}

這個選單用來控制 Nomad 中物件的拓樸，也提供在物件之間、以及在貼圖之間烘焙和轉移細節的工具。

![](/images/topology_overview.webp)

Nomad 以多邊形為基礎，使用三角形和四邊形來處理幾何。
這裡說的拓樸，指的不只是面的數量，也包括點（頂點）彼此連接的方式。

隨時掌握拓樸的狀況很重要，尤其是想雕刻或繪製細緻的細節時。

::: tip 如何掌握拓樸狀況？
您可以顯示[線框](settings.md#wireframe)，或者直接關閉[平滑著色](settings.md#smooth-shading)。
:::

![](/images/topology_top.webp)

Nomad 的拓樸選單有好幾個分頁，排成兩列：

## 多邊形統計 {#polygon-stats}

![](/images/topology_stats.webp)

每個分頁的最上方會顯示所選物件的多邊形數量；場景中有多個物件時，也會顯示整個場景的數量。各欄依序是頂點、三角形、四邊形（四個邊的多邊形）和 UV 座標的數量（物件沒有 UV 時為 0）。

輕點這個區塊，可以列出場景中每個物件的精確數量，包括面群組的數量。

## ![](/icons/cog.webp) 齒輪選單 {#gear-menu}
有些區塊（例如[四邊形重構](#quad-remesh)和[烘焙](#bake)分頁中的區塊）還有額外的選項。點區塊標題旁的齒輪圖示即可開啟。

## ![](/icons/multires.webp) 多解析度 {#multiresolution}

![](/images/topology_multires_menu.webp)

### 什麼是多解析度？ {#what-is-multiresolution}
多解析度功能主要用在兩種情況：
- 用平滑細分演算法提高物件的多邊形數量
- 管理多個解析度層級，讓您在小範圍和大範圍的修改之間來回切換

![](/videos/multiresolution.mp4)

#### 多解析度工作流程 {#multiresolution-workflow}
多解析度很重要的一點是：您可以回到較低的解析度修改物件，再回到最高解析度，而不會失去高解析度的細節。所有高解析度的細節都會自動投影回去。

每個解析度層級都可以使用[圖層](layers.md#layers)。

::: warning
如果您使用會改變物件拓樸的工具，物件的其他解析度層級將全部遺失！
發生這種情況前，您應該都會看到警告，例如在使用以下功能時：
- [體素重新網格化](#voxel-remesher)
- [動態拓樸](#dynamic-topology)
- [裁切工具](tools.md#trim)
- [分割工具](tools.md#split)
:::


### 多解析度滑桿 {#multiresolution-slider}
這個滑桿表示目前物件的細分層級數。有 6 條直線，就代表有 6 個細分層級。圓圈標示目前顯示的是哪一個細分層級。

滑桿上方的小圖示會顯示每個層級使用了哪些選項（`鎖定層級 0`、`線性`、`銳邊`、`保留三角形`）。

### 反細分 {#reverse}
在最低的細分層級時，反細分按鈕會嘗試在目前層級之下再建立一個層級。請注意，通常只有物件原本就是由細分產生時才做得到，例如在 Nomad 或其他支援多解析度細分曲面的 3d 應用程式中建立的物件。

### 細分 {#subdivide}
*細分*按鈕會讓多邊形數量變成 4 倍，所以請留意多邊形數量，它增加得非常快！結果會非常龐大時，Nomad 會先請您確認。
*細分曲面*很重要的一個特性，是它會逐漸收斂成*平滑曲面*。
想了解它的運作方式，可以在只有少量多邊形的物件上試試*細分*按鈕。

您可以用 `線性` 選項關閉這種*平滑*效果。

### 刪除低模 {#delete-lower}
如果目前顯示的層級之下還有細分層級，就把它們刪除。不小心刪掉的話，可以用反細分按鈕重新建立。

### 刪除高模 {#delete-higher}
如果目前顯示的層級之上還有細分層級，就把它們刪除。

### ![](/icons/lock.webp) 鎖定層級 0 {#lock-lv0}
在較高層級雕刻時，保持最低細分層級的形狀不變。繪畫仍然會傳遞到層級 0。如果物件是在其他應用程式中建立的，而基礎物件必須保持不變，這個選項就很重要。

這個選項只有在第一次細分之前才能使用。關閉時，在較高細分層級所做的大幅修改會移動到層級 0。

### ![](/icons/linear.webp) 線性 {#linear-subdivision}
細分網格時不套用任何平滑。

### ![](/icons/group.webp) 銳邊 {#sharp-border}
如果物件有面群組，啟用這個選項會讓面群組的邊界保持銳利。每個細分層級都可以分別設定（細分滑桿上該層級的上方會顯示一個小圖示）。

### ![](/icons/triangle.webp) 保留三角形 {#keep-triangles}
大多數標準的細分曲面系統在細分時，都會嘗試把所有多邊形轉成四邊形。這個開關會強制細分改用三角形。

::: tip

細分預設會把所有銳利的邊都變平滑。若想讓邊緣保留一點銳利感，可以試著在前 2 個細分層級使用 `線性` 或 `銳邊`，較高的層級再關掉。這樣就能做出半銳利的細分網格。

:::

### 顯示最高層級 {#show-highest-level}
在較低層級雕刻時，顯示帶有所有細節的最高層級。做大幅修改時，可以一邊看到最終結果，非常方便。

### 線框：僅限層級 0 {#wireframe-level-0-only}
開啟[線框](settings.md#wireframe)時，只顯示最低層級的線框。高層級的線框太密，會把形狀遮住。


## ![](/icons/voxel.webp) 體素重新網格化 {#voxel-remesher}
![](/images/topology_voxel_menu.webp)
使用 `體素重新網格化` 時，整個網格的拓樸會被強制變成均勻的解析度，也就是所有多邊形的大小都差不多。當您不想煩惱拓樸、只想自由雕刻時，這非常好用。

典型的雕刻流程，可以先用 `體素重新網格化` 以低解析度塑造出粗略的大形。
當網格被拉伸得太厲害時，偶爾按一下*重新網格化*按鈕，就能避免過度變形。

![](/videos/voxel_remesher.mp4)


::: tip 體素？
如前所述，Nomad 是以多邊形為基礎的軟體，但 `體素重新網格化` 是個例外：它會（暫時）改用另一種方式來進行重新網格化。

一個很大的差別是，體素方式不接受自我交叉，所以這些交叉會被消除。
此外，它也不支援有孔洞的網格。

這裡說的孔洞，不是指 `genus hole`（甜甜圈中間的那個 `hole`），而是指不 `watertight`／`closed`（不封閉）的網格。
一般來說，這表示在重新網格化之前，所有孔洞都會先被填補，方式類似[裁切工具](tools.md#trim)或[孔洞填補功能](#holes)。下方的[孔洞](#voxel-holes)選項決定填補的方式。
:::

### ![](/icons/voxel.webp) 重新網格化 {#voxel-remesh}
執行體素重新網格化。按鈕上的小圖示會提醒您下方哪些選項是開啟的。

### 解析度 {#voxel-resolution}
計算時使用的體素大小，數值越高細節越多。調整這個參數時，網格上會疊加棋盤格圖案，讓您預覽結果。

滴管會從您輕點位置的網格密度取得解析度。旁邊的立方體按鈕會把數值切換成以世界單位表示的 `邊長`：同樣的數值在任何物件上都會得到相同的細節。

### 構建多解析度 {#build-multiresolution}
為體素重新網格化的結果建立較低的多解析度層級。如果您用棋盤格圖案設定好解析度，並把構建多解析度設為 2，最終結果的細節會符合解析度滑桿的設定；到多解析度分頁查看，會是在層級 2，也就是在層級 1 和層級 0 還有較低解析度的多解析度網格。這是個好方法，既能產生多邊形均勻的乾淨網格，又能擁有一個較低解析度的控制網格。

在高解析度時，它也會算得更快、更省記憶體。但如果解析度低、層級又多，就會失去細節。

::: tip 技巧：構建多解析度與穩定平滑

這個選項有時會在幾何中產生難以平滑的「環」，形成小小的凸點。遇到這種情況，請在平滑工具的選項中啟用「穩定平滑」。

:::

### 加厚細薄部分 {#thicken-thin-parts}
比體素還薄的部分，在重新網格化時可能會斷開或消失。這個選項會把它們加厚，讓它們保留下來，數值越高加厚越多。使用 `硬邊` 或 `硬邊界` 時無法使用。

### 孔洞 {#voxel-holes}
重新網格化前封閉孔洞的方式：

* `填補` - 每個孔洞各自從邊界封閉。
* `形狀` - 順著周圍的曲面封閉孔洞，互相重疊的開放部分也會接合起來。

### ![](/icons/angle.webp) 硬邊 {#keep-sharp-edges}
讓新的點吸附到原始網格的銳利邊緣上。主要適用於簡單基本體的布林運算，而且可能會造成變形。

### ![](/icons/group.webp) 硬邊界 {#voxel-sharp-border}
新的面會沿著面群組的邊界生成，曲面沿邊界形成摺痕的地方，邊界也會保持銳利。

### ![](/icons/group_separate.webp) 保持面群組分離 {#keep-groups-separate}
每個面群組各自重新網格化：群組之間永遠不會合併，每個群組都會維持為各自群組中一個封閉的部分。這個模式不會構建多解析度。物件有多個面群組時才能使用。

## ![](/icons/dynamic.webp) 動態拓樸 {#dynamic-topology}

![](/images/topology_dyntopo_menu.webp)
多解析度和體素重新網格化都是業界常用的拓樸控制方法，但兩者都需要您留意，別把多邊形拉得太長，或擠得太密。

動態拓樸是另一種做法。雕刻時，Nomad 會在筆觸過程中自動新增和移除多邊形：雕刻細小細節時，會在需要的地方加入許多小多邊形；在其他地方平滑時，則會減少多邊形。

請注意，動態拓樸使用的是三角形而不是四邊形。看起來可能有點亂，但其實最好別去看線框，專心把作品雕好，不必擔心拓樸，之後再用 Nomad 其他的重新網格化工具產生乾淨的四邊形網格即可。

請看下面的實際操作影片。

![](/videos/dynamic.mp4)

### 啟用 {#enabled}
開啟動態拓樸。筆刷半徑和強度滑桿下方會出現一個動態拓樸圖示，讓您針對每個工具切換動態拓樸。它可能會明顯影響效能，圖層也會正確更新。

### 細節等級 {#dyn-detail}
控制細節的多寡，其行為會依「細節等級模式」的選擇而改變，請見下方說明。在 `螢幕解析度` 模式下，標籤會顯示以像素為單位的目標三角形大小。在 `固定` 模式下，可以用滴管從您輕點位置的網格密度取得細節。

### 細節等級模式 {#detail-based-on}
| 方法       | 說明                                                            |
| :--------: | :-------------------------------------------------------------: |
| 螢幕解析度 | 細節多寡取決於物件在螢幕上顯示的大小。細節滑桿設為 100% 以上可得到精細細節，產生小三角形；設為 1% 則細節較少，產生大三角形。 |
| 半徑       | 由工具半徑決定細節多寡。工具半徑小，細節就精細；工具半徑大，細節就少。細節滑桿是這個比例的倍數。 |
| 固定       | 由細節滑桿決定細節多寡，不受螢幕大小或工具大小影響。它與 `重新網格化` 的[細節](#all-detail)滑桿是同一個數值。 |

::: tip 技巧：半徑模式

想更清楚了解半徑模式的運作，可以先用一根手指拖動細節滑桿，同時用另一根手指調整工具半徑，就會看到兩者是連動的。

:::

### 偏向於… {#prefer}
| 方法 | 說明         |
| :--: | :----------: |
| 速度 | 以效能為優先 |
| 品質 | 以品質為優先 |

選擇以 `品質` 為優先時，主要有 2 個差別：
- 細化會在雕刻之前進行，因此在繪畫或雕刻非常小的細節時，內插造成的瑕疵會比較少
- 細化會一直進行到收斂至正確的細節等級為止，而不是逐步遞增。

這樣一來，即使雕刻非常小的細節或快速劃動筆觸，拓樸也一定會如預期般細化


### ![](/icons/pressure.webp) 在半徑上使用壓感 {#use-pressure-on-radius}
只有啟用 `半徑` 時才有作用。啟用後，即使筆刷大小受到觸控筆壓力影響，細節等級也會一直反映筆刷大小。

### 使用筆觸衰減 {#use-stroke-falloff}

在動態拓樸的計算中，也納入筆刷的衰減曲線和 Alpha。

### 模式 {#method}
選擇動態拓樸如何改變網格，雕刻時以及使用[重新網格化](#dyn-remesh)時都適用：

| 方法   | 說明                                                       |
| :----: | :--------------------------------------------------------: |
| 均勻化 | 可以新增和移除面，上方影片使用的就是這個模式               |
| 細分   | 只新增面，無法移除面                                       |
| 簡化   | 只移除面，無法新增面                                       |

### ![](/icons/shield.webp) 保護遮罩區域 {#protect-masked-area}
啟用後，遮罩區域的拓樸會受到保護，不會被改變。

### ![](/icons/normal.webp) 頂點擴張 {#vertex-extrapolation}
把點放在順著周圍曲率的平滑曲面上，而不是平貼在現有的面上。

### 細節 {#all-detail}
重新網格化操作所使用的解析度。如果動態拓樸處於「固定」模式，它會和這個選單最上方的細節等級滑桿是同一個數值。滴管會從您輕點位置的網格密度取得細節。

### 重新網格化 {#dyn-remesh}
用動態拓樸演算法對整個網格進行重新網格化。一般來說，完整的重新網格化應該使用[體素重新網格化](#voxel-remesher)。

不過它比體素方式多了一個優點：網格不需要封閉，而且遮罩區域會受到保護，讓您更能控制哪裡要密一點、哪裡要疏一點。



## ![](/icons/topo_extra.webp) 雜項 {#misc}

![](/images/topology_misc_menu.webp)

這個分頁集合了清理或轉換網格的工具：封閉孔洞、強制成為流形，或轉換成三平面。

### ![](/icons/hole.webp) 孔洞 {#holes}
![](/images/topology_holes_menu.webp)
大多數時候，您的物件應該是水密的，也就是網格是「封閉」的。

如果物件有孔洞，您可以把它們填補起來。

![](/videos/hole_filling.mp4)

::: tip
執行體素重新網格化時，所有孔洞都會自動封閉，不論您是對 1 個還是多個網格使用。
:::

#### 封閉孔洞 {#close-holes}
執行封閉孔洞的操作。

#### 選項 {#holes-gear-menu}
這些選項會改變孔洞填補的方式：

##### 面群組 {#fill-face-group}
選擇新的面所屬的面群組：

* `混合` - 只被單一面群組包圍的孔洞會沿用該群組，接觸到多個群組的孔洞則會得到新的群組。
* `新增` - 填補的孔洞會得到新的面群組。
* `重複使用` - 每個孔洞會採用周圍佔最多的面群組。

##### 細節 {#fill-detail}
填補孔洞時使用的多邊形密度。拖動這個滑桿時，模型上會顯示棋盤格圖案，提示要使用的三角形大小。核取方塊會停用這個功能，只使用現有的點，這通常會在孔洞上產生細長的三角形，不容易雕刻。

##### 橋接 {#fill-non-manifold}
把孔洞和其中的島狀部分當成一個曲面來填補，而不是各自填補每個邊界。角度越大，越能橋接彎曲的孔洞。核取方塊可以關閉這個功能。

### ![](/icons/cog.webp) 強制流形 {#force-manifold}
![](/images/topology_forcemanifold_menu.webp)
嘗試清理非流形邊。對於不支援兩個以上的面共用一條邊的外部軟體來說，這會很有用。

#### 清理 {#clean}
執行清理操作。

#### 選項 {#force-manifold-gear-menu}
這個選項會改變網格的清理方式：

##### 刪除小面 {#delete-small-faces}
用來移除並合併小多邊形的臨界值。勾選核取方塊即可啟用。


### ![](/icons/triplanar.webp) 三平面 {#triplanar}
![](/images/topology_triplanar_menu.webp)
把網格轉換成[三平面](scene.md#triplanar)基本體。
過程中很可能會失去大量細節：圖層、繪畫和多解析度也都會遺失。

#### 強制轉換為立方體 {#force-cubic}
讓三平面成為立方體。否則三平面會配合物件周圍最貼近的包圍盒。

#### 轉換 {#convert}
執行三平面轉換。

#### 解析度 {#triplanar-resolution}
三平面網格的解析度，數值越高保留的細節越多。

## ![](/icons/decimate.webp) 網格簡化 {#decimation}

![](/images/topology_decimation.webp)

在盡可能保留細節的情況下，以三角形減少多邊形的數量。

如果您要匯出做 3d 列印，這個功能會很有用。
不過如果還要繼續雕刻，最好不要使用，因為它可能會產生大小不均的三角形。

請注意，遮罩區域不會被簡化。

![](/videos/decimate.mp4)

::: tip

在高面數物件上使用[四邊形重構工具](tools.md#quad-remesher)可能要算很久，結果也很難控制。先用[面群組](tools.md#facegroup)和網格簡化預先處理網格，四邊形重構就會快得多，也能更好地控制拓樸。

* 用面群組劃分網格，定義您理想的四邊形走向。
* 對面群組進行規整，讓面群組邊界變平滑。
* 網格簡化。這能確保面群組邊緣上沒有細長或變形的面。在 `保留邊界` 底下，請確認已啟用 `面群組`。這樣三角形的邊就會精確地沿著面群組的邊緣分佈。
* 在四邊形重構的選項中，請確認已停用規整（因為您已經規整過網格），應該就能得到不錯的結果。

:::

### 網格簡化 {#decimate}
開始網格簡化操作。

網格簡化按鈕旁的圖示會顯示下列選項，也可以用它們來切換。百分比表示該選項的強度。

* ![](/icons/palette.webp)  `保留繪畫` - 在有繪畫細節的地方放置更多三角形。
* ![](/icons/triforce.webp) `網格均勻化` - 偏好產生大小平均的三角形。
* ![](/icons/hole.webp)  `孔洞` - 網格簡化會盡量讓開放幾何和孔洞附近的邊界保持不變。
* ![](/icons/group.webp) `面群組` - 網格簡化會盡量讓面群組邊界保持不變。
* ![](/icons/uv.webp) `UV` - 網格簡化會盡量讓 UV 邊界保持不變。

### 目標三角面數 {#target-triangles}
設定目標三角形數量。預設值是 50%，百分比／目標按鈕可以在百分比和確切的目標多邊形數量之間切換。

### 選項 {#decimate-gear-menu}
每個選項都有一個核取方塊用來切換，以及一個數值代表強度：

#### ![](/icons/palette.webp) 保留繪畫 {#preserve-painting}
這個數值決定繪畫細節保留的精確程度。數值越高，保留的繪畫越多。如果不在意繪畫，就設為 0。

#### ![](/icons/triforce.webp) 網格均勻化 {#uniform-faces}
數值越高，產生的三角形大小越接近。

#### 保留邊界 {#preserve-borders}
避免邊界被簡化。可以為 `孔洞`、`面群組` 或 `UV` 邊界設定邊界權重（`UV` 需要物件有 UV）。

## ![](/icons/quad.webp) 四邊形重構 {#quad-remesh}
![](/images/topology_quadremesh_menu.webp)
以整齊的四邊形佈線重建物件。這個分頁有好幾種重構器，各自有自己的 `重新網格化` 按鈕、`目標四邊形數` 滑桿和齒輪選單。在您的物件上都試試看，它們的結果差異相當大！

### Quad Remesher {#quad-remesher}
與 [Quad Remesher](tools.md#quad-remesher) 工具相同的重構器，由 [Exoside](https://exoside.com/) 開發。只在部分平台上提供，而且需要購買：購買前，`重新網格化` 按鈕會顯示購物車圖示。

`選擇工具` 會切換到 Quad Remesher 工具，讓您繪製引導線和繪製密度。齒輪選單中有 `適應性四邊形數量`、`適應性大小`（100% 時四邊形大小會隨曲率變化，0% 時四邊形大小一致）、`自動偵測硬邊` 和 `重投影頂點`。

::: tip
在有提供的平台上，Quad Remesher 通常能得到最好的結果，也最能掌控。
:::

### AutoRemesher {#autoremesher}
另一種四邊形重構器，提供可依曲面調整四邊形大小和形狀的選項。

#### ![](/icons/cog.webp) AutoRemesher 齒輪選單 {#autoremesher-gear-menu}
齒輪選單中有這些進階選項：

##### 邊緣縮放 {#edge-scaling}
縮放四邊形的大小，數值越高四邊形越大。

##### 自適應性 {#adaptivity}
讓四邊形密度配合曲率。0 會產生大小一致的四邊形，1 會在彎曲的區域產生較小的四邊形。

##### 各向異性 {#anisotropy}
沿著曲面最平坦的方向拉長四邊形。0 會產生正方形的四邊形，1 會在管狀和脊狀的部分產生長條形的四邊形。

##### 銳邊 {#sharp-edge}
彎折角度超過這個值的邊，會保留為銳利的特徵。

##### 平滑法線 {#smooth-normal}
0 會讓曲面在重新網格化時保持多面體般的稜角。數值越高，會考慮頂點法線，讓曲面越平滑。

##### 最大填洞 {#autoremesher-max-fill-hole}
演算法有時會產生不需要的孔洞。如果孔洞的頂點數少於這個值，就會被填補。

### Instant Mesh {#quad-remesh-instant}
使用 [Wenzel Jakob、Marco Tarini、Daniele Panozzo、Olga Sorkine-Hornung 的 Instant Meshes 演算法](https://igl.ethz.ch/projects/instant-meshes/)進行重新網格化。它會分析網格的走向，建立乾淨的四邊形拓樸。

#### 重新網格化 {#instant-remesh}
開始重新網格化操作。

#### 目標四邊形數 {#target-quads}
重構器會嘗試建立的四邊形數量。

#### ![](/icons/cog.webp) Instant Mesh 齒輪選單 {#quad-remesh-instant-gear-menu}
齒輪選單中有這些進階選項：

##### 摺痕角度 {#crease-angle}
銳利轉角的臨界值，用來幫助引導重新網格化操作。勾選核取方塊即可啟用。

##### 最大填洞 {#max-fill-hole}
演算法有時會產生不需要的孔洞。如果孔洞的頂點數少於這個值，就會被填補。

### QuadriFlow {#quadriflow}
使用 QuadriFlow 演算法進行重新網格化，這是另一種取得整齊四邊形佈線的方式。

#### ![](/icons/cog.webp) QuadriFlow 齒輪選單 {#quadriflow-gear-menu}
齒輪選單中有這些進階選項：

##### 保留邊界 {#quadriflow-preserve-boundary}
保護孔洞的邊界。

##### 保留銳邊 {#keep-sharp}
讓四邊形對齊曲面上的銳利邊緣。

##### 最小成本流 {#min-cost-flow}
使用最小成本流求解器來計算四邊形佈線。速度較慢，但可以產生更規則的拓樸。

## ![](/icons/uv.webp) UV 展開 {#uv-unwrap}
為所選物件計算貼圖座標（UV）。Nomad 有兩種方法：`UVAtlas` 和 `BFF`，各自有自己的 `展開` 按鈕。

![](/videos/unwrap.mp4)

::: tip UV 是什麼？
UV 常被比喻成包禮物：要怎麼裁切包裝紙，才能把物件完整包起來，又不會重疊？

UV 也是類似的概念，只不過不是裁切紙張，而是裁切物件本身。想像您的模型是用薄塑膠做成的，您會怎麼把它剪開、攤平，在平面狀態下上色，然後再組裝回去？

再想像模型的表面是用有彈性的萊卡布做成的。您可以把模型拉平，也可以剪開，或兩者並用。但如果在攤平的狀態下畫上棋盤格，組裝回去後棋盤格就會變形。哪種方法比較好：多剪幾刀、變形少一點，還是少剪幾刀、變形多一點？

UV 就是告訴 3d 軟體在套用貼圖時，要如何「裁切和拉伸」物件的指示。UV Atlas 工具通常採用「多剪幾刀、變形較少」的方式。


:::

::: tip UV、Nomad 與其他應用程式

在網路上找到的帶貼圖模型，大多都是透過 UV 來貼圖的。Nomad 可以透過[材質](material.md#textures)面板匯入並顯示這些貼圖。

在 Nomad 中製作的模型，可以直接在物件上繪畫，不需要 UV。如果需要匯出到其他應用程式，例如 [Procreate](https://procreate.art/)，您可以透過 UV 把 Nomad 的顏色資訊「烘焙」成貼圖。

:::

### UVAtlas {#uv-unwrap-uvatlas}

![](/images/topology_uvatlas_menu.webp)
UVAtlas 通常偏好多切幾刀、產生較多的 UV 島，以盡量減少變形。

#### 展開 {#unwrap}
為所選物件計算 UV。

#### 選項 {#uvatlas-gear-menu}
`展開` 旁邊的按鈕：

##### 面群組 {#atlas-face-group}
顯示 `是` 時，會以面群組定義 UV 的切割位置。這個設定與 BFF 共用。

##### 刪除UV {#delete-uvs}
垃圾桶按鈕會刪除物件的 UV。

##### 檢查 {#uv-inspect}
在背景中顯示物件的 UV。

#### 最大拉伸 {#max-stretch}
數值低時變形較少、UV 島較多；數值高時變形較多、UV 島較少。

#### UV 島間距 {#island-spacing}
UV 島之間的留白大小。數值低會比較不浪費空間，但貼圖可能會在 UV 島之間互相滲色。

::: warning
計算 UV 可能需要一些時間，最好使用頂點數少於 10 萬的網格。
:::

### BFF {#uv-unwrap-bff}
![](/images/topology_uvbff_menu.webp)

BFF 的 UV 偏好「少剪幾刀、變形較多」的方式。

#### 選項 {#uv-bff-gear-menu}
`展開` 旁邊有和 [UVAtlas](#uvatlas-gear-menu) 相同的 `面群組`、刪除和 `檢查` 按鈕。

##### 面群組 {#bff-face-group}

使用面群組定義 UV 的切割位置。

#### 錐體數量 {#cone-count}
定義主要投影的數量。數值越低，UV 島越少，但變形越多。數值越高，計算時間越長。

#### 無縫區塊 {#seamless-patches}
影響 UV 區塊的排列方式，可能會造成明顯的變形。搭配仔細建立的面群組效果最好。

::: warning
如果網格有把手狀的結構（例如甜甜圈中間的洞），BFF 可能會產生重疊的 UV。
:::

### ![](/icons/preview.webp) 展開後顯示 UV {#show-uv-after-unwrap}
展開後開啟 UV 檢視器，讓您馬上檢查結果。

### ![](/icons/bake.webp) 烘焙：貼圖 → 貼圖 {#unwrap-bake-texture}
只有物件的材質帶有貼圖時才能使用。重新展開時，貼圖會轉移到新的 UV 上，因此仍然會貼合。它的解析度預設為 `自動`，與最大的貼圖相同，您也可以自行設定。

## ![](/icons/bake.webp) 烘焙 {#bake}
這個分頁可以在物件之間，以及在頂點和貼圖之間，轉移細節和繪畫。

`從高解析度` 會使用其他物件作為來源，括號中的數字表示物件數量。Nomad 會這樣挑選：

- 使用所有選取的物件，主要選取的物件是目標（在[場景](scene.md)選單中反白最明顯的那個）
- 如果只選取了一個物件，Nomad 會改用所有可見的物件
- 如果其他物件全都隱藏了（例如使用獨顯），就會使用整個場景

### ![](/icons/bake.webp) 烘焙 → 貼圖 {#bake-texture}
![](/images/topology_bake_menu.webp)

貼圖烘焙會把場景中其他可見的物件投影到所選物件的 UV 上，藉此建立貼圖。物件必須有 UV。

以下是典型的烘焙流程：
- 您有一個帶有精細細節和繪畫的網格
- 複製它
- 進行網格簡化（將 `保留繪畫` 設為 0）
- 進行 UV 展開
- 烘焙！

現在您應該就有一個低解析度的網格，保留了原本物件大部分的繪畫和細節。

操作完成後，頂點顏色會被移到一個新的停用圖層中，以免干擾貼圖。

#### 從本身 {#tex-from-itself}
把物件烘焙到它自己的 UV 上：它的繪畫會變成貼圖；如果物件有多解析度層級，最高層級的細節會烘焙到目前的層級上（這時按鈕上會顯示多解析度圖示）。這種方式設定起來很簡單，但您常常會需要更多控制，這時下一個選項會更好用。

#### 從高解析度 {#tex-from-high-res}
從其他物件烘焙到所選物件。括號中的數字表示會有多少個其他物件被當作高解析度的來源，烘焙到目前這個帶有 UV 的低解析度物件上。其他物件的佈局或拓樸不需要與要烘焙的物件相似，讓烘焙流程更有彈性。

#### 解析度 {#tex-bake-resolution}
烘焙貼圖的解析度。烘焙出的貼圖一律是正方形，所以 1024 會建立 1024x1024 的圖片。

下方的按鈕是常用解析度的捷徑。參考一下：512x512 相對較小，適合網頁圖片和簡單的幾何；4096x4096（簡稱 4k）則適合高品質的算繪。

#### 顏色、粗糙度、金屬度、法線、位移、自發光、不透明度 {#tex-normal-roughness-metalness-color-emissive-opacity}
這些按鈕決定要烘焙哪些屬性，每種屬性會烘焙成各自的貼圖。烘焙完成後，這些貼圖會加到目前物件的材質中。`位移` 會把細節的高度烘焙成位移貼圖。

#### ![](/icons/cog.webp) 烘焙齒輪選單 {#tex-bake-gear-menu}
![](/images/topology_bake_gear_menu.webp)
齒輪選單中有這些進階選項：

##### 備份 {#tex-backup}
要預覽烘焙出的貼圖，必須停用物件的繪畫資訊。`備份 (繪畫 → 圖層)` 會把所有繪畫資訊轉移到一個新圖層作為備份，方便隨時啟用或停用。

##### 使用多解析度 {#tex-use-multires}
用於有多解析度層級的物件的 `從本身`。Nomad 會透過細分層級讀取高解析度，而不是發射射線：速度更快，也沒有投影誤差。關閉它，就會改用下方的選項來烘焙。

##### 平滑基底 {#tex-smooth-base}
用於有多解析度層級的物件的 `位移`。從細分後的基底量測位移，而不是從它平坦的面量測。如果位移貼圖要用在會細分的網格上（例如 Blender 的自適應細分），請保持開啟。

##### 搜尋距離 {#tex-cage-radius}
尋找來源曲面時使用的最大距離。預設這個距離設得較小以避免瑕疵，但如果目標物件離烘焙物件很遠，可以調大。

##### 投影 {#tex-projection}
尋找來源曲面的方式：

* `射線` - 沿著曲面法線投影。
* `射線 + 最近點` - 使用法線射線，如果射線沒打中，就改用最近的曲面。
* `最鄰近` - 投影到來源曲面上最近的點。

##### 射線偏移 {#tex-ray-offset}
調整烘焙計算在烘焙物件上的起始位置。與曲面保持一小段偏移，可以避免大多數常見的瑕疵。如果目標物件離烘焙物件非常遠，可能需要加大這個偏移。`最鄰近` 不會使用這個設定。


### ![](/icons/bake.webp) 重新投影 → 頂點 {#reproject-to-vertex}

![](/images/topology_reproject_menu.webp)

把雕刻的細節、繪畫、圖層、貼圖投影成頂點數值。

可以把它想成烘焙的反向操作：烘焙是把頂點屬性轉移到貼圖，重新投影則是把貼圖（和其他屬性）
 轉移回頂點。

::: tip
使用 `烘焙 → 貼圖` 或 `重新投影 → 頂點` 時，頂點顏色和材質貼圖都會被納入計算。
:::

#### 從本身 {#vertex-from-itself}
把材質中的貼圖轉換成頂點數值。只有物件有 UV、且材質中的貼圖為啟用狀態時，這個按鈕才能使用。

::: tip 技巧：貼圖繪製
Nomad 並不直接支援繪製和編輯貼圖，但只要先把貼圖投影成頂點數值、在頂點上繪畫，再把頂點烘焙回貼圖，就能達到非常接近的效果：

1. 準備一個有 UV 的低面數物件
1. 在它的材質中載入貼圖
1. 細分到足夠繪畫的程度
1. 以 `從本身` 模式執行 `重新投影 → 頂點`，貼圖就會轉換成頂點數值
1. 繪畫、平滑、塗抹、蓋印章，做任何您需要的編輯
1. 以 `從本身` 模式執行 `烘焙 → 貼圖`，這些編輯就會轉換回貼圖。
:::

#### 從高解析度 {#vertex-from-high-res}
把其他物件轉換成所選物件上的頂點數值。按鈕上的數字表示來源物件的數量。這主要也是用在高解析度的網格上，通常是拓樸乾淨的網格。

::: tip
重新投影其他物件，不只能從其他物件轉移顏色資訊，還能把頂點投影到其他物件上，例如把繃帶投影到角色身上。
:::

#### 頂點、顏色、粗糙度、金屬度、不透明度、遮罩、圖層、面群組 {#vertex-vertices-roughness-metalness-color-opacity-opacity-mask-mask-layers-face-group}
這些按鈕決定要把哪些屬性投影到所選物件上。`圖層` 會把其他圖層轉移到所選網格上。

#### ![](/icons/cog.webp) 重新投影齒輪選單 {#vertex-reproject-gear-menu}
齒輪選單中有這些進階選項：

##### 不透明度 → 遮罩 {#vertex-opacity-to-mask}
把來源的不透明度轉換成所選物件上的遮罩。

##### 迭代次數 {#vertex-iterations}
重新投影時要套用幾次規整操作。只有開啟 `頂點` 時才會使用。

##### 規整網格 {#vertex-relax}
所選網格的佈線可以進行一定程度的平滑或規整，以便更貼合重新投影的目標。`平滑` 較適合高面數網格，`規整網格` 較適合低面數網格。`自動` 會讓 Nomad 決定最佳方法。

##### 搜尋距離 {#vertex-cage-radius}
尋找來源曲面時使用的最大距離。預設這個距離設得較小以避免瑕疵，但如果目標物件離所選物件很遠，可以調大。

##### 投影 {#vertex-projection}
尋找來源曲面的方式：

* `射線` - 沿著曲面法線投影。
* `自適應混合` - 依照距離和 `射線偏好`，混合法線射線和最近曲面的結果。如果其中一個沒打中，就使用另一個。
* `最鄰近` - 投影到來源曲面上最近的點。

##### 射線偏好 {#vertex-ray-bias}
只用於 `自適應混合`。數值越高，混合結果越偏向法線射線；數值越低，越偏向最近點。

##### 射線偏移 {#ray-vertex-offset}
調整烘焙計算在所選物件上的起始位置。與曲面保持一小段偏移，可以避免某些瑕疵。如果目標物件離烘焙物件非常遠，可能需要加大這個偏移。`最鄰近` 不會使用這個設定。

### ![](/icons/bake.webp) 烘焙 → VDM {#bake-vdm}
從所選物件建立 VDM（向量位移）印章，並加入 VDM 庫。系統會請您輸入名稱。

以下是典型的流程：
- 新增一個平面，或在 VDM 選擇器中選擇 `新增 VDM`，加入一個已設定好的平面（即 [VDM](scene.md#add-menu) 基本體）
- 在上面雕刻出形狀，並保持邊緣平坦
- 烘焙！

平面的 UV 決定了要烘焙的正方形範圍，因此物件必須有 UV。用 `解析度` 選擇印章的大小，再用 `顏色`、`粗糙度`、`金屬度` 和 `不透明度` 選擇印章除了位移之外還要帶有哪些資訊。

::: tip
請避免在平面上使用動態拓樸，它會破壞 UV，讓印章變形。在圖層中雕刻可以得到最準確的結果，因為底下仍然保有平坦的平面。繪畫也需要使用圖層，否則材質會蓋滿整個正方形，而不是只出現在您繪畫的地方。
:::
