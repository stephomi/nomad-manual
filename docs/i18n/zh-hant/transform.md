# ![](/icons/transform.webp) 自由變換 {#transform}

這個選單以數值顯示所選物件的變換：它在哪裡、如何旋轉和縮放，以及有多大。你可以輸入精確數值、重設，或把變換烘焙進網格。

![](/images/transform_overview.webp)

## 概覽 {#overview}

除了頂點之外，每個物件還有一個節點，用來儲存它的位移、旋轉和縮放（也就是它的矩陣）。在視窗中拖曳時，[軸向變換](tools.md#gizmo)和[自由變換](tools.md#transform)工具改變的就是這個矩陣；這個選單則讓你讀取它，並直接輸入數值。移動節點和移動頂點有什麼不同，請參考[節點與頂點](tools.md#nodes-and-vertices)。

左右拖曳數值即可修改，或點一下直接輸入數字。X、Y、Z 的數值分別以紅、綠、藍標示，和軸向變換的座標軸一樣。

::: tip
輸入數值很適合用來精準擺放物件，例如讓好幾個零件位於完全相同的高度，或是用軸向變換自由旋轉後，把旋轉角度調回整數。
:::

## 矩陣 {#matrix}

標題會告訴你這些數值是在哪個空間中表示：`本地`（相對於父物件）或 `世界`。

### 物件與軸心 {#object-pivot}

* `物件` - 數值是物件本身的變換。
* `軸心` - 數值會以[軸心](tools.md#pivot)為準來操作選取的物件，就和軸向變換的控制把手一樣：每一列都顯示為零，修改它們會以軸心為中心移動、旋轉或縮放選取的物件。開啟 `編輯`（鎖頭圖示）就能只移動軸心，物件保持不動。

### 本地與世界 {#local-world}

當物件有父物件或子物件，或選取了多個物件時，你可以選擇以哪個空間顯示數值：`本地`（相對於父物件）或 `世界`。

### 動作 {#actions}

| 動作        | 圖示                          | 說明 |
| :-----------: | :---------------------------: | :---------- |
| 移至原點   | ![](/icons/target.webp)      | 把物件移到世界原點。 |
| 烘焙          | ![](/icons/bake.webp)        | 把矩陣套用到頂點上，再重設矩陣。外觀上不會有任何變化，但物件的原點現在就是世界原點。 |
| 軸心         | ![](/icons/gizmo.webp)       | 把軸心烘焙進物件：物件的原點和方向會變成軸心的原點和方向。外觀上不會有任何變化。 |
| 編輯          | ![](/icons/lock.webp)        | （`軸心` 模式）只移動軸心。 |
| 重設         | ![](/icons/reset.webp)       | 把變換重設為初始狀態。在 `軸心` 模式下，則是把軸心放回原位。 |

如果所選物件有實例，烘焙前會要求確認，並提供 `取消實例` 選項：因為烘焙會改變頂點，而頂點是實例之間共用的。

### 位移、旋轉、縮放 {#translation-rotation-scale}

物件在 X、Y、Z 上的位置、旋轉（以度為單位）和縮放。每一列最後的兩個按鈕，可以只把這部分的變換烘焙進頂點，或將它重設。

當物件有傾斜時，還會多出一列 `傾斜`，例如在父物件旋轉後又做了非等比縮放的情況。

### 等比縮放 {#uniform-scale}

啟用時，縮放只有一個數值，三個軸都相同。停用後就能分別縮放 X、Y、Z。

## 尺寸 {#dimension}

選取範圍的邊界框大小和中心，以世界單位表示。選取多個物件時，邊界框會涵蓋所有物件。

* `尺寸` - 寬度、高度和深度。開啟連結按鈕時，修改其中一個尺寸，另外兩個也會按相同比例縮放，保持比例不變。
* `中心` - 邊界框的中心。目標按鈕會移動選取的物件，讓它的中心對齊世界原點。

::: tip
`尺寸` 是讓物件符合真實尺寸最快的方法，例如在 3d 列印之前：設定你要的高度，連結按鈕會幫你保持比例。
:::
