# ![](/icons/scene.webp) 場景 {#scene}

這個選單用來管理 Nomad 中的物件、燈光、相機和重複器。它以樹狀檢視呈現場景的階層，讓您可以修改物件的許多屬性。您也可以在這裡建立新物件，並用各種方式合併和分割物件。


![](/images/scene_menu_summary.webp)

## 樹狀檢視 {#tree-view}
![](/images/scene_treeview.webp) 

樹狀檢視會列出場景中的物件、群組、重複器、燈光和相機。網格名稱旁會顯示它的頂點數，有圖層時還會顯示彩色的圖層圖示。每一列都有這些按鈕：

| 操作         | 圖示                       | 說明                     |
| :----------: | :------------------------: | :----------------------: |
| 名稱         | ![](/icons/pencil.webp)   | 重新命名物件。如果物件已選取，所有選取的物件會一次重新命名，並加上編號。長按可連同子項目一起重新命名。 |
| 選擇         | ![](/icons/checked.webp)  | 切換選取／取消選取       |
| 可見         | ![](/icons/eye_open.webp) | 切換可見性               |
| 選單         | ![](/icons/more.webp)     | 顯示[物件選單](#object-menu) |

::: tip 技巧：快速選取或隱藏多個物件

點選取圖示可以切換單一物件，在選取欄上垂直拖曳則可以選取多個物件。可見欄也可以這樣操作。

長按選取或可見圖示，就會連子項目一起套用。

:::

### 樹狀檢視標題列 {#tree-view-header}

清單上方的那一列有幾個小幫手：

* ![](/icons/sort_down.webp) - 一次收合或展開所有群組。
* ![](/icons/preview.webp) - 切換 `物件預覽`，為清單中的每個物件顯示一張小小的算繪縮圖。
* ![](/icons/search.webp) - 依名稱篩選清單。

### 樹狀檢視操作 {#tree-view-manipulation}

在樹狀檢視中長按某個項目，直到它反白顯示。接著就可以在樹狀檢視中上下移動它，也可以把它拖到另一個項目上，讓它成為該項目的子項目。

選取多個項目時，其中一個是主要選取，會顯示得比較亮。長按並拖曳其中任何一個，就能一次移動所有選取的物件。

選取父項目時，預設所有子項目也會一起被選取。再點一次父項目，就會在只選取父項目、或選取父項目和子項目之間切換。

點兩下項目可以讓相機聚焦在它上面（請見[進階設定](#focus-on-item)）。

### 多重選取 {#multiselection}
選取多個物件可以幫您做到兩件事：
- 使用軸向變換工具一次移動多個物件
- 使用合併和布林操作合併物件。

在樹狀檢視中，點每個物件的選取圖示，或沿著選取欄拖曳即可。點名稱時，按住 `遮罩` 快捷鍵（或鍵盤上的 `Ctrl`）可以加入或移除單一物件；按住 `平滑` 快捷鍵（或 `Shift`）則可以選取目前物件到您所點物件之間的所有物件。

::: tip 快速多重選取
您也可以在視窗中按住 `平滑` 快捷鍵（或 `Shift`），再點另一個網格來進行多重選取。

再點一次物件就能取消選取它（只有在選取了不只一個物件時才有效）。
:::

軸向變換會一起移動所有選取的物件，請見[軸向變換](tools.md#gizmo)。


## ![](/icons/merge.webp) 合併 {#join}
這個選項會把多個選取的物件，單純合成一個物件項目。
距離小於[焊接半徑](#weld-radius)的點和 UV 會被合併。

您可以在[分割](#separate)一節看到影片範例。

## ![](/icons/bool_subtract_circle.webp) 布林 {#boolean}
![](/images/scene_boolean_menu.webp) 
把多個物件結合成單一曲面。

`體素合併` 會保留物件的體積，並在表面重新計算出平均分佈的多邊形。由於有這個計算步驟，體素合併可以處理複雜的幾何，但如果目標解析度不夠高，就可能失去細微的細節。

`布林` 會盡量讓多邊形維持原本的佈線，並在物件重疊的地方把多邊形縫合起來。這可以得到比體素合併乾淨、銳利得多的結果，但它要求網格是「水密」的：物件中不能有孔洞或畸形的形狀。如果失敗了，通常改用體素合併就能成功。

### 布林操作 {#boolean-operations}
體素合併和布林都會用物件的可見性來控制操作，彈出視窗底部的提示也會提醒您：

#### 聯集 {#union}
兩個物件都可見時，會產生布林**聯集**：物件的外殼會結合在一起，沒有內部曲面。 ![](/images/boolean_union.webp)

#### 相減 {#subtract}
一個物件不可見 = 布林**相減**：不可見的物件會從可見的物件中減去。 ![](/images/boolean_subtract.webp)

#### 相交 {#intersect}
兩個物件都不可見 = 布林**相交**：只在兩個物件重疊的地方建立新形狀。 ![](/images/boolean_intersect.webp)


### ![](/icons/voxel.webp) 體素合併 {#voxel-merge-button}
按下這個按鈕，會對所選物件進行體素合併操作。對單一物件使用時，會把它重新拓樸成平均分佈的多邊形，在物件有被拉長的多邊形時很有用。下方的選項與[體素重新網格化](topology.md#voxel-remesher)的選項作用相同。

### 解析度 {#resolution}
計算時使用的 3d 體素網格的解析度。調整這個數值時，物件上會疊加棋盤格圖案，讓您預覽多邊形的大小。

滑桿旁的滴管會從您手指下方的網格密度取得細節。它旁邊的按鈕會把滑桿切換成 `邊長`，也就是世界空間中的大小：同樣的數值在任何物件上都會得到相同的細節。

### 構建多解析度 {#build-multiresolution}
在目標解析度之下建立多解析度層級。例如解析度是 400、構建多解析度是 3，您會得到一個大約 296,000 個多邊形的新網格，同時在它之下還有 3 個較低的細分層級，大約是 74,000、18,500 和 4,600。

### 加厚細薄部分 {#thicken-thin-parts}
把對體素網格來說太薄的部分加厚，避免它們斷開。使用 `硬邊` 或 `硬邊界` 時無法使用。

### 孔洞 {#holes}
合併前，開放物件上的孔洞如何封閉：
* `填補` - 每個孔洞各自從邊界封閉。
* `形狀` - 順著周圍的曲面封閉孔洞，互相重疊的開放部分也會接合起來。

### ![](/icons/angle.webp) 保留硬邊 {#keep-sharp-edges}
`硬邊` 按鈕會讓體素網格吸附到物件的銳利邊緣上。這在簡單的形狀上效果最好，在某些區域可能會造成變形。

### ![](/icons/group.webp) 硬邊界 {#sharp-border}
新的面會沿著面群組的邊界生成，曲面沿邊界形成摺痕的地方，邊界也會保持銳利。

### ![](/icons/group_separate.webp) 保持面群組分離 {#keep-groups-separate}
每個面群組各自重新網格化：群組之間永遠不會合併，每個群組都會維持為各自群組中一個封閉的部分。這個模式不會構建多解析度。

### ![](/icons/bool_subtract_circle.webp) 布林按鈕 {#boolean-button}
按下這個按鈕，會使用 Emmett Lalish 開發的 Manifold 函式庫進行多邊形布林操作。

### ![](/icons/bool_unite_circle.webp) 清理重疊 {#clean-overlaps}
只選取一個物件時，`布林` 按鈕會變成 `清理重疊`：它會把物件中互相交叉的部分合併成一個乾淨的曲面。


## ![](/icons/separate.webp) 分割 {#separate}
如果您有一個由多個互不相連的部分組成的物件，可以把它分割成好幾個物件。
這可以看成是[合併](#join)的相反操作。

`分割...` 彈出視窗提供三種分割所選物件的方式：
* `依部分分割` - 為每個互不相連的部分建立一個獨立的物件。
* `依面群組分割` - 為每個面群組建立一個獨立的物件。
* `依圖層分割` - 為基礎網格和每個圖層各建立一個獨立的物件。

![](/videos/merge_separate.mp4)


## ![](/icons/plus.webp) 新增選單 {#add-menu}

![](/images/scene_addmenu_overview.webp)

這個選單可以建立基本體、群組、相機、重複器和燈光。

基本體是可以用參數調整的基本形狀。把基本體調整到您需要的樣子後，就可以「轉換」它，把這些參數固定下來，變成可以雕刻和繪畫的多邊形網格。基本體一旦轉換後，就無法再調整它的參數。


![](/images/scene_addmenu_top.webp)

### ![](/icons/gizmo.webp) 軸向變換位置 {#on-gizmo}
啟用後，新的基本體會放在目前所選形狀或軸向變換的位置。停用時，基本體會放在場景中心。

### ![](/icons/gizmo.webp) 選擇軸向變換 {#select-gizmo}
啟用後，建立新的基本體時會自動切換到軸向變換工具。

### ![](/icons/cog.webp) 進階設定 {#add-advanced}

這個選單可以設定新的基本體、群組、重複器要建立在哪裡：可以在所選物件上、在世界原點，或在軸向變換的位置。

### 基本體工具列 {#primitive-toolbar}

![](/images/scene_primitive_toolbar.webp)

建立基本體後，會出現一個工具列，用來控制它的參數。

* `轉換` 把基本體固定成一般物件，以便雕刻和繪畫。
* `鏡像` 切換是否在基本體上方放置一個鏡像重複器。
* `全部`（眼睛圖示）選擇要在基本體上直接顯示哪些控制點來調整參數，例如立方體的寬度或圓柱體的孔洞半徑：`無`、`全部`，或依基本體不同，只顯示其中一種（半徑、孔洞、輪廓…）。
* `分段數` 基本體的分段數，這裡是長方體在 X 方向的分段。
* `恆定密度` 用軸向變換沿某個軸拉伸基本體時，增加的是它的尺寸和分段數，而不是把多邊形拉長，所以面會維持正方形。適用於長方體、平面和圓柱體。
* `...` 顯示基本體選單。

不同的基本體在工具列上還有額外的選項：

* `球體` 球體是以細分過的立方體建構而成，這樣比較適合雕刻，但也表示它並不是完美的圓形。這個選項會強制讓形狀更接近完美的球體。二十面體也有這個選項。
* `端蓋` 切換形狀兩端的端蓋，例如圓柱體可以在頂部、底部、兩端都有端蓋，或都沒有。
* `孔洞` 切換是否在形狀中心開一個貫穿的孔洞。會在無孔洞、單一半徑的孔洞、頂部和底部半徑不同的孔洞之間循環切換。
* `半徑` 切換圓柱體要使用單一半徑，還是頂部和底部使用不同的半徑。
* `圓盤` 切換平面要是四邊形，還是圓形。

主工具列下方的小工具列，可以在基本體專用的軸向變換和一般的變換軸向變換之間切換。

::: tip

點工具列的標題，可以把它切換到畫面頂端或底部。點角落的箭頭可以收合它。

### 基本體選單 {#primitive-menu}

![](/images/scene_primitive_menu.webp)

這裡包含所選基本體的所有參數。參數是描述一個形狀的基本資料。例如要描述一個圓環，您會描述它的外半徑、內半徑和多邊形數量。

大多數基本體的參數應該都一看就懂，另外還有一些所有基本體共用的參數：

* `UVs` 選單上方的小 UVs 按鈕會切換是否建立 UV 座標
* `轉換` 小小的轉換按鈕會把基本體固定成一般物件，以便雕刻和繪畫。
* `面數上限` 設定物件多邊形數量的上限，避免裝置當機。
* `後置細分` 套用拓樸選單中多解析度區塊所選的細分次數。搭配低分段數的拓樸，可以用來製作平滑、圓角的基本體。例如把長方體的拓樸分段數設為 2、後置細分設為 4，就能做出圓角的長方體。
* `線性細分` 設定在使用一般平滑細分之前，要先使用幾層線性細分。這可以用來控制細分曲面上轉角的銳利或柔和程度。例如把長方體的拓樸分段數設為 2、後置細分設為 4，再試著把線性細分在 0 到 4 之間調整，長方體的轉角就會從柔和變得銳利。

### 拓樸參數 {#topology}

這裡控制基本體的多邊形數量。這些控制項通常是連動的，所以調整其中一個啟用中的滑桿，就會平均調整所有多邊形。您可以點取消連結按鈕，分別控制形狀在 X/Y/Z 方向的分段。

### 幾何 {#geometry}

這裡控制基本體的整體大小，方形的形狀以 X/Y/Z 單位表示，圓形的形狀則以半徑表示。


### ![](/icons/circle.webp) UV球體 {#uv-sphere}
::: warning
UV球體不太適合雕刻，尤其是兩極的部分。

請優先使用四邊形球、長方體或二十面體[基本體](#primitives)，並搭配 `投影至球面` 選項。

請注意，如果把 `分段數` 滑桿設得非常低，拓樸還是可以用來雕刻的。
之後再用 `整體細分` 滑桿提高多邊形數量。

雖然它不適合一般雕刻，但很適合用來做眼睛：只要旋轉球體，讓極點對準瞳孔，多邊形佈線就會很自然地適合繪製和雕刻虹膜與瞳孔。
:::


### ![](/icons/triplanar.webp) 三平面 {#triplanar}
這個基本體很特別，您要在它上面使用[遮罩工具](tools.md#mask)來塑造幾何形狀。

![](/videos/triplanar.mp4)


::: tip
在某個平面上點兩下，相機就會聚焦到那個平面。
不過如果您用軸向變換旋轉過基本體，這個功能就無法使用。
:::

三平面使用 3 個平面上的遮罩資訊來填充體素網格，再將它多邊形化（多虧了[體素重新網格化](topology.md#voxel-remesher)）。

每個平面都有自己的對稱平面。

::: warning
每次更新三平面基本體的大小，遮罩繪製的品質都會下降。

目前還沒有選項可以把繪製「鎖定」在單一平面上，也許未來會加入。
您可以使用[連線拓樸](stroke.md#connected-topology)稍微幫點忙：只要游標精確地落在某個平面上，就不會影響其他平面。
:::

## 重複器 {#repeaters}
![](/images/scene_primitive_repeaters.webp)

重複器是一種節點，會為其下方的物件建立實例。

### ![](/icons/array.webp) 陣列 {#array}
![](/images/scene_primitive_array.webp)

物件成為這個節點的子項目後，就可以用格狀排列的方式產生實例。選取時，它有以下控制項：
* `向內貼合` - 開啟時，所有複本都會放在陣列的範圍內；關閉時，滑桿設定的是複本之間的間距
* `X/Y/Z 數量` - 每個軸上的實例數量
* `尺寸 X/Y/Z` - 格子沿每個軸的大小；關閉 `向內貼合` 時，則是複本之間的距離
* `隨機化...` - 為複本加入隨機變化，請見下方的[隨機化](#curve)。

### ![](/icons/curve.webp) 曲線 {#curve}
![](/images/scene_primitive_curve.webp)
這會建立一條曲線，這個節點的子項目會沿著曲線重複排列。選取時，它有以下控制項：
* `曲線` - 編輯曲線：在曲線上新增點，以及移動曲線上的點。
* `顯示` - 顯示或隱藏曲線和它的點。
* `吸附` - 讓曲線的點吸附到其他幾何上。
* `對稱` - 對稱地編輯曲線。
* `閉合` - 切換曲線是否要把起點和終點連起來，或是保持開放。
* `B樣條` - 切換實例要完全沿著曲線排列，還是使用結果更平滑的 B 樣條內插。
* `彎曲貼合` - 讓每個複本沿著曲線彎曲，使複本與相鄰的複本相接（`平滑` 會彎曲它們的側面，讓相接處沒有角度）。
* `對齊` - 旋轉複本，讓它們順著曲線的方向。
* `軸心` - 複本的軸心：曲線本身（`曲線本身`）或它的子項目。
* `數量` - 實例的數量。旁邊的模式按鈕可以切換成 `距離`：複本之間保持固定間距，數量則依曲線長度而定。
* `半徑` - 每個曲線點上的控制項，用來設定實例的縮放。
* `扭曲` - 每個曲線點上的控制項，用來設定實例的扭轉角度。
* `交替` - 讓每隔一個複本繞著曲線轉動：鏈條的環節用 90°，葉子或拉鍊齒用 180°，繞著您選擇的 `軸` 旋轉。
* `螺旋...` - 讓複本以多股（繩索、辮子、緞帶…）的方式纏繞曲線。
* `隨機化...` - 為複本加入隨機變化；每一列也可以改成在每個複本上加入相同的量。

工具列下方的 `(合併)` 開關，會在您把一個點拖到另一個點上時將兩者合併。`IK`（反向運動學）可以讓您擺出曲線的姿勢：拖動一個點，相連的點會跟著移動。點一下某個點可以鎖定或解除鎖定它，長按則會鎖定或解除鎖定所有點；鎖定的點會停在原處。

### ![](/icons/radial.webp) 徑向 {#radial}
![](/images/scene_primitive_radial.webp)

這個節點的子項目會以圓形排列產生實例。移動子物件可以改變這個重複器的半徑。選取時，它有以下控制項：
* RadialX/Y/Z - 選擇這些按鈕會設定徑向的軸，並設定實例的數量。



### ![](/icons/mirror.webp) 鏡像 {#mirror}
![](/images/scene_primitive_mirror.webp)

這個節點的子項目會沿著某個軸鏡像。選取時，它有以下控制項：
* 軸向變換 - 啟用變換用的軸向變換來設定鏡像的中心，也可以旋轉和縮放。完成後，再點一次軸向變換，就會顯示一般的控制項。
* X/Y/Z - 設定鏡像平面

### ![](/icons/surface.webp) 表面 {#surface}

這個節點的子項目會被複製到某個物件的表面上：每個面、每條邊或每個頂點一個複本，或隨機散佈。選取時，它有以下控制項：
* 模式 - 把複本放在 `面`、`邊` 或頂點上，或將它們 `散佈`。
* 每隔 - 每隔 N 個面、邊或頂點放一個複本。`隨機` 會改成隨機挑選，`重新隨機` 會重新抽出另一組隨機結果。
* 間距 - 散佈時，兩個複本之間的最小距離。
* 對齊 - 讓複本順著表面的法線立在表面上，而不是保持原始物件的方向。
* 吸附 - 把原始物件投影到最近的表面點上，複本也會跟著移動。
* 匹配尺寸、傾斜 - 縮放並拉伸複本，讓它們配合每個面的形狀。
* 彎曲貼合 - 讓每個複本彎曲貼合它所在的面，或沿著它所在的邊彎曲，使相鄰的複本無縫相接。

所有重複器都有一個 `轉換` 控制項，會把重複器的結果固定下來，並詢問您要如何進行：
* 合併子項目 - 把實例合併成單一物件
* 保留實例 - 實例仍然保持為實例，但不再有重複器這個「父項目」
* 取消實例 - 把實例轉換成獨立的物件

`全部展平` 也會把巢狀在這個重複器中的重複器一起固定下來，讓每個複本都變成一般物件。

::: tip 技巧：組合重複器
重複器可以互相設為父子關係，也可以把多個物件設為重複器的子項目，創造出複雜的效果。

![](/images/scene_repeater_combine.webp)
:::

::: tip 技巧：重複器的軸心

有些重複器會嘗試自動設定子物件的軸心，所以即使您用軸向變換工具移動或旋轉它們，它們也不會動。如果需要覆寫這個行為，請在重複器和子物件之間插入一個群組。這樣就能獨立於重複器移動子物件了。
:::

## ![](/icons/cog.webp) 進階設定 {#advanced}
面板左下角的 `進階設定` 按鈕會開啟一個有兩個分頁的彈出視窗：`一般` 和 `同步`。

### ![](/icons/focus.webp) UI：雙擊聚焦項目 {#focus-on-item}
在場景清單中點兩下某個項目，就會讓相機在 3d 視圖中以該項目為中心。

### ![](/icons/eye_open.webp) 同步可見性 {#sync-visibility}
啟用後，使用所選項目的眼睛圖示時，會影響所有選取的項目。

### ![](/icons/bang.webp) 反白 {#highlight}
選取範圍改變時，在視窗中反白顯示所選物件。

### ![](/icons/link.webp) 顯示 (實例) {#instance-show}
在場景清單左側顯示彩色膠囊，用來標示實例。

### ![](/icons/preview.webp) 物件預覽 {#object-previews}
在場景清單中為每個物件顯示一張算繪縮圖。與清單上方的預覽按鈕相同。

### 焊接半徑 {#weld-radius}
在 `合併` 標題下有 `位置焊接半徑` 和 `UV 焊接半徑`：距離小於這些半徑的點和 UV 會被合併。兩者都可以用各自的核取方塊關閉。這適用於合併、布林、裁切、網格簡化、重新網格化和檔案匯入。

### 圖示 {#icons}
設定視窗中群組、燈光、相機和重複器圖示的最小和最大 `尺寸`，以及 `不透明度`。

### ![](/icons/hierarchy.webp) 層級線 {#hierarchy-lines}
在視窗中，於父項目和子項目之間顯示連線。啟用後，還可以設定：
* `使用 Nomad 軸心` - 連線從自由變換和軸向變換工具所使用的軸心開始。停用時，會使用原本的基礎軸心，它可能離物件中心很遠。
* `厚度` - 連線的寬度。滑桿旁的按鈕可以為連線加上外框。
* 連線的顏色。

### ![](/icons/link.webp) 同步 {#sync}
`同步` 分頁可以為每個操作（`新增`、`刪除`、`鎖定`、`複製`、`實例`、`取消實例`、`合併`、`分割` 和 `布林`）設定是否套用到選取範圍的每一個實例：
* `自動` - 依照場景選單最上方的 `同步` 核取方塊。
* `否` - 只套用到所選物件。
* `是` - 一律套用到每一個實例。

預設 `合併`、`分割` 和 `布林` 為 `是`，其他則為 `自動`。`重設` 會恢復這些預設值。
