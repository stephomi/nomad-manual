# ![](/icons/operation.webp) 操作 {#operation}

這個選單會一次對所選物件的整個表面套用一項操作：平滑、規整網格、拋光、膨脹、調整顏色，以及模糊或銳化繪畫和遮罩。

![](/images/operation_overview.webp)

## 概覽 {#overview}

筆刷只作用在你畫過的地方，操作則會一口氣作用在所選物件的每個頂點上。標題會顯示物件的名稱；選取多個物件時，則顯示物件數量。

每項操作都是一個滑桿：往右拖曳會套用更多，往左拖曳則套用較少（如果滑桿兩側都有箭頭，往左則是套用相反的操作）。放開後滑桿會歸零，而每次拖曳都只算[歷史記錄](history.md)中的一個步驟，所以你可以少量多次地套用同一項操作。

::: tip
在體素重新網格化或布林運算之後，操作是快速整理整個網格的好方法：稍微 `規整網格` 一下能讓三角面更均勻，稍微 `平滑` 一下能去除雜訊，不必再拿筆刷到處找問題點。
:::

## 篩選 {#filters}

上方的按鈕可以限制操作的作用範圍：

* `遮罩` - 被遮罩的區域不受影響。
* `隱藏` - 被隱藏的區域不受影響。
* `偏移` - （已選取[圖層](layers.md)時）只影響目前圖層有雕刻內容的區域，讓你能平滑或膨脹圖層的內容，而不動到其他部分。

## 平滑 {#smoothing}

* `保持體積` - 平滑時不讓表面縮小。齒輪按鈕裡可以設定它使用的 `收縮` 和 `膨脹` 量。
* `保留邊界` - 網格邊界上的頂點（也就是破洞的邊緣）會保持不動。
* `穩定平滑` - 盡量讓平滑效果不受拓樸影響。在多邊形密度差異很大時效果最好。
* `平滑` - 讓表面變平滑。往左拖曳則改為 `銳化`。
* ![](/icons/group.webp) `平滑` - 平滑[面群組](tools.md#facegroup)之間的邊界，把鋸齒狀的群組輪廓拉直。往左拖曳則讓邊界變銳利。
* `規整網格` - 讓多邊形分布更均勻，同時保持形狀。
* ![](/icons/group.webp) `規整網格` - 沿著面群組邊界規整多邊形。
* `保留轉角` - 使用面群組的 `平滑` 和 `規整網格` 時，邊界轉折超過這個角度的地方會固定不動，讓轉角保持銳利，而兩側照樣平滑。勾選它的核取方塊即可啟用。

## 拋光 {#polish}

把表面壓平成乾淨的平面，就像[拋光](tools.md#polish)工具一樣。`角度` 決定哪些面會一起被壓平：彎曲程度小於這個角度的面會合併成同一個平面。角度越低，保留的摺痕越多，平面也越小。

## 膨脹 {#inflate}

沿著法線把表面往外推，往左拖曳則往內縮。`法線（規整網格）` 會同時規整多邊形，避免它們被拉伸；取消勾選它的核取方塊即可關閉。

## 顏色調整 {#color-adjustments}

先選擇要調整的通道：`顏色`、`粗糙度`、`金屬度`、`不透明度`、`密度`（物件上有 [Quad Remesher](tools.md#quad-remesher) 密度繪畫時）或 `遮罩`，然後：

* `曝光` - 讓數值變亮或變暗。
* `飽和度` - （僅限 `顏色`）讓顏色更鮮豔或更平淡。
* `對比度` - 拉開數值之間的差距，或讓它們更接近。
* `色相` - 讓顏色在色環上偏移。

## 模糊 {#blur}

在表面上模糊所選的通道：切換 `顏色`、`粗糙度`、`金屬度`、`不透明度`、`密度` 或 `遮罩`，再拖曳 `模糊`。往左拖曳則改為 `銳化`。

對遮罩來說，這和[遮罩](tools.md#mask)工具的 `模糊` 滑桿相同。不過在這裡，你也可以模糊繪畫通道。
