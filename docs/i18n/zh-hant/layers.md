# ![](/icons/layer.webp) 圖層 {#layers}

這個選單包含圖層堆疊，它能以非破壞性的方式儲存你對物件的編輯，並提供許多組合和重新利用圖層的方法。

![](/images/layers_overview.webp) 

## 概覽 {#overview}

Nomad 的圖層有好幾種用途。

繪畫資訊（顏色、粗糙度、金屬度、不透明度）在圖層上的運作方式和 2d 繪圖軟體類似。你可以建立一個圖層，在模型上繪畫。圖層可以開啟或關閉、調整不透明度、複製、在圖層堆疊中調整順序，也可以調整混合模式。

Nomad 也會用圖層來雕刻。圖層可以儲存皺紋這類細微的細節，也可以儲存大幅度的變化，讓它像其他 3d 軟體中的 blendshape、shape key 或 morph target 一樣運作。例如，你可以在不同圖層上雕刻不同的臉部表情，再調整圖層滑桿，把它們組合成新的表情。

這種情況下，圖層中儲存的變化純粹是疊加的，圖層的順序不像繪畫那樣有影響。

圖層可以用[刪除圖層](tools.md#delete-layer)工具局部擦除，也可以根據圖層中儲存的各種資訊來建立遮罩。

![](/videos/layer.mp4)

::: tip
和大多數雕刻軟體不同，改變網格的拓樸並不會捨棄圖層。你可以使用[體素重新網格化](topology.md#voxel-remesher)、[多解析度](topology.md#multiresolution)或[裁切](tools.md#trim)／[分割](tools.md#split)工具，但要注意，使用[體素重新網格化](topology.md#voxel-remesher)時，圖層的品質會受到影響。
:::

::: tip
如果你用圖層來做 blendshape 或 morph target，[場景選單](scene.md#object-menu)中還有更多圖層功能：你可以把圖層分離成物件，也可以把相符的物件合併成圖層。
:::
----

## 圖層選單 {#layer-menu}

![](/images/layers_menu.webp)

標題會顯示所選物件的名稱。基本體無法使用圖層，所以請先驗證基本體。

按 `新增圖層` 來建立新圖層。`合併圖層` 會把所有圖層合併到基礎網格中，圖示旁的數字是圖層的數量。

每個圖層都有名稱、控制強度（係數）的滑桿，以及選項按鈕。點一下圖層，就能讓它成為目前圖層：雕刻和繪畫都會進入這個圖層。點 `基底` 就能回到基礎網格上作業。

### ![](/icons/sort_right.webp) 展開清單 {#ui-expand-list}

圖層清單預設只會顯示每個圖層的可見性、混合模式和強度，目前圖層則會展開顯示完整的控制項。標題左側的箭頭可以展開所有圖層的完整控制項。

![](/images/layers_expand.webp)

### 選項 {#options}

| 動作       | 圖示                         | 說明                                         |
| :----------: | :--------------------------: | :-------------------------------------------------  |
| 可見      | ![](/icons/eye_open.webp)   | 顯示／隱藏圖層                                 |
| 混合模式   | ![](/icons/opacity.webp)    | 類似 Photoshop 的混合模式。4 個圖示分別顯示顏色、粗糙度、金屬度、不透明度的模式。                                 |
| 編輯名稱    | ![](/icons/pencil.webp)     | 編輯圖層名稱                                 |
| 刪除       | ![](/icons/trash.webp)      | 刪除圖層                                    |
| 複製    | ![](/icons/clone.webp)      | 複製圖層                                 |
| 向下合併   | ![](/icons/merge_down.webp) | 把圖層和下方的圖層（或基礎網格）合併 |
| 更多         | ![](/icons/more.webp)       | [更多…](#more)選項                            |

圖層沒有展開時，`編輯名稱`、`刪除`、`複製` 和 `向下合併` 都在它的[更多…](#more)選單中。

要把圖層移到圖層堆疊的其他位置，請按住它的名稱，然後拖曳。

### 基底 {#base}

`基底` 這一列的三點按鈕裡有 `基底 → 圖層` 按鈕，可以把基礎網格上的繪畫移到一個新圖層中，接著基底會重設為背景材質。如果你在建立任何圖層之前就已經畫了很多，這會很方便。

* 旁邊的遮罩和隱藏按鈕會讓被遮罩和被隱藏的區域保持不變。
* `擷取` - 要移動的通道：`顏色`、`不透明度`、`粗糙度` 和 `金屬度`。
* `背景材質` - 啟用後，只有和這個材質不同的數值會被移動。用滑桿設定它，或用滴管從模型上吸取。

### ![](/icons/more.webp) 更多… {#more}

「更多…」按鈕會顯示目前圖層的額外選項，分成兩個分頁：設定（齒輪圖示）和擷取（方塊圖示）。

![](/images/layers_more.webp) 

#### 通道係數 {#channel-factors}

這些控制項可以縮放圖層的雕刻、顏色、粗糙度、金屬度、不透明度的量。這些數值會和圖層的係數滑桿相乘，例如圖層強度是 1，但顏色通道係數是 0.5，那麼顯示的顏色就會是 0.5 的強度。

`偏移` 控制圖層的雕刻強度。顏色、粗糙度、金屬度被限制在 0 到 1 之間，而偏移可以是任何數值，正負都可以。

::: tip
偏移可以把一層凸起變成一層凹洞，或是把笑臉變成愁眉苦臉：
![](/videos/layer_happysad.mp4)


對稱的圖層可以先複製，再用擦除圖層工具分成左右兩個形狀：
![](/videos/layer_leftright.mp4)

偏移係數為負的圖層，可以烘焙到空白圖層上，做出新的正向形狀。

偏移係數大於 1 的圖層，可以用來嘗試更誇張的 blendshape。
:::

::: warning
目前圖層的 3 個通道（顏色／金屬度／粗糙度）只共用一個不透明度通道。
如果你合併多個各通道強度不是滿值的圖層，最後的結果看起來可能會不一樣。

也許未來每個通道都會有自己的 Alpha 通道，以解除這個限制。
:::


#### ![](/icons/shield.webp) 遮罩 {#mask}
每個滑桿旁的遮罩按鈕會根據該通道建立遮罩。這就像在繪圖軟體中用圖層建立選區一樣，讓你能把在圖層中做好的成果重新用在其他操作上。

#### ![](/icons/preview.webp) 預覽 {#preview}
![](/images/layers_preview.webp) 

以下選項位於「更多…」選單的擷取分頁中。

啟用後，會預覽這個圖層的擷取設定（請參考下一節）。

`X光` 用來選擇預覽時哪些物件要變成透明（`無`、`未選取`、`已選取` 或 `全部`），讓擷取出的形狀保持實心。當你使用負的擷取高度時特別有用。

#### ![](/icons/mask_extract.webp) 擷取 {#extract}
![](/images/layers_extract.webp) 

![](/videos/layer_shell.mp4)

`擷取` 按鈕會把圖層的內容複製成一個新物件，通常會帶有由下一節設定的厚度。

`封閉方式` 決定如何進行複製：

* `無` - 單純擷取該部分，不嘗試產生側面或填補任何破洞。
* `填補` - 用三角面填補破洞並加以平滑。平坦的表面不要使用這個選項。
* `外殼` - 用厚度數值和方向選項來封閉擷取出的形狀。
* `圖層` - 擷取圖層的差異。

#### ![](/icons/height.webp) 高度 {#thickness}
![](/images/layers_thickness.webp) 

外殼擠出的深度。正值會從表面往外長，負值則往表面內長。封閉方式為 `圖層` 時會隱藏。

數值旁的加號／減號用來設定擠出的方向：
* 減號（-）會從目前的表面開始往下擠出。
* 加號（+）會從目前的表面開始往上擠出。
* 正負號（±）會把擠出的頂部和底部往兩側推開相同的距離，讓它有一半埋在原本的表面裡。

#### 側面 {#edge-loop-side}
![](/images/layers_edgeloop.webp) 

封閉方式為 `外殼` 時，才會顯示這一區。

`側壁分段` 設定外殼側面的分段數。開啟它的 `自動` 切換鈕時，Nomad 會計算出能產生方形多邊形的環形邊數量。

#### 平滑度 {#smoothness}
![](/images/layers_smoothness.webp) 

如果要擷取的區域邊緣呈鋸齒狀，啟用這個選項就能把邊緣平滑成更好看的形狀。`全部` 會平滑整個擷取出的表面，`僅邊界` 則只平滑邊緣。`迭代次數` 設定平滑的強度。

_「更多…」子選單到此結束。_

### ![](/icons/cog.webp) 進階設定 {#advanced}
![](/images/layers_advanced.webp)

物件有圖層之後，選單底部才會出現 `進階設定` 按鈕。

#### 保留頂層圖層細節 {#keep-top-layers-details}

確保在下層圖層做出大幅變化時，上層圖層的細微細節依然可見。雕刻時，來自上層圖層的變形會被忽略，但它們的細節仍會顯示。只有在這些上層圖層的細節相對較小時，效果才會好。

預設情況下，如果你在某個圖層上雕刻了細小的皺紋，然後回到基底圖層做大幅修改，皺紋就會消失。開啟這個切換鈕後，這些細微的細節就能一直浮在下層的大幅變化之上。在下面的影片中，可以看到預設情況下皺紋細節會被抹掉，但啟用「保留頂層圖層細節」後就會保持可見：

![](/videos/layers_details.mp4)


#### 同步變換 {#sync-transform}

開啟時，當你使用軸向變換或自由變換工具，所有未選取的圖層都會依變換的旋轉、縮放、傾斜一起調整。可以設為 `自動`、`否` 或 `是`。

如果其他圖層不打算套用你正在做的新變換，請停用這個選項。

設為 `自動` 時，只有可見的圖層會被調整。
