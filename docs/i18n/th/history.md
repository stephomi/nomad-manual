# ![](/icons/history.webp) ประวัติ {#history}
![](/images/history_overview.webp)

เช่นเดียวกับเครื่องมือสร้างงานส่วนใหญ่ คุณสามารถเลิกทำ/ทำซ้ำการแก้ไขทุกอย่างใน Nomad ได้
ประวัติอาจมีขนาดใหญ่ขึ้นเรื่อย ๆ คุณจึงกำหนดเองได้ว่าจะเก็บไว้ในหน่วยความจำเท่าไร เก็บไว้ในพื้นที่จัดเก็บข้อมูลเท่าไร และจะบันทึกไปพร้อมกับโปรเจกต์หรือไม่

::: tip
คุณใช้ท่าทางลัดเพื่อเลิกทำ/ทำซ้ำได้:
- แตะด้วย 2 นิ้วเพื่อเลิกทำ
- แตะด้วย 3 นิ้วเพื่อทำซ้ำ
:::

## ![](/icons/history.webp) ประวัติ {#history-panel}
![](/images/history_history.webp)

แผงนี้แสดงสแต็กประวัติ ได้แก่ ลำดับขั้นตอน ชื่อการดำเนินการ ออบเจ็กต์ที่ได้รับผล และปริมาณหน่วยความจำที่ขั้นตอนนั้นใช้อยู่

แตะรายการใดก็ได้เพื่อย้อนกลับ (หรือข้ามไปข้างหน้า) ไปยังสถานะนั้น กดค้างที่รายการเพื่อลบรายการนั้นและประวัติที่เก่ากว่าทั้งหมดอย่างถาวร เป็นวิธีคืนหน่วยความจำแบบรวดเร็วเมื่อคุณพอใจกับงานปั้นแล้ว

### ![](/icons/speed.webp) เล่นซ้ำ {#replay}
ปุ่มเล่นที่มุมล่างซ้ายจะย้อนกลับไปที่จุดเริ่มต้น แล้วทำการดำเนินการซ้ำทีละขั้น เป็นวิธีสนุก ๆ ในการดูงานปั้นของคุณค่อย ๆ ถูกสร้างขึ้น ตัวเลื่อนใช้กำหนดความเร็วเป็นจำนวนการดำเนินการต่อวินาที แตะปุ่มอีกครั้งเพื่อหยุด การเลิกทำ/ทำซ้ำ หรือการแตะที่รายการก็จะหยุดการเล่นเช่นกัน

ก่อนเริ่มเล่น จะมีป๊อปอัปให้คุณเลือก:
* `ย้อนกลับ` - เลิกทำจากสถานะปัจจุบันย้อนไปจนถึงจุดเริ่มต้น แทนการเล่นซ้ำจากจุดเริ่มต้น
* `คืนค่ากล้อง` - กล้องจะเคลื่อนตามการดำเนินการที่เล่นซ้ำ แม้จะปิด[คืนค่ากล้อง](#restore-camera)ไว้ก็ตาม
* `ความนุ่มนวลของกล้อง` - กล้องจะค่อย ๆ เลื่อนไปมาระหว่างมุมมอง แทนที่จะกระโดดไปทีละมุม ค่ายิ่งสูง กล้องยิ่งเคลื่อนที่นิ่งนวล

::: warning
การเล่นซ้ำยังอยู่ในขั้นทดลอง
:::

## ได้แก่ การดำเนินการ {#include-actions}

ไอคอนที่ด้านล่างของแผงประวัติใช้เลือกว่าจะบันทึกการแก้ไขประเภทใดลงในประวัติบ้าง:

| การดำเนินการ      | ไอคอน                          | คำอธิบาย                                                                         |
| :---------- | :---------------------------: | :---------------------------------------------------------------------------------- |
| แสง      | ![](/icons/light.webp)        | การแก้ไขแสง การย้ายแสงด้วยกิซโม่จะถูกบันทึกเสมอ เพราะอาจส่งผลต่อออบเจ็กต์อื่นในลำดับชั้นของซีน |
| การแรเงา     | ![](/icons/sun.webp)          | โหมด PBR, MatCap และ Unlit รวมถึง MatCap และ HDRI                                   |
| PostProcess | ![](/icons/postprocess.webp)  | การแก้ไขโพสต์โปรเซส                                                                   |
| การเลือก   | ![](/icons/tool_lattice.webp) | การแก้ไขการเลือกของแลตทิซ เช่น การคลิก การเลือกด้วยลัสโซ และการยกเลิกการเลือก          |

## การตั้งค่า {#settings}
![](/images/history_settings.webp)

### ![](/icons/camera.webp) คืนค่ากล้อง {#restore-camera}
ทุกการดำเนินการจะบันทึกมุมมองของกล้องเอาไว้
ถ้าเปิดตัวเลือกนี้ การเลิกทำหรือทำซ้ำจะรีเซ็ตกล้องกลับไปที่มุมมองที่บันทึกไว้

### ![](/icons/history.webp) บันทึกประวัติ {#save-history}
เก็บประวัติการเลิกทำไว้เมื่อบันทึกโปรเจกต์ เพื่อให้ยังอยู่เมื่อเปิดโปรเจกต์ขึ้นมาใหม่ ปิดไว้ถ้าอยากให้ไฟล์โปรเจกต์มีขนาดเล็กลง

### ![](/icons/ram.webp) ขีดจำกัด RAM {#history-limit-mb}
ปริมาณประวัติสูงสุดที่เก็บไว้ใน RAM สถานะที่เก่ากว่าจะถูกย้ายไปไว้ในพื้นที่จัดเก็บข้อมูลและโหลดกลับมาเมื่อต้องใช้ ไม่ได้ถูกลบทิ้ง

### ![](/icons/save.webp) ขีดจำกัดพื้นที่จัดเก็บข้อมูล {#storage-limit}
ปริมาณพื้นที่จัดเก็บข้อมูลสูงสุดที่ประวัติของโปรเจกต์นี้ใช้ได้ เมื่อถึงขีดจำกัด การดำเนินการที่เก่าที่สุดจะถูกลบอย่างถาวร

::: tip
ขีดจำกัดใหม่จะมีผลหลังจากการแก้ไข การเลิกทำ หรือการทำซ้ำครั้งถัดไป
:::

### ![](/icons/undo.webp) คำเตือนการเลิกทำ {#maximum-undoable}
ถ้าย้อนกลับเกินจำนวนการดำเนินการนี้ในครั้งเดียว แอปจะขอให้ยืนยันก่อน เพราะถ้าคุณแก้ไขอะไรหลังจากนั้น การดำเนินการทั้งหมดหลังจุดนั้นจะหายไป ตัวเลือกนี้จึงช่วยป้องกันการแตะพลาดไปโดนรายการที่อยู่ลึกลงไปในลิสต์
