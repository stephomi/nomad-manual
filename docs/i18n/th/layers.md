# ![](/icons/layer.webp) เลเยอร์ {#layers}

เมนูนี้มีสแต็กเลเยอร์ ซึ่งเป็นวิธีเก็บการแก้ไขออบเจ็กต์แบบไม่ทำลายงานเดิม และมีหลายวิธีในการรวมและนำเลเยอร์ไปใช้ประโยชน์อย่างอื่น

![](/images/layers_overview.webp) 

## ภาพรวม {#overview}

เลเยอร์ใน Nomad ใช้ได้หลายจุดประสงค์

ข้อมูลการลงสี (สี ความหยาบ ความเป็นโลหะ ความทึบ) ทำงานกับเลเยอร์คล้ายกับแอปวาดภาพ 2d คุณสร้างเลเยอร์แล้วลงสีบนโมเดลได้ เลเยอร์เปิด/ปิดได้ ปรับความทึบได้ ทำสำเนาได้ เปลี่ยนลำดับในสแต็กเลเยอร์ได้ และปรับโหมดการเบลนด์ได้

Nomad ยังใช้เลเยอร์สำหรับการปั้นด้วย เลเยอร์เก็บรายละเอียดเล็กๆ อย่างริ้วรอยได้ หรือเก็บการเปลี่ยนแปลงขนาดใหญ่ได้ ทำให้มันทำหน้าที่เหมือน blendshape/shape key/morph target ในแอป 3d อื่นๆ เช่น คุณอาจปั้นสีหน้าต่างๆ ไว้บนเลเยอร์ต่างกัน แล้วปรับแถบเลื่อนของเลเยอร์เพื่อผสมออกมาเป็นสีหน้าใหม่

ในกรณีนี้ การเปลี่ยนแปลงที่เก็บไว้ในเลเยอร์จะเป็นการบวกเพิ่มล้วนๆ ลำดับของเลเยอร์จึงไม่มีผลเหมือนตอนลงสี

เลเยอร์ลบออกบางส่วนได้ด้วยเครื่องมือ[ลบเลเยอร์](tools.md#delete-layer) และยังใช้เลเยอร์สร้างมาส์กจากข้อมูลต่างๆ ที่เก็บไว้ในเลเยอร์ได้ด้วย

![](/videos/layer.mp4)

::: tip
ต่างจากซอฟต์แวร์ปั้นส่วนใหญ่ การเปลี่ยนโทโพโลยีของเมชจะไม่ทำให้เลเยอร์หายไป คุณใช้[การรีเมชว็อกเซล](topology.md#voxel-remesher) [ความละเอียดหลายระดับ](topology.md#multiresolution) หรือเครื่องมือ[ตัดแต่ง](tools.md#trim)/[แยก](tools.md#split)ได้ แต่โปรดทราบว่าเมื่อใช้[การรีเมชว็อกเซล](topology.md#voxel-remesher) คุณภาพของเลเยอร์จะได้รับผลกระทบ
:::

::: tip
ถ้าใช้เลเยอร์เป็น blendshape/morph target จะมีฟังก์ชันเลเยอร์เพิ่มเติมอยู่ใน[เมนูซีน](scene.md#object-menu) คุณแยกเลเยอร์ออกเป็นออบเจ็กต์ และรวมออบเจ็กต์ที่ตรงกันเข้าเป็นเลเยอร์ได้
:::

## เมนูเลเยอร์ {#layer-menu}

![](/images/layers_menu.webp)

หัวเมนูแสดงชื่อของออบเจ็กต์ที่เลือก รูปทรงพื้นฐานใช้เลเยอร์ไม่ได้ ดังนั้นให้ยืนยันรูปทรงพื้นฐานก่อน

กด `เพิ่มเลเยอร์` เพื่อสร้างเลเยอร์ใหม่ `รวมเลเยอร์` จะรวมทุกเลเยอร์เข้ากับเมชฐาน ตัวเลขข้างไอคอนคือจำนวนเลเยอร์ที่มีอยู่

แต่ละเลเยอร์มีชื่อ แถบเลื่อนควบคุมความแรง/แฟกเตอร์ และปุ่มตัวเลือก แตะที่เลเยอร์เพื่อให้เป็นเลเยอร์ที่ใช้งานอยู่: การปั้นและการลงสีจะเข้าไปอยู่ในเลเยอร์นั้น แตะ `ฐาน` เพื่อกลับไปทำงานบนเมชฐาน

### ![](/icons/sort_right.webp) ขยายรายการ {#ui-expand-list}

โดยค่าเริ่มต้น รายการเลเยอร์จะแสดงเฉพาะการมองเห็น โหมดการเบลนด์ และความแรงของแต่ละเลเยอร์ ส่วนเลเยอร์ที่ใช้งานอยู่จะถูกขยายพร้อมตัวควบคุมครบชุด ลูกศรทางซ้ายของหัวข้อจะขยายตัวควบคุมครบชุดให้ทุกเลเยอร์

![](/images/layers_expand.webp)

เมื่อเลเยอร์ไม่ได้ถูกขยาย `แก้ไขชื่อ` `ลบ` `ทำสำเนา` และ `รวมล่าง` จะอยู่ในเมนู[เพิ่มเติม...](#more)ของเลเยอร์นั้น

ถ้าต้องการย้ายเลเยอร์ไปยังตำแหน่งอื่นในสแต็กเลเยอร์ ให้กดค้างที่ชื่อของมัน แล้วลาก

### ฐาน {#base}

ปุ่มสามจุดของแถว `ฐาน` จะย้ายสีที่ลงไว้บนเมชฐานไปไว้ในเลเยอร์ใหม่ ด้วยปุ่ม `ฐาน → เลเยอร์` จากนั้นฐานจะถูกรีเซ็ตเป็นวัสดุพื้นหลัง วิธีนี้สะดวกเมื่อคุณลงสีไปเยอะแล้วก่อนจะสร้างเลเยอร์ใดๆ

* ปุ่มมาส์กและซ่อนที่อยู่ข้างๆ จะเว้นส่วนที่ถูกมาส์กและถูกซ่อนไว้ไม่ให้ถูกแตะต้อง
* `สกัด` - ช่องที่จะย้าย: `คัลเลอร์` `ความทึบ` `ความหยาบ` และ `ความเป็นโลหะ`
* `วัสดุพื้นหลัง` - ถ้าเปิดใช้งาน จะย้ายเฉพาะค่าที่ต่างจากวัสดุนี้ ตั้งค่าได้ด้วยแถบเลื่อน หรือเลือกจากโมเดลด้วยหลอดดูดสี

### ![](/icons/more.webp) เพิ่มเติม... {#more}

ปุ่ม 'เพิ่มเติม...' จะแสดงตัวเลือกเพิ่มเติมของเลเยอร์ปัจจุบัน แบ่งเป็นสองแท็บ: การตั้งค่า (ไอคอนเฟือง) และการสกัด (ไอคอนลูกบาศก์)

![](/images/layers_more.webp) 

#### แฟกเตอร์ของช่อง {#channel-factors}

ตัวควบคุมเหล่านี้ให้คุณปรับปริมาณของการปั้น/สี/ความหยาบ/ความเป็นโลหะ/ความทึบของเลเยอร์ ค่าเหล่านี้จะถูกคูณกับแถบเลื่อนแฟกเตอร์ของเลเยอร์ เช่น ถ้าความแรงของเลเยอร์เป็น 1 แต่แฟกเตอร์ของช่องสีเป็น 0.5 สีที่แสดงจะมีความแรง 0.5

`ออฟเซ็ต` ควบคุมความแรงของการปั้นในเลเยอร์ ขณะที่สี/ความหยาบ/ความเป็นโลหะถูกจำกัดไว้ระหว่าง 0 ถึง 1 ออฟเซ็ตจะเป็นค่าใดก็ได้ ทั้งบวกและลบ 

::: tip
ออฟเซ็ตใช้เปลี่ยนเลเยอร์ที่เป็นปุ่มนูนให้กลายเป็นเลเยอร์ของหลุม หรือเปลี่ยนรอยยิ้มให้เป็นหน้าบึ้งได้:
![](/videos/layer_happysad.mp4)


เลเยอร์ที่สมมาตรสามารถโคลนแล้วแยกเป็นรูปทรงซ้าย/ขวาได้ด้วยเครื่องมือลบเลเยอร์:
![](/videos/layer_leftright.mp4)

เลเยอร์ที่มีแฟกเตอร์ออฟเซ็ตติดลบสามารถเบคลงบนเลเยอร์ว่างเพื่อสร้างรูปทรงบวกใหม่ได้

เลเยอร์ที่มีแฟกเตอร์ออฟเซ็ตเป็นบวกมากกว่า 1 ใช้ทดลอง blendshape ที่สุดโต่งขึ้นได้
:::

::: warning
ตอนนี้เลเยอร์ใช้ช่องความทึบร่วมกันเพียงช่องเดียวสำหรับทั้ง 3 ช่อง (สี/ความเป็นโลหะ/ความหยาบ)
ถ้าคุณรวมหลายเลเยอร์ที่ตั้งความเข้มแยกตามช่องไว้ไม่เต็ม ผลลัพธ์สุดท้ายอาจดูต่างออกไปได้

ในอนาคต แต่ละช่องอาจมีช่องอัลฟ่าของตัวเองเพื่อตัดข้อจำกัดนี้ออก
:::


#### ![](/icons/shield.webp) มาส์ก {#mask}
ปุ่มมาส์กข้างแต่ละแถบเลื่อนจะสร้างมาส์กจากช่องนั้น คล้ายกับการใช้เลเยอร์ทำการเลือกในแอปวาดภาพ ช่วยให้คุณนำงานที่ทำไว้ในเลเยอร์กลับมาใช้กับการทำงานอื่นได้

#### ![](/icons/preview.webp) พรีวิว {#preview}
![](/images/layers_preview.webp) 

ตัวเลือกต่อไปนี้อยู่ในแท็บการสกัดของเมนู 'เพิ่มเติม...'

เมื่อเปิดใช้งาน จะแสดงพรีวิวของการตั้งค่าการสกัดสำหรับเลเยอร์นี้ (ดูหัวข้อถัดไป)

`เอ็กซ์เรย์` เลือกว่าออบเจ็กต์ใดจะโปร่งใสระหว่างพรีวิว (`ไม่มี` `ไม่ได้เลือก` `ที่เลือก` หรือ `ทั้งหมด`) เพื่อให้รูปทรงที่สกัดออกมายังดูทึบ มีประโยชน์ถ้าคุณใช้ความสูงการสกัดติดลบ

#### ![](/icons/mask_extract.webp) สกัด {#extract}
![](/images/layers_extract.webp) 

![](/videos/layer_shell.mp4)

ปุ่ม `สกัด` จะทำสำเนาเนื้อหาของเลเยอร์ออกมาเป็นออบเจ็กต์ใหม่ โดยปกติจะมีความหนาที่ผู้ใช้กำหนดไว้ในหัวข้อถัดไป

`การดำเนินการปิด` กำหนดวิธีทำสำเนา:

* `ไม่มี` - สกัดส่วนนั้นออกมาเฉยๆ ไม่พยายามสร้างด้านข้างหรืออุดรูใดๆ
* `เติม` - รูจะถูกอุดและเกลี่ยเรียบด้วยสามเหลี่ยม อย่าใช้ตัวเลือกนี้กับพื้นผิวแบน
* `เปลือก` - ปิดรูปทรงที่สกัดออกมาด้วยค่าความหนาและตัวเลือกทิศทาง
* `เลเยอร์` - สกัดส่วนต่างของเลเยอร์

#### ![](/icons/height.webp) ความสูง {#thickness}
![](/images/layers_thickness.webp) 

ความลึกของการดันเปลือกออกมา ค่าบวกจะงอกออกจากพื้นผิว ค่าลบจะงอกเข้าไปในพื้นผิว ค่านี้จะถูกซ่อนเมื่อการดำเนินการปิดเป็น `เลเยอร์`

เครื่องหมายบวก/ลบข้างค่านี้จะกำหนดทิศทางของการดันออก:
* ลบ ( - ) จะเริ่มจากพื้นผิวปัจจุบันแล้วดันลง 
* บวก ( + ) จะเริ่มจากพื้นผิวปัจจุบันแล้วดันขึ้น 
* บวกลบ ( ± ) จะดันด้านบนและด้านล่างของการดันออกไปเท่าๆ กัน จึงฝังอยู่ในพื้นผิวเดิมครึ่งหนึ่ง

#### ด้านข้าง {#edge-loop-side}
![](/images/layers_edgeloop.webp) 

หัวข้อนี้จะแสดงเมื่อการดำเนินการปิดเป็น `เปลือก` 

`จำนวนแบ่งผนัง` ตั้งจำนวนการแบ่งตามด้านข้างของเปลือก เมื่อเปิดสวิตช์ `อัตโนมัติ` ของมัน Nomad จะคำนวณจำนวนลูปขอบเพื่อให้ได้โพลิกอนรูปสี่เหลี่ยมจัตุรัส

#### ความเรียบ {#smoothness}
![](/images/layers_smoothness.webp) 

ถ้าขอบของบริเวณที่จะสกัดหยักเป็นฟันเลื่อย ให้เปิดตัวเลือกนี้เพื่อเกลี่ยให้เป็นรูปทรงที่สวยขึ้น `ทั้งหมด` จะเกลี่ยพื้นผิวที่สกัดออกมาทั้งหมด `เฉพาะขอบ` จะเกลี่ยเฉพาะขอบ `รอบการทำซ้ำ` กำหนดว่าการเกลี่ยจะแรงแค่ไหน

_เมนูย่อย 'เพิ่มเติม...' จบเพียงเท่านี้_

### ![](/icons/cog.webp) ขั้นสูง {#advanced}
![](/images/layers_advanced.webp)

ปุ่ม `ขั้นสูง` ที่ด้านล่างของเมนูจะปรากฏเมื่อออบเจ็กต์มีเลเยอร์แล้ว

#### เก็บเลเยอร์บนสุดไว้เหมือนเดิม {#keep-top-layers-details}

ทำให้รายละเอียดเล็กๆ บนเลเยอร์ที่อยู่สูงกว่ายังมองเห็นได้ เมื่อมีการเปลี่ยนแปลงขนาดใหญ่บนเลเยอร์ที่อยู่ต่ำกว่า ระหว่างที่คุณปั้น การเสียรูปที่มาจากเลเยอร์บนสุดจะถูกละเว้น แต่รายละเอียดของเลเยอร์เหล่านั้นยังมองเห็นได้ ใช้ได้ดีเฉพาะเมื่อเลเยอร์บนสุดเหล่านั้นมีรายละเอียดขนาดค่อนข้างเล็ก

โดยค่าเริ่มต้น ถ้าคุณปั้นริ้วรอยเล็กๆ บนเลเยอร์หนึ่ง แล้วไปเปลี่ยนเลเยอร์ฐานครั้งใหญ่ ริ้วรอยเหล่านั้นจะหายไป การเปิดสวิตช์นี้จะทำให้รายละเอียดเล็กๆ เหล่านั้นลอยอยู่เหนือการเปลี่ยนแปลงขนาดใหญ่ด้านล่างเสมอ ในวิดีโอต่อไปนี้ ดูว่ารายละเอียดริ้วรอยถูกลบไปอย่างไรในค่าเริ่มต้น แต่ยังมองเห็นได้เมื่อเปิด 'เก็บเลเยอร์บนสุดไว้เหมือนเดิม':

![](/videos/layers_details.mp4)


#### ซิงค์การเปลี่ยนรูป {#sync-transform}

เมื่อเปิด เลเยอร์ทั้งหมดที่ไม่ได้เลือกจะถูกปรับตามการหมุน สเกล และการเฉือนของการแปลง เมื่อคุณใช้เครื่องมือกิซโม่หรือทรานส์ฟอร์ม ตั้งค่าได้เป็น `อัตโนมัติ` `ไม่` หรือ `ใช่`

ปิดตัวเลือกนี้ถ้าเลเยอร์อื่นๆ ตั้งใจให้ใช้โดยไม่มีการแปลงใหม่ที่คุณกำลังใช้

เมื่อตั้งเป็น `อัตโนมัติ` จะปรับเฉพาะเลเยอร์ที่มองเห็นได้
