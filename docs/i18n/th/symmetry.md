# ![](/icons/symmetry.webp) สมมาตร {#symmetry}

เมนูนี้ควบคุมว่าเส้นที่คุณวาดจะถูกทำซ้ำอย่างไร ทั้งข้ามระนาบกระจก แบบรัศมี หรือแบบแบ่งช่อง รวมถึงวิธีคืนความสมมาตรให้ออบเจ็กต์ที่ไม่สมมาตร

![](/images/symmetry_overview.webp) 

## ภาพรวม {#overview}
คุณใช้สมมาตรได้หลายแบบ:

* แบบกระจก พลิกงานข้ามแกน X (ซ้าย/ขวา), Y (บน/ล่าง), Z (หลัง/หน้า) หรือหลายแกนรวมกัน
* สมมาตรแบบรัศมีตั้งได้บนแกน X Y Z พร้อมจำนวนการทำซ้ำ เช่น เวลาปั้นปลาดาว
* การแบ่งช่องจะทำซ้ำเส้นของคุณไปทั่วออบเจ็กต์ ให้งานปั้นต่อกันเป็นลายได้อย่างไร้รอยต่อ
* กระจกทำงานได้รอบจุดกำเนิด (เรียกว่าโหมดเวิลด์) หรือรอบจุดศูนย์กลางของออบเจ็กต์ (เรียกว่าโหมดโลคอล)
* งานปั้นที่เริ่มต้นแบบไม่สมมาตรสามารถบังคับให้สมมาตรได้

ยังมีทางลัดสำหรับเปิด/ปิดสมมาตรอยู่บนแผงด่วนด้านซ้ายด้วย (*"สมมาตร"*) ตัวอักษร 'L/W' เล็กๆ บอกว่า Nomad อยู่ในโหมดสมมาตรแบบโลคอลหรือเวิลด์ คุณยังกดค้างหรือปัดไปทางกลางจอเพื่อเปิดเมนูได้ด้วย

![](/images/symmetry_button.webp) 

การตั้งค่าสมมาตรจะถูกบันทึกไว้กับแต่ละออบเจ็กต์ และหัวเมนูจะแสดงชื่อของออบเจ็กต์ที่คุณกำลังแก้ไข
เครื่องมือปั้นทั้งหมดใช้สถานะเปิด/ปิดร่วมกัน ส่วนเครื่องมือแปลง ([ทรานส์ฟอร์ม](tools.md#transform)และ[กิซโม่](tools.md#gizmo)) มีสถานะของตัวเอง

::: tip
เมนูสมมาตรมีไว้ควบคุมสมมาตรของเส้นเป็นหลัก คุณยังมิเรอร์และทำซ้ำออบเจ็กต์ได้ผ่าน[ตัวทำซ้ำในเมนูซีน](scene#repeaters) 
:::

## ![](/icons/symmetry.webp) เปิดใช้งาน {#enabled}
เปิด/ปิดโหมดกระจก ซึ่งเหมือนกับปุ่ม `สมมาตร` บนแผงด่วนด้านซ้าย จะมีไอคอนเตือนให้เห็นเมื่อปิดอยู่ และเมนูยังบอกด้วยเมื่อเครื่องมือปัจจุบันไม่ใช้สมมาตร

## ระนาบ {#planes}

เปิดใช้ระนาบสมมาตร และตั้งจำนวนการทำซ้ำสำหรับสมมาตรแบบรัศมี คุณไม่จำเป็นต้องเลือกแค่ระนาบเดียว จะเปิดไว้ 1, 2 หรือทั้ง 3 ระนาบก็ได้สำหรับสมมาตรที่ซับซ้อน

แถว `เรเดียล` ตั้งจำนวนการทำซ้ำของสมมาตรแบบรัศมีรอบแต่ละแกน แถวนี้ก็ไม่จำกัดอยู่แค่แกนเดียวเช่นกัน และยังใช้ร่วมกับสมมาตรแบบระนาบเพื่อสร้างงานที่มีรายละเอียดได้อย่างรวดเร็ว (จำนวนการทำซ้ำทั้งหมดจำกัดไว้ที่ 200)

![](/videos/symmetry_demo.mp4) 

## แบ่งช่อง {#tile}

ทำซ้ำเส้นของคุณไปตามแกน เป็นระยะเท่าๆ กัน ให้งานปั้นต่อกันเป็นลายได้อย่างไร้รอยต่อ เหมาะกับลวดลาย อิฐ หรือเท็กซ์เจอร์ที่คุณตั้งใจจะนำไปใช้ซ้ำ

เปิดการแบ่งช่องของแต่ละแกนด้วยปุ่ม `แบ่งช่อง` แล้วตั้งค่า `จำนวน` (จำนวนการทำซ้ำที่กระจายเต็มออบเจ็กต์) หรือ `ระยะห่าง` (ระยะระหว่างการทำซ้ำสองครั้ง) แตะสวิตช์ทางซ้ายเพื่อสลับระหว่างสองแบบนี้

## วิธี {#method}
กระจกจะเป็นแบบ `โลคอล` และเคลื่อนที่ไปกับออบเจ็กต์ หรือเป็นแบบ `เวิลด์` และไม่เคลื่อนที่ก็ได้ ถ้าไม่แน่ใจว่าต้องใช้โหมดไหน ให้สังเกตตัวบอกระนาบกระจกและแบบรัศมีที่ซ้อนอยู่บนออบเจ็กต์ ในโหมดโลคอล ถ้าคุณใช้เครื่องมือแปลง (`กิซโม่` หรือ `ทรานส์ฟอร์ม`) ย้ายโมเดล ตัวบอกกระจกจะเคลื่อนตามไปด้วย ในโหมดเวิลด์ ตัวบอกกระจกจะอยู่กับที่ และออบเจ็กต์จะเลื่อนผ่านมันไป

## กระจก {#mirroring}
![](/images/symmetry_mirroring.webp)

เมื่อปั้นใกล้ระนาบสมมาตร แปรงบางตัวอาจให้ผลสมมาตรได้ไม่สมบูรณ์ ส่วนนี้ช่วยให้คุณคืนความสมมาตรได้ โดยคัดลอกงานปั้นด้านหนึ่งไปอีกด้านหนึ่ง

`ทิศทาง` - ปุ่มลูกศรสองปุ่มข้างหัวข้อ `กระจก` กำหนดว่าด้านไหนจะถูกคัดลอกไปอีกด้าน Nomad คำนวณจากวิวพอร์ตปัจจุบันของคุณ ด้านที่เลือกจึงอยู่ฝั่งเดิมบนหน้าจอเสมอ ไม่ว่าคุณจะมองโมเดลจากทางไหน

![](/icons/shield.webp) `มาส์ก` - ปุ่มมาส์กช่วยให้คุณแยกส่วนที่จะถูกมิเรอร์ได้: มาส์กด้านปลายทางจะปกป้องบริเวณนั้นไว้ ส่วนมาส์กด้านต้นทางจะทำให้บริเวณนั้นไม่ถูกมิเรอร์ไปยังปลายทาง

![](/icons/tool_hide.webp) `ซ่อน` - เมื่อเปิดใช้งาน บริเวณที่ถูกซ่อนไว้ทางด้านต้นทางจะไม่ถูกมิเรอร์ไปยังปลายทาง

`กระจก` (รักษาโครงสร้าง) จะพยายามตรวจดูว่าโทโพโลยีของทั้งสองด้านของกระจกเหมือนกันหรือไม่ ถ้าเหมือน ก็จะแค่ย้ายจุดยอด ซึ่งเป็นกรณีที่พบบ่อยที่สุด สมมาตรแบบรัศมีจะถูกข้ามไป ถ้าโทโพโลยีไม่สมมาตร Nomad จะเสนอให้บังคับมิเรอร์ด้วย `ตัด • กระจก` แทน

ปุ่ม `ตัด` จะตัดออบเจ็กต์ตามระนาบสมมาตร ปุ่มเหล่านี้เปลี่ยนโทโพโลยี จึงทำลายงานเดิมมากกว่า `กระจก` ตัวเลขบนแต่ละปุ่มคือจำนวนออบเจ็กต์ที่คุณจะได้:

* `ตัด` - ลบออบเจ็กต์ด้านหนึ่งออก
* `ตัด • กระจก` - ตัดออบเจ็กต์ คัดลอกด้านหนึ่ง มิเรอร์ไปอีกด้าน แล้วเชื่อมจุดยอดตามแนวกระจก บางครั้งจำเป็นต้องใช้วิธีนี้ถ้าโมเดลสองฝั่งของกระจกแตกต่างกันมาก
* `ตัด • แยก` - ตัดออบเจ็กต์ และเก็บแต่ละด้านไว้เป็นออบเจ็กต์แยกกัน
* `ตัด • กระจก • แยก` - เหมือน `ตัด • กระจก` แต่แต่ละด้านจะกลายเป็นออบเจ็กต์แยกกัน

ถ้าเลือกออบเจ็กต์ไว้หลายชิ้น `กระจก` และ[พลิกออบเจ็กต์](#flip-object)จะมีผลกับทุกชิ้น

### พลิกออบเจ็กต์ {#flip-object}
![](/images/symmetry_flip.webp)
สลับด้านซ้ายไปเป็นด้านขวา และกลับกัน ตามแกน `X`, `Y` หรือ `Z` ผลที่เห็นคล้ายกับการใช้เมนูเครื่องมือกิซโม่แล้วตั้งสเกลบนแกน X เป็น -1

## รีเซ็ตและแก้ไข {#reset-and-edit}

![](/images/symmetry_edit.webp)

คุณแก้ไขตำแหน่งและการวางแนวของสมมาตรได้ (แต่ไม่แนะนำ!) ถ้าจำเป็น `ศูนย์กลางของเวิลด์` (`ศูนย์กลางออบเจ็กต์` ในโหมดโลคอล) และ `การวางแนว` จะรีเซ็ตตำแหน่งและการวางแนวของสมมาตรกลับเป็นค่าเริ่มต้น

ปกติ Nomad รู้ว่าควรวางระนาบสมมาตรไว้ตรงไหน ไม่แนะนำให้ปรับเอง แต่ปุ่ม `แก้ไขกิซโม่` เปิดให้ผู้ใช้ขั้นสูงทำได้ เมื่อกดปุ่มนี้ จะมีกิซโม่ปรากฏขึ้นให้คุณเลื่อนและหมุนระนาบสมมาตร ถ้าต้องการคืนจุดศูนย์กลางและการวางแนวเริ่มต้น ให้ใช้ปุ่มรีเซ็ตด้านบน

`จากเดือย` จะวางระนาบสมมาตรไว้ที่จุดหมุนของเครื่องมือ[กิซโม่](tools.md#gizmo) ใช้ได้เฉพาะตอนที่เครื่องมือ `กิซโม่` ทำงานอยู่

ผลของตัวเลือกเหล่านี้จะเปลี่ยนไปตามพื้นที่ (*โลคอล/เวิลด์*) ที่คุณอยู่
ถ้ามันไม่ทำงานอย่างที่คุณคาดไว้ ให้ตรวจดูว่าคุณอยู่ในพื้นที่ที่ถูกต้องหรือไม่

::: tip
การแก้ไขระนาบสมมาตรด้วยกิซโม่ยังค่อนข้างอยู่ในขั้นทดลอง คุณน่าจะไม่จำเป็นต้องใช้!
:::

## ตัวเลือกการแสดงผล {#show-options}
![](/images/symmetry_show.webp)


`แสดงเส้น` และ `แสดงระนาบ` จะเปิด/ปิดภาพซ้อนในวิวพอร์ตที่แสดงตำแหน่งของสมมาตร การปิดตัวเลือกเหล่านี้จะมีผลก็ต่อเมื่อปิดเมนูสมมาตรแล้วเท่านั้น
