# ![](/icons/image.webp) พื้นหลัง {#background}

เมนูนี้ใช้ควบคุมสีพื้นหลังของ Nomad รวมถึงภาพอ้างอิงที่คุณต้องการใช้

![](/images/background_overview.webp)

## ชนิด {#type}
![](/images/background_selector.webp)

พื้นหลังของวิวพอร์ตมีให้เลือกสามแบบ

* `สภาพแวดล้อม` - แสดงแผนที่สภาพแวดล้อม (environment map) ที่เลือกไว้ใน[การแรเงา](shading.md) ปรับเพิ่มเติมได้ด้วยตัวเลื่อน `เบลอ` และ `การเปิดรับแสง` (ความสว่าง)
* `คัลเลอร์` - สีเรียบสีเดียวที่คุณเลือกเองได้
* `การไล่ระดับสี` - ไล่สีระหว่างสองสี ตัวเลื่อน `แฟกเตอร์` ใช้เลื่อนจุดกึ่งกลางของการไล่สี

### ชนิดการไล่ระดับสี {#gradient-type}
เมื่อเลือก `การไล่ระดับสี` คุณเลือกรูปแบบของมันได้ดังนี้
* `เชิงเส้น` - ไล่สีเป็นแนวตรง ทิศทางกำหนดด้วยตัวเลื่อน `มุม`
* `แนวรัศมี` - ไล่สีเป็นวงกลมจากกึ่งกลางหน้าจอออกไป
* `ท้องฟ้า` - ไล่สีโดยยึดกับเส้นขอบฟ้าของโลก จึงเปลี่ยนตามกล้องเมื่อคุณมองขึ้นหรือมองลง

แต่ละสีมีปุ่มรีเซ็ต และที่ดูดสีสำหรับเลือกสีจากบนหน้าจอ

## ![](/icons/lock.webp) ซิงค์กับการล็อคกล้อง {#sync-on-camera-lock}
เมื่อล็อคกล้องด้วย[ตัวนำทาง](settings.md#snap-cube) ภาพอ้างอิงจะเคลื่อนตามกล้อง ทำให้ภาพยังคงตรงกับงานปั้นของคุณเสมอ

* `อนุญาตให้เอียงกล้อง (แทร็กบอล)` - ให้กล้องเอียงได้เมื่อคุณออกจากการล็อคกล้อง
* `รีเซ็ตมุมมองเมื่อปลดล็อค` - รีเซ็ตมุมมองเมื่อคุณออกจากการล็อคกล้อง

## ภาพอ้างอิง {#reference}

![](/images/background_reference.webp)

คุณสามารถใส่รูปภาพที่ต้องการไว้บนพื้นหลังเพื่อใช้เป็นภาพอ้างอิงได้ แตะ `นำเข้า...` เพื่อเพิ่มภาพ แล้วติ๊ก `ภาพอ้างอิง` เพื่อให้แสดงขึ้นมา
คุณปรับตำแหน่งและขนาดของภาพได้ เช่น ถ้าอยากย้ายภาพไปไว้ที่มุมจอ

### ![](/icons/tool_transform.webp) ทรานส์ฟอร์ม {#transform}

ปุ่มนี้ให้คุณจัดวางภาพอ้างอิงแบบโต้ตอบได้ ใช้ 2 นิ้วเพื่อเลื่อน ย่อขยาย และหมุนภาพอ้างอิงให้เข้าที่ ส่วน `รีเซ็ตการตั้งค่า` จะคืนภาพกลับไปที่ตำแหน่งเริ่มต้น ตำแหน่งสุดท้ายที่จัดไว้จะแสดงอยู่ในตัวเลื่อนด้านล่าง:

* `โอเวอร์เลย์` - ที่ 0% ภาพอ้างอิงจะอยู่หลังออบเจ็กต์ของคุณเสมอ ที่ 100% ภาพจะอยู่ด้านหน้า
* `ความทึบ` - ความโปร่งใสของภาพ
* `โพสต์โปรเซส` - ใช้เอฟเฟกต์โพสต์โปรเซสกับภาพอ้างอิงด้วย ปิดไว้ถ้าอยากเก็บสีดั้งเดิมของภาพ
* `ตำแหน่ง X` / `ตำแหน่ง Y` - ตำแหน่ง X และ Y ของภาพ
* `สเกล` - ขนาดของภาพ
* `การหมุน` - การหมุนของภาพ


::: tip

กล้องและภาพอ้างอิงเชื่อมโยงกัน

หมายความว่า ถ้าคุณจัดภาพอ้างอิงให้ตรงกับงานปั้นแล้วสร้างกล้องจาก[เมนูกล้อง](camera.md) ตำแหน่ง การหมุน และสเกลของภาพอ้างอิงจะถูกบันทึกไว้กับกล้องด้วย จากนั้นคุณจะปิดภาพอ้างอิงแล้วหมุนไปดูมุมอื่นก็ได้ เมื่อกลับมามองผ่านกล้องตัวนั้นอีกครั้ง ภาพอ้างอิงจะเปิดขึ้นพร้อมการตั้งค่าที่คุณใช้ไว้

แม้แต่การเลือกใช้ภาพต่างกันสำหรับกล้องแต่ละตัวก็ทำได้!
