# ![](/icons/transform.webp) ทรานส์ฟอร์ม {#transform}

เมนูนี้แสดงการแปลงของออบเจ็กต์ที่เลือกเป็นตัวเลข: อยู่ตรงไหน หมุนและย่อขยายไว้อย่างไร และมีขนาดเท่าใด คุณพิมพ์ค่าที่แน่นอน รีเซ็ต หรือเบคค่าเหล่านี้ลงในเมชได้

![](/images/transform_overview.webp)

## ภาพรวม {#overview}

นอกจากจุดยอดแล้ว ออบเจ็กต์ทุกชิ้นยังมีโหนดที่เก็บการเลื่อนตำแหน่ง การหมุน และสเกลของมันไว้ (แมทริกซ์ของมัน) เครื่องมือ[กิซโม่](tools.md#gizmo)และ[ทรานส์ฟอร์ม](tools.md#transform)จะเปลี่ยนแมทริกซ์นี้เมื่อคุณลากในวิวพอร์ต ส่วนเมนูนี้ให้คุณอ่านค่าและพิมพ์ค่าแทนได้ ดู[โหนดและจุดยอด](tools.md#nodes-and-vertices)สำหรับความแตกต่างระหว่างการย้ายโหนดกับการย้ายจุดยอด

ลากค่าไปทางซ้ายหรือขวาเพื่อเปลี่ยน หรือแตะเพื่อพิมพ์ตัวเลข ค่า X, Y และ Z มีสีแดง เขียว และน้ำเงิน เหมือนแกนของกิซโม่

::: tip
การพิมพ์ค่าช่วยให้วางออบเจ็กต์ได้อย่างแม่นยำ เช่น วางชิ้นส่วนหลายชิ้นให้สูงเท่ากันพอดี หรือปรับการหมุนให้กลับเป็นตัวเลขกลมๆ หลังจากหมุนอิสระด้วยกิซโม่
:::

## แมทริกซ์ {#matrix}

หัวข้อจะบอกว่าค่าเหล่านี้อ้างอิงกับพื้นที่ใด: `โลคอล` (เทียบกับออบเจ็กต์แม่) หรือ `เวิลด์`

### ออบเจ็กต์และจุดหมุน {#object-pivot}

* `ออบเจ็กต์` - ค่าเป็นการแปลงของตัวออบเจ็กต์เอง
* `จุดหมุน` - ค่าจะควบคุมส่วนที่เลือกจาก[จุดหมุน](tools.md#pivot)ของมัน แบบเดียวกับที่จุดจับของกิซโม่ทำ: ทุกแถวแสดงศูนย์ และการเปลี่ยนค่าจะย้าย หมุน หรือย่อขยายส่วนที่เลือกรอบจุดหมุน เปิด `แก้ไข` (ไอคอนแม่กุญแจ) เพื่อย้ายจุดหมุนอย่างเดียว โดยออบเจ็กต์อยู่กับที่

### โลคอลและเวิลด์ {#local-world}

เมื่อออบเจ็กต์มีออบเจ็กต์แม่หรือออบเจ็กต์ลูก หรือเมื่อเลือกออบเจ็กต์ไว้หลายชิ้น คุณเลือกได้ว่าจะแสดงค่าในพื้นที่ใด: `โลคอล` (เทียบกับออบเจ็กต์แม่) หรือ `เวิลด์`

### การทำงาน {#actions}

| การทำงาน      | ไอคอน                         | คำอธิบาย |
| :-----------: | :---------------------------: | :---------- |
| ย้ายไปจุดกำเนิด | ![](/icons/target.webp)      | ย้ายออบเจ็กต์ไปที่จุดกำเนิดของเวิลด์ |
| เบค           | ![](/icons/bake.webp)        | นำแมทริกซ์ไปใช้กับจุดยอดแล้วรีเซ็ตแมทริกซ์ หน้าตาจะไม่เปลี่ยน แต่จุดกำเนิดของออบเจ็กต์จะกลายเป็นจุดกำเนิดของเวิลด์ |
| จุดหมุน       | ![](/icons/gizmo.webp)       | เบคจุดหมุนลงในออบเจ็กต์: จุดกำเนิดและการวางแนวของออบเจ็กต์จะกลายเป็นของจุดหมุน หน้าตาจะไม่เปลี่ยน |
| แก้ไข         | ![](/icons/lock.webp)        | (โหมด `จุดหมุน`) ย้ายจุดหมุนอย่างเดียว |
| รีเซ็ต        | ![](/icons/reset.webp)       | รีเซ็ตการแปลงกลับเป็นค่าเริ่มต้น (identity) ในโหมด `จุดหมุน` จะนำจุดหมุนกลับเข้าที่แทน |

เมื่อออบเจ็กต์ที่เลือกมีอินสแตนซ์ การเบคจะขอให้ยืนยันก่อน พร้อมตัวเลือก `ยกเลิกอินสแตนซ์`: การเบคจะเปลี่ยนจุดยอด ซึ่งอินสแตนซ์ใช้ร่วมกัน

### การเลื่อนตำแหน่ง, การหมุน, สเกล {#translation-rotation-scale}

ตำแหน่ง การหมุน (เป็นองศา) และสเกลของออบเจ็กต์ บนแกน X, Y และ Z ปุ่มสองปุ่มท้ายแต่ละแถวจะเบคเฉพาะส่วนนั้นของการแปลงลงในจุดยอด หรือรีเซ็ตส่วนนั้น

แถว `เฉือน` จะปรากฏขึ้นด้วยเมื่อออบเจ็กต์ถูกเฉือน เช่น หลังจากย่อขยายแบบไม่เท่ากันทุกแกนบนออบเจ็กต์แม่ที่ถูกหมุนไว้

### ทำให้เป็นขนาดเดียวกัน {#uniform-scale}

เมื่อเปิดใช้งาน สเกลจะเป็นค่าเดียว เท่ากันทั้งสามแกน ปิดตัวเลือกนี้เพื่อย่อขยาย X, Y และ Z แยกกัน

## มิติ {#dimension}

ขนาดและจุดศูนย์กลางของกรอบล้อมรอบส่วนที่เลือก ในหน่วยของเวิลด์ เมื่อเลือกออบเจ็กต์ไว้หลายชิ้น กรอบจะครอบคลุมทั้งหมด

* `ขนาด` - ความกว้าง ความสูง และความลึก เมื่อเปิดปุ่มลิงก์ การเปลี่ยนขนาดด้านหนึ่งจะย่อขยายอีกสองด้านในสัดส่วนเดียวกัน เพื่อคงสัดส่วนไว้
* `อยู่กึ่งกลาง` - จุดศูนย์กลางของกรอบล้อมรอบ ปุ่มเป้าหมายจะย้ายส่วนที่เลือกให้จุดศูนย์กลางอยู่ที่จุดกำเนิดของเวิลด์

::: tip
`ขนาด` เป็นวิธีที่เร็วที่สุดในการกำหนดขนาดจริงให้ออบเจ็กต์ เช่น ก่อนพิมพ์ 3d: ใส่ความสูงที่ต้องการ แล้วลิงก์จะคงสัดส่วนไว้ให้
:::
