# ![](/icons/camera.webp) กล้อง {#camera}

เมนูนี้ให้คุณสร้างและแก้ไขกล้อง รวมถึงควบคุมวิธีที่คุณโต้ตอบกับกล้อง

![](/images/camera_overview2.webp)

กล้องใน Nomad ใช้ได้หลายอย่าง:

* ตั้งมุมมองไว้สำหรับปั้นจากมุมที่แม่นยำ
* ใช้เหมือนกล้องถ่ายรูปเพื่อจัดเฟรมออบเจ็กต์ของคุณ
* ใช้เป็นกล้องมุมมองบุคคลที่หนึ่งเพื่อเดินสำรวจซีน
* ใช้เป็นกล้องออร์โทกราฟฟิกสำหรับเกมมุมมองไอโซเมตริก หรือการเร็นเดอร์แบบงานอุตสาหกรรม

## การควบคุมกล้อง {#control}

### การหมุน {#rotation}
คุณหมุนกล้องได้โดยลาก*หนึ่ง*นิ้วบนพื้นหลัง
ถ้าคุณลากนิ้วบนโมเดล จะเป็นการเริ่มปั้นแทน

::: tip หมุนกล้องได้ไหม ถ้าไม่มีพื้นหลังให้แตะ?
ได้ คุณวาง*สอง*นิ้วบนหน้าจอ เหมือนจะเริ่มท่าทางแพน/ซูม แล้วยก*หนึ่ง*นิ้วออก
:::

### โฟกัส / รีเซ็ต {#focus}
*แตะสองครั้ง*บนโมเดลเพื่อโฟกัสไปที่จุดที่แตะ
ถ้าคุณ*แตะสองครั้ง*บนพื้นหลัง กล้องจะโฟกัสไปที่เมชที่เลือกหรือทั้งซีนแทน ดู[แตะสองครั้งที่พื้นหลัง](#dtap-tap-background)


### การเลื่อนตำแหน่ง {#translation}
เลื่อน*สอง*นิ้วเพื่อแพนกล้อง


### การซูม {#zooming}
ใช้ท่าทางจีบนิ้วเพื่อซูมเข้า/ออก


### การเอียง {#rolling}
คุณ*เอียง*มุมมองได้โดยหมุน*สอง*นิ้ว
::: warning
ท่าทางนี้ใช้ได้เฉพาะโหมดการหมุนแบบ `แทร็กบอล` เท่านั้น
:::

### การควบคุมบนเดสก์ท็อป {#desktop}

บนเดสก์ท็อป ใช้ปุ่ม alt/opt เพื่อควบคุมกล้อง:

* ลากปลายปากกาในพื้นที่ว่าง = หมุนกล้อง
* alt+ลากปลายปากกา = แพน
* alt+ลากปลายปากกา แล้วปล่อย alt = ซูม (เหมือน zbrush)

สำหรับเมาส์ปากกา Wacom ที่มีปุ่มบนปากกาตั้งแต่ 2 ปุ่มขึ้นไป ให้ใช้การตั้งค่าของ Wacom กำหนดปลายปากกาและปุ่มต่างๆ ดังนี้:

* ปลายปากกา = คลิกซ้าย
* ปุ่มกดด้านล่าง = คลิกกลาง
* ปุ่มกดด้านบน = คลิกขวา

เมื่อตั้งค่าแบบนี้ คุณจะควบคุมกล้องได้ด้วยปากกาล้วนๆ:

* กดปุ่มด้านบนค้างแล้วเลื่อนปากกาลอยเหนือจอ = หมุนกล้อง
* กดปุ่มด้านล่างค้างแล้วเลื่อนปากกาลอยเหนือจอ = แพน

## ตัวควบคุมกล้อง {#camera-controls}

### มุมมอง {#views}
คุณบันทึกมุมมองของกล้องได้ด้วย `เพิ่มมุมมอง`
ถ้าคุณคลิกที่ชื่อมุมมอง กล้องจะกลับไปที่มุมมองนั้น


::: tip
มุมมองที่บันทึกไว้จะเก็บการตั้งค่า[ประเภทการฉายภาพ](#projection)และ[ภาพอ้างอิง](background.md)ไว้ด้วย  
มีประโยชน์เมื่อคุณอยากสลับไปมาระหว่างมุมมองอ้างอิงด้านหน้า/ซ้าย/หลังที่ใช้พื้นหลังต่างกัน
:::

### ![](/icons/camera_add.webp) เพิ่มมุมมอง {#add}
สร้างกล้องใหม่จากมุมมองปัจจุบัน

### ![](/icons/camera.webp) ไอคอน {#icons-test}

เปิด/ปิดการแสดงไอคอนกล้องในวิวพอร์ต ปุ่มนี้จะปรากฏข้าง `เพิ่มมุมมอง` เมื่อคุณมีกล้องแล้ว ถ้ามีกล้องถูกเลือกอยู่ ไอคอนของกล้องนั้นจะแสดงเสมอ

### ประเภทการฉายภาพ {#projection}
เลือกระหว่าง `เพอร์สเปกทีฟ` และ `ออร์โทกราฟฟิก`

ในแบบเพอร์สเปกทีฟ คุณเปลี่ยน `FoV แนวตั้ง` (มุมมองภาพ) ของกล้องได้ ทางยาวโฟกัสที่เทียบเท่ากับกล้อง 35mm จะแสดงอยู่เหนือแถบเลื่อน สะดวกถ้าคุณคุ้นเคยกับการถ่ายภาพ
โดยทั่วไปแนะนำให้ใช้ FOV ต่ำสำหรับการปั้น เพราะช่วยเรื่องสัดส่วน  
โหมด `ออร์โทกราฟฟิก` ก็คล้ายกับ FOV เท่ากับ 0

### บุคคลแรก {#fps}
เฉพาะแบบเพอร์สเปกทีฟ ตั้งให้จุดหมุนอยู่ที่ตัวกล้องเอง แทนที่จะอยู่บนงานปั้น การลากนิ้วบนพื้นหลังจะล็อกตำแหน่งกล้องไว้แต่เปลี่ยนการหมุน คล้ายกับเกมมุมมองบุคคลที่หนึ่ง มีประโยชน์เมื่อปั้นฉากสภาพแวดล้อมแทนที่จะเป็นออบเจ็กต์ชิ้นเดียว

![](/images/camera_rotation_ortho_view.webp)

### ประเภทการหมุน {#rotation-type}
โดยค่าเริ่มต้น กล้องใช้โหมดการหมุนแบบ `แท่นหมุน`
หมายความว่าคุณมีอิสระในการหมุนแค่สองทิศทาง ซึ่งใช้งานง่ายกว่า แต่บางครั้งคุณอาจต้องการความยืดหยุ่นมากขึ้น  
คุณสลับไปใช้ `แทร็กบอล` ได้ แล้วจะ*เอียง*มุมมองได้โดยหมุน*สอง*นิ้วบนวิวพอร์ต โหมด `แทร็กบอล` มีสองแบบ: แบบแรกหมุนมุมมองเหมือนลูกบอลใต้นิ้วของคุณ ส่วนแบบที่สอง (ไอคอนรูปลูกศร) หมุนมุมมองตามการเคลื่อนที่แนวนอนและแนวตั้งของการลาก ซึ่งผู้ใช้บางคนอาจคุ้นเคยมากกว่า

### สแนปแบบออร์โทกราฟฟิก {#orthographic}

เมื่อเปิดใช้งาน ถ้าคุณมีคีย์บอร์ด การกด shift ค้างไว้ขณะหมุนมุมมองจะสแนปกล้องไปที่มุมมองหน้า/หลัง/บน/ล่าง/ซ้าย/ขวาที่ใกล้ที่สุด และเปลี่ยนกล้องเป็นแบบออร์โทกราฟฟิก กล้องจะเป็นแบบออร์โทกราฟฟิกด้วยเมื่อคลิกที่ลูกบาศก์มุมมองเพื่อสแนปไปด้านหน้า/หลัง/ซ้าย/ขวา/บน/ล่าง

### รีเซ็ตมุมมอง {#reset}

ย้ายกล้องไปด้านหน้า และปรับให้ซีนพอดีกับมุมมอง

### มุมมองแบบสแนป {#snap}
สแนปไปที่มุมมองหน้า/หลัง/ซ้าย/ขวา/บน/ล่างที่ใกล้ที่สุด ถ้าคุณอยู่ในมุมมองเหล่านั้นอยู่แล้ว การคลิกอีกครั้งจะสแนปหมุน 180 องศาไปด้านตรงข้าม

### ความเร็ว {#speed}

ถ้าคุณรู้สึกว่ากล้องเคลื่อนที่ช้าหรือเร็วเกินไป คุณตั้งตัวคูณความเร็วสำหรับ `การหมุน` `การซูม` และ `การแพน` ได้ มีประโยชน์เมื่องานปั้นของคุณใหญ่หรือเล็กมาก

### ภาพรวมของจุดหมุน {#pivot}

เมื่อคุณหมุนกล้อง คุณจะเห็นจุดสีชมพูเล็กๆ นี่คือจุดหมุนของกล้อง  
การเข้าใจว่าจุดหมุนอยู่ตรงไหนสำคัญมาก จะได้ไม่หลงทางหรือหงุดหงิดกับกล้อง

โดยค่าเริ่มต้น จุดหมุนจะถูกอัปเดตด้วยการกระทำเหล่านี้:
- แตะสองครั้งบนโมเดล
- แตะสองครั้งบนพื้นหลัง (จุดหมุนใหม่จะอยู่ที่จุดศูนย์กลางของเมช)
- วาง*สอง*นิ้วบนหน้าจอ (แพน/ซูม/เอียง) จะอัปเดตจุดหมุนไปที่กึ่งกลางระหว่าง*สอง*นิ้ว

### อัปเดตจุดหมุน... {#update-pivot}

คุณปรับแต่งเพิ่มเติมได้ว่าจะให้อัปเดตจุดหมุนเมื่อใด ด้วยตัวเลือกเหล่านี้:

* `เมื่อกล้องเริ่มเคลื่อนที่` - อัปเดตจุดหมุนเมื่อคุณเริ่มโต้ตอบกับกล้อง
* `จุดหมุนลอย` - อนุญาตให้ตั้งจุดหมุนใหม่ได้แม้ตอนซูมอยู่นอกพื้นผิวของออบเจ็กต์ ต้องเปิด `เมื่อกล้องเริ่มเคลื่อนที่` ด้วย
* `อัพเดทเมื่อแตะสองครั้ง` - อัปเดตจุดหมุนของการหมุนเมื่อคุณแตะสองครั้งบนพื้นผิวของออบเจ็กต์
* `แกะสลัก (วาดเส้น)` - อัปเดตจุดหมุนเมื่อคุณปั้น

::: tip
เมื่อคุ้นแล้ว คุณซ่อนจุดสีชมพู (ตัวช่วยบอก) ได้ในเมนู[การตั้งค่า](settings.md)
:::

### กึ่งกลางมุมมองเมื่อซูมออก {#center-view-when-zooming-out}
เมื่อซูมออก กล้องจะไม่แพนไปด้านข้าง: มันจะถอยหลังอย่างเดียว มุมมองจึงยังอยู่ตรงกลาง

### แตะสองครั้งที่ออบเจ็กต์ {#dtap-object}
เมื่อเปิดใช้งาน การแตะสองครั้งบนออบเจ็กต์จะโฟกัสกล้องไปที่จุดที่แตะ

### แตะสองครั้งที่พื้นหลัง {#dtap-tap-background}
เมื่อเปิดใช้งาน การแตะสองครั้งบนพื้นหลังจะโฟกัสกล้องไปที่:
* `การเลือก` - ออบเจ็กต์ที่เลือก
* `ซีน` - ทั้งซีน
* `สลับ` - สลับระหว่างสองแบบนี้ทุกครั้งที่แตะสองครั้ง ตัวเลือก `สลับ` มีสองแบบ ต่างกันที่ว่าแบบไหนมาก่อน ตามที่ไอคอนแสดง
