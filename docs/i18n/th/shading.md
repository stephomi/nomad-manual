# ![](/icons/sun.webp) การแรเงา {#shading}

เมนูนี้ควบคุมโหมดการแรเงาที่ Nomad ใช้ คุณสมบัติของแสง สภาพแวดล้อมและ MatCap รวมถึงหมอก

![](/images/shading_overview.webp)



คุณเลือกโหมดการเร็นเดอร์ได้หลายแบบ:

| โหมด                        | ความหมาย                    | คำอธิบาย                                                     |
| :-------------------------: | :------------------------: | :-------------------------------------------------------------: |
| [ให้แสง (PBR)](#pbr)           | การเร็นเดอร์ตามหลักฟิสิกส์ (Physically Based Rendering) | แสง เงา สภาพแวดล้อม และความเป็นโลหะ/ความหยาบที่ลงสีไว้   |
| [MatCap](#matcap)           | Material Capture           | โหมดที่เร็วสำหรับการปั้น ใช้ GPU/CPU น้อยกว่า PBR        |
| [ไม่ให้แสง](#unlit)             | สีพื้นผิว              | แสดงเฉพาะสีพื้นผิว ไม่มีการแรเงาหรือแสง                  |
| [ออบเจ็กต์ ID](#object-id)     | ออบเจ็กต์ ID                  | สีแบบสุ่มต่อหนึ่งออบเจ็กต์ มีประโยชน์กับแอปวาดภาพ    |
| [อินสแตนซ์ ID](#instance-id) | อินสแตนซ์ ID                | สีแบบสุ่มต่อหนึ่งอินสแตนซ์ ช่วยให้ระบุเมชที่ใช้ร่วมกันได้   |

ถ้าต้องการเรียนรู้เพิ่มเติมเกี่ยวกับความเป็นโลหะและความหยาบ ดูได้ที่หัวข้อ[ลงสีจุดยอด](painting.md)

### ![](/icons/group_gray.webp) กลุ่มเฟส {#face-group}
แสดงสีของกลุ่มเฟสซ้อนทับบนโมเดล กลุ่มเฟสคือการเลือกโพลิกอนที่มีสีกำกับ ซึ่งสร้างได้ด้วยเครื่องมือ[กลุ่มเฟส](tools#facegroup) และรูปทรงพื้นฐานส่วนใหญ่ก็สร้างกลุ่มเฟสให้โดยอัตโนมัติ

เครื่องมือบางตัวจะกรองตามกลุ่มเฟสโดยอัตโนมัติเมื่อกลุ่มเฟสแสดงอยู่

### ![](/icons/palette.webp) แสดงการวาดลงสี {#show-paint}
Nomad เก็บสี ความหยาบ และความเป็นโลหะไว้ในจุดยอดของงานปั้นของคุณได้ คุณเปิดหรือปิดการแสดงคุณสมบัติเหล่านี้ทั้งหมดได้ด้วยช่องทำเครื่องหมายนี้

โปรดทราบว่าถ้าคุณมีทั้งคุณสมบัติของจุดยอดและเท็กซ์เจอร์ และเปิดใช้ทั้งสองอย่าง ค่าทั้งสองจะถูกนำมาคูณกัน

### ![](/icons/shield.webp) แสดงมาส์ก {#show-mask}
เปิดหรือปิดการแสดงมาส์กสีเทาของ[เครื่องมือมาส์ก](tools#mask) เมื่อปิดไว้ มาส์กจะถูกปิดใช้งานด้วย มีประโยชน์เวลาต้องการแก้ไขอะไรเร็วๆ โดยไม่มีมาส์ก แล้วค่อยเปิดกลับมาโดยที่มาส์กไม่หายไป

### ![](/icons/tool_hide.webp) ใช้ซ่อน {#use-hide}

เปิดหรือปิดเฟสที่ถูกซ่อน โปรดทราบว่าใช้ได้เฉพาะเมื่อคุณ*ไม่ได้*อยู่ในเครื่องมือซ่อนเท่านั้น!

### ![](/icons/image.webp) ใช้พื้นผิว {#use-textures}

Nomad ให้คุณกำหนดเท็กซ์เจอร์ให้ออบเจ็กต์ได้จากเมนู[วัสดุ](material) ถ้ามีการกำหนดเท็กซ์เจอร์ไว้ คุณเปิดหรือปิดทั้งหมดได้ด้วยช่องทำเครื่องหมายนี้

คุณสร้างหรือแก้ไขเท็กซ์เจอร์ใน Nomad ไม่ได้ แต่เท็กซ์เจอร์จากไฟล์ที่นำเข้าใช้งานได้ เท็กซ์เจอร์ความทึบใช้ได้ในโหมดให้แสง MatCap และไม่ให้แสง นอร์มอลแมปใช้ได้ในโหมดให้แสงและ MatCap สีใช้ได้ในโหมดให้แสงและไม่ให้แสง ส่วนความเรืองแสง ความหยาบ และความเป็นโลหะใช้ได้เฉพาะในโหมดให้แสง ปุ่มนี้จะเป็นสีเทาเมื่อซีนไม่มีเท็กซ์เจอร์

### ภาพรวม PBR และแสง {#pbr}
คู่มือนี้จะไม่ลงรายละเอียดเรื่องการเร็นเดอร์ตามหลักฟิสิกส์ (Physically Based Rendering)

สิ่งสำคัญที่ควรจำไว้คือ แสงและวัสดุแยกจากกันโดยสิ้นเชิง
หมายความว่าคุณลงสี ความหยาบ และความเป็นโลหะให้ออบเจ็กต์ได้ ในขณะที่แสงถูกจัดการแยกต่างหาก
คุณจึงลงสีออบเจ็กต์ก่อน แล้วค่อยปรับแสงทีหลังได้ โดยไม่ทำให้ภาพรวมของโมเดลเสีย

แสง สภาพแวดล้อม และหมอก ใช้ได้เฉพาะใน[โหมด PBR](#pbr)
ด้วยเหตุผลด้านประสิทธิภาพ คุณใช้แสงได้สูงสุด 4 ดวงบนมือถือ และ 6 ดวงบนเดสก์ท็อป

::: tip
คุณโหลดไฟล์ glTF ที่มีแสงมากกว่านั้นได้ และ Nomad จะเก็บแสงไว้ทั้งหมด
แต่ประสิทธิภาพอาจไม่ดีนัก
:::

::: tip
คุณจำลองแสงจำนวนมากได้ โดยทำให้ออบเจ็กต์ไม่รับแสงหรือเรืองแสง แล้วเปิด Global Illumination ในเมนู[โพสต์โปรเซส](postprocess)
:::

### ภาพรวมประเภทแสง {#light-types-overview}

ประเภทแสงที่รองรับในตอนนี้มีดังนี้:

| โหมด                        | คำอธิบาย                                             | ทอดเงาได้ |
| :-------------------------: | :-----------------------------------------------------: | :--------------: |
| [ทิศทาง](#directional) | แสงอาทิตย์ที่อยู่ไกลออกไปไม่สิ้นสุด                           | ได้              |
| [สภาพแวดล้อม](#env-light)   | แสงที่อยู่ไกลซึ่งปรับให้ตรงกับ HDR ของสภาพแวดล้อม  | ได้              |
| [สปอต](#spot)               | แสงรูปกรวย                                      | ได้              |
| [จุด](#point)             | แสงจากจุดเดียวที่ส่องไปทุกทิศทาง                         | ได้              |

#### ![](/icons/sun.webp) ทิศทาง {#directional}
เปล่งแสงจากระยะไกลไม่สิ้นสุด ด้วยความเข้มที่สม่ำเสมอ
ตำแหน่ง 3d ของแสงในซีนไม่มีผล มีแค่ทิศทางเท่านั้นที่สำคัญ

คุณผูกแสงนี้ไว้กับกล้องได้ เพื่อให้แสงสม่ำเสมอเสมอ  
เช่น ใช้ทำแสงขอบ (rim light คือแสงจ้าที่ส่องมาจากด้านหลังโมเดล หันเข้าหากล้อง) ที่ส่องด้านหลังโมเดลของคุณอยู่ตลอด

#### ![](/icons/panorama.webp) แสงสภาพแวดล้อม {#env-light}
การใช้ [HDR ของสภาพแวดล้อม](#environment) ให้แสงนุ่มโดยรวมได้ดี แต่ถ้าใน HDR มีแสงจ้าที่คมชัด เงาที่เกิดจากแสงนั้นจะนุ่มมาก จนบ่อยครั้งแทบมองไม่เห็นเลย การใช้แสงทิศทางร่วมกับ HDR ของสภาพแวดล้อมช่วยได้ แต่ก็อาจจัดให้ตรงกันได้ยาก

แสงนี้ทำงานส่วนนั้นให้คุณ แสงจะหมุนให้ตรงกับส่วนที่สว่างที่สุดของ HDR โดยอัตโนมัติ แล้วคุณก็ควบคุมความเข้มและมุม (ความนุ่มของเงา) แยกกันได้ 

#### ![](/icons/spotlight.webp) สปอต {#spot}
แสงสปอตเปล่งแสงไปในทิศทางเดียว โดยจำกัดอยู่ในรูปกรวย

#### ![](/icons/light.webp) จุด {#point}
แสงจุดเปล่งแสงไปทุกทิศทาง และทอดเงาได้ด้วย

#### เงา {#shadows}
แสงทุกดวงทอดเงาได้ และคุณเลือกวิธีคำนวณเงาได้ใน[การตั้งค่า](#light-extra-controls)ของแสงนั้น ถ้าเห็นรอยผิดปกติของเงา ตัวเลื่อน `เกณฑ์การยอมรับ` ในส่วนนั้นช่วยได้

คุณภาพของเงาขึ้นอยู่กับขนาดของออบเจ็กต์เมื่อเทียบกับทั้งซีน  
ถ้าในซีนมีออบเจ็กต์ใหญ่ที่ไม่จำเป็นต้องทอดเงา (เช่น ระนาบขนาดใหญ่) อย่าลืมปิดการทอดเงาใน[การตั้งค่าวัสดุ](material.md#casts-shadows)ของมัน

### เพิ่มแสง {#add-light}

เพิ่มแสงเข้าไปในซีน ได้สูงสุด 4 ดวงบนมือถือ และ 6 ดวงบนเดสก์ท็อป เมื่อเพิ่มแสงแล้ว รายการแสงจะแสดงขึ้นพร้อมปุ่มต่างๆ และจะมีแถบเครื่องมือแสงเพิ่มขึ้นที่ด้านบนของวิวพอร์ต

![](/images/shading_lights_icons.webp)

* ข้อความแสดงชื่อและความสว่างของแสง แตะเพื่อเลือกแสงนั้น
* ไอคอนรูปตาใช้เปิดหรือปิดการมองเห็น
* ไอคอนรูปดินสอใช้เปลี่ยนชื่อแสง
* ไอคอนรูปถังขยะใช้ลบแสง
* ไอคอนคัดลอกใช้ทำสำเนาแสง 
* ไอคอนจุด 3 จุดจะเปิดตัวแก้ไขแสงแบบเต็ม ฟังก์ชันส่วนใหญ่ในนี้ใช้ได้จากแถบเครื่องมือที่ปรากฏในวิวพอร์ตด้วย 

คุณยังลากแสงในรายการเพื่อจัดลำดับใหม่ได้

### ![](/icons/spotlight.webp)  ไอคอน {#icons}

เปิดหรือปิดการแสดงไอคอนแสงในวิวพอร์ต

### แถบเครื่องมือแสง {#light-toolbar}
![](/images/shading_lights_toolbar.webp) 

แถบเครื่องมือนี้จะปรากฏที่ด้านบนของวิวพอร์ตเมื่อเลือกแสง

* `ที่เห็นได้` ใช้เปิดหรือปิดการมองเห็นของแสง
* ทิศทาง/สภาพแวดล้อม/สปอต/จุด ใช้เปลี่ยนประเภทแสง แตะเพื่อวนเปลี่ยน หรือกดค้างเพื่อดูเมนู
* ความเข้มควบคุมความแรงของแสง ค่าเกิน 1.0 ได้สำหรับแสงที่จ้ามาก ซึ่งมีประโยชน์เมื่อใช้ร่วมกับ Global Illumination ในโพสต์โปรเซส
* เมื่อแตะช่องสี จะเปิดตัวเลือกสีขึ้นมา Nomad มีหลายวิธีให้เลือกสี การควบคุมแบบเคลวินเป็นวิธีที่เป็นธรรมชาติในการเลือกแสงโทนอุ่นหรือโทนเย็น
* เงาใช้เปิดหรือปิดเงา
* มุม (_ทิศทางและสภาพแวดล้อม_) หรือขนาด (_สปอตและจุด_) กำหนดความกว้างของแสง แสงที่กว้างกว่าจะให้เงานุ่ม แสงนุ่ม และไฮไลต์บนออบเจ็กต์ที่นุ่มกว่า
* การผนวก (_เฉพาะทิศทาง_) มุมกรวยและความนุ่ม (_เฉพาะสปอต_) อธิบายไว้ใน[ตัวแก้ไขแสง](#light-extra-controls)ด้านล่าง
* ... จะเปิด `โคลนนิ่ง`, `รีเซ็นเตอร์` และ `ลบ` พร้อมกับการตั้งค่าเงา

### ตัวควบคุมเพิ่มเติมของแสง {#light-extra-controls}

![](/images/shading_extra_controls.webp) 

ไอคอนจุด 3 จุดของแสงในรายการจะเปิดตัวแก้ไขแบบเต็มของแสงนั้น โปรดทราบว่าบางตัวเลือกใช้ได้เฉพาะกับแสงบางประเภท

* `ทิศทาง/สภาพแวดล้อม/สปอต/จุด` ให้คุณเปลี่ยนประเภทแสง
* เมื่อแตะ `ช่องสี` จะเปิดตัวเลือกสีขึ้นมา 
* `ความเข้ม` ควบคุมความแรงของแสง
* `การผนวก` (_เฉพาะทิศทาง_) กำหนดให้แสงผูกอยู่กับโลก (`อยู่กับที่`) หรือผูกอยู่กับกล้อง (`กล้อง`) เช่น ถ้าคุณใช้แสงทิศทางไว้ด้านหลังตัวละครเป็นแสงขอบ เมื่อเลือกผูกกับกล้อง แสงจะอยู่ด้านหลังตัวละครเสมอแม้จะหมุนกล้อง
* `ความนุ่ม` (_เฉพาะสปอต_) ควบคุมความคมของขอบกรวยแสงสปอต 0 คือขอบที่คมมาก 1 คือนุ่มมาก โดยไล่ระดับเข้าหาตรงกลางของกรวยแสง ในวิวพอร์ต คุณใช้จุดสีฟ้าเล็กๆ บนกรวยแสงสปอตเพื่อปรับความนุ่มได้โดยตรง
* `มุมกรวย` (_เฉพาะสปอต_) ควบคุมมุมการกระจายของแสงสปอต มุมเล็กคือลำแสงที่แคบมาก 170 คือแสงที่กระจายกว้างมาก ในวิวพอร์ต คุณใช้จุดสีส้มเพื่อปรับมุมกรวยได้โดยตรง
* `มุม` (_เฉพาะทิศทางและสภาพแวดล้อม_) คือขนาดที่ปรากฏของแสง ลองนึกว่าดวงอาทิตย์ดูใหญ่แค่ไหนบนท้องฟ้า มุมที่ใหญ่ขึ้นจะให้เงาที่นุ่มขึ้นและไฮไลต์ที่กว้างขึ้น
* `ขนาด` (_เฉพาะสปอตและจุด_) คือความกว้างของแสง แสงที่ใหญ่ขึ้นจะให้เงาที่นุ่มขึ้น
* `เงา` ใช้เปิดหรือปิดเงาของแสงปัจจุบัน
* ชนิดของเงากำหนดวิธีคำนวณเงา `แผนที่เงา` จะเร็นเดอร์ซีนจากมุมของแสง จึงสร้างเงาให้รูปทรงที่กล้องมองไม่เห็นได้ด้วย `พื้นที่หน้าจอ` ใช้เฉพาะสิ่งที่มองเห็นบนหน้าจออยู่แล้ว ใช้ทรัพยากรน้อยกว่าแต่ยังอยู่ในขั้นทดลอง โดยทั่วไปแผนที่เงาจะเชื่อถือได้มากกว่า
* `เกณฑ์การยอมรับ` (_เฉพาะพื้นที่หน้าจอ_): ถ้าเห็นรอยผิดปกติของเงา (เงาดูไม่แนบกับพื้นผิว หรือมีนอยส์และลวดลายในเงา) การปรับค่านี้ช่วยแก้ปัญหาได้
* `สัมผัส` เพิ่มเงาที่แม่นยำขึ้นในระยะสั้นๆ ตรงที่ออบเจ็กต์สัมผัสกัน เมื่อเป็น `อัตโนมัติ` จะมีเพียงแสงที่เด่นที่สุดในซีนที่ได้เงาสัมผัส ส่วน `ไม่` และ `ใช่` จะบังคับปิดหรือเปิดสำหรับแสงนี้ ตัวเลื่อน `เกณฑ์การยอมรับ` ของมันทำงานเหมือนตัวด้านบน

ปุ่ม `...` ของแถบเครื่องมือในวิวพอร์ตมีการตั้งค่าเงาชุดเดียวกัน พร้อมกับ:

* `โคลนนิ่ง` ใช้ทำสำเนาแสง
* `รีเซ็นเตอร์` ย้ายแสงมาไว้ด้านหน้ากล้อง โดยคงทิศทางเดิมไว้
* `ลบ` ใช้ลบแสง


## ![](/icons/panorama.webp) สภาพแวดล้อม {#environment}

![](/images/shading_environment.webp)

แสงในโลกจริงมาจากทุกทิศทาง ทั้งสีฟ้าของท้องฟ้า สีเขียวของหญ้า สีแดงของตึก แสงทั้งหมดจาก 'สภาพแวดล้อม' นี้จำลองได้ด้วยแมปสภาพแวดล้อม 

ใช้ช่องทำเครื่องหมายข้างชื่อหัวข้อเพื่อเปิดหรือปิดแสงจากสภาพแวดล้อม

Nomad มีแมปสภาพแวดล้อมตัวอย่างหลายแบบทั้งในอาคารและกลางแจ้ง ซึ่งมีโทนสีและระดับความสว่างต่างกัน ลองใช้หลายๆ แมปเพื่อดูว่าแบบไหนดึงรายละเอียดของงานปั้นออกมาได้ดีที่สุด

แตะที่ภาพเพื่อดูแมปสภาพแวดล้อมที่มีให้เลือก ในหน้าต่างนั้นให้เลือก `นำเข้า...` เพื่อโหลดแมปของคุณเอง ควรใช้ภาพ High Dynamic Range (HDR) ในรูปแบบ latlong หรือ equirectangular เป็นไฟล์ .hdr หรือ .exr เบราว์เซอร์ยังดาวน์โหลดสภาพแวดล้อมได้โดยตรงจาก [Poly Haven](https://polyhaven.com/hdris) ซึ่งมีแมปสภาพแวดล้อมฟรีให้เลือกมากมาย

### การเปิดรับแสง {#env-exposure}
ปรับความสว่างของแมปสภาพแวดล้อม บ่อยครั้งแมปจะสว่างเกินไปเมื่อใช้ร่วมกับแสงปกติ การลดการเปิดรับแสงช่วยให้สมดุลขึ้น โดยเฉพาะเมื่อใช้ร่วมกับ Global Illumination ในการตั้งค่า[โพสต์โปรเซส](postprocess)

### การหมุน {#env-rotation}

เนื่องจากแมปสภาพแวดล้อมเก็บแสงจากทุกทิศทาง คุณจึงหมุนมันเพื่อให้แสงสะท้อนและแสงโดยรวมเข้ากับงานปั้นของคุณได้ คุณยังหมุนสภาพแวดล้อมได้ด้วยการลาก 3 นิ้วในแนวนอนบนวิวพอร์ต

### ติดกับกล้อง {#env-attached}
ผูกสภาพแวดล้อมไว้กับกล้อง

จะทำให้แสงคงที่เสมอ ซึ่งมีประโยชน์ระหว่างการปั้น

### เบลอ (พื้นหลัง) {#env-background-blur}
ตัวเลื่อนนี้จะแสดงเฉพาะเมื่อตั้ง[พื้นหลัง](background.md)เป็นสภาพแวดล้อม จะเบลอภาพสภาพแวดล้อมที่อยู่ด้านหลังโมเดล โดยไม่เปลี่ยนแสง


## ![](/icons/fog.webp) หมอก {#fog}

หมอกเพิ่มมิติความลึกของบรรยากาศให้ซีน และทำให้มองเห็นลำแสงได้ เปิดใช้ด้วยช่องทำเครื่องหมายข้างชื่อหัวข้อ เช่นเดียวกับแสงและสภาพแวดล้อม หมอกใช้ได้เฉพาะในโหมด[ให้แสง (PBR)](#pbr)

::: tip ลำแสงที่ชัดขึ้น
ลด `สภาพแวดล้อม` ของหมอก แล้วใช้แสงสปอตหรือแสงจุดที่สว่าง เพิ่ม `ความหนาแน่น` จนมองเห็นหมอกได้ชัด ถ้าต้องการเห็นลำแสงในหมอกที่บางกว่า ให้ตั้ง `ทิศทางการกระเจิง` เป็นค่าบวกสูงๆ แล้วหันกล้องเข้าหาแสง
:::

### คัลเลอร์ {#fog-color}
สีของหมอกและของแสงที่หมอกกระเจิงออกไป

### ความหนาแน่น {#fog-density}
หมอกจะหนาขึ้นเร็วแค่ไหนตามระยะทาง

### ความทึบสูงสุด {#fog-opacity}
จำกัดว่าหมอกจะบังซีนได้มากแค่ไหน แม้ความหนาแน่นจะสูงก็ตาม

### ทิศทางการกระเจิง {#fog-scattering}
ทิศทางที่หมอกกระเจิงแสง (เรียกอีกอย่างว่า anisotropy) ค่าบวกจะทำให้หมอกสว่างขึ้นเมื่อคุณมองเข้าหาแสง ค่าลบจะสว่างขึ้นเมื่อคุณมองออกจากแสง และค่าศูนย์จะกระเจิงแสงเท่ากันทุกทิศทาง

### ![](/icons/panorama.webp) สภาพแวดล้อม {#fog-environment}
[สภาพแวดล้อม](#environment)ให้แสงกับหมอกมากแค่ไหน จะเป็นสีเทาเมื่อปิดสภาพแวดล้อมอยู่

### นอยส์ {#fog-noise}
ผสมนอยส์เข้าไปในหมอกเพื่อให้แตกเป็นหย่อมๆ โดยไม่เปลี่ยนความหนาแน่นโดยรวม เมื่อนอยส์มากกว่า 0 จะมีตัวเลื่อน `ขนาด` สำหรับกำหนดขนาดของลวดลาย

### รูปทรง {#fog-shape}
หมอกจะเติมเต็มซีนตรงไหน:

* `สม่ำเสมอ` - เติมเต็มทั้งซีน
* `แนวตั้ง` - ให้หมอกอยู่ในแถบแนวตั้งที่ขอบนุ่ม ตัวเลื่อน `ด้านล่าง` และ `ด้านบน` กำหนดความสูงของขอบล่างและขอบบน และปุ่มรูปตาของตัวเลื่อนจะแสดงแถบนี้ในวิวพอร์ตขณะที่คุณปรับ


## ![](/icons/sphere_smooth.webp) MatCap {#matcap}

![](/images/shading_matcap.webp)

ตามชื่อ (MATerial CAPture) MatCap จัดการทั้งข้อมูลแสงและวัสดุไว้ในภาพเดียว
เนื่องจากตัววัสดุอยู่ใน MatCap แล้ว ช่องการลงสีความหยาบและความเป็นโลหะจึงถูกละเลย
สีที่ลงจะถูกคูณกับ MatCap หมายความว่าถ้าคุณใช้ MatCap สีดำหรือสีเทา การลงสีขาวก็ไม่ได้ทำให้สว่างขึ้น

ศิลปินมักชอบใช้โหมดนี้ในการปั้น เพราะช่วยให้โฟกัสที่รูปทรงและเรขาคณิตได้เต็มที่

แตะที่ทรงกลมเพื่อเปิดเบราว์เซอร์ภาพ คุณเพิ่ม MatCap ของตัวเองได้ด้วย โดยทั่วไปใช้ได้ทั้งภาพถ่าย ภาพเร็นเดอร์ หรือแม้แต่ภาพวาดของทรงกลมที่ครอปให้พอดีเป็นสี่เหลี่ยมจัตุรัส มีคลัง MatCap ให้เลือกมากมายทางออนไลน์ แหล่งที่มีประโยชน์คือ [คลัง MatCap ของ nidorx](https://github.com/nidorx/matcaps)

### ใช้ MatCap ทั้งหมด {#matcap-global}

โดยปกติศิลปินจะใช้ MatCap เดียวกับงานปั้นทั้งชิ้น แต่ถ้าปิดตัวเลือกนี้ ออบเจ็กต์ที่เลือกจะมี MatCap ของตัวเองได้ ใช้เชิงศิลปะเพื่อให้ได้ผลลัพธ์ที่โดดเด่นได้

::: tip
ปิดตัวเลือกนี้ แล้วใช้ภาพลูกตาเป็น MatCap สำหรับดวงตาของตัวละคร!
:::

### การหมุน {#matcap-rotation}
MatCap เป็นแมปสภาพแวดล้อมรูปแบบหนึ่ง จึงหมุนได้เหมือนแมปสภาพแวดล้อม คุณยังหมุนได้ทุกเมื่อในวิวพอร์ตด้วยการลาก 3 นิ้วไปทางซ้ายและขวา

ปุ่มรูปกุญแจข้างตัวเลื่อนจะล็อกการหมุน เพื่อไม่ให้การลาก 3 นิ้วหมุน MatCap โดยไม่ตั้งใจ



## ![](/icons/circle_fill.webp) ไม่ให้แสง {#unlit}

โหมดนี้จะแสดงเฉพาะสีพื้นผิว มีประโยชน์สำหรับตรวจว่าสีพื้นผิวของออบเจ็กต์เป็นไปตามที่คาดไว้หรือไม่ โดยไม่ถูกแสง เงา แสงสะท้อน หรือความโปร่งใสรบกวน 

โหมดนี้ยังใช้กับการเร็นเดอร์แบบไม่สมจริงได้ เพื่อให้ได้ลุคแบนๆ แบบการ์ตูน

## ![](/icons/cube.webp) ออบเจ็กต์ ID {#object-id}

ข้อมูลแสงและพื้นผิวทั้งหมดจะถูกละเลย และแต่ละออบเจ็กต์จะถูกแรเงาด้วยสีแบนที่ไม่ซ้ำกัน ถ้าเร็นเดอร์ภาพนี้คู่กับภาพเร็นเดอร์ PBR คุณจะใช้ภาพนี้ในโปรแกรมวาดภาพเพื่อเลือกตามสี แล้วปรับแก้สีเฉพาะออบเจ็กต์ได้

โปรดทราบว่าสีเหล่านี้จะปรากฏใน[มุมมองแบบต้นไม้ของเมนูซีน](scene#tree-view)ด้วย
