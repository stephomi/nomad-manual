# ![](/icons/history.webp) 履歴 {#history}
![](/images/history_overview.webp)

多くの制作ツールと同じように、Nomad ではすべての編集を取り消し／やり直しできます。
履歴はかなり大きくなることがあるので、メモリに置いておく量、ストレージに保存しておく量、そしてプロジェクトと一緒に保存するかどうかを自分で決められます。

::: tip
ジェスチャーですばやく取り消し／やり直しができます。
- 2 本指でタップすると取り消し
- 3 本指でタップするとやり直し
:::

## ![](/icons/history.webp) 履歴 {#history-panel}
![](/images/history_history.webp)

このパネルには履歴のスタックが表示されます。ステップ番号、操作名、その操作を適用したオブジェクト、そしてそのステップが使っているメモリ量がわかります。

項目をタップすると、その状態まで戻る（または進む）ことができます。項目を長押しすると、その項目とそれより古い履歴をすべて完全に削除します。スカルプトの出来に満足したら、手早くメモリを空けるのに便利です。

### ![](/icons/speed.webp) 再生 {#replay}
左下の再生ボタンを押すと、最初の状態まで巻き戻してから操作を 1 つずつやり直していきます。スカルプトができあがっていく様子を眺められる、ちょっと楽しい機能です。スライダーで速度（1 秒あたりの操作数）を設定します。もう一度ボタンをタップすると停止します。取り消し／やり直しや、項目のタップでも停止します。

開始する前に、ポップアップで次の項目を選べます。
* `逆再生` - 最初からやり直すのではなく、現在の状態から最初の状態まで取り消していきます。
* `カメラを復元` - [カメラを復元](#restore-camera)がオフになっていても、カメラが再生中の操作に合わせて動きます。
* `カメラのスムージング` - カメラが視点から視点へ飛ぶのではなく、なめらかに移動します。値を大きくするほど、カメラの動きが穏やかになります。

::: warning
再生は実験的な機能です。
:::

## アクションを含める {#include-actions}

履歴パネルの下部にあるアイコンで、どの種類の編集を履歴に記録するかを選びます。

| アクション     | アイコン                      | 説明                                                                                |
| :---------- | :---------------------------: | :---------------------------------------------------------------------------------- |
| ライト      | ![](/icons/light.webp)        | ライトの編集。Gizmo でライトを動かす操作は、シーン階層の他のオブジェクトに影響することがあるため、常に記録されます |
| シェーディング | ![](/icons/sun.webp)          | PBR、MatCap、Unlit モードの切り替えと、MatCap や HDRI の変更                       |
| ポストプロセス | ![](/icons/postprocess.webp)  | ポストプロセスの編集                                                                |
| 選択内容    | ![](/icons/tool_lattice.webp) | ラティスの選択の編集（クリック、投げ縄での選択、選択解除など）                     |

## 設定 {#settings}
![](/images/history_settings.webp)

### ![](/icons/camera.webp) カメラを復元 {#restore-camera}
操作ごとに、カメラの視点が保存されています。
このオプションを有効にすると、操作を取り消したりやり直したりしたときに、カメラが保存された視点に戻ります。

### ![](/icons/history.webp) 履歴を保存 {#save-history}
プロジェクトを保存するときに取り消し履歴も残すので、プロジェクトを開き直しても履歴が使えます。プロジェクトファイルを小さくしたい場合はオフにしてください。

### ![](/icons/ram.webp) RAM上限 {#history-limit-mb}
RAM に置いておく履歴の最大量です。古い状態はストレージに移され、必要になったときに再び読み込まれます。削除されるわけではありません。

### ![](/icons/save.webp) ストレージ上限 {#storage-limit}
このプロジェクトの履歴が使うストレージの最大量です。上限に達すると、いちばん古い操作から完全に削除されます。

::: tip
新しい上限は、次の編集、取り消し、やり直しのあとに反映されます。
:::

### ![](/icons/undo.webp) 取り消しの警告 {#maximum-undoable}
一度にこの数より多くの操作をさかのぼろうとすると、先に確認を求められます。そこから編集を加えると、その時点より後の操作はすべて失われるので、リストのずっと下の項目をうっかりタップしてしまったときの保険になります。
