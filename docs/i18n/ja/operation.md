# ![](/icons/operation.webp) 操作 {#operation}

このメニューでは、選択中のオブジェクトの表面全体に一度に処理を適用します。スムーズ、リラックス、ポリッシュ、膨張、カラーの調整、ペイントやマスクのぼかし・シャープ化ができます。

![](/images/operation_overview.webp)

## 概要 {#overview}

ブラシはストロークした場所にだけ作用しますが、操作は選択中のオブジェクトのすべての頂点にまとめて作用します。タイトルにはオブジェクトの名前が表示され、複数選択している場合はオブジェクトの数が表示されます。

各操作はスライダーになっています。右にドラッグすると強く、左にドラッグすると弱く適用されます（両側に矢印があるスライダーでは、左にドラッグすると逆の操作になります）。スライダーは指を離すと 0 に戻り、1 回のドラッグが[履歴](history.md)の 1 ステップになるので、少しずつ何度も適用できます。

::: tip
ボクセルリメッシュやブーリアンのあとに、メッシュ全体をさっと整えるのに便利です。少しの `リラックス` で三角形が均一になり、少しの `スムーズ` でノイズが消えます。ブラシで 1 か所ずつ探して直す必要はありません。
:::

## フィルター {#filters}

上部のボタンで、操作を適用する範囲を制限できます。

* `マスク` - マスクされた部分は変更されません。
* `隠す` - 非表示の部分は変更されません。
* `オフセット` - （[レイヤー](layers.md)を選択しているとき）アクティブなレイヤーにスカルプトが入っている部分だけが影響を受けます。ほかの部分には触れずに、レイヤーの内容だけをスムーズにしたり膨らませたりできます。

## スムージング {#smoothing}

* `ボリュームを保持` - 表面を縮ませずにスムーズにします。歯車ボタンに、そのための `収縮` と `膨張` の量があります。
* `境界を保持する` - メッシュの境界（穴の縁）にある頂点は動きません。
* `安定したスムージング` - スムージングがトポロジーに左右されにくくなるようにします。ポリゴンの密度が場所によって大きく異なる場合に特に効果的です。
* `スムーズ` - 表面をなめらかにします。左にドラッグすると、逆に `シャープ` になります。
* ![](/icons/group.webp) `スムーズ` - [フェースグループ](tools.md#facegroup)同士の境界をなめらかにし、ギザギザしたグループの輪郭をまっすぐにします。左にドラッグするとシャープになります。
* `リラックス` - 形を保ったまま、ポリゴンを均一にします。
* ![](/icons/group.webp) `リラックス` - フェースグループの境界に沿ってポリゴンをリラックスさせます。
* `コーナーを保持` - フェースグループの `スムーズ` と `リラックス` で、この角度より大きく曲がる箇所では境界が固定されます。辺はなめらかになりつつ、角はシャープなまま残ります。チェックボックスでオンにします。

## ポリッシュ {#polish}

[ポリッシュ](tools.md#polish)ツールと同じように、表面をきれいな平面の集まりにします。`角度` は、どの面をまとめて平らにするかを決めます。この角度より曲がりの小さい面同士が 1 つの平面になります。角度を小さくすると、折り目が多く残り、平面も小さくなります。

## 膨張 {#inflate}

表面を法線に沿って外側に押し出します。左にドラッグすると内側に押し込みます。`法線 (リラックス)` は同時にポリゴンをリラックスさせて、引き伸ばされないようにします。オフにするにはチェックボックスを使います。

## カラーの調整 {#color-adjustments}

調整するチャンネルを `カラー`、`粗さ`、`メタリック`、`不透明度`、`密度`（オブジェクトにある場合は、[クワッドリメッシュ](tools.md#quad-remesher)の密度ペイント）、`マスク` から選び、次の項目を調整します。

* `露出` - 値を明るく、または暗くします。
* `彩度` - （`カラー` のみ）色の鮮やかさを上げ下げします。
* `コントラスト` - 値の差を広げたり、縮めたりします。
* `色調` - カラーホイール上で色をずらします。

## ブラー {#blur}

選択したチャンネルを表面全体でぼかします。`カラー`、`粗さ`、`メタリック`、`不透明度`、`密度`、`マスク` を切り替えてから、`ブラー` をドラッグします。左にドラッグすると、逆に `シャープ` になります。

マスクについては、[マスク](tools.md#mask)ツールの `ブラー` スライダーと同じです。ここでは、ペイントのチャンネルもぼかせます。
