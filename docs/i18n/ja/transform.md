# ![](/icons/transform.webp) トランスフォーム {#transform}

このメニューでは、選択中のオブジェクトのトランスフォームを数値で確認できます。位置、回転、スケール、そしてサイズです。正確な値を入力したり、リセットしたり、メッシュにベイクしたりできます。

![](/images/transform_overview.webp)

## 概要 {#overview}

すべてのオブジェクトは、頂点とは別に、移動・回転・スケール（つまりマトリクス）を記録するノードを持っています。[Gizmo](tools.md#gizmo) ツールや[トランスフォーム](tools.md#transform)ツールでビューポートをドラッグすると、このマトリクスが変わります。このメニューでは、その値を読み取ったり、直接入力したりできます。ノードを動かすことと頂点を動かすことの違いは、[ノードと頂点](tools.md#nodes-and-vertices)を参照してください。

値を左右にドラッグすると変更でき、タップすると数値を入力できます。X、Y、Z の値は、Gizmo の軸と同じく赤、緑、青で色分けされています。

::: tip
数値入力は、オブジェクトを正確に配置したいときに便利です。たとえば、複数のパーツをぴったり同じ高さに揃えたり、Gizmo で自由に回転させたあとに角度をきりのいい数値に戻したりできます。
:::

## マトリクス {#matrix}

タイトルには、値がどの空間で表されているかが表示されます。`ローカル`（親オブジェクトに対する相対値）か `ワールド` です。

### オブジェクトと回転軸 {#object-pivot}

* `オブジェクト` - オブジェクト自体のトランスフォームの値です。
* `回転軸` - Gizmo のハンドルと同じように、選択範囲をその[ピボット](tools.md#pivot)から操作します。各行は 0 と表示され、値を変えるとピボットを中心に選択範囲が移動・回転・スケールします。`編集`（鍵アイコン）をオンにすると、オブジェクトは動かさずにピボットだけを移動できます。

### ローカルとワールド {#local-world}

オブジェクトに親や子がある場合や、複数のオブジェクトを選択している場合は、値を表示する空間を選べます。`ローカル`（親に対する相対値）か `ワールド` です。

### 操作 {#actions}

| 操作          | アイコン                      | 説明 |
| :-----------: | :---------------------------: | :---------- |
| 原点に移動    | ![](/icons/target.webp)      | オブジェクトをワールドの原点に移動します。 |
| ベイク        | ![](/icons/bake.webp)        | マトリクスを頂点に適用し、マトリクスをリセットします。見た目は何も変わりませんが、オブジェクトの原点はワールドの原点になります。 |
| 回転軸        | ![](/icons/gizmo.webp)       | ピボットをオブジェクトにベイクします。オブジェクトの原点と向きがピボットのものになります。見た目は何も変わりません。 |
| 編集          | ![](/icons/lock.webp)        | （`回転軸` モード）ピボットだけを移動します。 |
| リセット      | ![](/icons/reset.webp)       | トランスフォームを初期状態（単位行列）に戻します。`回転軸` モードでは、代わりにピボットを元の位置に戻します。 |

選択中のオブジェクトにインスタンスがある場合、ベイクの前に確認が表示され、`インスタンスを解除` を選ぶこともできます。ベイクは頂点を変更しますが、頂点はインスタンス同士で共有されているためです。

### 平行移動、回転、スケール {#translation-rotation-scale}

オブジェクトの X、Y、Z における位置、回転（度単位）、スケールです。各行の末尾にある 2 つのボタンで、トランスフォームのその部分だけを頂点にベイクしたり、リセットしたりできます。

オブジェクトが歪んでいる場合（たとえば、回転した親を不均一にスケールしたあと）には、`シアー` の行も表示されます。

### 均一スケール {#uniform-scale}

オンにすると、スケールは 3 つの軸すべてで同じ 1 つの値になります。オフにすると、X、Y、Z を個別にスケールできます。

## 寸法 {#dimension}

選択範囲のバウンディングボックスのサイズと中心を、ワールド単位で表示します。複数のオブジェクトを選択している場合は、そのすべてを囲むボックスになります。

* `サイズ` - 幅、高さ、奥行きです。リンクボタンがオンのときは、1 つのサイズを変えると残りの 2 つも同じ比率で変わり、プロポーションが保たれます。
* `中央揃え` - バウンディングボックスの中心です。ターゲットボタンを押すと、選択範囲の中心がワールドの原点に来るように移動します。

::: tip
`サイズ` は、オブジェクトに実際の寸法を与えるいちばん手軽な方法です。たとえば 3d プリントの前に、欲しい高さを入力すれば、リンクによってプロポーションが保たれます。
:::
