## Nomad へようこそ！ {#welcome-to-nomad}

Nomad はさまざまなデバイスで動く 3d スカルプトアプリです。特に、Apple iPad と Apple Pencil、Samsung Galaxy Tab とスタイラスのような、筆圧対応のスタイラスを使えるタブレットで真価を発揮します。

ZBrush や Blender のようなデスクトップのスカルプトアプリから着想を得ていて、機能を犠牲にせず、わかりやすい UI を重視しています。3d スカルプトアプリを使ったことがあれば、Nomad はすぐになじむはずです。

3d スカルプトが初めてなら、いくつかの基本を知っておくとよいでしょう。

## はじめてのスカルプト {#your-first-sculpt}

Nomad を初めて起動すると、画面に球体が表示されます。球体の上でスタイラスをドラッグするだけで、スカルプトを始められます。スカルプトしやすいように、対称はデフォルトでオンになっています。

![](/videos/gettingstarted_01.mp4)

ブラシを大きくしたり小さくしたりするには、左側の半径スライダーを使います。

![](/videos/gettingstarted_02.mp4)

ブラシを強くしたり弱くしたりするには、左側の強度スライダーを使います。

![](/videos/gettingstarted_03.mp4)

デフォルトのツールは `粘土` ツールで、表面に盛り上げていきます。表面を削るには、左側の `減算` ボタンをタップします。盛り上げに戻すには、もう一度減算ボタンをタップします。

![](/videos/gettingstarted_04.mp4)

表面をなめらかにするには、`スムーズ` ボタンをタップします。通常のスカルプトに戻るには、もう一度スムーズボタンをタップします。

![](/videos/gettingstarted_05.mp4)

モデルの周りを回転するには、モデルの外の何もない場所をドラッグします。

![](/videos/gettingstarted_06.mp4)

ズームするには、2 本指のピンチ操作を使います。

![](/videos/gettingstarted_07.mp4)

カメラをパンするには、画面に指を 2 本置いてドラッグします。

![](/videos/gettingstarted_08.mp4)

失敗したときは、2 本指でタップすると取り消せます。左下の取り消しボタンを使ってもかまいません。

![](/videos/gettingstarted_09.mp4)

::: tip デスクトップ版
デスクトップでは、Alt/Option キーでカメラを操作します。

* 何もない場所でペン先をドラッグ = カメラを回転
* Alt + ペン先でドラッグ = パン
* Alt + ペン先でドラッグしてから Alt を離す = ズーム（ZBrush と同じ）

ペンに 2 つ以上のボタンがある Wacom タブレットでは、Wacom の設定でペン先とボタンを次のように割り当てます。

* ペン先 = 左クリック
* サイドスイッチ下 = 中クリック
* サイドスイッチ上 = 右クリック

この設定にすると、ペンだけでカメラを操作できます。

* サイドスイッチ上を押しながらホバー移動 = カメラを回転
* サイドスイッチ下を押しながらホバー移動 = パン
:::

## 色を付ける {#add-color}

Nomad では、スカルプトの表面にペイントできます。右側のツールメニューから `ペイント` ツールを探してクリックします。左のツールバーに色付きの球が表示されるので、それをクリックするとカラーピッカーが開きます。色を選んで、モデルにペイントしましょう。

![](/videos/gettingstarted_10.mp4)

消すには、左のツールバーの `消しゴム` ボタンをタップしてから、表面をなぞります。ペイントモードに戻るには、もう一度消しゴムボタンをタップします。

![](/videos/gettingstarted_11.mp4)

粘土ブラシの盛り上げ／減算モード、スムーズ、ペイントを使って、シンプルなカートゥーン風の頭を作ってみましょう。

![](/images/gettingstarted_head1.webp)

## ほかのツール {#other-tools}

ツールパレットには、スカルプトに役立つツールがたくさんあります。ここまでに使ったのは、粘土ブラシ（最初に選ばれているツール）、スムーズ、ペイントです。スムーズはよく使うので、左のツールバーにも専用のショートカットがあります。

Nomad のツールでできることはさまざまです。ムーブ、クリース、膨張のようなスカルプト向けのツールから、分割やトリムのような、木工や金属加工の道具に近いツールまであります。詳しくは[ツール](tools.md)のページを参照してください。

ムーブ、クリース、膨張、スムーズのツールを使って、頭にディテールを加えたり、形を変えたりしてみましょう。

![](/images/gettingstarted_head2.webp)

Nomad の基本がわかったところで、インターフェースのほかの部分も見ていきましょう。

## インターフェース {#interface}

![](/images/interface_overview1.webp)

* `上部メニュー` - Nomad のほとんどの機能にアクセスするためのメニューです。左上のメニューは主にシーンとオブジェクトの機能、右上のメニューはツールに関するものです。小さな画面では、スペースを節約するためにこれらのメニューがまとめて折りたたまれます。
* `統計情報` - シーン、現在のオブジェクト、マスクの状態、メモリ使用量などの情報です。
* `ナビゲーター` - スカルプトのどの面を見ているかを示し、ほかのビューにすばやく切り替えるショートカットにもなります。面をタップすると、その面のビューに切り替わります。ナビゲーターをドラッグすると回転します。横にある小さなアイコンをタップすると、現在のオブジェクトを画面に収めたり、デフォルトのホームビューに戻したり、カメラをロックしたり、グリッドを切り替えたりできます。見た目（キューブ、球、ノーモン）や位置は[設定](settings.md#snap-cube)で変更できます。
* `ツールボックス` - Nomad のツールは、このスクロールできる領域から選べます。
* `左ツールバー` - ほとんどのツールで使う半径と強度のスライダー、ツールごとのボタン、そして対称、ツールの代替／減算モード、スムーズ、マスク、非表示、フェースグループ、Gizmo、ペイントオプションのショートカットがあります。ショートカットの並び順は[インターフェース](interface.md#side-bar)メニューで変更できます。
* `下部ツールバー` - よく使う機能のショートカットです。詳しくは下で説明します。

::: tip 左利きですか？
すべてのツールバーの配置と並び順を左右反転できます。[トップバーを左右反転](interface.md#mirror-top-bar)などの関連オプションを参照してください。
:::

## 下部ツールバー {#bottom-toolbar}

![](/images/interface_bottom_toolbar.webp)

* `取り消す` - 直前の操作を元に戻します
* `やり直す` - 直前に取り消した操作をやり直します
* `履歴` - 履歴のオプションにアクセスします。詳しくは[履歴](history.md)メニューで説明しています。
* `ソロ` - 現在のオブジェクトだけを表示するか、すべてのオブジェクトを表示するかを切り替えます
* `X線` - 現在のオブジェクトはそのままで、ほかのオブジェクトをすべて X 線モードで表示します。長押しするか上にスワイプすると、X 線のマットキャップと色、適用するオブジェクトを選べます。
* `ボクセル` - [ボクセルリメッシュ](topology.md#voxel-remesher)のリメッシュボタンのショートカットです。長押しするか上にスワイプすると、解像度などのボクセルリメッシュのオプションが表示されます。
* `グリッド` - グリッドの表示を切り替えます。長押しするか上にスワイプすると、色やスナップなどのグリッドのオプションが表示されます。
* `ワイヤーフレーム` - ワイヤーフレームの重ね表示を切り替えます。長押しするか上にスワイプすると、ワイヤーフレームのオプションが表示されます。
* `インスペクタ` - 現在のメッシュの追加データの表示を切り替えます。デフォルトでは UV を表示しますが、長押しするか上にスワイプすると、ほかのプロパティがあればそれを確認でき、背景とメッシュ上のどちらに表示するかも選べます。
* `ログ` - Nomad のデバッグログのウィンドウを表示／非表示にします。
* `フェースグループ` - フェースグループの重ね表示を切り替えます。[フェースグループ](tools.md#facegroup)ツールを参照してください。

これらのショートカットは、[インターフェース](interface.md#add-shortcuts-bottom)メニューで追加、削除、並べ替えができます。
