# ![](/icons/postprocess.webp) ポストプロセス {#post-process}

このメニューでは、レンダリングの見た目に関わる Nomad のさまざまな要素を調整します。

![](/images/postprocess_overview_drac.webp)

ポストプロセスを使うと、シーンの最終的な見た目が大きく変わります。

![](/images/postprocess_overview.webp)
*同じシーンのポストプロセス前と後。ライトやマテリアルは追加・変更していません。*

デバイスによっては、ポストプロセスがパフォーマンスに大きく影響することがあります。
全体の `ポストプロセス` チェックボックスで、すべてのポストプロセスを一度にオフにできるので、プリセットを失わずにすぐスカルプトやモデリングに戻れます。
PBR のレンダリングでは、[アンビエントオクルージョン](#ambient-occlusion-ssao)、[反射](#reflection-ssr)、[トーンマッピング](#tone-mapping)をオンにしておきましょう。

とはいえ、スカルプト中はたいていポストプロセスをオフにして、レンダリングではなく形そのものに集中したいはずです。


## クオリティ {#quality}

![](/images/postprocess_quality.webp)

これらのオプションは、パフォーマンスと引き換えにレンダリングの品質を高めます。

### 最大フレーム数のサンプリング {#max-frame-sampling}
Nomad が 1 フレームのレンダリングで計算するポストプロセスの量は限られていて、そのままではノイズが目立つことがあります。この設定では、何フレームをレンダリングして合成し、ノイズをほとんど取り除くかを決めます。追加のサンプルが要らない効果（カラーグレーディングなど）もあれば、ソフトシャドウやグローバルイルミネーションのように、ノイズをなくすのに数百のサンプルが必要な効果もあります。

ビューポートでは、Nomad を操作せずに置いておくと、画質が最大サンプル数まで少しずつ向上し、そこで止まる様子が見られます。止まったあとは Nomad は何もしないので、バッテリーの節約になります。この計算回数は、[ファイルメニュー](files)のレンダリングのセクションで「PNG を書き出す」を押したときにも使われます。

スライダーの横にあるチェックボックスで、フレームのサンプリングをオン／オフします。

### レンダーの解像度 {#resolution-multiplier}
このスライダーで、レンダリングの解像度を調整します。x1.0 では、デバイスのピクセル解像度でレンダリングします。x0.5 では半分の解像度でレンダリングするので、速い代わりに品質が下がります。1 より大きい値では、大きなサイズでレンダリングしてから縮小します。品質が上がってノイズも減りますが、レンダリングに時間がかかります。

パフォーマンスへの影響が大きいので、x1.25 以下に抑えるようにしましょう。この値は設定に保存されず、[ピクセルアート](#pixel-art)の効果がこの値を上書きします。

### ![](/icons/intensity.webp) 最大サンプル {#max-samples}

パフォーマンスと引き換えに、ポストプロセスの効果の品質を高めます。

### ![](/icons/material_dithering.webp) ディザ合成 {#dithering}

ピクセルにディザをかけて、バンディング（グラデーションやビネットなどに出る縞）を軽減します。ふつうはオンにしておきますが、特定の作業（深度マップの書き出しなど、データを扱う作業）ではオフにすることもできます。

### ![](/icons/denoise.webp) ノイズ除去 (oidn) {#oidn}

すべてのフレームが蓄積されたあと、画像にノイズ除去をかけます。これにより、サンプル数をずっと少なくできます。ノイズ除去はプロセッサへの負荷が高いので、画像にノイズがある場合だけオンにしましょう。すべてのデバイスで使えるわけではありません。

## プリセットブラウザ {#preset-browser}
![](/images/postprocess_presets.webp)
`ポストプロセス` のタイトルの下にある画像をクリックすると、ポストプロセスのプリセット集が表示されます。`新規` を押すと、現在の設定からプリセットを作成します。組み込みのプリセットはクローンすることしかできません。自分のプリセットを作るには、プリセットを選んで `クローン` を押し、変更を加えます。プリセットにまだ保存されていない変更がある場合は `変更内容が保存されていません！` と表示されます。保存するには、プリセットの画像をクリックし、プリセットブラウザの中でもう一度クリックして、`保存` を選びます。

## ショートカットバー {#shortcut-bar}
ポストプロセスがオンのときは、メニューの下部にすべての効果（`SSR`、`SSGI`、`SSAO`、`DoF`、`ブルーム` など）を並べたバーが表示されます。タップすると、その効果のセクションに移動します。オフになっている効果はグレーアウトするので、このバーを見れば、現在のプリセットが何をしているかがひと目でわかります。

## ![](/icons/postprocess_ssr.webp) 反射 (SSR) {#reflection-ssr}
このオプションをオンにすると、オブジェクトにシーン内のほかのオブジェクトが映り込むようになります。ただし、映り込むのは画面に見えているオブジェクトだけです。
シーンに金属や光沢のあるオブジェクトがある場合は、このオプションを使うとよいでしょう。
このオプションには、[ライトあり (PBR)](shading.md#pbr) のシェーディングモードが必要です。

## ![](/icons/postprocess_ssgi.webp) グローバルイルミネーション (SSGI) {#global-illumination-ssgi}

グローバルイルミネーションは、光が面と面の間で跳ね返る様子をシミュレートします。たとえば、赤い壁の近くにある白いオブジェクトは赤みを帯びます。アンビエントオクルージョンや反射と組み合わせると、レンダリングのリアルさが大きく向上します。反射と同じく、[ライトあり (PBR)](shading.md#pbr) のシェーディングモードが必要です。

`強さ` - グローバルイルミネーションの強さです。

| ![](/images/ssgi_off.webp) | ![](/images/ssgi_on.webp) |

## ![](/icons/postprocess_ssao.webp) アンビエントオクルージョン (SSAO) {#ambient-occlusion-ssao}
アンビエントオクルージョンは、光が届きにくい部分（隅など）を暗くします。
この効果は、モデルのジオメトリだけで決まります。

* `強さ`- 効果の強さです。
* `サイズ`- 効果が広がる範囲です。
* `厚さ` - 遮る物体に想定する奥行きの厚みで、`サイズ` に対するパーセンテージで指定します。
* `色合い` - オクルージョンに乗算するカラーで、表現上の効果に使います。


| SSAO オフ                   | SSAO オン                  |
| :-------------------------: | :------------------------: |
| ![](/images/ssao_off.webp) | ![](/images/ssao_on.webp) |

::: tip
AO がいちばんよく見えるのは、主に環境光で照らされている部分です。強い直接光が当たっている部分では、AO の効果はずっと弱くなります。

:::

## ![](/icons/postprocess_dof.webp) 被写界深度 {#depth-of-field-dof}
ピントが合っていない領域をぼかします。

モデルをタップするだけで、ピントの位置を変えられます。

* `絞りモード` - 下にある 2 つのぼかしのスライダーの代わりに、カメラの絞りの値 1 つでぼかしを調整します。
* `絞り`（_絞りモードのみ_）- 実際のカメラと同じく、レンズの F 値です。値を小さくするとレンズが開き、ぼけが大きくなります。
* `背景のぼかし` - ピントの位置より奥側に適用するぼかしの量です。
* `前景のぼかし` - ピントの位置とカメラの間に適用するぼかしの量です。


| DOF オフ                  | DOF 奥のリングにピント       | DOF 手前のリングにピント   |
| :-----------------------: | :-------------------------: | :------------------------: |
| ![](/images/dof_off.webp) | ![](/images/dof_near.webp) | ![](/images/dof_far.webp) |


## ![](/icons/sun.webp) ブルーム {#bloom}
ブルームは、シーンの明るい部分を光らせます。

* `強度` - 効果の強さです。
* `半径` - 効果が広がる範囲です。
* `しきい値` - ピクセルがどれだけ明るければブルームが始まるかです。0 ではすべてが光り、高くするといちばん明るいピクセルだけが光ります。
* `色合い` - 表現上の効果のために、ブルームに加えるカラーです。

| ブルーム オフ                | ブルーム 半径 0             | ブルーム 半径 1             |
| :--------------------------: | :-------------------------: | :-------------------------: |
| ![](/images/bloom_off.webp) | ![](/images/bloom_r0.webp) | ![](/images/bloom_r1.webp) |


## ![](/icons/postprocess_tone.webp) トーンマッピング {#tone-mapping}
トーンマッピングは、HDR の値を `[0, 1]` の範囲に変換する処理です。
これを使わない（または `なし` を選ぶ）と、1 を超える色の成分はすべて切り捨てられます。
そのため、この範囲を超える色の変化は失われてしまいます。

* `なし/ニュートラル/Agx/ACES` - 使用するトーンマッパーです。`なし` では変換を行いません（ほかの設定は引き続き使えます）。ほかのオプションは、異なるフィルムを選ぶようなもので、露出オーバーの値や色をそれぞれ異なる方法で扱います。とても奥の深いテーマなので、詳しくはトーンマッピング、Agx、ACES について調べてみてください！
* `露出` - 画像全体の明るさで、カメラの絞りを調整するのに似ています。画像全体をさっと明るくしたり暗くしたりするのに便利です。
* `彩度` - 色の強さです。1 で変化なし、0 でモノクロになり、1 より大きい値ではどんどん鮮やかになります。
* `コントラスト` - 暗い部分をより暗く、明るい部分をより明るくします。値を高くするとアーティファクトが出ることがあるので、慎重に使いましょう。

`トーンマッピング` がオフだと、ピクセルが明るすぎて一部のディテールが消えてしまうのがわかります。

| トーンマッピング オフ       | トーンマッピング オン      |
| :-------------------------: | :------------------------: |
| ![](/images/tone_off.webp) | ![](/images/tone_on.webp) |

::: tip
トーンマッピングで、グローバルイルミネーションの効果を引き立てられます。環境マップの強度を下げ、メインの光源を強くしたうえで、トーンマッピングの `露出` を上げると、跳ね返った光の効果がよりよく見えるようになります。
:::

## ![](/icons/postprocess_cavity.webp) 曲率 {#curvature}
曲率が急に変わる部分を検出して、そこに色を付けます。

* `係数` - 効果全体の強さです
* `バンプ` - 鋭く凸になっている部分をどれだけ検出して、選んだ色（デフォルトは白）を付けるかです
* `キャビティ` - 凹になっている部分をどれだけ検出して、選んだ色（デフォルトは黒）を付けるかです
* `厚さ` - 検出されたエッジの幅です。

`バンプ` と `キャビティ` の横には、色を選ぶカラースウォッチと、その色を画像にどうブレンドするかを選ぶ小さなボタンがあります。


| 曲率 オフ                        | 曲率 オン                      |
| :------------------------------: | :----------------------------: |
| ![](/images/curvature_off.webp) | ![](/images/curvature_on.webp) |
