# ![](/icons/camera.webp) カメラ {#camera}

このメニューでは、カメラの作成や変更、カメラの操作方法の設定ができます。

![](/images/camera_overview2.webp)

Nomad のカメラにはいくつかの使い道があります。

* 正確な角度からスカルプトするためのビューを用意する
* 写真用のカメラのように、オブジェクトを構図に収める
* 一人称視点のカメラとして、シーンの中を移動する
* 正投影のカメラとして、アイソメトリックなゲームや工業製品風のレンダリングに使う

## カメラの操作 {#control}

### 回転 {#rotation}
背景の上で指 *1 本* をドラッグすると、カメラが回転します。
モデルの上で指をドラッグすると、カメラの回転ではなくスカルプトが始まります。

::: tip 背景に触れられないときもカメラを回転できますか？
はい。パンやズームを始めるときのように画面に指を *2 本* 置き、そのうち *1 本* を離してください。
:::

### フォーカス／リセット {#focus}
モデルを *ダブルタップ* すると、タップした点にフォーカスします。
背景を *ダブルタップ* すると、代わりに選択中のメッシュかシーン全体にフォーカスします。[背景をダブルタップ](#dtap-tap-background)を参照してください。


### 平行移動 {#translation}
指を *2 本* 動かすと、カメラをパンできます。


### ズーム {#zooming}
ピンチ操作でズームイン／ズームアウトできます。


### ロール {#rolling}
指を *2 本* 回転させると、ビューを *ロール* できます。
::: warning
この操作は、`トラックボール` の回転モードでのみ使えます。
:::

### デスクトップでの操作 {#desktop}

デスクトップでは、Alt/Option キーでカメラを操作します。

* 何もない場所でペン先をドラッグ = カメラを回転
* Alt + ペン先でドラッグ = パン
* Alt + ペン先でドラッグしてから Alt を離す = ズーム（ZBrush と同じ）

ペンに 2 つ以上のボタンがある Wacom タブレットでは、Wacom の設定でペン先とボタンを次のように割り当てます。

* ペン先 = 左クリック
* サイドスイッチ下 = 中クリック
* サイドスイッチ上 = 右クリック

この設定にすると、ペンだけでカメラを操作できます。

* サイドスイッチ上を押しながらホバー移動 = カメラを回転
* サイドスイッチ下を押しながらホバー移動 = パン

## カメラの管理 {#camera-controls}

![](/images/camera_list.webp)

### ビュー {#views}
`ビューを追加` で、カメラの視点を保存できます。
ビューの名前をクリックすると、カメラがそのビューに戻ります。


::: tip
保存したビューには、[投影の種類](#projection)の設定と[参照画像](background.md)も保存されます。  
正面・左・背面の参照ビューを、それぞれ異なる背景で切り替えたいときに便利です。
:::

| 操作        | アイコン                      | 説明                                                                        |
| :---------: | :---------------------------: | :-------------------------------------------------------------------------: |
| 表示        | ![](/icons/eye_open.webp)    | カメラの表示を切り替えます。非表示のカメラは、前へ／次へボタンで飛ばされます |
| 名前        |                               | カメラを選択します                                                          |
| 画像        | ![](/icons/image.webp)       | カメラに参照画像がリンクされている場合、そのサムネイルです                  |
| 投影        | ![](/icons/perspective.webp) | カメラの投影方法です。透視投影のときは画角も表示されます                    |
| ビューを更新 | ![](/icons/update_view.webp) | 保存したビューを現在の視点で更新します                                      |
| 名前を変更  | ![](/icons/pencil.webp)      | カメラの名前を編集します                                                    |
| 削除        | ![](/icons/trash.webp)       | カメラを削除します                                                          |

### ![](/icons/camera_add.webp) ビューを追加 {#add}
現在のビューをもとに、新しいカメラを作成します。

### ![](/icons/camera.webp) アイコン {#icons-test}

ビューポートにカメラのアイコンを表示するかどうかを切り替えます。このボタンは、カメラを 1 つ作ると `ビューを追加` の横に表示されます。選択中のカメラのアイコンは常に表示されます。

### 投影の種類 {#projection}
`透視投影` と `正投影` から選びます。

透視投影では、カメラの `垂直画角`（視野角）を変更できます。スライダーの上には、35mm カメラに換算した焦点距離が表示されるので、写真に慣れている人には便利です。
スカルプトでは、一般的に画角を小さめにするのがおすすめです。プロポーションをつかみやすくなります。  
`正投影` モードは、画角を 0 にしたのとほぼ同じです。

### ファーストパーソン {#fps}
透視投影でのみ使えます。ピボットを彫刻ではなく、カメラそのものの位置に置きます。背景の上で指をドラッグすると、カメラの位置は固定されたまま向きだけが変わります。一人称視点のゲームと同じような動きです。単体のオブジェクトではなく、環境をスカルプトするときに便利です。

![](/images/camera_rotation_ortho_view.webp)

### 回転の種類 {#rotation-type}
デフォルトでは、カメラは `ターンテーブル` の回転モードを使います。
自由度が 2 つしかないぶん直感的ですが、もっと自由に動かしたい場面もあるでしょう。  
`トラックボール` に切り替えると、ビューポート上で指を *2 本* 回転させてビューを *ロール* できるようになります。`トラックボール` のモードは 2 種類あります。1 つ目は指の下でボールを転がすようにビューを回し、2 つ目（矢印のアイコン）はドラッグの水平・垂直の動きからビューを回します。人によっては 2 つ目のほうがなじみやすいかもしれません。

### 正投影スナップ {#orthographic}

オンにすると、キーボードがある場合、Shift キーを押しながらビューを回転させると、カメラが最も近い正面・背面・上面・底面・左・右のビューにスナップし、正投影になります。ビューキューブをクリックして正面・背面・左・右・上面・底面にスナップしたときも、カメラは正投影になります。

### ビューをリセット {#reset}

カメラを正面に移動し、シーン全体がビューに収まるようにします。

### スナップビュー {#snap}
最も近い正面・背面・左・右・上面・底面のビューにスナップします。すでにそのいずれかのビューにいる場合は、もう一度クリックすると 180 度反対側にスナップします。

### 速度 {#speed}

カメラの動きが遅すぎる、または速すぎると感じたら、`回転`、`ズーム`、`平行移動` の速度の倍率を設定できます。スカルプトがとても大きい場合や小さい場合に便利です。

### ピボットの概要 {#pivot}

カメラを回転させると小さなピンクの点が見えます。これがカメラのピボット（回転の中心）です。  
ピボットがどこにあるかを把握しておくことはとても大切です。そうすれば、カメラで迷子になったりイライラしたりせずに済みます。

デフォルトでは、ピボットは次の操作で更新されます。
- モデルをダブルタップする
- 背景をダブルタップする（新しいピボットはメッシュの中心になります）
- 画面に指を *2 本* 置く（パン／ズーム／ロール）と、ピボットが *2 本* の指の中間に更新されます

### ピボットを更新… {#update-pivot}

次のオプションで、ピボットを更新するタイミングをさらに細かく設定できます。

* `カメラ操作開始時` - カメラの操作を始めたときにピボットを更新します。
* `エアーピボット` - オブジェクトの表面の外でズームしたときも、新しいピボットを設定できるようにします。`カメラ操作開始時` が必要です。
* `ダブルタップでアップデート` - オブジェクトの表面をダブルタップしたときに、回転のピボットを更新します。
* `スカルプト (ストローク)` - スカルプトしたときにピボットを更新します。

::: tip
慣れてきたら、[設定](settings.md)メニューでピンクの点（ヒント）を非表示にできます。
:::

### ズームアウト時、ビューの中央に表示 {#center-view-when-zooming-out}
ズームアウトするとき、カメラは横にパンせず後ろに下がるだけなので、ビューが中央に保たれます。

### オブジェクトをダブルタップ {#dtap-object}
オンにすると、オブジェクトをダブルタップしたときに、タップした点にカメラがフォーカスします。

### 背景をダブルタップ {#dtap-tap-background}
オンにすると、背景をダブルタップしたときに、カメラが次の対象にフォーカスします。
* `選択内容` - 選択中のオブジェクト。
* `シーン` - シーン全体。
* `切り替える` - ダブルタップするたびに、この 2 つを交互に切り替えます。`切り替える` のオプションは 2 つあり、アイコンが示すとおり、どちらが先に来るかが異なります。
