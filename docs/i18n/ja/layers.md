# ![](/icons/layer.webp) レイヤー {#layers}

このメニューにはレイヤースタックがあります。オブジェクトへの編集を非破壊的に記録する仕組みで、レイヤーを組み合わせたり、別の用途に活用したりする方法もたくさん用意されています。

![](/images/layers_overview.webp) 

## 概要 {#overview}

Nomad のレイヤーには、いくつかの役割があります。

ペイントの情報（カラー、粗さ、メタリック、不透明度）は、2d のペイントアプリと同じようにレイヤーで扱えます。レイヤーを作成して、モデルにペイントできます。レイヤーはオン／オフを切り替えたり、不透明度を調整したり、複製したり、レイヤースタック内で順番を変えたり、ブレンドモードを調整したりできます。

Nomad では、スカルプトにもレイヤーを使います。レイヤーにはしわのような細かいディテールも、大きな変形も記録できるので、ほかの 3d アプリのブレンドシェイプ／シェイプキー／モーフターゲットのように使えます。たとえば、異なる表情をそれぞれ別のレイヤーにスカルプトしておき、レイヤーのスライダーを調整して組み合わせ、新しい表情を作ることができます。

この場合、レイヤーに記録された変更は単純に足し合わされるので、ペイントとは違ってレイヤーの順番は関係ありません。

[レイヤー消去](tools.md#delete-layer)ツールでレイヤーを部分的に消したり、レイヤーに記録されたさまざまな情報からマスクを作ったりすることもできます。

![](/videos/layer.mp4)

::: tip
ほとんどのスカルプトソフトと違って、メッシュのトポロジーを変えてもレイヤーは失われません。[ボクセルリメッシュ](topology.md#voxel-remesher)、[マルチレゾリューション](topology.md#multiresolution)、[トリム](tools.md#trim)／[分割](tools.md#split)ツールを使えます。ただし、[ボクセルリメッシュ](topology.md#voxel-remesher)を使うと、レイヤーの品質が落ちることに注意してください。
:::

::: tip
レイヤーをブレンドシェイプ／モーフターゲットとして使う場合は、[シーンメニュー](scene.md#object-menu)にもレイヤー関連の機能があります。レイヤーを別々のオブジェクトに分けたり、対応するオブジェクトをレイヤーとしてまとめたりできます。
:::
----

## レイヤーメニュー {#layer-menu}

![](/images/layers_menu.webp)

タイトルには、選択中のオブジェクトの名前が表示されます。プリミティブではレイヤーを使えないので、まずプリミティブを確定してください。

`レイヤーを追加` を押すと、新しいレイヤーが作成されます。`レイヤーを結合` は、すべてのレイヤーをベースメッシュに結合します。アイコンの横の数字は、レイヤーの数です。

各レイヤーには、名前、強さ（係数）を調整するスライダー、オプションボタンがあります。レイヤーをタップするとアクティブになり、スカルプトやペイントはそのレイヤーに記録されます。ベースメッシュでの作業に戻るには、`ベース` をタップします。

### ![](/icons/sort_right.webp) リストを展開 {#ui-expand-list}

デフォルトでは、レイヤーのリストには各レイヤーの表示、ブレンドモード、強さだけが表示され、アクティブなレイヤーだけがすべての操作項目付きで展開されます。タイトルの左にある矢印を押すと、すべてのレイヤーの操作項目が展開されます。

![](/images/layers_expand.webp)

### オプション {#options}

| 操作         | アイコン                     | 説明                                                |
| :----------: | :--------------------------: | :-------------------------------------------------  |
| 可視         | ![](/icons/eye_open.webp)   | レイヤーを表示／非表示にします                      |
| ブレンドモード | ![](/icons/opacity.webp)    | Photoshop のようなブレンドモードです。4 つのアイコンは、カラー、粗さ、メタリック、不透明度のモードを表します。 |
| 名前を変更   | ![](/icons/pencil.webp)     | レイヤーの名前を編集します                          |
| 削除         | ![](/icons/trash.webp)      | レイヤーを削除します                                |
| クローン     | ![](/icons/clone.webp)      | レイヤーを複製します                                |
| 下へ結合     | ![](/icons/merge_down.webp) | レイヤーを下のレイヤー（またはベースメッシュ）と結合します |
| その他       | ![](/icons/more.webp)       | [その他…](#more)のオプション                        |

レイヤーが展開されていないときは、`名前を変更`、`削除`、`クローン`、`下へ結合` は[その他…](#more)メニューの中にあります。

レイヤースタック内でレイヤーを移動するには、名前を長押ししてからドラッグします。

### ベース {#base}

`ベース` の行にある 3 つの点のボタンを開き、`ベース → レイヤー` ボタンを押すと、ベースメッシュのペイントが新しいレイヤーに移動します。その後、ベースは背景マテリアルにリセットされます。レイヤーを作る前にたくさんペイントしてしまったときに便利です。

* 横にあるマスクと非表示のボタンをオンにすると、マスクされた部分と非表示の部分はそのまま残ります。
* `抽出` - 移動するチャンネルです：`カラー`、`不透明度`、`粗さ`、`メタリック`。
* `背景マテリアル` - オンにすると、このマテリアルと異なる値だけが移動します。スライダーで設定するか、スポイトでモデルから拾います。

### ![](/icons/more.webp) その他… {#more}

「その他…」ボタンを押すと、現在のレイヤーの追加オプションが 2 つのタブで表示されます。設定（歯車アイコン）と抽出（キューブアイコン）です。

![](/images/layers_more.webp) 

#### チャンネル係数 {#channel-factors}

レイヤーのスカルプト／カラー／粗さ／メタリック／不透明度の量を調整できます。これらの値はレイヤーの係数スライダーと掛け合わされます。たとえば、レイヤーの強さが 1 でも、カラーチャンネルの係数が 0.5 なら、表示されるカラーの強さは 0.5 になります。

`オフセット` は、レイヤーのスカルプトの強さを調整します。カラー／粗さ／メタリックは 0 から 1 の範囲に制限されますが、オフセットは正でも負でも、どんな値にもできます。

::: tip
オフセットを使うと、でこぼこのレイヤーをくぼみのレイヤーに変えたり、笑顔をしかめ顔に変えたりできます。
![](/videos/layer_happysad.mp4)


対称なレイヤーをクローンしてから、レイヤー消去で左右の形に分けることもできます。
![](/videos/layer_leftright.mp4)

オフセット係数が負のレイヤーを空のレイヤーにベイクすると、新しい正の形を作れます。

オフセット係数が 1 より大きいレイヤーを使えば、より極端なブレンドシェイプを試せます。
:::

::: warning
現在、レイヤーには 3 つのチャンネル（カラー／メタリック／粗さ）すべてで共有する不透明度チャンネルが 1 つしかありません。
チャンネルごとの強さが最大になっていないレイヤーを複数結合すると、最終的な見た目が変わってしまうことがあります。

将来的には、チャンネルごとに独自のアルファチャンネルを持たせて、この制限をなくすかもしれません。
:::


#### ![](/icons/shield.webp) マスク {#mask}
各スライダーの横にあるマスクボタンを押すと、そのチャンネルからマスクを作成します。ペイントアプリでレイヤーから選択範囲を作るのと同じように、レイヤーで作業した内容をほかの操作に再利用できます。

#### ![](/icons/preview.webp) プレビュー {#preview}
![](/images/layers_preview.webp) 

ここからのオプションは、「その他…」メニューの抽出タブにあります。

オンにすると、このレイヤーの抽出設定をプレビューします（次のセクションを参照）。

`X線` は、プレビュー中にどのオブジェクトを透明にするかを選びます（`なし`、`未選択`、`選択済み`、`すべて`）。こうすることで、抽出される形状が不透明なまま見えます。抽出の高さを負の値にしているときに便利です。

#### ![](/icons/mask_extract.webp) 抽出 {#extract}
![](/images/layers_extract.webp) 

![](/videos/layer_shell.mp4)

`抽出` ボタンを押すと、レイヤーの内容が新しいオブジェクトとして複製されます。通常は、次のセクションで設定する厚みが付きます。

`閉じるアクション` で、複製の方法を決めます。

* `なし` - その部分をそのまま抽出し、側面を作ったり穴を埋めたりはしません。
* `埋める` - 穴を三角形で埋めて、なめらかにします。平らな面には使わないでください。
* `シェル` - 厚みの値と方向のオプションを使って、抽出した形状を閉じます。
* `レイヤー` - レイヤーの差分を抽出します。

#### ![](/icons/height.webp) 高さ {#thickness}
![](/images/layers_thickness.webp) 

シェルを押し出す深さです。正の値では表面から外側に、負の値では表面の内側に伸びます。閉じるアクションが `レイヤー` のときは表示されません。

この値の横にあるプラス／マイナスで、押し出しの方向を設定します。
* マイナス（-）は、現在の表面から下に向かって押し出します。
* プラス（+）は、現在の表面から上に向かって押し出します。
* プラスマイナス（±）は、押し出しの上面と下面を同じ量だけ押し広げるので、元の表面に半分埋まった状態になります。

#### 側面 {#edge-loop-side}
![](/images/layers_edgeloop.webp) 

このセクションは、閉じるアクションが `シェル` のときに表示されます。

`壁の分割数` は、シェルの側面の分割数を設定します。`自動` をオンにすると、四角いポリゴンになるように Nomad がエッジループの数を計算します。

#### なめらかさ {#smoothness}
![](/images/layers_smoothness.webp) 

抽出する領域の縁がギザギザしている場合は、このオプションをオンにすると、縁をなめらかできれいな形にできます。`すべて` は抽出した面全体を、`境界のみ` は縁だけをなめらかにします。`反復回数` で、なめらかにする強さを設定します。

_「その他…」サブメニューの説明はここまでです。_

### ![](/icons/cog.webp) 高度な機能 {#advanced}
![](/images/layers_advanced.webp)

メニューの下部にある `高度な機能` ボタンは、オブジェクトにレイヤーがあるときに表示されます。

#### 上のレイヤーのディテールを残す {#keep-top-layers-details}

下のレイヤーに大きな変更を加えても、上のレイヤーの細かいディテールが見えたままになるようにします。スカルプト中は上のレイヤーからの変形は無視されますが、そのディテールは表示されたままです。上のレイヤーが比較的細かいディテールだけを持っている場合にうまく機能します。

デフォルトでは、あるレイヤーに細かいしわをスカルプトしたあと、ベースレイヤーに大きな変更を加えると、しわは失われてしまいます。このトグルをオンにすると、細かいディテールが下の大きな変更の上に常に乗った状態になります。次の動画では、デフォルトではしわのディテールが消えてしまいますが、「上のレイヤーのディテールを残す」をオンにすると見えたままになる様子がわかります。

![](/videos/layers_details.mp4)


#### トランスフォームを同期 {#sync-transform}

オンにすると、Gizmo ツールやトランスフォームツールを使ったときに、選択していないすべてのレイヤーも、トランスフォームの回転、スケール、シアーに合わせて調整されます。`自動`、`いいえ`、`はい` から選べます。

ほかのレイヤーを、今適用しようとしているトランスフォームなしで使うつもりなら、このオプションをオフにしてください。

`自動` に設定すると、表示されているレイヤーだけが調整されます。
