# ![](/icons/paint.webp) ペイント {#painting}

ペイントストロークのカラー、粗さ、メタリックを設定します。ペイントの属性で塗りつぶしたり、ペイント系のツールがレイヤー、マスク、非表示の範囲とどう関わるかを設定したりできます。

![](/images/paint_overview.webp)  

## 概要 {#overview}

Nomad は PBR の頂点ペイントを使っています。これはどういう意味でしょうか？

### PBR {#pbr}
PBR（Physically Based Rendering、物理ベースレンダリング）は、映画、テレビ、ゲーム、モバイルで広く使われている CG の手法です。ライトを物理的な特性にもとづいて扱い、表面をカラー、粗さ、メタリックで定義することで、さまざまなフォトリアルな見た目を実現できます。

### 頂点ペイント {#vertex-painting}

頂点ペイントとは、ペイントの情報をテクスチャではなく、モデルの頂点に記録する方式です。Nomad は数十万、ときには数百万の頂点を持つモデルを扱えるので、表面にとても細かいペイントを施せます。ディテールをスカルプトできるなら、そのディテールにペイントもできるということです。

また、Nomad でのペイントには UV マッピングが必要ありません。ほかの 3d アプリでは、UV マッピングは時間がかかり技術的にも難しい作業になりがちです。Nomad ほど多くの頂点を扱えない 3d アプリも多いですが、Nomad には便利なテクスチャのベイクやデシメイトのツールも揃っています。

### テクスチャリング {#texturing}

Nomad はテクスチャに対応していますが、テクスチャはインポートしたモデルに含まれているか、頂点ペイントをテクスチャにベイクして作る必要があります。

テクスチャとは単なる画像ですが、3d の文脈では、ふつうオブジェクトに割り当てられた画像を指します。
画像をモデルに巻き付けるには、モデルにテクスチャ座標（UV）が必要です。

Nomad は[UV を自動で計算](topology.md#uv-unwrap)できますが、全体的な品質はあまり細かく調整できません。

::: tip
ワークフローの一例：
- Nomad でスカルプトしてから、[UV 展開](topology.md#uv-unwrap)する
- Nomad ですでにペイントを始めている場合は、[頂点ペイントをテクスチャに転送](topology.md#bake-texture)できる
- Procreate に書き出す
- Procreate でテクスチャを描く
- レンダリングのために Nomad に戻す
:::

概要は以上です。ここからは、ペイントメニューの各セクションを見ていきましょう。


## ストロークペイント {#stroke-painting}
![](/images/paint_intensity.webp)  

このツールでペイントを有効にします。スカルプトとペイントを同時に行いたいときに便利です。ペイントできるツールでこのチェックボックスがオフになっていると、タイトルの横に警告アイコンが表示されます。

ペイントが主な機能のツール（ペイント、指先、マスクなど）には、このチェックボックスはありません。

### ![](/icons/opacity.webp) ペイントの強度 {#paint-intensity}

ツール本来の強度とは別の強度でペイントできるスライダーです。

横にあるスライダーボタンを押すと、サイドバーにペイントの強度のスライダーが追加されます。スカルプトとペイントを同時に行うツールで便利です。

`アルファ`、`フォールオフ`、`強度をランダム化` のボタンで、それぞれの機能をペイントにも反映させるかどうかを決めます。たとえば、粘土ツールでランダム化をオンにしていても、カラーはランダム化しない、といった使い方ができます。

* `アルファ` - オフにすると、ペイントはアルファを無視してブラシの範囲全体を塗ります。VDM ツールでは、このボタンは `スタンプマテリアル` に置き換わり、スタンプに記録されたマテリアルのオン／オフを切り替えます。
* `フォールオフ` - オフにすると、ブラシの縁まで最大の強度でペイントします。
* `強度をランダム化` - ストロークのランダム化のうち、強度の部分をペイントに反映させるかどうかです。位置、回転、スケールのランダム化は、常にスタンプ全体を動かします。

これらのオプションは[すべてをペイント](#paint-all)では無視されますが、そのトライプラナー版ではアルファが使われます。

### ![](/icons/link.webp) グローバルマテリアル {#global-material}
このオプションをオンにすると、選択したマテリアルがほかのツールと共通になります。対象になるのは粗さ、メタリック、カラーの設定だけです。このツール専用のマテリアルを使いたいときはオフにします。


## マテリアル {#material}
![](/images/paint_material.webp) 

1 つ目のアイコンは、マテリアルのプレビュー用の形状です。3d のマテリアルプレビューをドラッグすると回転します。

2 つ目のアイコンは、選択中のアルファとフォールオフの設定でのペイントストロークのプレビューです。

### ![](/icons/falloff.webp) カーブ {#curves}

[PBR スライダー](#pbr-sliders)のテクスチャスロット用のカーブエディタを開きます。画像ファイルには手を加えずに、ペイントする前のテクスチャの値を変換します。テクスチャスロットに小さなカーブのアイコンが表示されていれば、そのカーブが編集されていることを示します。

### ![](/icons/cog.webp) マテリアルのオプション {#material-options}

タイトルの横にある `マテリアル` ボタンには、2 つの設定があります。

`ビューポートのマテリアルプレビュー` は、カラー、粗さ、メタリック、不透明度、強度のスライダーを変えている間、選択中のオブジェクトにどう表示するかを決めます。

* `なし` - プロパティを調整しても、モデルにはプレビューを表示しません
* `マテリアル` - プロパティを調整すると、オブジェクト上でマテリアルの値をプレビューします。
* `トライプラナー` - マテリアルをトライプラナー投影としてプレビューします。

その下にあるカラー、粗さ、メタリック、不透明度のチェックボックスで、[マテリアルスポイト](#material-picker)で置き換えるチャンネルを選びます。

### ![](/icons/dropper.webp) マテリアルスポイト {#material-picker}

スポイトで、シーン内のどのオブジェクトからでも、カーソルの下にあるマテリアルを拾えます。置き換えられるのは、[マテリアルのオプション](#material-options)でチェックしたチャンネルだけです。

## マテリアルのプリセット {#material-presets}
3d のプレビュー形状をタップすると、マテリアルのプリセットメニューが開きます。プリセットをクローンして、自分だけのプリセットを作れます。

![](/images/paint_presets.webp) 

`テクスチャを埋め込む` をオンにすると、このマテリアルで使っているテクスチャのコピーがプリセットの中に保存されます。オフの場合、プリセットは Nomad の textures/ フォルダにあるテクスチャを参照するだけです。テクスチャ付きのプリセットを、テクスチャを別に送らずに共有したいときはオンにしましょう。

`アルファを含める` をオンにすると、ブラシのアルファもマテリアルのプリセットに保存されます。

## PBR スライダー {#pbr-sliders}
![](/images/paint_sliders.webp) 

[PBR](shading.md#pbr) のペイントでは 4 つのチャンネルを使います。
- `カラー` ペイントする色です。スポイトを使うと、モデルのほかの部分や参照画像から色を拾えます。
- `粗さ` 表面がどれだけ「ざらざら」しているか、「つるつる」しているかを表します。粗さが低いと、反射がくっきりします。
- `メタリック` 表面が金属かどうかを表します。ほとんどの場合、値は 0% か 100% のどちらかにするべきで、その中間の値は例外的なものです。
- `不透明度` マテリアルがどれだけ透けて見えるかです。厳密には PBR の仕様には含まれませんが、多くの場面で役に立ちます。1 で完全に不透明、0 で透明になります。不透明度と屈折は別物です。Nomad では、屈折は屈折マテリアルで扱います。

マテリアルのプリセットを選ぶと、3 つのチャンネルが同時にペイントされます（不透明度は意図的に除外されていることが多いです）。つまり、ただ「赤」を塗るのではなく、「ざらざらした赤い金属」や「つるつるした白いプラスチック」を塗れるということです。

四角はテクスチャスロットです。クリックすると、そのプロパティに単一の値ではなくテクスチャを使えます。カラーのテクスチャは色を着色し、粗さ、メタリック、不透明度のテクスチャはスライダーの値を置き換えます（そのことを示すため、ラベルに取り消し線が引かれます）。不透明度のテクスチャでは、`アルファを値として使用` をオンにすると、グレースケールの値の代わりにテクスチャのアルファチャンネルを読み取ります。

VDM ツールでは、スタンプが独自のマテリアルを持っている場合、テクスチャスロットの横にそれを示す追加のスロットが表示されます。タップすると、スタンプのそのチャンネルを使うか無視するかを切り替えられます。

スライダーの横にあるブラシのアイコンを押すと、そのプロパティでオブジェクト全体を塗りつぶします。

チェックボックスで、各プロパティをオン／オフできます。たとえば、カラーだけをペイントしたり、粗さと不透明度だけをペイントしたりできます。

粗さとメタリックの組み合わせの例を紹介します。

|                | メタリック 0%                     | メタリック 100%              |
| :------------: | :-------------------------------: | :--------------------------: |
| 粗さ 0%        | ![](/images/dielectric_r0.webp)   | ![](/images/metal_r0.webp)   |
| 粗さ 50%       | ![](/images/dielectric_r50.webp)  | ![](/images/metal_r50.webp)  |
| 粗さ 100%      | ![](/images/dielectric_r100.webp) | ![](/images/metal_r100.webp) |

::: warning
粗さとメタリックには、[ライトあり (PBR)](shading.md#pbr) のシェーディングモードが必要です。[MatCap](shading.md#matcap) や[ライトなし](shading.md#unlit)のモードでは無視され、メニューに警告が表示されます。
:::

::: tip
PBR のペイントにテクスチャを使うときは、`スタンプ` ツールのようなツールに切り替えるか、ストロークメニューでドット以外のモードを使うと便利なことが多いです。ドットではテクスチャがにじんでしまうことがあります。

![](/videos/paint_color_texture.mp4)  
:::

::: tip
ポリゴン数の少ないオブジェクトに金属の表面をペイントする場合は、`スムーズシェーディング` を[全体で](settings.md#smooth-shading)、または[オブジェクトごとに](material.md#smooth-shading)オンにすることを検討してみてください。
:::

## ![](/icons/paint.webp) すべてをペイント {#paint-all}

![](/images/paint_paint_all.webp)

現在のマテリアルを選択中のオブジェクトに適用します。`すべてをペイント` で標準のモードで適用するか、`すべてをペイント + トライプラナー` でトライプラナー投影として適用します。トライプラナー版は、確定していないプリミティブでは使えません。

カラー／メタリック／粗さ／不透明度のスライダーの横にあるチェックボックスが反映され、オフになっているプロパティは塗りつぶされません。

追加のボタンで、すべてをペイントの効果をさらに調整できます。ほとんどのボタンにはパーセンテージが表示され、効果がない場合はグレーアウトします。

| アイコン                    | 説明                                          |
| :-------------------------: | :-------------------------------------------: |
| ![](/icons/shield.webp)    | マスクされた部分は影響を受けません。          |
| ![](/icons/tool_hide.webp) | 非表示の部分は影響を受けません。              |
| ![](/icons/opacity.webp)   | 上にあるツールのペイント係数を使います。      |
| ![](/icons/layer.webp)     | レイヤーのペイントされていない部分は影響を受けません。 |
| ![](/icons/triplanar.webp) | `頂点`：トライプラナー版では、表示されているツールの強度で、アルファに合わせて表面もオフセットします。 |
| ![](/icons/cog.webp)       | トライプラナーの設定を開きます                |

### ![](/icons/cog.webp) トライプラナーの設定 {#triplanar-settings}
![](/images/paint_triplanar_settings.webp)

[マテリアルメニューのトライプラナー設定](material.md#triplanar)と同じように、投影のブレンド、タイル、オフセットを調整できます。

このメニューの上部にあるプレビューのチェックボックスをオンにすると、値を調整している間ずっとプレビューが表示されます。
