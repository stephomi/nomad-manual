# ![](/icons/brush.webp) ストローク {#stroke}

---
![](/images/stroke_overview.webp) 

## 概要 {#overview}

ほとんどのツールのブラシは、ストロークの挙動をカスタマイズできます。
設定は2dペイントアプリにあるものとほぼ同じですが、スカルプトや3dならではのオプションもあります。

オプションは5つのサブメニューに分かれています。

| 名前     | アイコン                     | 説明                                                               |
| :------: | :--------------------------: | :----------------------------------------------------------------: |
| ストローク | ![](/icons/brush.webp)      | ストロークをモデルにどう適用するかを設定します                      |
| アルファ  | ![](/icons/alpha.webp)      | グレースケールのテクスチャをブラシのスタンプにどう使うかを決めます   |
| フォールオフ | ![](/icons/falloff.webp) | ブラシの強さが中心から端に向かってどう変化するかを設定します         |
| フィルタ  | ![](/icons/filter.webp)     | モデルの形状がブラシにどう影響するかを決めます                       |
| 筆圧     | ![](/icons/pressure.webp)   | スタイラスの筆圧への反応を設定します                                 |

::: tip
すべてのストロークオプションがすべてのツールに当てはまるわけではありません。現在のツールで使われないオプションは、無効になるか非表示になります。
:::


## ![](/icons/brush.webp) ストローク {#stroke-1}

### ![](/icons/radius.webp) 半径 {#radius}

![](/images/stroke_radius.webp)

半径のオプションはグローバル設定で、すべてのツールに適用されます。

#### 空間 {#size}

* `スクリーン` - 半径を画面上の単位で設定します。半径を100ピクセルにすると、ズームイン・ズームアウトしても100ピクセルのままです。
* `ワールド（3D）` - 半径を3dの単位で設定します。たとえば球を作って半径を球と同じ大きさにすると、ズームイン・ズームアウトしても半径は球と同じ大きさのままです。

#### ![](/icons/link.webp) ショートカットを同期 {#sync-shortcut}

有効にすると、ショートカットのブラシ（`スムーズ`、`マスク`、`隠す`）に切り替えたときに、半径とシルエットの設定が同期されます。これで、さっとスムーズやマスクをかけるときも、直前まで使っていたツールと同じブラシサイズになります。

#### ![](/icons/link.webp) 半径を共有 {#share-radius}

有効にすると、すべてのツールが同じ半径を使います。デフォルトでは、ツールごとに別々の半径を持ちます。


### ストロークタイプ {#stroke-type}

![](/images/stroke_strokemode.webp)

ストロークにはいくつかのモードがあります。

### ![](/icons/stroke_dot.webp) ドット {#dot}
普通のペイントストロークのようにドラッグします。
![](/videos/stroke_dot.mp4) 

### ![](/icons/stroke_roll.webp) ロール {#roll}
ブラシのアルファがストロークの方向に沿って回転します。布の縫い目を作るのに便利です。
![](/videos/stroke_roll.mp4) 

### ![](/icons/radius.webp) ロック + 半径 {#lock-radius}
**_高さ_** を固定してブラシストロークをスタンプします。ドラッグでスケールと回転が決まります。
![](/videos/stroke_lock_radius.mp4) 

### ![](/icons/normal.webp) ロック + 強度 {#lock-intensity}
**_半径_** を固定してブラシストロークをスタンプします。ドラッグで高さと回転が決まります。
![](/videos/stroke_lock_intensity.mp4) 

::: tip
`ロック + 半径` と `ロック + 強度` のモードでは、ドラッグがすでにサイズと強さを決めるため、[筆圧](#pressure)の設定は無視されます。
:::

![](/images/stroke_strokemodemove.webp)

`移動` ツールと `ドラッグ` ツールには、専用の3つのオプションがあります。

### ![](/icons/snake.webp) ドラッグ {#drag}

ストローク中、ブラシの半径内にあるものを更新し続けます。速いストロークでは表面が置いていかれ、ゆっくりしたストロークでは素材をつかんだままになり、長い形を作れます。`ドラッグ` ツールのデフォルトのモードです。`ダイナミックトポロジー` と組み合わせると、ヘビのような押し出しを作れます。
![](/videos/stroke_drag.mp4) 


### ![](/icons/grab.webp) グラブ {#grab}
ブラシを置いた時点で半径内にあるものを選択し、その選択を保ちます。移動の距離を慎重に調整でき、最初に選んだ範囲より多くを誤って動かすこともないので、より正確な移動操作に向いています。`移動` ツールのデフォルトのモードです。
![](/videos/stroke_grab.mp4) 


### ![](/icons/radius.webp) ロック + 半径（ドラッグ） {#lock-radius-drag}
設定した半径は無視され、始点からどれだけ離れてドラッグしたかで半径が動的に決まります。距離が短ければ半径は小さく、長ければ大きくなります。強度のスライダーでフォールオフの形を調整します。有機的でゴムのような形のブロックアウトに便利です。
![](/videos/stroke_lockradius_drag.mp4) 

ほかにも、ここに独自のストロークタイプを並べるツールがあります。たとえばスムーズ系のツールの `リラックス`、`スムーズ`、`指先` や、選択ベースのツールの `投げ縄`、`曲線` などの形です。これらは各[ツール](tools.md)で説明しています。


### 間隔に応じて強度を調整 {#adjust-spacing-intensity}
![](/images/stroke_space_smooth.webp)

間隔が狭い（50%未満の）ストロークはすぐに重なって積み上がり、間隔が広い場合より強いストロークになります。このトグルはそれを補正し、間隔に関係なくほぼ同じ強さのストロークにします。

### ストロークの間隔 {#stroke-spacing}
ドラッグ中、ブラシのスタンプをどれくらいの間隔で置くかを決めます。100%未満では重なり合って、連続したストロークに見えます。100%を超えると隙間ができ始めるので、縫い目やファスナーのようなディテールのスカルプトに便利です。

### 手ぶれ補正ロープ {#lazy-rope-stabilizer}
ストロークがポインタの位置から一定の距離だけ遅れてついてきます。なめらかな線を描くのに使えます。
![](/videos/stroke_lazy_rope.mp4) 

### ストロークのスムージング {#stroke-smoothing}
複数のポインタ位置を平均して、ストロークをなめらかにします。
値を大きくするとストロークはポインタより遅れますが、最終的には追いつきます。
なめらかな線を描くのに便利です。

### スナップの半径 {#snap-radius}
前のストロークの終点の近くからポインタを動かし始めると、ストロークを前のストロークにスナップします。半径は、前のストロークの終点をどこまで探すかを決めます。こまめに手を止めながら長い連続した線を描くときに便利です。

### ![](/icons/trail.webp) トレイル {#trail}

有効にすると、新しいスタンプを置くたびに、その後ろにあるストロークの直近のポイントも再適用されます。`トレイル数` は再適用するポイントの数、`トレイルの強度` はその強さ、`トレイル半径` はどれだけ大きくなるかを決めます。

トレイルは `ドット` のストロークタイプでのみ機能し、`リッジ` の[フォールオフの影響](#influence)では使えません。

### ![](/icons/silhouette.webp) シルエット {#silhouette}
![](/images/stroke_silhouette.webp)
デフォルトでは、ストロークはブラシの半径内にあるモデルの表面にしか効きません。シルエットを有効にすると、ストロークがモデル全体を貫いて投影されます。モデルの最初のブロックアウトや、側面を垂直に保ちたい形を作るときにとても便利です。

投影の方向は明示的に設定できます。

* `X`、`Y`、`Z` - 固定した軸に沿って投影します。
* `ビュー` - カメラの方向に沿って投影します。
* `スナップされている場合` - カメラがビューにスナップしている間だけ、カメラの方向に沿って投影します。それ以外では普通のストロークのままです。
* `最も近い` - カメラの方向に最も近い軸に沿って投影します。これがデフォルトです。

![](/videos/stroke_silhouette.mp4) 

### ![](/icons/dice.webp)ランダム化 {#randomize}

![](/images/stroke_randomize.webp)

ストロークの `強度`、`オフセット`、`回転`、`スケール` は、それぞれランダム化できます。各行のチェックボックスでオン・オフを切り替えます。さまざまな効果に使えます。たとえばペイントツールでランダム化すればまだら模様の色を、クリースツールでランダム化すれば肌のディテールを作れます。

`周期（遅く）` はランダムの周期の長さを決めます。大きくするとゆっくりうねるような変化に、小さくすると細かいノイズになります。各行の横にある小さなボタンで、その行だけ周期をスケールできます。

![](/videos/stroke_randomize.mp4) 

### ![](/icons/paint.webp) ランダム化 - HSV {#randomize-hsv}

ペイントするツールでは、ペイントカラーの `色相`、`彩度`、`値` も、それぞれ専用の周期でランダム化できます。肌や石に、さりげない色の変化を加えるのにぴったりです。

### ストロークのオフセット {#stroke-offset}

ストロークに一定のオフセットをかけて、指でストロークが隠れないようにします。小さな画面で便利です。グローバル設定で、チェックボックスで有効にすると、すべてのツールに適用されます。


## ![](/icons/alpha.webp) アルファ {#alpha}
![](/images/stroke_alpha.webp) 

`アルファ` は、ブラシの挙動を変調するテクスチャです。
グレースケールの画像で、黒いピクセルは変形なし、白いピクセルは最大の変形を意味します。

アルファの画像をクリックすると変更できます。組み込みのアルファや自分でインポートしたものに加えて、アルファのリストからPoly Havenのディスプレイスメントマップをダウンロードすることもできます。

マテリアルのプレビューをクリックすると、マテリアルプリセットからアルファを読み込めます。ここでマテリアルプリセットを保存したり、テクスチャをツールに埋め込むかどうかを選んだりもできます。

::: tip
テクスチャはリサイズされないため、大きなテクスチャはパフォーマンスを低下させることがあります。
:::

### ![](/icons/blend_contrast.webp) アルファを修正 {#invert-pixels}
インポートしたアルファの `修正...` ボタンを押すと、画像そのものを補正するポップアップが開きます。中間値、ピクセルの反転（黒が白に、白が黒になります）、90°の回転、左右または上下の反転ができます。画像ファイルが書き換えられるので、ほかのアプリでも補正後の画像が見えます。

::: tip

Nomadに付属している組み込みのアルファは修正できません。

:::

### 投影 {#projection}

アルファをモデルにどう投影するかを決めます。

* `サーフェス` - アルファはブラシの下の表面に、その向きに沿って置かれます。
* `スクリーン` - アルファはビューからまっすぐ投影されます。
* `タイル` - アルファはビューから投影され、ステンシルのように、上からペイントしてもその場に留まります。そのため繰り返しパターンが継ぎ目なくつながります。回転はロックされ、ペンの筆圧でパターンのサイズは変わりません。
* `トライプラナー` - アルファは3つの軸に沿って投影されます。下のサイズ調整、回転、タイリングのオプションは、トライプラナーテクスチャの設定に置き換わります。

### ![](/icons/diagonal.webp) サイズ調整 {#scaling}

Nomadのブラシサイズは、ユーザーが設定した半径の円です。テクスチャは正方形や長方形のことが多いので、`サイズ調整` のパラメータで、テクスチャを円の中にどう収めるかを決めます。正方形のテクスチャなら、0.7で円の中に収まります。1にするとテクスチャが大きくなって円がテクスチャの内側に収まり、端が切り取られます。

![](/images/alpha_scaling.webp) 

`サイズ調整 Y` を有効にすると、アルファを縦方向に伸ばせます。このとき、最初のスライダーは `サイズ調整 X` になります。

![](/images/alpha_scaling_y.webp) 

`左右反転` はアルファを左右に反転します。

### 回転 {#rotation}

アルファのテクスチャは、ストロークの方向に沿って回転します。回転のオフセットを加えることもでき、ロックアイコンを有効にすると、テクスチャは画面に対してその回転に固定されます。

その横のペンのボタンを有効にすると、スタイラスを軸回転（バレルロール）させたときにアルファが回転します。回転がロックされていない状態で、`ロック + 半径` と `ロック + 強度` のストロークで使えます。対応しているスタイラスでのみ機能します。

### タイリング {#tiling}
![](/images/stroke_tiling.webp) 

ブラシのプロファイル内でテクスチャを何回繰り返すかを決めます。`タイリング - X` と `タイリング - Y` のモードでは、ストローク内のテクスチャを1つだけにする（`なし`）、繰り返す（`繰り返す`）、または1つおきにテクスチャを反転してパターンを作ったりシームレスなテクスチャを作りやすくしたりする（`ミラー`）を選べます。これらは `ロール` のストローク、`タイル` の投影、または `タイリング` が1より大きいときに使えます。

`タイトにフィット（非正方形画像）` は、正方形でないアルファやブラシのテクスチャにだけ関係します。有効にすると、それぞれの画像が隙間なく個別にタイル状に並びます。縦横比が異なるときにアルファとほかの画像をそろえたままにしたい場合は、無効にします。

![](/videos/alpha_tiling.mp4) 



### 中間値 {#mid-value}

デフォルトでは、黒いピクセルは変形なし、白いピクセルは最大の正の変形を意味します。たとえば岩のアルファテクスチャを使った粘土ブラシは、アルファが黒でないところだけ表面を引き出します。

ブラシで表面を押し込みたい場合や、押し込みと引き出しの両方をしたい場合は、中間値を変更します。値を0.5にすると、アルファの中間のグレーは何もせず、黒は押し込み、白は引き出します。

ちょうどよい値を見つけるためのボタンが2つあります。四角いボタンは画像の縁から中間値を読み取り、スポイトではアルファ上で直接値を拾えます。




## ![](/icons/falloff.webp) フォールオフ {#falloff}

![](/images/falloff_menu.webp) 

[アルファ](#alpha)に似ていますが、こちらは1本のカーブで強度を制御します。アルファと組み合わせて使われるので、ディテールはテクスチャで、ツールの縁のぼかしと中心の強度はフォールオフで調整できます。

カーブが上にあるときは最大の変形、下にあるときはブラシの効果がありません。

カーブは、ブラシの先端の断面だと考えるとわかりやすいでしょう。下の部分には、ブラシの「スタンプ」1つがモデルの表面にどう見えるかのプレビューが表示されます。ブラシにアルファテクスチャがある場合はそれも表示され、フォールオフとアルファがどう組み合わさるかを確認できます。

### ![](/icons/fx.webp) プリセット {#preset}
`プリセット...` を選んだ状態でカーブのグラフをクリックすると、プリセットのメニューが出ます。丸みのあるカーブはやわらかい結果に、角ばったカーブはシャープな結果になります。左のツールバーにある `減算` ボタンは、フォールオフを実質的に反転させます。カーブの上側が表面を引き出す代わりに押し込むようになり、その逆も同様です。

### ![](/icons/curve_catmull.webp) Catmull-Rom {#catmull-rom}
選択すると、自分でフォールオフのカーブを描けます。カーブエディタの使い方は、Nomadのほかの場所のカーブと同じです。

* カーブをクリックすると新しいポイントを作成します
* ポイントをドラッグすると位置を変えられます
* ポイントをクリックすると、シャープとなめらかを切り替えます
* ポイントを隣のポイントにドラッグして重ねると削除されます

### ![](/icons/curve_bspline.webp) B-スプライン曲線 {#b-spline}
選択すると、自分でフォールオフのカーブを描けます。エディタの使い方はCatmull-Romと同じですが、ポイントはカーブの上に直接乗るのではなくカーブに影響を与えるだけなので、よりなめらかなカーブの形を作りやすくなります。

### ![](/icons/curve_bevel.webp) ベベル {#bevel}
ポイントどうしは直線でつながり、角は丸められます。丸みの大きさは各ポイントのシャープさで決まります。上が平らで、縁にきれいなベベルがあるブラシを作るのに便利です。

カーブエディタには3つのボタンがあります。

| 項目     | アイコン                    | 説明                                         |
| :------: | :-------------------------: | :------------------------------------------: |
| 最大化   | ![](/icons/maximize.webp)  | カーブエディタを拡大します                   |
| リセット | ![](/icons/reset.webp)     | カーブをデフォルトの状態に戻します           |
| 対称     | ![](/icons/symmetric.webp) | カーブを左右対称の「ブラシの先端」として表示します |


### 影響 {#influence}

* `球`（3d） - 頂点からブラシの中心までの距離をもとに影響を計算します。
* `円`（2d） - 頂点をまずエリアの平面に投影してから、ブラシの中心までの距離を求めます。アルファのサンプリング方法に近いやり方です。
* `円柱` - 影響がエリアを円柱状に貫いて投影されます。下の[シルエット](#silhouette-1)を有効にするのと同じです。
* `リッジ` - フォールオフをストロークを横切る方向に測るので、カーブがストローク全体の断面になります。このとき `対称` ボタンを使うと、プロファイルがストロークの左右でミラーされ、片側を編集するともう片側も追従します。オフのときは、カーブはストロークの左側から右側までを表します。フラット化系のツールでは使えません。

### ![](/icons/silhouette.webp) シルエット {#silhouette-1}
デフォルトでは、ストロークはブラシの半径内にあるモデルの表面にしか効きません。シルエットを有効にすると、ストロークがモデル全体を貫いて投影されます。モデルの最初のブロックアウトや、側面を垂直に保ちたい形を作るときにとても便利です。投影のオプションは、ストロークタブの[シルエット](#silhouette)と同じです。



## ![](/icons/filter.webp) フィルタ {#filter}

![](/images/filter_menu.webp) 

### ![](/icons/accumulate.webp) ストロークを累積 {#accumulate-stroke}
1回のストロークで盛ったり削ったりできる量の上限をなくします。たとえば `粘土` ツールはこれが有効なので素材をどんどん盛り続けられますが、`ブラシ` ツールは無効なので、同じストロークでメッシュの同じ部分をなぞり続けても、それ以上は盛られなくなります。

### ![](/icons/culling.webp) 正面を向いている頂点のみ {#front-facing-vertex-only}
裏を向いている頂点を無視します。
薄いジオメトリの片側だけを、反対側に影響を与えずにペイントしたいときに便利です。
スカルプトでも使えますが、アーティファクトが出ることがあります。

### ![](/icons/eye_open.webp) 見える頂点のみ {#visible-vertex-only}
カメラから見て、ほかの面の陰に隠れている頂点を無視します。このオプションは、マスク系、ペイント系、`フェースグループ`、`隠す` の各ツールのシェイプストローク（投げ縄、長方形など）で表示されます。

### ![](/icons/dynamic.webp) ダイナミックトポロジーを許可 {#allow-dynamic-topology}
メッシュが[ダイナミックトポロジー](topology.md#dynamic-topology)モードのときだけ使えるオプションです。ツールごとにダイナミックトポロジーを有効・無効にできます。

### ![](/icons/connect.webp) トポロジー接続 {#connected-topology}
ツールで触れた表面とつながっている頂点だけをスカルプトします。たとえば `移動` ツールで使うと、ほかのパーツと交差しているパーツでも動かせます。
![](/videos/connected_topology.mp4)

### 保護エリア {#protect-area}
![](/images/filter_protect_area.webp) 

これらのオプションは、さまざまな条件でツールがメッシュの一部に効かないようにします。それぞれ `自動`、`いいえ`、`はい` に設定でき、小さな矢印は `自動` が現在どちらになっているかを示します。

* `隠す` - メッシュの一部が隠すツールで非表示になっているとき、その部分を保護するかどうかを決めます。`自動` では、非表示の面は保護されます。ただし、そのワイヤーフレームが表示されている場合は除きます（[ワイヤーフレーム](settings.md#wireframe)の設定を参照）。
* `マスク` - メッシュの一部がマスクされているとき、その部分を保護するかどうかを決めます。`自動` では、[シェーディング](shading)メニューでマスクが表示されている間、マスクされた部分が保護されます。
* `フェースグループ` - 最初に触れたフェースグループの中だけでツールを使えるようにするかどうかを決めます。`自動` では、[シェーディング](shading)メニューでフェースグループが表示されているかどうかに従います。

`（すべて）` ボタンで、これらの保護をすべてのツールで共有するグローバル設定にするか、ツールごとの設定にするかを決めます。


### エリアサンプリング {#area-sampling}
ブラシやストロークのオプションの中には、動作するために表面に対する平面の法線と位置を必要とするものがあります。

この平均平面の計算方法は、サンプリングエリアをツールの半径に対する比率で設定して調整できます。

100%では、選択円の中にあるすべてのポイントが考慮されます。

0%では、最も近い頂点または三角形だけが考慮されます。`ノーマル半径` と `ポジション半径` の値はリンクさせることも、ロックを外して別々に設定することもできます。

### エリアノーマルフィルター {#keep-sharp-edges}
法線が表面の法線から大きくずれているポイントを除外します。

平面エリアの計算（エリアサンプリング）が変わるので、主に粘土系やフラット化系のツールで役立ちます。ほぼ平らな面に、はみ出さずに色を塗りたいときにも便利です。

`最小` と `最大` の角度で、除外されるポイントと完全に影響を受けるポイントの間のフェードを調整します。横の小さな色付きの円盤がその様子を示します。

![](/videos/filter_keep_sharp_edges.mp4)

### フォールオフノーマルフィルター {#falloff-normal-filter}
[エリアノーマルフィルター](#keep-sharp-edges)と同じく、法線が表面の法線から大きくずれているポイントを除外しますが、平面の計算ではなくブラシのフォールオフに作用します。くぼみや出っ張りをペイントするのに便利です。


### 深度マスキング {#depth-masking}
![](/images/stroke_depthmask.webp)

計算された平面（エリアサンプリング）から、一定の距離より上または下にあるポイントを除外します。

出っ張った部分だけ、あるいはくぼんだ部分だけをペイントするのに使えます。

グラフは表面の断面を表しています。水平線が表面の位置で、円は表面の上下に対するペイントのフォールオフ半径を表します。`高さのオフセット` は、マスクの計算を始める位置を表面より上または下のパーセンテージで指定します。`深度フォールオフ` を有効にすると、`上部エリア` と `下部エリア` で、オフセットの位置より上と下のフォールオフをスケールできます。

#### 例：くぼみにペイントする {#example-paint-in-cavities}
くぼんだ部分だけをペイントするには、高さのオフセットを-100%にし、上部エリアのスライダーを調整して水平線から離します。こうすると最初のクリックで「ゼロ」の深さが決まり、その深さより下の部分だけが影響を受けます。

![](/videos/stroke_depth_cavity.mp4)

#### 例：出っ張りにペイントする {#example-paint-on-bumps}
高い部分だけをペイントするには、高さのオフセットを+90%にして、円の下側が水平線と少しだけ交わるようにします。「高い」部分の上をクリックするとその深さが決まり、その深さにあるもの、その少し下、そしてそれより高いものすべてがペイントされます。深いくぼみはスキップされます。
![](/videos/stroke_depth_bump.mp4)


## ![](/icons/pressure.webp) 筆圧 {#pressure}
![](/images/pressure_menu.webp) 

スタイラスやペンの筆圧がブラシにどう影響するかを設定します。

### グローバル設定を使用 {#use-global-settings}

デフォルトでは `グローバル設定を使用` が有効で、すべてのブラシが同じ筆圧の値を共有します。チェックを外すと、現在のツールに専用の筆圧設定を持たせられます。

### ![](/icons/radius.webp) 半径 {#pressure-radius}

このカーブは、筆圧がブラシの半径にどう影響するかを決めます。デフォルトは比例関係なので、スタイラスの反応がなめらかなら、半径の変化もなめらかに感じられるはずです。とはいえ、多くのスタイラスは反応が比例しないので、このカーブで補正できます。たとえば強く押しても半径が最大まで届かないように感じる場合は、「out-pow3」のような上向きに曲がるカーブのプリセットを使えば、早めに半径が大きくなります。

このダイアログはフォールオフのカーブ表示と似ています。カーブのウィンドウをタップしてプリセットを使うことも、`Catmull-Rom`、`B-スプライン曲線`、`ベベル` のモードで自分のカーブを描くこともできます。

半径を一定にしたい場合は、このセクションを無効にします。

### ![](/icons/intensity.webp) 強度 {#pressure-intensity}

半径のカーブと同じですが、強度を制御します。強度を一定にしたい場合は、このセクションを無効にします。

### 筆圧を100%に制限する {#limit-pressure}

スタイラスの筆圧が100%を超えないようにします。グローバル設定です。

### 筆圧平滑化 {#pressure-smoothing}

スタイラスの筆圧イベントを平均して、よりなめらかな結果にします。
