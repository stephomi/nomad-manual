# ![](/icons/sun.webp) シェーディング {#shading}

このメニューでは、Nomadで使うシェーディングモード、ライトのプロパティ、環境とMatCap、そしてフォグを設定します。

![](/images/shading_overview.webp)



いくつかのレンダリングモードから選べます。

| モード                      | 意味                       | 説明                                                            |
| :-------------------------: | :------------------------: | :-------------------------------------------------------------: |
| [ライトあり (PBR)](#pbr)     | 物理ベースレンダリング       | ライト、シャドウ、環境、ペイントしたメタルネスと粗さ              |
| [MatCap](#matcap)           | マテリアルキャプチャ         | スカルプト向けの軽いモードで、PBRよりGPU/CPUの負荷が低い          |
| [ライトなし](#unlit)         | 表面の色                    | シェーディングやライティングなしで、表面の色だけを表示            |
| [オブジェクト ID](#object-id) | オブジェクト ID            | オブジェクトごとにランダムな色。ペイントアプリでの作業に便利      |
| [インスタンス ID](#instance-id) | インスタンス ID          | インスタンスごとにランダムな色。共有メッシュの見分けに便利        |

メタルネスと粗さについて詳しくは、[頂点ペイント](painting.md)のセクションを参照してください。

---

![](/images/shading_second.webp)

### ![](/icons/group_gray.webp) フェースグループ {#face-group}
フェースグループの色を重ねて表示します。フェースグループは、ポリゴンを色分けしてまとめたもので、[フェースグループ](tools#facegroup)ツールで作れるほか、ほとんどのプリミティブでは自動的に作られます。

ツールによっては、フェースグループが表示されているときに自動的にフェースグループでフィルタします。

### ![](/icons/palette.webp) ペイントを表示 {#show-paint}
Nomadは、色、粗さ、メタルネスをスカルプトの頂点に保存できます。このチェックボックスで、これらのプロパティの表示をまとめて切り替えられます。

頂点のプロパティとテクスチャの両方があり、どちらも有効になっている場合は、値が掛け合わされる点に注意してください。

### ![](/icons/shield.webp) マスクを表示 {#show-mask}
[マスクツール](tools#mask)のグレースケールのマスク表示を切り替えます。無効にするとマスクそのものも無効になります。マスクなしでちょっとした変更をしたいときに便利で、あとで再び有効にしてもマスクは失われません。

### ![](/icons/tool_hide.webp) 非表示を使用 {#use-hide}

非表示にした面の表示を切り替えます。隠すツールを使っている間は機能しないので注意してください。

### ![](/icons/image.webp) テクスチャを使用 {#use-textures}

Nomadでは、[マテリアル](material)メニューからオブジェクトにテクスチャを割り当てられます。テクスチャが割り当てられている場合、このチェックボックスでまとめて表示を切り替えられます。

Nomadの中でテクスチャを作ったり編集したりはできませんが、読み込んだファイルのテクスチャは使えます。不透明度のテクスチャはライトあり、MatCap、ライトなしで、ノーマルマップはライトありとMatCapで、色はライトありとライトなしで、エミッシブ、粗さ、メタルネスはライトありでのみ機能します。シーンにテクスチャがないときは、ボタンはグレーアウトします。

### PBRとライトの概要 {#pbr}
このマニュアルでは、物理ベースレンダリングの詳細には踏み込みません。

覚えておきたい大事な点は、ライティングとマテリアルが完全に分かれていることです。
つまり、オブジェクトの色、粗さ、メタルネスをペイントしつつ、ライティングは別に扱えます。
オブジェクトをペイントしてから、モデル全体の見た目を崩さずに、あとでライティングを調整できます。

ライト、環境、フォグは[PBRモード](#pbr)でのみ使えます。
パフォーマンスの都合上、ライトはモバイルで4つ、デスクトップで6つまでです。

::: tip
それより多くのライトを含むglTFファイルを読み込むと、Nomadはすべてのライトを保持します。
ただし、パフォーマンスがよいとは限りません。
:::

::: tip
オブジェクトをライトなしやエミッシブにして、[ポストプロセス](postprocess)メニューでグローバルイルミネーションを有効にすれば、たくさんのライトがあるように見せかけられます。
:::

### ライトの種類の概要 {#light-types-overview}

現在対応しているライトの種類は次のとおりです。

| モード                       | 説明                                                    | シャドウを落とせる |
| :-------------------------: | :-----------------------------------------------------: | :--------------: |
| [ディレクショナル](#directional) | 無限に遠くにある太陽の光                           | はい              |
| [環境](#env-light)           | 環境HDRに合わせた遠くの光                                | はい              |
| [スポットライト](#spot)       | 円錐形の光                                              | はい              |
| [ポイント](#point)           | 全方向に光る点光源                                       | はい              |

#### ![](/icons/sun.webp) ディレクショナル {#directional}
無限に遠くから、均一な強さで光を放ちます。
シーン内の3dの位置は関係なく、向きだけが影響します。

このライトはカメラに追従させることができ、そうするとライティングが常に一定になります。
たとえばリムライト（モデルの背後からカメラに向かって当てる強い光）を作り、常にモデルの背面を照らすようにできます。

#### ![](/icons/panorama.webp) 環境ライト {#env-light}
[環境HDR](#environment)を使うと全体的にやわらかいライティングになりますが、HDRの中に強くはっきりした光があっても、それが作るシャドウはとてもやわらかく、まったく見えないことも多いです。環境HDRにディレクショナルライトを組み合わせると改善できますが、両者の向きを合わせるのは難しいことがあります。

このライトはそれを代わりにやってくれます。ライトはHDRの一番明るい部分に合わせて自動的に回転し、そのうえで強度と角度（シャドウのやわらかさ）を別々に調整できます。

#### ![](/icons/spotlight.webp) スポットライト {#spot}
スポットライトは、円錐形の範囲に限って一方向に光を放ちます。

#### ![](/icons/light.webp) ポイント {#point}
ポイントライトは全方向に光を放ち、シャドウも落とせます。

#### シャドウ {#shadows}
どのライトもシャドウを落とせます。シャドウの計算方法は、ライトの[設定](#light-extra-controls)で選べます。シャドウにアーティファクトが見える場合は、そこにある `許容値` のスライダーが役立ちます。

シャドウの品質は、シーン全体に対するオブジェクトの大きさに左右されます。
シャドウを落とす必要のない大きなオブジェクト（たとえば大きな平面）がシーンにある場合は、その[マテリアルの設定](material.md#casts-shadows)でシャドウを落とさないようにしておきましょう。

## ![](/icons/sun.webp) ライト {#lights}

![](/images/shading_lights.webp)

### ![](/icons/checked.webp) ライトのチェックボックス {#lights-checkbox}

シーン内のすべての直接光をまとめてオン・オフします。



### ライトを追加 {#add-light}

シーンにライトを追加します。モバイルでは4つ、デスクトップでは6つまでです。ライトを追加すると、ボタンつきのライトのリストが表示され、ビューポートの上部にライトのツールバーが現れます。

![](/images/shading_lights_icons.webp)

* テキストにはライトの名前と明るさが表示されます。タップするとライトを選択します。
* 目のアイコンで表示・非表示を切り替えます。
* 鉛筆のアイコンでライトの名前を変更できます。
* ゴミ箱のアイコンでライトを削除します。
* コピーのアイコンでライトを複製します。
* 3つの点のアイコンで、ライトの詳細なエディタが開きます。この機能のほとんどは、ビューポートに表示されるツールバーからも使えます。

リストのライトをドラッグして並べ替えることもできます。

### ![](/icons/spotlight.webp)  アイコン {#icons}

ビューポートでのライトのアイコンの表示を切り替えます。

### ライトのツールバー {#light-toolbar}
![](/images/shading_lights_toolbar.webp) 

ライトを選択すると、ビューポートの上部にこのツールバーが表示されます。

* `可視` でライトの表示・非表示を切り替えます。
* ディレクショナル/環境/スポットライト/ポイントでライトの種類を変えます。タップで順に切り替わり、長押しでメニューが表示されます。
* 強度はライトの強さを決めます。とても強いライトでは1.0を超える値にもでき、ポストプロセスのグローバルイルミネーションと組み合わせるときに便利です。
* カラースウォッチをクリックすると色の選択画面が開きます。Nomadには色を選ぶ方法がいくつかあります。ケルビンの設定を使うと、暖色や寒色のライティングを自然に選べます。
* シャドウでシャドウのオン・オフを切り替えます。
* アングル（_ディレクショナルと環境_）またはサイズ（_スポットライトとポイント_）でライトの幅を設定します。幅の広いライトほど、シャドウもライティングもやわらかくなり、オブジェクトのハイライトもやわらかくなります。
* 追従先（_ディレクショナルのみ_）、円錐の角度と柔らかさ（_スポットライトのみ_）については、下の[ライトのエディタ](#light-extra-controls)で説明しています。
* ... を押すと、シャドウの設定と一緒に `クローン`、`中心に戻す`、`削除` が表示されます。

### ライトの詳細設定 {#light-extra-controls}

![](/images/shading_extra_controls.webp) 

リストにあるライトの3つの点のアイコンで、詳細なエディタが開きます。一部のオプションは特定のライトの種類専用です。

* `ディレクショナル/環境/スポットライト/ポイント` でライトの種類を変更できます。
* `カラースウォッチ` をクリックすると色の選択画面が開きます。
* `強度` はライトの強さを決めます。
* `追従先`（_ディレクショナルのみ_）は、ライトをワールドに固定する（`固定`）か、カメラに追従させる（`カメラ`）かを決めます。たとえばキャラクターの背後にディレクショナルライトを置いてリムライトにしている場合、追従先にカメラを選ぶと、カメラを回してもライトは常にキャラクターの背後にあります。
* `柔らかさ`（_スポットライトのみ_）は、スポットライトの円錐の縁のシャープさを決めます。0はとてもシャープな縁、1はとてもやわらかく、光の円錐の中心に向かってグラデーションがかかります。ビューポートでは、スポットライトの円錐にある小さな青い点で柔らかさを直接調整できます。
* `円錐の角度`（_スポットライトのみ_）は、スポットライトの広がる角度を決めます。小さな角度ではとても細い光線に、170ではとても広く広がる光になります。ビューポートでは、オレンジの点で円錐の角度を直接調整できます。
* `アングル`（_ディレクショナルと環境のみ_）は、ライトの見かけの大きさです。空に見える太陽の大きさだと考えてください。角度が大きいほど、シャドウはやわらかく、ハイライトは広くなります。
* `サイズ`（_スポットライトとポイントのみ_）は、ライトの幅です。大きなライトほどシャドウがやわらかくなります。
* `シャドウ` で、このライトのシャドウのオン・オフを切り替えます。
* シャドウの種類で、シャドウの計算方法を選びます。`シャドウマップ` はライトの位置からシーンをレンダリングするので、カメラから見えないジオメトリによるシャドウも落とせます。`スクリーンスペース` は画面にすでに見えているものだけを使います。負荷は軽いものの、実験的な機能です。一般的にはシャドウマップのほうが確実です。
* `許容値`（_スクリーンスペースのみ_）：シャドウにアーティファクトが見える場合（シャドウが表面に接していないように見える、シャドウの中にノイズや模様が出るなど）、許容値を調整すると改善することがあります。
* `コンタクト` は、オブジェクトどうしが触れ合う短い距離で、より正確なシャドウを加えます。`自動` ではシーン内で最も支配的なライトだけにコンタクトシャドウがつきます。`いいえ` と `はい` では、このライトについて強制的にオフまたはオンにします。その `許容値` スライダーは、上のものと同じように働きます。

ビューポートのツールバーの `...` ボタンには、同じシャドウの設定に加えて次のものがあります。

* `クローン` でライトを複製します。
* `中心に戻す` で、向きを保ったままライトをカメラの前に移動します。
* `削除` でライトを削除します。


## ![](/icons/panorama.webp) 環境 {#environment}

![](/images/shading_environment.webp)

現実の世界では、光はあらゆる方向からやってきます。空の青、草の緑、建物の赤など、こうした「環境」からの光を環境マップでシミュレートできます。

タイトルの横のチェックボックスで、環境のライティングをオン・オフします。

Nomadには、屋内と屋外の環境マップのサンプルがいくつか付属しており、色味や明るさもさまざまです。いろいろなマップを試して、スカルプトのディテールが一番引き立つものを見つけてください。

画像をタップすると、使える環境マップが表示されます。そのダイアログで `読み込む...` を選ぶと、自分のマップを読み込めます。ハイダイナミックレンジ（HDR）の画像を、緯度経度（正距円筒図法）形式の.hdrまたは.exrファイルで使うのが最適です。ブラウザからは[Poly Haven](https://polyhaven.com/hdris)の環境を直接ダウンロードすることもできます。無料の環境マップが充実しています。

### 露出 {#env-exposure}
環境マップの明るさを調整します。通常のライトと一緒に使うとマップが明るすぎることがよくあるので、露出を下げるとバランスが取りやすくなります。[ポストプロセス](postprocess)の設定でグローバルイルミネーションを使うときは特にそうです。

### 回転 {#env-rotation}

環境マップはあらゆる方向からの光を取り込んでいるので、回転させて、反射や全体のライティングがスカルプトとうまくなじむようにできます。ビューポート上で3本指を横にドラッグして環境を回転させることもできます。

### カメラに固定 {#env-attached}
環境をカメラに固定します。

ライティングが常に一定になるので、スカルプト中に便利なことがあります。

### ぼかし (背景) {#env-background-blur}
このスライダーは、[背景](background.md)が環境に設定されているときだけ表示されます。ライティングを変えずに、モデルの背後の環境画像をぼかします。


## ![](/icons/fog.webp) フォグ {#fog}

フォグはシーンに空気感のある奥行きを加え、光の筋を見えるようにします。タイトルの横のチェックボックスで有効にします。ライトや環境と同じく、[ライトあり (PBR)](#pbr)モードでのみ使えます。

::: tip 光の筋をもっと強く
フォグの `環境` を下げ、明るいスポットライトかポイントライトを使います。フォグがはっきり見えるまで `密度` を上げます。薄いフォグで光の筋を見せたいときは、`散乱方向` を大きな正の値にして、カメラをライトのほうに向けます。
:::

### カラー {#fog-color}
フォグと、フォグが散乱する光の色です。

### 密度 {#fog-density}
距離に応じて、フォグがどれだけ早く濃くなるかを決めます。

### 最大不透明度 {#fog-opacity}
密度が高くても、フォグがシーンを覆える度合いに上限を設けます。

### 散乱方向 {#fog-scattering}
フォグが光を散乱させる方向です（異方性とも呼ばれます）。正の値ではライトのほうを見たときにフォグが明るくなり、負の値ではライトと反対のほうを見たときに明るくなります。0ではすべての方向に均等に光を散乱させます。

### ![](/icons/panorama.webp) 環境 {#fog-environment}
[環境](#environment)がフォグをどれだけ照らすかを決めます。環境がオフのときはグレーアウトします。

### ノイズ {#fog-noise}
フォグにノイズを混ぜてまだらにします。全体の密度は変わりません。ノイズが0より大きいときは、`サイズ` スライダーで模様の大きさを設定します。

### 形状 {#fog-shape}
フォグがシーンのどこを満たすかを決めます。

* `均一` - シーン全体を満たします。
* `垂直` - フォグを、縁のやわらかい縦方向の帯の中に収めます。`下端` と `上端` のスライダーで下の縁と上の縁の高さを設定し、それぞれの目のボタンを押すと、調整中に帯がビューポートに表示されます。


## ![](/icons/sphere_smooth.webp) MatCap {#matcap}

![](/images/shading_matcap.webp)

名前（MATerial CAPture）のとおり、MatCapはライティングとマテリアルの両方の情報を1枚の画像で扱います。
マテリアルそのものがMatCapに含まれているので、粗さとメタルネスのペイントチャンネルは無視されます。
ペイントの色はMatCapに掛け合わされます。つまり黒やグレーのMatCapでは、白でペイントしても明るくなりません。

形状やジオメトリそのものに集中できるので、アーティストはスカルプトにこのモードを好んで使います。

球をタップすると画像ブラウザが開きます。自分のMatCapを追加することもできます。球を写した写真やレンダリング、さらには絵でも、正方形にぴったりトリミングすれば、たいていのものが使えます。オンラインには多くのMatCapライブラリがあり、[nidorx matcap library](https://github.com/nidorx/matcaps)が役に立ちます。

### グローバルMatCapを使用 {#matcap-global}

通常、アーティストはスカルプト全体に1つのMatCapを使いますが、このトグルを無効にすると、選択中のオブジェクトに専用のMatCapを持たせられます。表現として使えば、印象的な結果が得られます。

::: tip
このオプションを無効にして、キャラクターの目に眼球の画像を使ってみましょう！
:::

### 回転 {#matcap-rotation}
MatCapは環境マップの特殊な形なので、環境マップと同じように回転できます。ビューポートで3本指を左右にドラッグすれば、いつでも回転させられます。

スライダーの横にあるロックボタンで回転をロックすると、3本指でドラッグしてもうっかりMatCapが回らなくなります。



## ![](/icons/circle_fill.webp) ライトなし {#unlit}

このモードでは表面の色だけを表示します。ライト、シャドウ、反射、透明度に惑わされずに、オブジェクトの表面の色が思ったとおりになっているかを確認するのに便利です。

フラットでアニメ調の見た目を出す、非フォトリアルなレンダリングにも使えます。

## ![](/icons/cube.webp) オブジェクト ID {#object-id}

ライティングと表面の情報はすべて無視され、各オブジェクトが固有のフラットな色で表示されます。PBRのレンダリングと一緒にこれもレンダリングしておけば、ペイントソフトで色によって選択でき、特定のオブジェクトだけに色補正をかけられます。

これらの色は、[シーンメニューのツリービュー](scene#tree-view)にも表示されます。

### IDをランダム化 {#object-random}

新しいランダムな色の組み合わせを生成します。

## ![](/icons/link.webp) インスタンス ID {#instance-id}

オブジェクト IDと同じですが、インスタンスどうしは同じ色になります。

### IDをランダム化 {#instance-random}

新しいランダムな色の組み合わせを生成します。
