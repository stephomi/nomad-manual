# ![](/icons/image.webp) 背景 {#background}

このメニューでは、Nomad の背景色と、使用する参照イメージを設定します。

![](/images/background_overview.webp)

## タイプ {#type}
![](/images/background_selector.webp)

ビューポートの背景には 3 つの種類があります。

* `環境` - [シェーディング](shading.md)で選んだ環境マップを表示します。`ブラー`と`露出`（明るさ）のスライダーでさらに調整できます。
* `カラー` - 好きな色を選べる単色の背景です。
* `カラーグラデーション` - 2 色の間をつなぐグラデーションです。`係数`スライダーでグラデーションの中間点を動かせます。

### グラデーションのタイプ {#gradient-type}
`カラーグラデーション`では、その形を選べます。
* `線形` - まっすぐなグラデーションで、向きは`角度`スライダーで決めます。
* `放射状` - 画面の中央から広がる円形のグラデーションです。
* `空` - ワールドの地平線に固定されたグラデーションで、カメラで上や下を見るとそれに合わせて動きます。

それぞれの色にはリセットボタンと、画面から色を拾うためのカラーピッカーがあります。

## ![](/icons/lock.webp) カメラロックと同期 {#sync-on-camera-lock}
[方向キューブ](settings.md#snap-cube)でカメラをロックしているあいだ、参照イメージがカメラの動きに追従するので、スカルプトとの位置がずれません。

* `ロールを許可 (トラックボール)` - カメラロックを解除したときに、カメラのロール（傾き）を許可します。
* `ロック解除時にビューをリセット` - カメラロックを解除したときにビューをリセットします。

## 参照イメージ {#reference}

![](/images/background_reference.webp)

好きな画像を背景に置いて、参考資料として使えます。`読み込む...`をタップして画像を追加し、`参照イメージ`にチェックを入れると表示されます。
位置やスケールも変えられるので、たとえば画面の隅に寄せておくこともできます。

### ![](/icons/tool_transform.webp) トランスフォーム {#transform}

このボタンを使うと、参照イメージを画面上で直接配置できます。2 本指で参照イメージを移動、拡大縮小、回転させて位置を合わせましょう。`設定をリセット`で画像を初期の配置に戻せます。最終的な配置は、下のスライダーに反映されます。

* `オーバーレイ` - 0% では参照イメージは常にオブジェクトの後ろに、100% では手前に表示されます。
* `不透明度` - 画像をどれだけ透けさせるかを決めます。
* `ポストプロセス` - 参照イメージにもポストプロセス効果をかけます。元の色のままにしたい場合はオフにしてください。
* `位置 X` / `位置 Y` - 画像の X 方向と Y 方向の位置です。
* `スケール` - 画像の大きさです。
* `回転` - 画像の回転です。


::: tip

カメラと参照イメージは連動しています。

つまり、参照イメージをスカルプトに合わせて配置したあとで[カメラメニュー](camera.md)からカメラを作成すると、参照イメージの位置、回転、スケールもそのカメラに一緒に保存されます。参照イメージをオフにして、別の視点に回り込んでも大丈夫です。もう一度そのカメラから見ると、そのとき使っていた設定で参照イメージが有効になります。

カメラごとに別の画像を使い分けることもできます！

:::
